# 接触历史是否改变未来响应和阻抗选择？

2026-10-18。文献核读后的**探索性机制核查**，比较版本`57e08ca`。它不是新的连续扫描控制器、强prior复现或未知参数辨识实验，不用于给NEOC/PPO排名。

## 动机与精确命题

Tiezzi/Kao T-RO2007研究有限面积接触的松弛、蠕变和载荷分布；Moreira等CMPB2014比较软组织模型并做生理运动补偿。因此“接触有记忆”是已有知识，不是我们的发现。NNBO和Xue的HC参数化、AuSoScan的滑动接触模型以及Matschek的静态GP力映射各有能力和条件，不能把它们统称为没有接触模型。

本次只问两件事：**相同当前压入、速度和力，能否对应不同未来力；这种差异是否足以让阻抗选择获得重要改善？** 第一件成立不自动证明第二件。

使用已知、被动、双松弛支路的广义Maxwell模型：

\[
 F=k_\infty\delta+z_1+z_2,\qquad
 \dot z_i=k_i\dot\delta-z_i/\tau_i.
\]

储能为 \(S=\frac12k_\infty\delta^2+\sum_i z_i^2/(2k_i)\)，满足
\(\dot S=F\dot\delta-\sum_i z_i^2/(k_i\tau_i)\)。在持续压缩、参数固定条件下这是成熟的被动流变元件；不是新接触理论或完整机器人无源证明。参数是明确给定的机制示例，**未按真实组织标定**。

两条可实现的单调平滑加载历史均持续20ms，分别恰在当前和150ms前结束；调整加载幅值而非随意指定隐藏状态，使当前均为4mm、0m/s、3N，随后保持同一压入。材料参数完全相同，只是内部松弛状态不同。HC形式 \(F=(k+c\dot\delta)\delta^n\) 若参数固定且不带额外内部状态，只是当前运动的单值函数；此处不能同时精确表示两条未来保持曲线。**不否认它可以在某些真实测量轨迹上拟合良好，或借在线时变参数追踪松弛。** Moreira原文也报告HC在其试验中的良好拟合，不能改写成其实验已证明HC失效。

## 结果与边界

- 保持压入后，两条力曲线最大相差约**0.2806N**，出现在128ms；100ms时相差约0.2752N。因此任何仅由该相同当前快照决定的单值保持预测，至少一条在128ms处误差不低于0.1403N。这是模型中的信息混叠例，不是组织总体误差下界。
- 给定真实支路参数和完整已知位移历史，普通二状态线性观察器就能恢复并预测内部状态。以100Hz力采样、0.01/0.05N独立高斯测量噪声各100次，保持预测平均RMSE约0.0008/0.0040N。模型参数、位移和初始准备均理想，**不是未知组织辨识或域外泛化证据**；零噪声重建误差约4.4e−16N。
- 同一1kg法向运动模型、共同初始实际K/D=500/40、共同增益幅值/速率及目标跟踪动态，比较36组固定目标K/D的0.3秒实际执行代价。两条历史的最好候选分别为100/15与30/15，但**同一个30/15候选相对各自最好候选的两例平均代价差仅0.4334%**。该数字没有总体统计含义；这里不能据预测差异宣称重要阻抗收益。它也不以“低于1%”为否定标准，而是目前缺乏重要任务能力的验证。

代价是力误差平方、压入参考偏差平方和速度平方的明确加权和，没有偏好某个K/D的标签项；系数与完整候选表见源码/JSON。按已知状态的36候选数值参照评价观察器选择，在这批噪声样本中未选错最好候选；这不证明连续动作全局最优。此处未包含能量过滤、执行器饱和、真实延迟、接触丢失、切向扫描或充分直接力反馈，不能据此比较完整任务能力。所有候选保持正压入和正力，故所用压缩接触方程没有被外推到脱离区。

独立DOP853复核两条最好候选，代价相对差最大约7.92e−10；步长减半差最大约7.37e−10。保持过程另有解析指数表达；未来噪声不参与预测。100次噪声样本是同两条历史的条件重复，不是100种独立组织。

## 保留用途

可复用的已知模型观察器、可实现历史构造与任务代价核查，帮助区分预测差异和阻抗收益。它没有确定“记忆网络”或新的必做实验；普通观察器是合法工具，不把观察器已够用解释为该方向不得研究。
