## 后续自动同步

项目 AGENTS.md 要求 Codex 每完成一项逻辑完整的研究改动，在更新变更记录和
完成相应检查后，自动执行 scripts/research_sync.py，创建提交并推送 main。
这是研究完成点的自动操作规则，不是常驻监视任意文件写入的服务。

脚本验证仓库身份、main 分支、B0快照和未结束的 Git 操作；无新改动时仍可
重试此前未推送的提交。网络失败保留本地提交，报告失败；不强制推送、不重写历史。
未来修改当前方法是允许的；固定 B0 快照保留供比较。

Git 使用已存在的 Windows Credential Manager GitHub 登录。凭据不写入脚本或仓库。
本项目的 http/https proxy 覆盖为空，以绕过原全局失效的127.0.0.1:7897代理；
不改动其他项目的代理配置。提交身份为仓库账号及 GitHub noreply 邮箱。

普通编辑器的手动改动，需要运行同一同步脚本，或在下一次 Codex 研究完成点
一并同步；此配置不声称后台捕获尚未完成的任意编辑。

规则依据：[OpenAI 官方 AGENTS.md 说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。
采用项目操作规则与本地同步脚本，无需更改全局通知或运行未经信任的原生 hook。
