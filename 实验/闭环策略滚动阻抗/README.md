# 闭环策略滚动、任务收益空间与输运认识候选

2026-10-19。比较版本`272a5855466aff4362999bccb9346502e0cb41e5`。继续原“环境变化时及时生成有实际收益的阻抗”问题。本轮完成一个模型/学习组合候选、独立24例控制测试，并形成一个有条件的接触认识机制。**组合控制尚未可靠胜过调优固定或原学习反馈；新认识机制只完成识别探查，不能当作控制优势或顶刊贡献。**

## 1. 组合候选：滚动比较闭环反馈，而非仅比较增益目标

借鉴成熟的策略滚动/策略空间预测控制：以已训练的固定、解析、联合学习、纯增益学习反馈及4种缩放反馈为8个延续策略。当前动作由同一部署信息决定；预测中每个响应分支生成自己的后续观测、运行同一因果观察器，并以25Hz重新计算该延续策略的增益目标。实际增益、速率/能量执行及机械状态共同滚动。

局部力响应为

\[
F_n(\tau)=\big[F_0+k\Delta z+c\Delta v_z+g\Delta s+b\tau\big]_+.
\]

9种局部响应取当前斜率的0.5/1/2倍和2/8/15ms黏性比例；用已到达、对齐的历史拟合剩余漂移及误差权重。选择加权预测任务损失最低的延续策略。**这些是有限局部假设和经验权重，不是校准后验、覆盖集合或安全证书。** 未实现全贝叶斯双重控制、完整MHE/HJB/NEOC或PPO。

名义预测只用单一响应；另在训练初筛中比较不补偿未来观测的版本。前轮预测器对未来力反馈使用了简化的延迟/滤波，实际执行却有响应补偿；本轮显式预测未来观察器。修正这个不一致是实现改进，不自动证明它是此前所有失利的原因，也不作为新科学发现。

数据按20ms传感延迟交付。仿真缓冲中的未到达样本在预测前被模型值替换，未来分支不偷读真实隐藏力。预测允许未来反馈对各自观测作不同响应，不允许当前动作知道真实分支。计算期间旧控制继续运行；首个发布延迟按2ms预测网格近似、实际执行精确分段。后续延续策略推理很轻，预测不假装每个未来时刻都已再次完成昂贵规划。并非全问题精确动态规划。

- 单策略模式与前轮独立执行器实现逐项结果一致；3个验证例最大指标差<1e−10。
- 将当前尚未到达的两帧力／矩改成极大错误值，预测评分完全不变；检查了预测是否偷读待交付数据。
- 3个验证状态，以真实物理模型离线重算8个策略的0.16秒后果，多响应相对名义减少其中两例的有限策略库选择后悔，另一例同样选对。只有3个状态，不能据此称普遍改善或真实最优；真实未来仅作离线诊断标签。
- 新测试指定3例×固定/联合学习/多响应，将物理积分从0.5ms/129节点细化到0.25ms/257节点，J相对变化最大约8.20e−6，结果见`refinement.json`。未改变预测器自身网格，非全域误差保证；前轮环境功率检查也不等于实物有效性。

## 4. 为什么这个任务容易只留下小收益

冻结线性接触、忽略动态和控制代价时，设恒定目标力对应位置为\(z_F\)，当前参考为\(z_r\)，代价为
\(Q_F k^2(z-z_F)^2+Q_z(z-z_r)^2\)。令\(q=Q_z/(Q_Fk^2)\)，直接完成平方得到

\[
J_*={Q_z(z_F-z_r)^2\over1+q},\qquad
{J_F-J_*\over J_F}={q\over1+q}.
\]

法向控制\(u=F_d+k_p(F_d-F)-K_n(z-z_r)\)的平衡取舍在
\(K_n=(1+k_p)Q_z/(Q_Fk)\)达到该静态最优。若\(\alpha=K_n/((1+k_p)k)\)，固定增益的相对静态超额为

\[
{J(K_n)\over J_*}-1={(\alpha-q)^2\over q(1+\alpha)^2}.
\]

原任务\(\sqrt{Q_z/Q_F}=200\,\mathrm{N/m}\)。例如接触斜率1500/3000N/m时，相对理想恒力状态的静态可改善比例仅约1.75%/0.44%；一个近58N/m的固定增益还已取得部分收益。不是说动态优化最多只能改善这些数值——**该公式不是非线性、有噪、有限时域的收益上界**。它解释了为何应检查任务与时间尺度，而非继续靠增加预测器/网络期待重要增量。此为熟知二次优化的应用，不当新定理。

## 5. 下一具体机制：用材料输运区分软硬变化和整体运动

原B0已经提出联合估计材料与表面运动；本轮不是发现它漏了这个状态，而是寻找更直接、可分析的物理结构。

在静态材料场局部为仿射、表面在足迹内整体平移、准静态法向弹性的条件下，写
\(\kappa(s+u)=\kappa_0(s)+\kappa_1u\)，偶对称已知压入核为\(w(u,d)\)。令
\(A(d)=\int w\,du\)、\(B(d)=\int u^2w\,du>0\)，几何长度因子包含在核内。则

\[
F_n=\kappa_0A(d),\quad M=\kappa_1B(d),\quad
\dot\kappa_0=v_s\kappa_1.
\]

已知初始表面参考时，由初始力和位姿得到初始\(\kappa_0\)，随后构成标量输运观察器

\[
\dot{\widehat\kappa}_0=
{v_s M\over B\big(A^{-1}(F_n/\widehat\kappa_0)\big)},\quad
\widehat h=z-A^{-1}(F_n/\widehat\kappa_0).
\]

在正载荷、紧压入区间、\(A'>0\)且\(B>0\)时，右端局部Lipschitz，给定初值可局部唯一推进。只给力和机器人位置、允许任意未知表面运动时，可通过改变材料并相应改变表面得到相同观测；输运和矩给出额外约束。**这是条件性的构造，不是一般联合辨识定理或首次性结论。** 普通联合EKF/MHE也应利用同一结构并作为强比较；初始参考、空间几何、黏性和矩校准不能省略。

`transport_probe.py`用独立257点压力积分生成恒定目标力下的扫描，不主动叠加辨识扰动，机器人位姿仍随组织运动。5mm/0.2Hz来自Moreira §5.3.1，不冒充我们的实测参数。主表按原始Fn/Ft各0.03N、My为0.0001Nm的独立噪声生成，再以\(M=-M_y+0.025F_t\)扣除切向力臂；修正后M噪声约0.000757Nm，不能假定它仍只有0.0001Nm。结果为**同步采样时刻**估计；若传感链路20ms，结果就晚20ms，尚未验证当前时刻的发布/预测补偿。

|---|---:|---:|---:|
| 仿射变软＋原始wrench噪声 | 0.980% | 0.0302 | 0.6174 |

匹配仿射弹性场时无噪误差约数值精度，属于反演/可辨识机制检查，**不能验证真实接触模型**。另保留直接给修正后M加0.0001Nm噪声的乐观敏感性，仿射场位置RMS为0.016–0.022mm，不拿它代替主表。尖锐过渡与黏性是有意的模型失配，误差增加，不只展示匹配例。固定材料是假设作用的参照，不是充分领域强prior。尚无输运机制的闭环控制、增益价值或成像优势。
