# 两候选各自的任务仿真

实验先由原研究问题确定：连续扫描中，如何把已到达的接触信息转成及时、有效的阻抗调整？先写两候选和对应实验，再选接口适合的论文方法；不是先找一个MPC让候选击败它。具体参数是可复核的合成工程设置，不是组织标定或临床标准。

## 方法与代码

| 对象 | 实际代码与作用 | 明确边界 |
|---|---|---|
| 接触与执行 | [physics.py](physics.py)：B0柱面Hertz双区域合力/力矩、平面两轴力矩接口、四实际增益、能量账本、增益/率/能量约束；代价含跟踪、速度、力、正定增益偏好、正定率惩罚和终端项 | 两自由度合成模型，不是完整机械臂或标定组织。真实法向接触准静态、表面运动单独生成 |
| 环境估计 | [estimator.py](estimator.py)：到达窗口内同时拟合两区材料、边界、常速度表面与三个传感器偏置，带到达正则 | B0常速度、窗口内固定偏置的实例；未实现全逐时刻随机过程状态MHE或统计置信证书。弱可辨参数依赖先验 |
| **候选1** | [local_hjb.py](local_hjb.py)：有限时域局部二次价值函数及反馈；状态/模型方向扰动的邻近Riccati更新，校正及名义轨迹检查；[run.py](run.py)接入实际执行 | 先前66项全域多项式配置未找到合格根，已明确改为轨迹附近二次HJB/iLQR表示。保留价值反馈与NEOC机制，不是原B0固定节点根，不继承其隐函数/发布证书；邻近更新采用Gauss–Newton近似 |
| **候选2** | [learning.py](learning.py)：MHE/预瞄、运动/实际增益/能量输入；64–64网络输出四增益率，用接触与执行后的任务代价梯度离线训练，部署滚动反馈 | YOPO训练分工的接触适配，不是PPO或YOPO原算法。训练真值只计算代价，不能输入actor；短时训练模型用真值场的局部常速度表面近似，不读取真实未来传感器 |

候选1不是只给一条开环轨迹：后向递推得到每时刻价值梯度、Hessian和状态反馈矩阵，执行随当前状态修正增益率。它的最优性仅是当前离散局部数值近似。候选2不是另写一个手工公式：本目录保存实际训练数据、随机种子及网络权重。

所有方法都使用同一增益、变化率和实际能量投影，没有为某候选增设直接力伺服。轨迹的力、位姿、速度、驱动力、接触、增益、能量约束进入名义检查及实际结果记录；采样检查不等于连续安全证明。初始能量不在模型更新时重置。

## 先按任务设置实验

- **跟踪实验：** 刚度变化、摩擦变化、表面运动、叠加噪声/延迟四类；各6个，共24个未用于调参的物理场景。每条1.6秒；积分2ms，力觉100Hz，控制请求50Hz、估计/模型更新10Hz；传感器延迟20/40ms。
- **候选1自身机制：** 关闭邻近预测、保持相同两次校正；另用较充分的同一价值函数求解作数值质量参照。它们是机制实验，不冒充外部论文基线。
- **候选2自身机制：** 有预瞄与无材料预瞄分别训练；主模型用三个种子。无预瞄保留当前区材料和表面估计，只移除前方区差异及边界位置。该消融不等于去掉整个MHE或复现E27。
- **泛化：** 另测训练中没有的变软方向及更快表面运动，不与同分布24场景混为同一批。
- **计算与执行：** 零计算等待用于隔离方法效果；另在没有其他任务并发时，将实测估计/决策耗时加入发布队列，未完成时沿用上一可用反馈，记录跳过更新及过期。不能用并发训练时的耗时声称实时性。

计时复核发现NumPy逐点调用占据大量费用，现[fast_physics.py](fast_physics.py)编译同样的标量公式，所有方法共用；1000状态最大项差约7.1e-15。四个既有场景回放，完整代价最大差1.84e-6、力RMSE差1.86e-7N，故不声称轨迹逐字一致；差异检查保存在[compiled_replay_check.json](compiled_replay_check.json)。主24场景表保留原零等待实现，当前时间结论仅用`compiled_timed_*`单任务新计时；旧`timed_*`为软件开销诊断。两种计时版本不是新独立场景。复现当前实现的微小数值变化须与该范围区分。

力RMSE、法/切向位置RMSE、力峰值和约束违反分别报告。对外部不同控制器的比较不把本候选的增益偏好/率正则当共同评分；共同物理跟踪评分按预先固定尺度从相同采样网格计算，来源与单项误差同时报告。候选内部的完整OCP代价另报。

48个训练物理场景，3840个相关上下文；600固定梯度步、批48。开发seed16201，主要独立seed16301、分布变化seed16401。三个actor训练种子16111–16113；没有根据测试挑选最好种子。训练数据的首版描述符存在最多80ms时间戳差，已用其自身速度传播到actor查询时刻，操作可由[align_training.py](align_training.py)复现；没有读取未来观测。

**空间信息消融纠正：** 初版`*_without_preview_test`把前区参数始终替换成旧区参数，连新材料成为当前接触后也删掉，不能隔离“预瞄”。其26.86%/6.17%已撤回为诊断，不用于贡献。现`physics.current_equivalent`将因果估计的当下足迹转成均匀接触模型，严格保持当前Fn/Ft（核对约2.2e-16），删除显式空间材料变化；候选2重新训练`candidate2_no_spatial_preview_seed16111.pt`，新seed16501、24场景的`*_preview_audit_*`用于正式信息消融。该对照不匹配全部力矩/局部导数，检验空间参数化整体作用，不能把收益单独归于时间提前量。旧网络以legacy特征版本加载；`--legacy-old-region-mask`只为复核旧错误，不是有效基线。

训练曾出现不激活能量分支中的0×∞梯度污染，已修为所有分支均数值有界并增加非有限立即失败；失败训练未生成主模型。两种独立实现的接触积分、能量QP、代价和方向梯度检查见[checks.py](checks.py)。初版配置点失败保留在[critic.py](critic.py)/[collocation_diagnosis.py](collocation_diagnosis.py)，不混入方法成功结果。

## 完成候选后选择的外部比较

选Jin等 *Model Predictive Variable Impedance Control of Manipulators for Adaptive Precision–Compliance Tradeoff*（TMECH2023，E41），因为它能直接调K/D，并处理接触下的精度—柔顺权衡。[baseline.py](baseline.py)重建其多步模型、tanh参数化、软状态惩罚和能量罐条件，优化器改用同一问题的解析梯度L-BFGS；[独立核对](baseline_check.py)检查源方程成本及梯度。它是明确的扫描任务适配，不是Panda原实验复现，也不把旧OS适配继续冒充整篇方法。

适配保持两轴K/D自由度及原能量罐；非零法向目标力作为共同固定前馈，预测外力为实测力减该前馈及共同已知阻尼。所有方法服从同一实际增益/速率/能量执行限制。基线不使用MHE就不计无用估计开销；保留其原生力观测方式。Q/R按训练场景调优，切向/法向允许论文形式所容许的不同R权重，不用一个共享权重把两个任务目标绑死。

训练8场景、每轴七个对数候选，选定R=(1e-10,1e-5)并组合复核；固定后运行24场景。额外8场景执行审计中，640次优化有5次未返回成功状态，所输出仍为有界可执行局部解；原能量罐最小0.1J。本轮不把它称为精确全局解，候选本身也只做有限次局部求解。原式/成本/梯度核对通过不等于重现了原论文的全部性能。

NNBO原文目标力/参考反演尚未成功适配本非零持续接触任务，本轮不以它的失败适配作主比较；不据此否定原论文。E27是重要方法来源，但其参考/阻抗联合输出及训练未在本轮完整重建，未用普通网络冒充。选择一个合适外部方法并不表示已穷尽领域。

实验目的由本项目决定，再参考论文安排证据：E41 §VI-A1/A2拆开权衡与约束；E27 §IV-B/C、TableIII区分训练、典型地形和未见环境；YOPO §III-A/B、TableI同时核查任务代价、部署可得信息和耗时；NNBO §V/表II与V比较模型、位置/力权衡。本轮核读这些段落，不声称新做了全文证明审计。来源位置与方法范围见[protocol.json](protocol.json)。发表身份不等于本项目所有实验都已达到发表水平。

## 复现

依赖沿用前一分线目录的NumPy/SciPy/CasADi/PyTorch版本；每个进程限制为一个BLAS/torch线程，机器总CPU配额为2核。

```bash
OPENBLAS_NUM_THREADS=1 python checks.py
OPENBLAS_NUM_THREADS=1 python run.py --method candidate1 --n 24 --seed 16301 --output replay_candidate1.json
OPENBLAS_NUM_THREADS=1 python learning.py --data training_aligned_contexts.npz --seed 16111 --iterations 600 --output replay_actor.pt
OPENBLAS_NUM_THREADS=1 python run.py --method candidate2 --model replay_actor.pt --n 24 --seed 16301 --output replay_candidate2.json
```

脚本拒绝覆盖原结果；硬件计时重跑会变化。所有旧实验、原文、B0三核心和冻结快照保持原字节。当前数值结果不能替代实物、材料标定、跨模型和临床证据。
