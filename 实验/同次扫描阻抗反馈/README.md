# 同次扫描：空间接触预测、阻抗与前馈的快速验证

当前是探索性训练/验证检查点，尚无独立测试、实物或顶刊达标结论。原问题不变；模型不是完整B0或任何论文的完整复现。

载体采用有限宽度柱面探头/独立Winkler-Kelvin地基、切/法向机械状态、四实际K/D及速率/能量执行。控制器只读取有20ms延迟及噪声的力/力矩、机器人运动和历史，不读取材料/表面真值。共同起点是3N静态法向平衡、已建立切向扫描；不检验接触建立。材料/运动量级来自已有探索与文献范围，未联合标定为真实组织。

`run.py --pilot`先用18条训练扫描选择48组固定PD/力PI配置，再用18条新验证扫描比较固定、观察器、临界阻尼、解析空间前馈、时间预测/空间预测的增益和前馈优化。所有方案有相同执行接口，正常参考/力补偿均允许。这里的模型优化是短时局部响应/有限候选，不是HJB全域最优。

首轮固定控制已选Kn=0、力PI增益为零，法向近似为恒力＋低阻尼。验证集平均力RMS约0.00714N；仅优化增益未改善；空间信息配合固定增益前馈约0.00249N，但绝对量很小，不能以相对降幅宣称重要任务收益。复杂联合优化未超过该简化实现。总代价含非零稳态切向作动力成本，不把其比例当临床改善。

`verify.py`独立写压力积分及增益执行，并与DOP853比较单个控制间隔。自适应压力积分相对33节点离散的最大力差约0.00133N，已与上述小误差同量级；包含大切向误差和低能量激活的离域压力例在1ms显式积分上也有明显差异。因此这些只是机制筛查，下一检查点须做细化与完整闭环核对，不能直接用这些数字评价原研究。

文件：`model.py`与`run.py`为当前源码；`validation.json`、`validation_arrays.npz`保存首轮配置和逐例结果；`numerical_checks.json`保存包括不利差异的检查。下一轮将区分法向自由随动与原研究含法向运动代价的任务，并加入闭式代价匹配增益及廉价固定增益空间前馈，而非放大扰动制造优势。原结果通过本检查点Git版本恢复，不覆盖其含义。

## 第二轮：区分任务与闭式代价匹配

`iterate.py --task force`保留法向自由随动；`--task joint`加入原研究已有的法向运动误差，参考为同一起点直线扫描轨迹，不读取真实组织运动。两者均保留，不把新增任务描述成首轮已定义。18训练扫描/128固定配置及18验证扫描，加入更低阻尼和简单代价匹配Kn，以及同信息的廉价空间/时间前馈。

局部静态关系F=F0+k(z-z0)、目标Qf(F-Fd)^2+Qz(z-zref)^2下，常规力反馈比例kp对应的闭式阻抗规则为Kn=(1+kp)Qz/(Qf k)。这是成熟二次优化的直接代数，不是新定理；时变、黏性和估计误差下不保证任务最优。空间前馈取Dn乘以预测的平衡法向速度，候选优化也允许相同参考补偿。

联合任务的验证集：固定J=2.4216，空间增益优化J=2.4053，闭式代价匹配＋前馈J=2.4065；复杂优化未获得相对简单组合的明显任务增量。力RMS约0.034–0.048N，法向位置RMS约0.83mm，二者一起报告。纯力任务中扩大固定调参范围后Dn=2胜出，复杂联合优化仍未胜廉价固定增益前馈。`force_validation*`与`joint_validation*`为本轮原始结果；与首轮不同方法库/调参范围，不合并成同一预定实验。

## 第三轮：按整段闭环损失离线训练结构化反馈

`learn_policy.py`使用成熟交叉熵策略搜索，直接最小化18条训练扫描的实际任务损失，18验证扫描选择检查点。先用98次连续优化调好常数增益/前馈对照，再对8参数结构化反馈搜索280次。actor只用可部署的响应估计、当前力和速度，输出Kn、Dn及前馈；没有材料/表面真值、唯一最优K/D标签、PPO或神经网络必要性主张。

验证集连续简单策略J=2.41235，所选条件反馈J=2.39820。学得Kn近似与k的−0.87次方成正比，接近前述成熟逆刚度规则；Dn近似常数。这提示先检验更充分解析实现，不能将重新学出已有规律当贡献。尚无独立测试优势结论。

`audit_closed_loop.py`在两条验证扫描、固定/预测/学习三种反馈上，使用独立编码的压力、执行器与代价及DOP853重新计算因果闭环，而非只重放旧动作。相对代价差最大约1.23e−5；时间步细化四倍并增加到129压力节点后相对变化最大约0.1164%。这只核数值，在初轮故意离域例上的问题仍保留；不是材料模型有效性或安全认证。
