# 机械接触包络与整段扫描：复杂方法还有多少改善空间？

2026-10-18。独立准静态弹性地基载体；机械全覆盖不等于声学耦合、目标视图或诊断质量。不是B0柱面Hertz、在线未知组织控制或实机验证。

## 问题、理论与强简单方法

半宽a=15mm、接触长度10mm、曲率半径50mm，局部表面g含已知表面及探头曲率。独立地基完整接触时

\[
p(u)=\kappa(u)[z+\theta u-g(u)],\quad
F=A_0z+A_1\theta-C,\quad c=A_1/A_0.
\]

在全部位置压入至少50µm的几何设计约束下，求最小F等价于求最小 \(z+c\theta\)。**此条件模型只需材料刚度重心c，不需完整材料图**；同地点、静态、已完整接触的两次法向位移读数有 \(c=\Delta M/\Delta F\)。这不包含安全建立全接触、等待稳定或探测时间；噪声与黏弹性也需另核。

更关键的反事实：若g凸、两端弦斜率在姿态边界内、深度边界不限制，则两端弦是对所有正κ都最优的仿射上包络。证明：任一可行仿射函数在两端均不低于弦，因此内部也不低于弦；正κ加权积分不能更小。**此时连c也无需辨识。** 一般情况对应常规线性规划/凹包络，不作为新算法或顶刊贡献。

零力矩不总等于好覆盖：平探头、平面、左右两常刚度、比值9时，令α=0.8，零矩完整接触方程给最小边缘压入 \(d(1-1.5|\alpha|)=-0.2d\)，与正压入矛盾。该特例不适用于所有曲面、控制器；不是复现或击败任何完整强prior。真正对照还包括几何弦控制和直接标量搜索。

## 已执行的判别

`envelope.py`：两族各48场景，每条80mm路径17位置，全部方法共享已知几何。比较完整材料LP oracle、两读数约化、几何弦＋理想全接触深度、直接标量搜索、最佳零矩及带噪两读数。另12场景×9位置×3剪切长度核横向耦合地基。协议与配对量分别在`protocol.json`、`results.json`、`paired.npz`。

- 光滑组：所有几何弦控制与完整材料LP一致，平均载荷约1.086N。局部起伏组几何弦平均仅多0.000109N，最大多0.0446N；直接搜索与LP最大差约2.4e−8N。**材料约化没有重要的已显示任务优势。** 带噪读数也相同主要因为几何最优性，不能称辨识抗噪已证明。
- 最佳零矩部分路径不可行，但强几何方法足够；不能把只胜零矩作为主要贡献。两读数需共同的既有全接触初态；部分场景校准初态已超过示例6N上限，不主张无准备/安全探测。
- 横向耦合后，简单刚度重心仍可约化总力目标，但未变换的几何约束不能保证全接触。原结果的“全接触候选可行率0”指假设全活跃时有负节点力，**绝不是实际接触面积为0**。

`independent_check.py`另解带单边接触的能量极小化 \(\min_{w\ge d}w^TKw/2\)，以 \(Kw\ge0\)、间隙与力互补恢复实际平衡。324例全部求解成功；剪切长度0.5/1.5/3mm时，约化方案平均接触节点比例约96.1%/88.6%/77.1%，不是声学覆盖率；最大间隙约0.137/0.435/0.818mm。说明不能把独立地基约化无条件迁移到耦合组织，**不说明该耦合模型已匹配真实组织**。独立坐标下降与优化器一个预选实例的总力差1.9e−10N；18个预选位置的61/121/241节点核对，最后一次细化最优力最大相对变化1.52%。

`path_screen.py`：另24场景、每条81位置，所有方案知道未来几何及材料；共同已接触起点，速度约束，载荷设计上限1.5/2/3/6N、滚转速率0.1/0.25/0.5rad/s。比较联合姿态—时间LP、逐点最小力后速率缩放、几何弦后速率缩放、充分离线选角的恒定滚转。

**联合规划没有超过逐点/几何方案：共同可行时均10秒，达到本协议80mm/8mm·s⁻¹的时间下界；可行场景数也相同。** 不能靠压低基线带宽、继续加难地形或只比较较弱恒角方法来制造优势。该结果没有否定图像/未知运动条件下的任务规划，只说明本纯机械全信息载体没有已显示的必要性。

两条预选路径的加密中间点仍接触且峰值低于3N，但最小压入48.53/49.64µm，未保住50µm设计裕量。节点LP不是连续时间安全证明；没有加速度、执行器、延迟、真实声窗或成像结果。

## 重跑与研究决定

根目录NumPy/SciPy即可，建议限制BLAS线程：

```bash
OPENBLAS_NUM_THREADS=1 python 实验/采集覆盖与接触载荷/envelope.py
OPENBLAS_NUM_THREADS=1 python 实验/采集覆盖与接触载荷/path_screen.py
OPENBLAS_NUM_THREADS=1 python 实验/采集覆盖与接触载荷/independent_check.py
```

保留源码、协议、配对数值及独立核对，不把接触重心、约束修补或小LP作为论文主问题。强简单几何/反馈可复用为执行层；接下来的科学主张必须落到整段真实采集与资源/接触风险的改善，见[候选A设计](../../研究/候选A_问题与方法设计.md)。
