# 未来观测的任务价值能否改善阻抗更新？

2026-10-19。围绕已确定的环境变化后快速最优阻抗问题，迁移Bayes双重控制：当前K/D改变接触，也改变下一次观测；将后续控制收益计入当前决策。本组是**两阶段局部机制验证**，不是完整B0、连续扫描或顶刊方法成果。

## 方法与物理任务

在3N预载附近取单轴接触

\[
F=3+kq+b\dot q,\quad
m\,d\dot q=(u-F)dt+\sigma dW,\quad
u=3-K(q-r)-D(\dot q-\dot r),\quad m=0.5\mathrm{kg}.
\]

\(q\)为相对初始预载平衡的位移，参考\(r(t)=vt\)给定，非额外探测动作。不同k的预载平衡表面位置不同，不把这个局部模型当统一未压缩组织表面。代价为力误差、位置/速度跟踪和实际作用：

\[
\ell=((F-3)/0.3)^2+((q-r)/0.0015)^2
+0.04((\dot q-v)/0.03)^2+0.015((u-3)/3)^2.
\]

未知切线刚度\(k\in\{300,1500\}\mathrm{N/m}\)，阻尼\(b\in\{1.5,18\}\mathrm{Ns/m}\)，四种已知模型假设。每例随机给初始后验、位置/速度、参考速度2–8mm/s、首段20–60ms、后段0.3–0.7s；\(\sigma=0.015/0.03/0.06\mathrm{N\sqrt{s}}\)。阶段交界测得准确位置/速度及有噪声力，力标准差0.03/0.1/0.3N。参数是探索设定，非组织/传感器实测标定；不把四种假设覆盖说成未知模型已解决。初始后验作为已有信息提供，未重建完整起始wrench流。

每段K/D固定，15个动作是\(K\in\{0,50,150,400,1000\}\)、\(D\in\{4,20,60\}\)的组合。优化的是物理阻抗动作，没有预选8套算法。第二段后无其他决策，第一段按预测观测与贝叶斯更新计算真实任务代价的后续最小值，无信息奖励、熵权重或增益偏好。三个自适应方法**在实际阶段交界都用相同位置、速度、力更新后验**，区别只在第一步如何规划：

- 冻结认识规划：预测未来运动反馈，但规划中后验权重保持当前值。
- 预期编码器更新：规划时计算未来位置/速度对后验的影响。
- 预期编码器＋力更新：规划时计算完整新观测对后验的影响。

另有训练集调优的固定两段K/D。两个时段的期望代价来自线性随机动力学均值/协方差传播；每种真实模型分别抽样第一段状态和有噪力，再按可得观测选第二段动作。第一段期望代价解析化，第二段积分未来过程噪声；不是有限次数随机轨迹的硬力保证。

## 设计迭代与独立结果

8例初筛发现低阶Gauss–Hermite会改变动作，个别规划甚至劣于冻结方案。改为Sobol观测积分，3个初筛例上比较512/2048/8192点；保留[integration_pilot.json](integration_pilot.json)。该记录与初筛不作独立性能证据，初筛计时含JIT/并行探查影响，不用于实时性结论。

用16例（11501）调优固定两段方案，记录[协议](protocol.json)及源码哈希后生成新64例（11601）。每个首段动作积分4096点预测观测；独立评估每种真实模型4096次首段过程/观测随机量（11602+i），共同随机数配对，第二段代价再取条件期望。按每例已给后验加权四种真实模型；不是只测试对方法最有利的材料。各例在新噪声下评估，不使用规划节点作测试噪声。

| 方法 | 平均J | 相对冻结认识规划的逐例平均改善 |
|---|---:|---:|
| 调优固定两段 | 0.981751 | — |
| 冻结认识规划，执行时仍更新后验 | 0.921430 | 0 |
| 预期编码器更新 | 0.920965 | 0.03935% |
| 预期编码器＋力更新 | 0.920165 | 0.08363% |

完整观测方案的改善区间约[0.03794%,0.13985%]，为64个场景的配对重采样；包含这次有限蒙特卡洛评估误差，未覆盖材料/机器人/任务迁移。64例中26例第一步动作改变。均值之比与逐例相对值的平均不同，不能混用。完整[逐例结果](results.json)与[配对数组](paired.npz)保留。

**判断：** 在这一局部模型族中，预期未来信息确实能改变阻抗，但相对本来就能更新认识的规划，额外任务收益很小。与固定K/D的差距不能全归于主动信息；因此不把“后验＋双重控制＋离线网络”直接指定为论文主方法，也不围绕这一小差值继续加网络。该结果不否定整个原问题或所有未知非线性接触条件。

暖JIT、单线程顺序评估：三种规划中位约358/666/668ms，每例模型/代价构造另约162ms。**表中是决策立即可用的期望效果；这些计算时间远超首段，不代表可部署收益。** 当前实现是机制数值参照；本轮未训练快速actor或验证其误差，也未实现延迟补偿。原问题的快速部署目标尚未完成。

## 核查、边界与复现

[verify.py](verify.py)独立积分物理均值、协方差和代价，12例DOP853相对代价差最大约5.03e−12；已知单一模型时三种规划完全一致，力噪声趋于无穷时完整方案退化为编码器方案，差约6.02e−14。此为公式/信息使用检查，不替代实物验证。

[audit.py](audit.py)对测试前两例及改善最大/最小例做事后积分敏感性，使用不同Sobol扰乱种子、16384节点与每模型32768次评估；见[integration_audit.json](integration_audit.json)。它们是数值复核，不增加独立测试计数。

局部线性、已知假设集、准确编码器、每段固定参数及给定初始后验均限制结论。未含有限足迹、连续空间环境变化、完整MHE/HJB、实际增益速率/能量/发布延迟、接触丢失、真实组织/成像，也未复现领域强控制器或允许参考/前馈自由调整的充分对照。高斯过程噪声无界，不能由预载3N声称硬力安全。不能据此宣布胜过领域已有能力。
