# Data from: A pioneering experimental investigation of a novel in-situ dynamic characterization of the tensile/compression stress-strain mechanism on human plantar soft tissue

## Description of the data and file structure

The primary\_data\_anon\_upload\_dryad.xlsx is an extension of table 1 in the manuscript. Please note that for privacy protection, the policy requires to publish no more than 3 indirect identifiers, thus the info of gender, weight, and random one of age and height of each testee are marked out, and the BMI are required to be marked out.

The v1-TC2.opju, v4-TCjyy.opju, v6-TCcrb.opju are the original tensile/compression test data of volunteers 1,4 and 6. The mimicfoot-sample\_dataTC5.opju is the original test data of mimic foot. The brick-sample\_dataTC3.opju is the original test data of brick sample. The FEA-fullfoot-heel-TC.opju is the FEA simulation. In all these forms and figures, the X-axis is time, Y-axis shows force (in color black) and displacement (in color red), which presents the stress-strain behavior. These data correspond respectively to the figure 1 in the manuscript.
