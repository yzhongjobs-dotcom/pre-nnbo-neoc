# 研究问题

**机器人连续扫描软组织、接触环境发生变化时，怎样利用新接触信息，快速更新刚度和阻尼，改善实际接触力与运动表现？**

研究同时涉及环境认识、阻抗决策和及时执行；不只是在固定模型上加快一个求解器。问题保持具体任务和完整控制链，方法可以修订。

## B0起点

[原方法§1](方法设计.md)提出：从接触过程中获得新的环境信息，在环境变化后快速得到可认证的近最优控制策略与实际阻抗，避免每次从头求解完整最优控制问题。

B0路线为：柱面有限接触足迹 → Fn/Ft/My与MHE → 环境描述符η → 四个实际增益率动作的有限时域HJB → 固定节点根 → ANEOC → 条件性认证发布和实际执行。完整[方法](方法设计.md)、[附录](技术附录.txt)与[证明](理论证明.txt)保留原样，便于检查和后续有依据地修订。

“可认证”是B0在相应正则性、近似误差和执行等条件下的设计目标，不是已经实现的机器人保证。仓库中的假设、推导和已发表论文均需独立核查。

## 当前范围与未验证内容

- 两套候选共用环境估计/空间预瞄思路，分别探索模型优化更新与仿真离线学习生成阻抗，见[方法说明](最优阻抗更新_问题与方法.md)。
- “最优”必须明确任务代价、信息、约束和控制策略类；学习输出、自洽节点根或局部数值解不能自动称为最优。
- 完整带噪MHE、可实际利用的空间预瞄、四增益闭环及真实机器人控制收益尚未打通。几何提前量不等于可用预瞄时间。
- 原问题有应用与已有研究依据，但相对领域充分已有能力的具体重要进展尚待建立；局部简化实验不足以给完整构想下成败结论。
- 材料、速度、传感器与内环尺度、参考和平台接口仍需核实。不把这些不确定性预先固定成新选题。
