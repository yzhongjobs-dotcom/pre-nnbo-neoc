# 研究问题：已有基础与待重审之处

本文件忠实整理既有内容，未提出一个已经锚定的新研究问题。用户要求研究优化暂不开始。

## 原科学意图

连续软接触、特别是机器人超声扫描，需要接触质量、运动/姿态与交互安全。9月8日领域分析希望减少患者特异的离线逐点触诊，在扫描中获得对任务有用的接触认识，并转化为实际施加的柔顺行为。空间接触信息、模型修订与控制执行之间的关系是原意图，不能把它全部缩成求解器更新。

该分析还提出更广的信息获取与反馈力学共同演化；其重要性、共性困难以及现有强方法实际还缺什么，尚须回到原文审查，不能因旧文件有FINAL标签就认定成立。

## B0实际落实的问题

机器人扫描空间变化软组织时，从接触观测获得环境信息；环境描述符修订后复用已有有限维解，快速产生带条件性误差、可行性和局部性能界的阻抗策略，并生成实际增益及执行力矩。

已有[完整方法](方法设计.md)采用：柱面有限接触足迹 → Fn/Ft/My与MHE → 环境描述符η → 四个实际增益率动作的有限时域HJB → 固定节点根 → ANEOC → 认证发布与实际执行。

这套方法没有主动信息获取代价，未实现完整dual control；也没有证明取消离线触诊、带噪在线预瞄或整条扫描任务的实际收益。原意图、数学问题和已验证能力存在差距，后续要共同调整，不能用一个更窄的技术题遮住差距。

## 目前能据实说什么

- B0有完整定义与条件性证明，尚无全维MHE—四维增益率—机器人验证。
- 简化载体支持局部连续更新可行，并显示误差累积、critic质量、强结构化对照和准备/维护成本的重要性。
- Q1/Q2的强简单反馈及短预测接近局部优化，只限定这些载体中的收益；不否定整个领域问题。
- Q3“哪些模型修订值得更新策略”已撤回为主线。信息代理、固定增益反例和完整wrench退化均不能直接充当新的论文级问题。
