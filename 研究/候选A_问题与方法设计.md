# 候选A：让扫描中的接触认识服务于采集，而非先完成整张材料图

更新：2026-10-18。用户在现状审查后授权继续向顶刊目标推进。本轮沿推荐A开展问题—方法共同打磨；它是当前探索主线，尚不是已确立的新颖问题或论文贡献。没有将某个器官、平台、固定测试清单或新算法小题擅自选成永久目标。

## 1. 工作问题与科学意图

**在未知、异质并可能运动的软接触中，怎样利用扫描过程自身获得的信息，以更少独立表征/重扫的资源，保持实际采集结果与可接受的接触表现？**

这是对B0连续扫描—接触认识—实际执行意图的候选修订。B0原问题和三份方法/证明保持原文，可比较、可复用，但不再默认“每次材料修订后快速求近最优K/D”就是最重要的贡献。没有把本轮两自由度载体替换为最终题目。

这个问题的重要性有应用与文献支持，**“强已有方法仍不能以同等资源完成它”尚未证实**。Beber的离线触诊负担、Piedra的点式肋骨探测提供具体动机；Xue、直接力/姿态控制和新的连续触诊方法提供强反事实。不能把某一先例需要离线地图，推广成全领域都需要它。

候选贡献应同时回答：省了什么资源、保住/改善了什么任务结果，以及信息改变了哪个有效动作。更准材料图、更多模块、输出K/D、某个求根器更快都不足以单独回答。

## 2. 本轮近邻使哪些主张失效

在[研究现状](研究现状.md)的完整能力对照之外，新核相关原文：

- [连续遍历触诊，arXiv:2602.14287v1](https://arxiv.org/html/2602.14287v1)，§III–V：在线黏弹估计、信息密度与连续轨迹闭环，含硅胶实物；BO对照还允许沿途取样。故“连续过程中估计并引导探索”和“省去逐点停留”已有直接机制，不能作为本项目独立新颖性。
- [接触感知阻抗，arXiv:2609.34400v1](https://arxiv.org/html/2609.34400v1)，§II–IV：图像接触检测/定位、接触条件去偏与随动交互坐标系。其曲面探头在均匀平面琼脂上验证，比较还改变了去偏机制；不能把结果全归于材料适应，也不能称任何异质组织条件已解决。
- [接触自适应视图保持，arXiv:2609.37456v1](https://arxiv.org/html/2609.37456v1)，§III–V：示范导出的图像条件纠正、共同力调节及监督器，在单操作者动态假体上做配对视图试验。静止保持是其主要比较，不能据此给成熟视觉伺服排名；但“用图像和力保持任务视图”显然已有人做。

三者均按预印本处理，未当成熟领域共识。成熟任务导向探索、UFIC和在线自适应仍可直接复用；来源成熟不否定迁移价值，迁移本身也不是贡献证明。当前还没有由这些文献对照确立一个新的共性failure。

## 3. 理论形成：先问行动需要什么信息

### 3.1 分不开材料与表面，不等于做不好控制

以本轮独立有限接触面模型为例，令

\[
p(u)=\kappa(s+u)[z+\theta u-c(u)-h(s+u,t)]_+,
\quad x=(z,a\theta),\quad y=(F,M/a).
\]

局部接触响应为

\[
G=\frac{\partial y}{\partial x}
=L\int_{\text{受压区域}}\kappa(s+u)
\begin{bmatrix}1&u/a\\u/a&(u/a)^2\end{bmatrix}du.
\]

矩阵半正定；受压区域有非零宽度、正地基系数时正定，接触丢失/极窄覆盖时会退化。正定不提供延迟闭环或患者安全保证。

对于完整覆盖、均匀材料和平面，\(F=2aL\kappa[z-h-a^2/(6R)]\)、\(M=0\)（零滚转）。\(\kappa\)和h可以同时改变，使同一位姿产生同一静态wrench，却产生不同G。具体两世界数值与独立积分见[实验](../实验/扫描接触信息判别/README.md)。

这说明单个静态接触历史不必能区分刚度与表面高度；它是已知辨识原则的具体实例，**不是新发现B0失效**。一旦运动/载荷提供足够激励，数据可能消除歧义；相反，强反馈也可能无需完整消除歧义就完成任务。

### 3.2 可尝试的表示是控制响应，不必是完整材料图

在局部有效范围内考虑

\[
y_{t+\Delta t}=y_t+G_tu_t\Delta t+d_t\Delta t+r_t,
\quad\|r_t\|\le\delta.
\]

G描述法向/滚转动作对wrench的响应，d吸收短时空间变化和表面运动；它们不自动包含图像、完整黏弹记忆或接触模式转换。若两个兼容模型满足\(\|G_1-G_2\|\le\epsilon_G\)、\(\|d_1-d_2\|\le\epsilon_d\)，则对**同一**局部动作，有

\[
\|y_1^+-y_2^+\|\le\Delta t(\epsilon_G\|u\|+\epsilon_d)+2\delta.
\]

这是直接三角不等式，界定一阶预测需要的知识；不是新的稳定性定理、完整多步后悔界或成像质量界。真实模型必须落在集合、局部余项必须可信，才能用作保证。

进一步，若对同一组可行动作的预测**任务损失**误差一致不超过ε，按预测损失选择动作相对该组真实最优的损失不超过2ε（用两次一致误差界即可）。因此候选方法可围绕行动相关预测检验是否足够，不必先把所有材料参数都估准。这个标准是方法工具，不能把研究主线再次缩成“哪些模型修订值得更新”的Q3小题。

### 3.3 主动探测需要算任务账

信息增益大并不意味着应做探测。成熟任务导向探索给出的启发是：比较“继续采集”和“先/同时作一个信息动作再采集”的**共同任务时域总代价**，包括力偏离、时间、路径、图像失效和额外接触；而不是给参数误差或Fisher信息人为设置一个奖励就宣布收益。

本轮固定探测仅检验机制是否值得，没有实现完整此类策略。真正的扫描内动作既可能产生信息，也可能直接推进任务；所以不能把只适用于纯测量步骤的“完美信息价值上界”直接用于所有扫描动作。已知的任务导向/dual-control机制可复用，不宣称首次提出。

## 4. 完整候选技术路线与当前取舍

| 环节 | 候选实现及依据 | 当前判断 |
|---|---|---|
| 共同执行层 | 充分调优直接力—姿态/UFIC或适合平台的导纳；统一处理实测力、接触建立/丢失、接口限制 | 优先复用强方法，不先重写低层控制；本轮PI只是简化参照 |
| 接触认识 | 被动扫描数据更新局部输入—输出响应或小型模型集合；必要时结合视觉表面与声学接触信息 | 可避免要求完整材料图；需把数据信息与正则化先验分开，验证局部模型/偏差 |
| 任务决策 | 根据剩余采集目标，在共同资源约束下调整参考力、姿态、速度/路径，必要时阻抗；保留简单规则与结构化小优化的竞争 | 不强迫所有信息经K/D产生作用；具体动作由实际任务确定 |
| 可选信息动作 | 只有兼容模型会导致有意义的任务决策差别，且任务收益覆盖探测代价时，才比较短时探测或改路径 | 候选机制，非默认模块；当前固定探测结果不支持优先投入 |
| 计算实现 | 先用小维度结构化估计/反馈/优化，若总链路确有成本再考虑热启动、NEOC或离线策略学习 | 不预设NEOC/PPO，也不把“不可替代”作为门槛 |

这是可实现的候选路线，**各部分已知，组合也尚未证明有新的任务能力**。本轮实现只到二维直接反馈、点式局部G拟合和两种固定激励；没有实现模型集合、主动任务规划或图像闭环，更没有把它们当成已验证算法。

## 5. 新实验改变了什么判断

源码、全部初始/后续配对结果、图与独立核对见[扫描接触信息判别](../实验/扫描接触信息判别/README.md)。新增的是有限足迹力—矩/位姿闭环、未知空间表面与材料、实际执行滞后，不是旧Q2已知表面程序/PPO试验的重复。

结果支持以下分层判断：

1. **在线适应有用，尚不能归因为必须获得某种物理信息。** 成熟被动拟合在后续384个新环境中降低平均误差，说明不能用旧Q2结论宣布整个接触认识无用；更简单的带宽调度是否也能做到，尚未排除。它不是我们的新贡献。
2. **完整辨识不是任务收益的必要条件。** 在本载体中，被动估计G仍有较大误差，机械调节已较好；提高G精度的固定探测反而比被动方案代价高约4.9–14.6倍。
3. **平均误差与风险存在不同排序。** 被动方法平均误差更低，部分条件的最坏峰值却高于范围筛选固定PI；尚未形成性能—接触风险的全面优势。
4. **不能保护当前想法，也不能过度否定。** 不继续为了额外探测赢而堆条件。本结果不否定任务条件化探测、更高维组织认识或完整B0；累计证据已足以让“NEOC/PPO/固定激励本身”退出优先贡献组织。

局部响应oracle表明还有有限改善空间，不能解释成全局最优或实际能达到的收益。没有同强prior做充分实机比较，不能把比PI好写成比领域最好方法好。

## 6. 从机械载体走向实际任务的具体工作

**下一阶段优先找真实采集中的剩余任务损失，而不是继续扩大合成仿真或训练预算。** 当前假设是：少量扫描内认识可能减少准备或重扫；它需要实际任务依据，不是既定验收结论。

1. **先核查可用数据与执行接口。** 已找到[US-PPNR](https://github.com/PieceZhang/US-PPNR-Dataset)宣称同步超声、F/T与位姿，以及[ForceU-VLA](https://github.com/VMVLab/ForceU-VLA)的USForce部分发布。前者有不少模板字段未填写，后者目前README说只发布两位操作者；本轮未取到可分析原始样本，不能据目录宣布数据足够。Hugging Face和arXiv原始文件在当前命令网络接口返回403，部分元数据可经网页访问，不是用户没有数据或数据不存在。
2. **利用现成记录约束模型与指标。** 新预印本Jeong公开仓库[FR5-for-RUS](https://github.com/suung23/FR5-for-RUS/tree/d2fa8b30b0115492b6180e5674677ce29ab02a1a)可核代码/表格，其力控制测试主要调节合力模长而非单一法向；稳态位移—力表能提供量级线索，不能验证我们的有限足迹模型。仓库不同文档的去偏残差状态不一致，不能挑一个数字当本平台噪声。图像/力时间对齐、坐标与去偏应由对应记录确认。
3. **在选定的采集任务中定义真实比较。** 候选例是连续体积扫查的有效覆盖/重建，或有障碍声窗时的任务视图；不在无平台/数据依据时强选器官。选择会影响目标力、允许姿态/路径和哪些信息有价值。先看强直接力/姿态、在线适应、已有图像伺服在同准备资源下的实际损失；允许它们沿途取样、调速度和路径，不能人为锁死能力。
4. **针对已观测的困难选择方法。** 若主要是偏置/交互坐标，优先复用接触去偏/随动坐标机制；若是声窗或目标视图，接触信息必须连到相应动作和采集结果；若强反馈/规则已足够，就采用它并撤回不成立的增量主张。若发现辨识—采集冲突，再做任务条件化信息动作，比较相同时间和接触预算，不仅比较材料误差。
5. **将实际机制与理论对应。** 根据真实不确定性与动作接口决定是否需要模型集合、余项界、约束或学习，完成方法消融与跨材料/运动核对；理论证明只承诺其假设支持的层次。顶刊贡献应来自有意义的新能力、可信解释及匹配证据，而不是上述流程完成。

已授权范围内的调研、公开数据核查与方法验证主动推进。项目自身平台/同步数据状态仍未得到用户确认；这影响下一项实际任务的选择与实验证据，不阻止已经完成的理论与机制筛选。真实数据的观察关联也不能替代新控制动作的闭环因果验证。

## 7. 与B0及长期要求的关系

保留连续软接触的科学意图；重新组织信息—任务—执行关系。B0有限足迹、完整wrench、MHE和条件性控制证明可作为机制来源与比较基础；原三份正文未改、固定快照未动。新的地基模型和直接力/姿态动作不能直接继承B0的HJB/KKT/无源证明。

当前仅形成了更具体、经过一次有判别力筛选的候选问题与方法路线；尚未确立顶刊问题缺口或独立方法贡献。候选A也可被后续文献/实际证据修订。重点不回到保住原算法、不换成辨识精度或求根更新小题，也不以“尚未证明完整B0失败”回避已有累计证据。

## 8. 面向一篇顶刊论文的推进规划

回应用户进一步要求：明确标准、原两种方法的潜力及后续规划。方法1指B0模型—最优阻抗—NEOC完整路线，方法2指学习生成阻抗；候选A是问题假设，不是第三个已验证方法。目标是一篇有说服力的论文，不要求两个算法分别写成论文；它们可以竞争、作对照、合理融合或退出。

### 标准与潜力判断

以机器人领域T-RO/IJRR级研究暂作参照，具体投稿刊物随最终贡献确定：问题重要且准确；相对充分理解的强prior有实质进展；方法为何提供所需能力可以解释；理论/实验匹配主张；比较公平、证据可复核、范围明确；认识对同行有迁移价值。这不是模块/证明数量、固定提升百分比或录用保证。

对拟作的控制性能/效率主张：若调优简单方法在相同任务、可部署信息与实际资源条件下已有同等效果，复杂候选却没有重要的成本、风险、能力或适用范围收益，就不支持该贡献。胜过简单方法只是起点，仍需说明相对强相关研究的增量；不要求所有指标/场景同时第一。成熟机制的有效复用可以带来贡献，不以模块已知直接否定。

| 原候选 | 现有证据与可继续研究的空间 | 当前投入判断 |
|---|---|---|
| 方法1 | 有空间接触认识、优化和条件性证明基础，但NEOC对Newton/固定Jacobian等的稳定整体优势未建立；名义阻抗代价与重要任务收益也未连通 | 完整路线可重构。先建立接触认识的任务价值与实际瓶颈，不以更精细求根或更长证明预设顶刊潜力，不承诺保留NEOC/HJB |
| 方法2 | 实现可行，能胜固定目标；当前未胜较强简单调度，PPO输出阻抗已有直接先例 | 只增加训练预算可能改善实例，不补出新颖性。若领域问题需要尚未获得的历史利用/长期决策等能力，再检验学习；不预选这些难点或PPO |

**当前没有依据认定两个原版本只需继续调优就能达到顶刊。** 保留形成重要贡献的研究空间，允许实质重构；局部失利不等于整个应用无价值。新增被动适应试验只是机制参照，不是原两种方法已经获得的优势。

### 工作步骤、产出与调整依据

各阶段允许交叉与回访，不把先严格证明强prior失败作为试想法的门槛，不设置所有研究统一的阈值。

| 阶段 | 工作与具体产出 | 怎样改变路线 |
|---|---|---|
| 1．收敛问题与论文主张 | 复用现状表，结合任务/资源形成一页“任务—强prior能力—重要剩余损失—候选机制”。候选A继续接受质疑，不固定器官 | 不把输出K/D或缺一条信息边当问题。若建议实质换题，给出有依据选项，由用户取舍 |
| 2．做强简单方案，同时判别机制 | 根据任务选择直接力/姿态、在线适应、观测器等充分版本，补必要简单调度。估计还有多少重要改善空间，输出强基线与判别协议 | 简单方法已足够则采用并修正增量；仍有损失则分析信息、执行、目标表达或决策成因。现有载体仅补未排除的带宽调度替代解释，不把它升级为长期主任务 |
| 3．围绕所需能力设计和竞争方法 | 主动寻找、复用成熟机制；以理论与低成本实验共同修订模型路线/学习路线。共享可部署观测、物理限制，强对照可调有效的参考力/姿态/路径 | 先核对阻抗是否是有效动作。没有求解瓶颈就不主打加速，学习不胜简单调度就不盲增训练。允许换模块，不要求NEOC独占能力 |
| 4．取得能改变判断的结果 | 在保留重要困难的最小任务上，明确任务指标和成本/风险，冻结配置后独立测试；按主张选择去信息、去预测、冻结反馈等消融，输出可复核优势及解释 | 排除调参、额外真值、奖励偏置或执行器差异。无优势时更新对应方法或问题层次，不堆条件，不用局部性无限保护候选 |
| 5．补足完整证据与理论 | 接入实际接口，核模型/感知误差、延迟和执行条件；评估均值、尾部与总资源。超声应用贡献补采集/重建证据；理论贡献核其真正假设和推导 | 不把正定、能量池或根残差当全部安全/最优。逐步补证据，不把临床或全系统认证提前作为初期研究门槛 |
| 6．形成论文并审查 | 按“问题—已有不足—机制—获得能力—证据边界”成稿，针对最新强prior及简单替代解释检查，据最终贡献选刊 | 缺实质进展就返回相应阶段，不能靠增加篇幅包装。达到有竞争力的投稿水平仍不保证录用 |

紧接着的产出应是**具体任务定义、强已有/简单方法能力核对，以及一个会改变两种路线取舍的判别协议**。复用已有调研和实验，不从头重做综述。方法1先查任务收益与真实计算瓶颈；方法2先查任务是否需要简单反馈/调度尚未获得的决策能力。两条路线服务于同一重要问题，不预定必须保留谁。

资源状态影响任务与验证规模，但用户未回复不表示没有实机，也不应导致理论/模拟研究全部停工。可以先做可信模拟和机制验证；需实际采集支撑的结论据实保持未验证。优先形成一条有证据的论文主线，不把两个弱主张分别无限优化。本规划是阶段安排，不修改长期要求或把候选A固化为永久选题。
