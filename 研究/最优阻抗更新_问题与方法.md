# 环境变化时的快速阻抗更新：两套候选与实际进度

本文件保留两候选的原定义及历史证据。最新各自代码/实验见[双候选任务仿真](../实验/双候选任务仿真/README.md)、[结果](../实验/双候选任务仿真/结果.md)；[分线方法与迭代](两候选分线方法设计与迭代.md)记录表示改变及前一轮。当前是有完整列明任务/执行关系的平面数值实例，非完整B0固定根、实物或顶刊验证。清理前全文见Git提交 `db28365f33dc314ce8bfe83a23796dd18cf27f5b`。

## 1. 要解决什么

机器人扫描软组织、遇到软硬变化或组织运动后，利用新接触信息及时更新K/D，兼顾接触力与运动表现。比较时必须明确相同任务、可得信息、实际执行和计算成本；不同目标下的“最优”不直接等价。

原B0考虑有限时域任务，实际增益为状态，动作是增益率；代价、动力学和约束见[原方法](方法设计.md)。此前随机期望、参考/前馈联合动作和简化接触模型属于探索扩展，未自动继承B0证明。

## 2. 两候选的共同前端

接触力/力矩与运动观测 → MHE及有限足迹空间预瞄 → 对环境变化和接触响应的估计 → 阻抗决策 → 实际执行。

这里MHE不是已实现事实，预瞄也不是已经验证的控制优势。真实Fn/Ft/My中的表面、材料、摩擦、偏置及组织运动可能混淆；估计误差与信息到达时序需要具体处理。原B0已写有这些条件，不能包装为后来新发现。

## 3. 候选1：模型优化与快速更新

**构想：** 用估计的环境变化建立最优控制问题，借鉴NNBO的critic/HJB思路获得可复用反馈，再以NEOC预测、必要校正和重锚加快模型变化后的更新。

**关键区别：** [NNBO原文](../文献/原文/NNBO.pdf)通过预辨识HC模型、critic力—位置关系和Newton下降生成位置参考；不是四个K/D输出。B0将控制对象扩展到实际增益率和有限时域问题，相关理论与数值有效性须单独检查。部署时也不是每个低层周期重新训练critic、求整套HJB。

**当前状态：** 有条件性书面设计和局部数值工具，没有完整MHE—四增益—机器人实现。现有局部试验中NEOC式灵敏度没有稳定超过普通热启动/弦迭代；不能由此宣布完整候选1无效，也不能宣称NEOC已有独特优势。

前一轮曾用直接OCP暂代critic。最新已实现轨迹附近的二次HJB价值反馈及状态/模型方向扰动Riccati更新；这是全域二次配置求根未成功后的明确表示改变，不是B0原节点根，也不继承认证证明。24场景中NEOC开/关收益很小、区间跨零，不能宣称其独特优势；原问题保留并据此改进。

## 4. 候选2：参考YOPO的仿真离线学习

**原始借鉴思路：** 先用MHE与空间预瞄得到环境变化，再以环境估计、机器人状态和任务信息作为输入，利用仿真离线训练网络，部署时快速生成自适应阻抗，替代候选1的在线HJB/NEOC求解路线。

**借鉴对象：** [YOPO，RA-L2024](../文献/原文/方法借鉴/YOPO.pdf)，DOI10.1109/LRA.2024.3399589。其训练利用轨迹代价梯度进行guidance learning，部署单次前向输出轨迹候选及评分，运行中仍滚动规划；并非PPO。可借鉴的是把在线决策负担转到离线学习，以及训练目标与实际决策的结合。如何适配接触和阻抗仍待设计，不能只套一个网络名称。

**PPO的地位：** 用户提出的可选训练工具，可在不可微接触仿真中训练；不意味着必须PPO，也不意味着训练结果全局或逐实例最优。输出K/D目标或增益率，需要与真实增益执行接口一致。一般预训练允许，部署输入应是实际可得信息。

**当前状态：** 原完整构想尚未实现。之前直接PPO读取短观测历史的实验省略上述完整前端；后来的监督映射、任务代价网络及CEM反馈公式也是不同简化实例，均未通过充分比较证明可作为更优替代。因此撤回“它们已完整验证/优化候选2”及由这些实例否定原构想的说法。

前一轮完成约化前端与三组权衡。最新在Hertz/正定增益率代价/终端任务上训练三种子网络；48物理训练场景、3840相关上下文、24独立测试，另做分布变化及计算发布。经纠正消融过度删除当前材料信息后，另在新24场景比较有/无空间参数化：固定种子改善区间跨零，尚无可靠信息收益结论。网络推理快，但对Jin多步扫描适配仍无总体物理性能优势，尚不能宣称完整候选2或顶刊达标。

## 6. 尚需厘清的事项

实际平台和参考、接触模型适用范围、估计/预瞄的可用信息、优化的真实任务收益、完整候选相对简单及领域强方法的表现仍待核实。两候选可改造或融合，不能为保住NEOC/PPO收缩问题。方法形成与阶段判断的确认认识已落实[长期要求](../项目记录/长期要求.md)，后续按相应阶段及用户最新任务设计；本次文档更新不指定新科学主线。
