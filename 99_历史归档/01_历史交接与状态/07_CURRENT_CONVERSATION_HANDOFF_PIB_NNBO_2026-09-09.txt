6. 必须忠实恢复的 NNBO 与 IDOC 数学对象
======================================================================

6.1 NNBO 的实际结构

NNBO 使用 Hunt-Crossley（HC）软接触模型，例如：

f = B_e delta^n dot{x} + K_e delta^n,
delta = x - x_e。

EWRLS 用于估计环境参数 K_e、B_e、n。

随后构造 augmented input-affine dynamics：

dot{X} = F_chi(X) + G_chi(X) f + K epsilon，

并使用无限时域 HJB 代价：

integral [e^T Q e + f^T R f + zeta_epsilon^2] dt。

最优策略形式为：

f* = -1/2 R^{-1} G^T grad V*。

single critic 近似 value function。最终执行时，论文把最优 force policy 改写成 nonlinear force-position relation，再用 Newton 类方法求目标参考位置 x_r，交给底层 position loop。

【禁止误述】

- NNBO 不是直接求解一般意义上的 K、B；
- NNBO 的 inner problem 不是有限时域 constrained trajectory NLP；
- critic 不是可直接套用 IDOC differential-KKT 的通用 OCP solver。

6.2 Revisiting IDOC 的实际结构

IDOC 研究的是有限时域、离散时间、带动力学/状态/控制约束的轨迹优化 NLP：

min_{x,u} J(x,u;theta)，

通过 active-set KKT 系统与 implicit function theorem 求最优轨迹对参数的灵敏度：

partial xi*/partial theta。

其关键条件包括二阶可微、约束 Jacobian 适当满秩以及 KKT 矩阵非奇异。其 O(T) 结果依赖有限时域 KKT 的块稀疏结构。

【正确的 source-mechanism 迁移】

IDOC 可以提供一般思想：

“不要展开整个迭代求解过程，而是对定义最优解的最优性方程进行隐式微分。”

但 IDOC 的有限时域 KKT 公式和 O(T) 结论不能未经重新推导直接移植到 NNBO 的连续时间、无限时域 HJB/critic。

7. 候选路线演化与当前边界
======================================================================

7.1 原始 Idea：环境自适应 Q、R

原始链路：

环境/任务状态
→ NN 学习 Q、R
→ NNBO 最优控制
→ 机器人交互
→ 外层误差反传。

原始动机是 NNBO 的 Q、R 需要人工设定，不同软环境下难以自动调整 tracking 与 contact 的权衡。

已发现的问题：

- 环境动力学变化不必然意味着任务偏好变化；
- 同一个环境可以对应不同任务偏好；
- “人工调权重”本身可能只是工程标定症状，不足以形成顶刊级 RMC；
- 自由 NN→Q,R 存在尺度、可辨识性与语义混淆。

7.2 PIB-NNBO：当前被审计的冻结候选

PIB-NNBO 保留 NNBO 的 HC/EWRLS、robust auxiliary dynamics、无限时域 HJB、single critic、force policy 和 Newton reference realization。

核心修改：

- 将原始 Q、R 改为归一化、低维 objective coordinate eta；
- eta = h_psi(p, chi)，其中 p 是任务描述，chi 是环境信息；
- 对 HJB/Bellman operator 或 empirical critic stationary equation 做隐式微分；
- 当前冻结版使用 sparse expert force-position demonstrations 作为主要 outer supervision；
- 不直接改成一般 MPC，也不直接输出 K、B。

工作名：Preference-Identifiable Bellman-Differentiable NNBO（PIB-NNBO）。

7.3 对冻结版 PIB-NNBO 的最新暂定审计

最新审计的核心不是“IOC prior 出现，所以 PIB 不新”，而是信息—问题—机制闭环的二分困境：

A. 若真实问题是从专家示范恢复 task preference：
   sparse expert state-force demonstrations 已经提供 inverse optimality information。此时 direct inverse-Bellman / IOC 可能比“反复求 forward critic，再通过 demonstration loss 做 implicit hypergradient”更直接。PIB 尚未证明其关闭了 IOC 无法关闭的 residual failure。

B. 若真实问题是不同软环境下 raw e^2、f^2 与真实 physical consequence 之间的映射发生变化：
   这是更强、更贴近领域的 failure；但标量或低维 eta 对 e^2/f^2 重加权未必能表达材料非线性引起的 consequence function shape change，而且 expert force-position demonstration 未必提供所需 consequence supervision。

因此，冻结版 PIB 同时混合了：

- task preference specification；
- mechanics-dependent physics-to-consequence mapping；
- 可能的模型/critic 误差补偿。

最新暂定 verdict：冻结版不是“只差 theorem 的 Final Method”，可能需要在 RMC/信息源/核心机制层重新收敛。

【注意】该 verdict 仍等待用户验收，不能在新对话中直接宣布为最终决定。

8. 已经成立或必须保留的关键理论判断
======================================================================

1. 环境参数 chi 进入 dynamics 时，即使 Q、R 固定，最优策略也会随环境变化。因此“环境变化”本身不能证明 objective adaptation 必要。

2. 同一环境可以对应不同任务或用户偏好。因此不能普遍用 h(chi) 唯一决定 task preference；任务信息 p 与 mechanics chi 必须在科学语义上分离。

3. HC 非线性可以改变真实物理后果的函数形状。例如准静态 f = K_e delta^n 时，储能为：

U(delta) = K_e delta^{n+1}/(n+1)
         = f^{1+1/n}/[(n+1) K_e^{1/n}]。

因此，当 n 变化时，一般不存在一个 scalar R(chi) f^2 在全域保持相同 consequence ranking。这个结果只能支持“某些后果表示需要改变”，不能自动证明必须学习 eta 或必须使用 implicit differentiation。

4. 对 exact HJB solution branch 作形式灵敏度推导在 classical unique stabilizing solution、足够光滑和线性化算子可逆等条件下可以成立。

5. 对 empirical critic objective 的 stationary equation g(W,theta)=0 使用 IFT，可在 Hessian/Jacobian 非奇异时得到：

dW*/dtheta = -H_WW^{-1} H_Wtheta。

但它只对所选 regularized empirical stationary branch 精确，不等于对真实 HJB solution 的精确导数。

6. 若要把 critic hypergradient 声称为 HJB hypergradient，需要建立 approximation、collocation/data distribution、regularization、solver residual 和 conditioning 到 policy/outer-gradient error 的显式桥梁。

7. NNBO 原文使用 instantaneous lambda_min(xi xi^T)>0 的 critic 收敛步骤在 critic dimension 大于 1 时存在 rank-one 问题。不能无条件继承原证明；需要正确的 integral PE / concurrent-learning Gramian / UUB 推导。

8. Newton reference realization 还要求根存在、局部唯一、Jacobian 不退化以及底层执行误差有界。

9. 若环境/context 变化快于 critic/optimizer 的跟踪时间尺度，不能主张广义实时适应。

10. 学习 Q、R 或 soft penalty 不能提供 hard force/deformation safety guarantee。若研究问题要求 hard constraints，才有理由引入 constrained HJB、MPC、CBF、passivity safety filter 等机制；不能为了增加理论深度预先堆入。

   - 这种不一致是否足够重要，还是更准确的模型、加权辨识或 robust/adaptive control 已足够？
   - 该 failure 是否能被理论反例、局部敏感度或不可辨识性论证，而不是凭直觉假设？

3. Method fit / necessity 审计：
   - 若根因是 decision-relevant model error，为什么必须或最自然地通过 optimal-solution sensitivity 反向学习？
   - 更简单的 sensitivity-weighted identification、robust control、online adaptation、domain randomization、BO 或 direct policy learning 是否已足够？
   - 若 Route H 与 Route O 都能解决，哪一个对同一目标能力是最小充分路线？
   - 只有 hard constraints、preview、rate limits 或 direct K,B decision 真正属于问题要求时，才能据此选择 Route O；不能因 IDOC 原式更方便而替换 HJB。

4. Scientific strength 初审：
   - “把 implicit differentiation 用到 NNBO”不能单独作为创新；
   - 必须说明它带来的新机器人能力、target-domain theorem 和不可被简单路线替代的闭环机制；
   - 必须评估 HJB exact sensitivity、critic approximation、model semantics、stability/robustness 和 execution chain 是否可能统一。

5. 输出明确 verdict：
   - Route H 已达标 / 只需优化 / 需要大改；
   - Route O 已达标 / 只需优化 / 需要大改；
   - 若两者都不应保留，说明根因所在层级；
   - 若其中之一更自然，说明不是因为避开 prior，而是因为它更直接关闭同一 failure。

6. 给出审计结论后停止，等待用户验收。不要在同一轮擅自产出新的 Final Method。
