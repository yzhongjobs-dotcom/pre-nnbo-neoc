3. 当前已收敛的研究问题与技术路线
======================================================================

3.1 当前研究问题

在未知、缓慢时变的非线性黏弹软环境中，低扰动持续接触数据通常只能部分辨识环境参数。机器人需要判断现有信息是否已经足以确定 HJB-optimal interaction/impedance decision；若不足，只补充会改变最优决策的信息；同时不能在参数漂移后等待 critic 从头重学，而要跟踪移动的 frozen-parameter HJB optimum。

一句话版本：

如何在未知缓慢时变软环境只能被部分辨识时，仅辨识会改变 HJB-optimal impedance 的环境方向，并沿闭环 HJB 解流形预测—校正地运输 NNBO critic，以持续跟踪瞬时最优交互律？

3.2 当前方法

方法名：Decision-Sufficient Adaptive Neighboring-Extremal Neural Optimal Impedance Control（DS-ANEOC-NNBO）。

核心路线：

1. 保留 NNBO 的 Hunt–Crossley 物理模型、HJB/single-critic 骨架和 position-based realization；
2. 对参数化连续时间闭环 HJB 做 NEOC 灵敏度推导，得到 value sensitivity 与 optimal-policy tangent；
3. 用同一 policy tangent 比较 observation-null directions 与 decision-null/relevant directions，构造 decision-sufficiency 判据；
4. 信息不足时只针对 decision-relevant 缺口进行有界、低扰动探测；
5. 参数估计发生变化时，用 Galerkin-NEOC tangent 预测 critic root，再用 corrector / homotopic re-anchoring 抑制一阶近似累积误差；
6. 将估计误差、NEOC 截断、Galerkin/critic 误差、corrector 残差和 reference realization 误差统一映射到性能与稳定性。

统一科学对象：闭环 HJB optimal-policy tangent。

论文级 Scientific Delta 必须表述为：

同一个闭环 HJB policy tangent 同时刻画“哪些软环境不确定性在观测上不可辨但对最优阻抗决策无关/相关”，并作为 moving-optimum critic transport 的局部生成元；由此形成 partial-identifiability → decision sufficiency → targeted information → critic transport → executable policy performance/stability 的统一闭环。

不得把创新写成：
- 首次把 NNBO 与 NEOC/IDOC 组合；
- 首次使用 Galerkin HJB sensitivity；
- 首次使用 homotopy；
- 首次进行 decision-weighted identification/probing；
- online identification + neighboring-extremal update。

这些原子机制已有 prior；创新必须落在目标领域的新关系、新能力和统一理论闭环上。

4. 已核实的 strongest-prior 边界
======================================================================

1. NNBO（Kong et al., IEEE TSMC 2025, DOI 10.1109/TSMC.2025.3579017）已经覆盖 HC/EWRLS、HJB critic、optimal force policy 与 position-based realization，但未解决部分信息是否足以确定最优决策，也未提供 estimated-drift 下的 HJB root transport。

2. NEOC（Rai, Mou, Anderson, Automatica 184, 112693, 2026, DOI 10.1016/j.automatica.2025.112693）已经覆盖已知参数变化下的连续时间无限时域 closed-loop HJB sensitivity、policy adjustment、Galerkin 权重 sensitivity 和 homotopy。不得把这些作为当前创新；也不得误述 NEOC 只处理 exact value function。

3. 时变环境中的 critic-based optimal impedance 已有早期工作，因此“时变环境 + critic + optimal impedance”不是 novelty。

4. application-oriented / task-oriented identification 已经覆盖“并非所有模型误差对控制等价”的一般思想；Fisher-information 或 decision-weighted probing 本身不是当前核心创新。

5. 过程控制中已有 online identification + neighboring-extremal control 的组合先例，因此一般意义上的组合也不是创新。

6. 当前未发现 prior 覆盖完整的同一 problem–mechanism role–capability：低扰动部分可辨识软环境下，用闭环 HJB policy tangent 同时给出 decision sufficiency 与 estimated-drift critic transport，并闭合到机器人可执行策略的性能—稳定性界。因此当前未触发 novelty veto。

注意：第 6 项是基于当前检索范围的审计结论，不等价于数学上的“绝对首次”。正式投稿前仍需更新 strongest-prior 检索。

6. 尚未通过的关键理论与复杂度问题【下一步必须修复】
======================================================================

M1. 分离结构信息与 prior/ridge【强制】

当前 I_t 若包含正定 Lambda_prior，会人为消除 ker(I_t)，使 decision-sufficiency 条件 vacuous。必须：

- 使用 raw data information I_data 判断结构 observation-null space；
- 将正则项、统计 prior 或置信集单独建模；
- 若 prior 真有物理/统计信息，明确其来源和可辨识语义，不能用数值 ridge 冒充信息。

M2. 把 approximate tangent 纳入 robust DSI【强制】

当前 decision metric 由 P_hat 构造，而理论 DSI 针对真实 P。必须给出 P = P_hat + E、||E|| <= epsilon_P 下的保守 metric upper bound 或等价 robust test，避免 approximate tangent 导致 false pass。

可采用但必须正式推导的结构示例：

M_true <= (1+eta) M_hat
          + (1+1/eta) lambda_max(R) epsilon_P^2 I,

再用 M_bar 与 I_data 构造 robust generalized-eigenvalue / kernel condition。

M3. 限定 DSI 的局部性并闭合二阶余项【强制】

若 I_data 奇异，未与 trust region 或有界参数集相交的 confidence ellipsoid 在零空间上无界。即使一阶 policy tangent 为零，二阶 policy 变化仍可能增长。必须：

- 明确 local parameter neighborhood / trust region；
- 给出 policy Taylor remainder 或 action-gap remainder；
- 将 first-order decision sufficiency 改成对真实局部决策误差有效的 robust certificate。

M4. 建立统一 executable-policy error theorem【强制】

必须把 estimator error、NEOC truncation、approximate tangent、Galerkin root error、corrector residual 与 reference realization error合成一个显式可计算界，再代入 performance difference 与 practical stability theorem。目标结构至少应覆盖：

||e_u|| <= L_theta ||theta-theta_hat||
           + c_2 ||Delta theta_hat||^2
           + L_W ||e_W||
           + epsilon_P ||Delta theta_hat||
           + epsilon_G + epsilon_ref.

当前 Method 只列出误差源，没有完成这一总闭环。

M5. 修正 critic tracking 的 re-anchor / data-stack jump【强制】

现有固定 D 的 tracking recurrence 不能直接覆盖 re-anchor 时的数据集、collocation stack 或 residual map 跳变。必须采用 blockwise theorem 并加入 reset/jump 项，或在 full corrector 后明确定义 e_W 重置条件。

M6. 证明稳定 critic branch / policy admissibility 的保持【强制】

HJB residual 下降不保证预测/校正后的 critic 仍处于 stabilizing/admissible branch。必须建立 Lyapunov/admissibility trust gate，使 predictor、corrector 和 homotopy intermediate policies 都满足局部稳定裕度；失败时回退到最近 verified anchor。

M7. 给出 Galerkin Jacobian 可逆的可检查条件【强制】

不能仅把 A_W 可逆写成假设或数值检查。应针对选定的 Petrov–Galerkin residual / basis / data stack 给出局部 inf-sup、coercivity 或 Newton–Kantorovich 条件，并说明如何在线估计 conditioning margin。

M8. 完整稳定性增长条件【强制】

practical stability theorem 需明确 ||V_X|| <= c_x ||X|| 和 ||V_theta|| <= c_theta ||X||^2 等成立条件，并将 policy error、parameter drift 和 realization error纳入最终 UUB 半径。

M9. 修复 targeted-probe 的复杂度矛盾【强制】

当前未来 probe sequence / information optimization 本质上是短时域 experiment-design OCP，却又宣称不引入 finite-horizon OCP，造成 underreported complexity。

推荐的最小充分修复：使用安全有限波形库或 1–3 个参数的解析 probe family，仅在线选择幅值、频率、持续时间；证明其可以增加缺失 decision-relevant information，同时保持持续接触有效域和扰动上界。

若保留 probe OCP，则必须承认其模块地位，并给出变量规模、求解频率、deadline 和 fallback；不能继续宣称没有 finite-horizon OCP。

M10. 把 M_t / state distribution 变成可执行对象【强制】

必须明确 rho_t 的来源，以及 E[P_hat^T R P_hat] 是通过固定 state stack、occupancy approximation、quadrature 还是在线 buffer 计算；同时给出计算量与误差界。

M11. 完成 NNBO-specific 与实现层证明义务【强制】

- 从 NNBO 的具体 F、G、q 展开 F_theta、G_theta、q_theta；
- 正式完成 T1–T7 的 lemma/theorem/proof，不能以 NEOC 原定理替代 estimated/approximate 情形；
- 给出 beta_t、epsilon_C、epsilon_H、r_theta、mu 等保守上界或在线估计规则；
- 证明 force-to-reference root 的存在、局部唯一和 Jacobian 非退化，并传播 e_ref；
- 用 symbolic / automatic differentiation 与有限差分做 sensitivity equation 一致性检查。

7. 下一步唯一任务与严格执行顺序
======================================================================

下一步不是再做一次泛泛路线审计，而是生成“理论闭环修订版 Final Method”，并重新过同一 venue Gate。按以下顺序执行：

Step 1：修正信息几何对象。
分离 I_data、prior 与 confidence set；定义 true/approximate policy tangent；给出 robust local DSI certificate、impossibility condition 和二阶余项边界。

Step 2：修正 probe 机制与复杂度。
先尝试有限安全波形库/低维解析探测；证明 information gain 针对 decision-relevant subspace。只有该简单机制不能关闭 failure 时才允许保留 probe OCP。

Step 3：闭合 critic transport。

Step 4：闭合 admissibility 与执行链。
为所有 intermediate policies 定义 stability/admissibility gate；证明 reference root 条件和 fallback；所有 claim 以实际 applied policy/reference 为准。

Step 5：写出一个主定理，而不是继续增加平行 theorem。
主定理应从 partial identifiability 与 drift 假设出发，联合给出：robust decision sufficiency 或触发探测、critic tracking error、executable policy error、frozen performance loss 和 time-varying practical stability/UUB。

Step 6：进行理论反例和 killer-condition 检查。
至少检查：full identification 可轻易实现、P_theta 在 observation-null space 上为零/非零、A_W 病态、参数变化越出 trust region、corrector 不收敛、reference root 消失、probe 无安全 authority。说明每种情况下方法简化、触发探测、重锚或回退到 baseline 的逻辑。

Step 7：按经验分布重新验收。
与 NNBO、NEOC、时变 critic optimal impedance、application-oriented identification、full-ID+NEOC、forgetting/concurrent-learning NNBO、robust NNBO 及 T-RO 同 morphology exemplar 做成对比较。不得仅做文献列表或数字评分。

Step 8：只有所有实验前门槛通过后，冻结新的 Final Method；随后停止并等待用户确认。未经确认不得进入实验。

9. 当前方法的简化竞争者与 falsifiers【必须持续对抗】
======================================================================

1. full identification + NEOC：若安全、低扰动数据下 I_data 稳定满秩且估计足够快，DSI 的必要性显著下降，应简化方法。

2. forgetting/concurrent-learning NNBO：若其在相同 drift、数据和算力下能达到相同 moving-optimum tracking error，则 NEOC predictor 的必要性不成立。

3. robust/fixed NNBO：若一个不确定集鲁棒策略在相同目标下达到相同性能且无需主动信息，decision-sufficiency/probing 的复杂度不成立。

4. P_theta 与 observation-null space 的关系：若不可辨方向始终 decision-null，探测模块应删除；若它们强 decision-relevant 且没有安全可用 excitation，则当前问题在给定信息结构下不可解，不能靠算法包装。

5. critic branch：若 A_W 在目标工作域无法保持适当 conditioning，或 intermediate policy 无法保持 admissible，则不能主张在线 tangent transport，应退化为较低频 re-solve / verified anchor 更新。
