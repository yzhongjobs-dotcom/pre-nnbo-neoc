R15 Final Research Problem and Method — Theory-Reconverged
DS-ANEOC-NNBO: Decision-Sufficient Adaptive Neighboring-Extremal NNBO
日期：2026-09-09
状态：实验前完整 Method；下一阶段仅做正式证明与逐式复核，不展开实验

======================================================================
0. 最终结论
======================================================================

最终研究问题保持为：

  在持续接触未知、缓慢时变的非线性黏弹软环境时，有限且低扰动的在线接触数据可能
  只能部分辨识环境。如何判断这些信息是否足以确定当前最优阻抗决策，并在环境估计
  改变、HJB 最优闭环律随之移动时，无需从旧 critic 被动重新学习，持续跟踪瞬时冻结
  参数最优策略，从而保证可量化的策略跟踪误差、交互次优性与闭环稳定裕度？

主要矛盾是：

  partial information 下的 moving-optimum tracking。

最终技术路线是：

  NNBO physical/HJB backbone
  + closed-loop HJB-NEOC sensitivity
  + decision-sufficient information gate
  + trust-region predictor-corrector / homotopic re-anchoring。

路线名称：

  Decision-Sufficient Adaptive Neighboring-Extremal NNBO（DS-ANEOC-NNBO）。

选择 NEOC 而不选择 IDOC 作为主求导机制。原因不是 NEOC 更新更“新”，而是数学对象
完全对齐：NNBO 求解连续时间、无限时域、非线性、闭环 HJB policy；NEOC 正是对这种
闭环 HJB 解随参数变化的函数导数。IDOC 的原始对象是离散有限时域、带约束最优轨迹
的 KKT solution map。把 IDOC 直接搬到 NNBO，必须额外构造 trajectory NLP 或对非凸
Bellman-loss stationary point 求导；这两者均比直接微分 HJB/Galerkin 方程更间接，
并引入不必要的 KKT/Hessian 可逆性负担。

但原始 NEOC 不能直接解决本问题，因为它假设：参数变化已知、名义最优值函数已知、
扰动足够小，并未闭合在线参数估计误差、近似 critic、部分可辨识性和连续漂移下的
累计误差。因此本方法必须完成“estimated-parameter + approximate-HJB + online
re-anchoring”扩展；不能把 NNBO 与 NEOC 两篇论文简单串联。

创新性按当前任务前提冻结为已达标，本稿不重新审计；以下只收敛 Problem fit、
Method fit / necessity、理论正确性、复杂度合理性与可行边界。

======================================================================
1. 问题边界与正确 comparator
======================================================================

1.1 系统与软环境

主实例为持续压入区间内的 Hunt–Crossley（HC）环境：

  f = B_e delta^n delta_dot + K_e delta^n,
  delta = x-x_e,
  theta = [log K_e, log B_e, n]^T in Theta。

采用正值参数化保证 K_e>0、B_e>0，并限定：

  delta_min <= delta <= delta_max,
  Theta 为紧集，theta(t) 分段 C1，||theta_dot|| <= v_theta。

接触建立、分离、冲击、一般 hybrid/multi-contact switching 不在主理论内。

NNBO 的增广辅助系统统一写为：

  X_dot = F(X,theta) + G(X,theta)u + d(X,t),                 (1)

其中 u=f 为 interaction-force decision，d 汇总 HC 失配、测量误差与位置内环实现误差。
阶段代价写为：

  l(X,u,theta) = q(X,theta) + u^T R u,  R=R^T>0,            (2)

其中 q 包含 NNBO 的 tracking term 与 uncertainty-compensation term。

1.2 comparator 必须冻结清楚

对固定 theta，定义 frozen-parameter infinite-horizon optimum：

  V*(X,theta) = min_u integral_0^infinity l(X(t),u(t),theta)dt,
  pi*(X,theta) = argmin_u H(X,u,V_X*,theta)。                (3)

当 theta(t) 随时间变化且未来变化未知时，本文不声称求得整个非自治未来问题的全局最优
策略。正确 comparator 是每个时刻的 frozen-parameter HJB policy pi*(.,theta(t))。
主结论是跟踪该移动闭环律，并给出有限时域性能分解；这是可定义、可证明且与在线阻抗
适应一致的目标。

1.3 研究问题的两个不可分割子条件

  P1 Information sufficiency：当前数据看不见的 theta 方向是否都会保持 pi* 不变？

  P2 Optimality tracking：当 theta_hat 改变时，如何以一阶正确、二阶余项的方式移动
     value/policy，而不是重新等待 critic 收敛？

只解决 P1，会继续执行 stale policy；只解决 P2，会沿可能错误且不可辨识的 theta_hat
高速移动。完整 Method 必须用同一个 policy sensitivity 同时闭合 P1 与 P2。

======================================================================
2. 固定参数 HJB 与闭环 NEOC 的精确推导
======================================================================

以下先令 d=0，并假设最优 action 位于输入集合内部。记：

  p(X,theta) = grad_X V*(X,theta),
  A(X,theta) = G R^{-1} G^T。

HJB 方程为：

  0 = p^T F + q - (1/4)p^T A p,                            (4)

最优交互力为：

  pi*(X,theta) = -(1/2)R^{-1}G^T p。                       (5)

对第 j 个环境参数定义值函数灵敏度：

  xi_j(X,theta) = partial V*(X,theta)/partial theta_j。     (6)

对式 (4) 关于 theta_j 求导，并利用 envelope/stationarity 消去不必要的
partial pi*/partial theta_j 项，得到线性 transport PDE：

  grad_X xi_j^T F_cl
  + p^T F_theta_j + q_theta_j
  - (1/4)p^T A_theta_j p = 0,                              (7)

其中：

  F_cl = F + G pi* = F-(1/2)A p。                          (8)

边界条件为 xi_j(0,theta)=0。若名义闭环可容许并渐近稳定，则沿
y_dot=F_cl(y,theta)、y(0)=X 有：

  xi_j(X,theta)
    = integral_0^infinity [p^T F_theta_j + q_theta_j
       -(1/4)p^T A_theta_j p]_(y(t),theta) dt。             (9)

最优策略对 theta_j 的闭环灵敏度为：

  P_j(X,theta) := partial pi*/partial theta_j
    = -(1/2)R^{-1}[G_theta_j^T p + G^T grad_X xi_j]。       (10)

将各列拼成 P_theta=[P_1,...,P_p]。对小参数变化 Delta theta：

  V*(X,theta+Delta theta)
    = V*(X,theta) + xi(X,theta)^T Delta theta
      + O(||Delta theta||^2),                              (11)

  pi*(X,theta+Delta theta)
    = pi*(X,theta) + P_theta(X,theta)Delta theta
      + r_pi,                                              (12)

  ||r_pi|| <= (L_pi,2/2)||Delta theta||^2。                (13)

式 (7)–(13) 是最终方法的理论核心。它们直接说明：环境变化移动的不是一个孤立 critic
weight，而是 parameterized HJB closed-loop solution branch；NEOC 给出的正是该分支的
切向量。

======================================================================
3. 从精确 NEOC 到 NNBO critic 的可计算形式
======================================================================

3.1 不能直接继承原始 NEOC 的理想假设

实际 NNBO 只有近似值函数：

  V_W(X)=W^T phi(X),                                       (14)

参数由在线数据估计，且 HJB 只能在有限 basis/data 上满足。因此必须明确区分：

  - exact HJB branch V*(.;theta)；
  - finite-dimensional Galerkin branch V_N*(.;theta)；
  - 当前在线 iterate V_W。

不把三者混为同一个 W，也不把 approximation error 省略。

3.2 Anchor HJB root

令：

  p_W = grad_X V_W,
  pi_W = -(1/2)R^{-1}G^T p_W,

  delta_H(X;W,theta)
    = p_W^T F + q -(1/4)p_W^T A p_W。                      (15)

在固定 anchor data/test set D 与测试函数 chi_1,...,chi_m 上构造 Petrov–Galerkin
HJB residual：

  r_a(W,theta;D)
    = sum_i omega_i chi_a(X_i)delta_H(X_i;W,theta),
    a=1,...,m。                                             (16)

定义局部 anchor root：

  r(W_N*(theta),theta;D)=0。                               (17)

这比对单个瞬时 Bellman residual 更新更适合作为理论对象：它是有限维 HJB 方程，而非
瞬时 rank-one excitation；D 在一次 continuation block 内冻结，更新 D 时执行重锚定。

假设在目标局部分支上：

  A_W := partial r/partial W 可逆，
  sigma_min(A_W) >= mu_A>0。                               (18)

这里只主张局部分支 regularity，不声称一般 nonlinear critic objective 全局强凸或全局
唯一。

3.3 Galerkin-NEOC tangent

对式 (17) 隐式求导：

  C_theta := D_theta W_N*(theta)
           = -A_W^{-1}B_theta,
  B_theta := partial r/partial theta。                     (19)

这里的式 (19) 与 NEOC 数值方法一致：它是对 Galerkin HJB 方程求导。IDOC/IFT 只提供
一般数学解释，不再充当主算法。一次分解 A_W 后，对低维 HC 参数的多个右端求解即可。

相应的近似值函数和策略灵敏度为：

  xi_hat(X)=C_theta^T phi(X),                              (20)

  P_hat_j(X)
    = -(1/2)R^{-1}[G_theta_j^T p_W
       + G^T grad_X(phi^T C_theta(:,j))]。                 (21)

若直接对 online Bellman-loss stationary point 求导，所得 tangent 是训练目标最优点的
导数，未必是 HJB 解的 Galerkin 导数；因此最终方法采用式 (16)–(21)，避免此前路线中
“empirical optimizer sensitivity 与 closed-loop HJB sensitivity 是否同一对象”的歧义。

3.4 Corrector

预测之后使用同一个 HJB residual 做 damped Newton / policy-evaluation correction：

  W^+ = W^- - alpha A_W(W^-,theta_hat;D)^{-1}
                    r(W^-,theta_hat;D),                   (22)

其中 alpha 由 residual decrease/trust region 决定。若不希望每周期更新 Jacobian，可在
一个 continuation block 内复用 factorization；当 conditioning、residual 或 data-stack
gate 失败时重新分解并重锚定。

======================================================================
4. Decision-sufficient information gate
======================================================================

4.1 观测几何

对接触观测 y_i=h(z_i,theta)+noise，令：

  Phi_i = partial h(z_i,theta_hat)/partial theta,

  I_t = sum_i Phi_i^T Sigma_i^{-1}Phi_i + Lambda_prior。   (23)

I_t 的零空间表示当前历史在局部无法区分的参数方向。I_t 可以来自 recursive MAP / 
damped Gauss–Newton/EWRLS 的窗口化近似，但不能把其逆无条件称为精确 posterior。

4.2 决策几何由 NEOC policy tangent 给出

对于式 (2) 的 control-affine/quadratic-action HJB，Hamiltonian action gap 恰为：

  H(X,u,p*,theta)-H(X,pi*,p*,theta)
    = (u-pi*)^T R(u-pi*)。                                 (24)

因此对任务相关状态分布 rho_t 定义：

  M_t = E_(X~rho_t)[P_hat_theta(X)^T R P_hat_theta(X)]。   (25)

局部 decision-null directions 为 ker(M_t)。这里无需另造 task Hessian；R 已由 HJB 的
精确 action gap 给出，减少一个不可验证的额外对象。

4.3 Decision-Sufficient Identifiability（DSI）

当前信息足以支持一阶最优决策，当且仅当：

  ker(I_t) subseteq ker(M_t)。                             (26)

在有限维 PSD 情形，这等价于存在有限 gamma_t 使：

  M_t <= gamma_t I_t。                                    (27)

对置信椭球 E_t={e:e^T I_t e<=beta_t^2}，若式 (26) 成立，则最坏一阶决策损失为：

  sup_(e in E_t) e^T M_t e
    = beta_t^2 lambda_max(I_t^{dagger/2}M_t I_t^{dagger/2}), (28)

其中 dagger 为 Moore–Penrose 逆；式 (26) 保证 I_t 的零空间不会漏掉 M_t 的有效方向。

若式 (26) 不成立，则存在 v in ker(I_t) 且 v^T M_t v>0：数据在 v 上一阶局部不可区分，但
最优阻抗会一阶变化。此时任何只利用同一数据历史的算法都不能给出统一的局部近最优
证书；更快的 critic 或更精确的 continuation 不能修复信息缺失。

4.4 只在必要时激励

若式 (26) 成立且式 (28) 低于阈值，不进行额外 excitation。若失败，则在保持持续接触
与幅值/速率边界内选择最小代价 probe nu：

  min_nu  J_probe(nu)
  s.t.    M_t <= gamma_bar I_t^+(nu),
          delta_min<=delta<=delta_max,
          ||nu||<=nu_max。                                 (29)

I_t^+(nu) 是候选短时交互后的预测信息。式 (29) 的角色只是恢复 decision sufficiency，
而非追求全部 HC 参数的最大 Fisher information。没有独立 barrier/constraint proof 时，
这里只声称 bounded probing burden，不声称 hard safety certificate。

======================================================================
5. Adaptive NEOC predictor-corrector
======================================================================

5.1 参数更新

估计器输出 theta_hat_k、信息矩阵 I_k/置信界 beta_k，以及：

  Delta theta_hat_k = theta_hat_(k+1)-theta_hat_k。         (30)

5.2 一阶预测

在 anchor tangent C_k 下：

  W_(k+1)^- = W_k + C_k Delta theta_hat_k。                (31)

等价的闭环策略预测是：

  pi_(k+1)^-(X)
    = pi_k(X)+P_hat_theta,k(X)Delta theta_hat_k。           (32)

只保存 weight predictor 作为实现；式 (32) 用于误差与稳定性分析，不再并行维护第二个
actor。

5.3 Corrector 与重锚定

对新 theta_hat_(k+1) 执行式 (22) 的一到少量步 correction。触发下列任一条件时重建
anchor、更新 D、重新分解 A_W 并重算 C_theta：

  - ||r(W,theta_hat;D)|| > epsilon_H；
  - sigma_min(A_W) < mu_min 或 condition(A_W)>kappa_max；
  - DSI gate/置信界失败；
  - 实际策略变化超出 trust region；
  - 持续接触条件失效。

5.4 大变化不是一次线性外推

设允许的局部步长为 r_theta。若：

  ||Delta theta_hat_k|| > r_theta，

则取：

  N_k = ceil(||Delta theta_hat_k||/r_theta)                (33)

个 homotopy substeps，每步 predictor 后做 residual correction/verification。r_theta 由
二阶余项、critic sensitivity error、参数置信界和闭环稳定裕度联合决定，而非仅凭参数
相对变化百分比经验设置。

5.5 为什么 corrector 是必要的

纯 NEOC Euler predictor 每步都有 O(||Delta theta||^2) 余项；长时间运行会累计。周期性
corrector 将误差压回同一 HJB root 邻域，重锚定则处理 tangent 曲率、basis/data 变化与
估计跳变。因此最终路线不是“NEOC 一次修正”，而是 adaptive predictor-corrector。

======================================================================
6. Position-based impedance realization closure
======================================================================

高频层保留 NNBO 的 position-based implementation，不把 force policy 直接当作已经实现
的物理阻抗。由 HC 关系与 pi_W 求 reference/root，采用 safeguarded Newton/line search。

在主理论域内要求：

  - reference equation 存在局部唯一根；
  - root derivative 的绝对值 >= m_ref>0；
  - Newton iterate 始终保持 delta>=delta_min；
  - inner position loop 的 force-realization error e_ref 有界。

实际执行误差统一写为：

  e_u = u_applied-pi*(X,theta)
      = e_est + e_NEOC + e_Galerkin + e_corrector + e_ref。 (34)

最终性能与稳定性定理只对 e_u 的总界成立，不能用“位置内环足够准确”删除 e_ref。

======================================================================
7. 最小且闭合的理论链
======================================================================

T1 — Exact closed-loop HJB-NEOC sensitivity

假设 F、G、q 对 (X,theta) 至少为 C2，R>0，且 V*(.;theta) 的 solution map 关于 theta
二次连续可微、所需混合导数存在并连续；名义最优
闭环可容许且指数稳定。则 xi_j 满足式 (7)–(9)，P_j 满足式 (10)，且式 (13) 的二阶
余项在紧集上一致成立。

证明主线：对 reduced HJB 求参数导数；由 Hamiltonian stationarity 使用 envelope
theorem；沿 F_cl 特征线积分；最后对 solution map 作 Taylor 展开。

T2 — Decision sufficiency and impossibility boundary

对局部线性观测模型与一阶策略映射，式 (26) 成立当且仅当所有 observation-null
direction 均为 decision-null direction。若成立，式 (28) 给出有限 worst-case 一阶
Hamiltonian loss；若失败，则存在一阶局部不可区分环境对，其 frozen-optimal policies 一阶
分离，故任何仅依赖当前历史的 deterministic controller 至少在其中一个环境产生正的
局部决策损失。

证明主线：PSD null/range 等价、广义 Rayleigh quotient，以及 two-point indistinguishability
argument。

T3 — Galerkin tangent correctness and approximation error

若式 (17) 的 root regular 且式 (18) 成立，则式 (19) 是 finite-dimensional HJB root
W_N*(theta) 的精确局部导数。令 C_theta^proj 是 exact sensitivity 在同一 basis/test
space 上的理想投影解；若计算 Galerkin operator 与该理想投影 operator 的矩阵、右端
误差分别有界 epsilon_A、epsilon_B，则：

  ||C_theta-C_theta^proj||
    <= ||A_W^{-1}||(epsilon_B+epsilon_A||C_theta^proj||),   (35)

再由式 (21) 得：

  ||P_hat_theta-P_theta||
    <= c_G epsilon_gradV + c_phi ||C_theta-C_theta^proj||
       + epsilon_proj
       + epsilon_model。                                   (36)

这一定理把 basis/HJB residual、operator conditioning 与 policy-sensitivity error 显式
连接，避免把数值线性方程“可解”直接等同于真实 HJB derivative 正确。

T4 — Predictor-corrector tracking recurrence

令 e_k^W=W_k-W_N*(theta_hat_k)。若 D_theta W_N* 为 Lipschitz、常数 L_C，计算 tangent
误差不超过 epsilon_C，corrector 在 trust region 内收缩率 rho_c<1、残余求解误差
epsilon_r，则：

  ||e_(k+1)^W||
    <= rho_c[||e_k^W||
       + epsilon_C||Delta theta_hat_k||
       +(L_C/2)||Delta theta_hat_k||^2] + epsilon_r。       (37)

因此 bounded parameter increments 下 tracking error UUB；在 exact tangent/corrector 极限，
predictor 的局部移动误差由不补偿时的一阶 O(||Delta theta||) 降为二阶
O(||Delta theta||^2)。

T5 — Frozen-parameter exact performance identity

固定 theta、d=0。对任何使状态收敛且代价有限的 admissible u，令
e_u(X)=u(X)-pi*(X,theta)，则由式 (24)：

  J_theta(u;X_0)-V*(X_0,theta)
    = integral_0^infinity e_u(X(t))^T R e_u(X(t))dt。       (38)

这不是启发式 regret proxy，而是当前 control-affine/quadratic-action HJB 下的精确
performance-difference identity。若 ||e_u(X)||<=c_e||X|| 且闭环指数稳定，则式 (34)–(38)
给出有限 interaction suboptimality bound。

T6 — Slowly varying parameter performance decomposition

在 d=0 时，对有限时域 [0,T]、瞬时 frozen value V*(X,theta(t))，有：

  J_[0,T](u)
    = V*(X_0,theta_0)-V*(X_T,theta_T)
      + integral_0^T e_u^T R e_u dt
      + integral_0^T V_theta*(X,theta)^T theta_dot dt。     (39)

式 (39) 将可控的 policy-tracking loss 与不可避免的 environment-drift term 分开。若单步
参数变化为 h，stale nominal policy 的控制误差一般为 O(h)，而一阶 NEOC predictor 在
理想条件下为 O(h^2)；相应的二次 action-gap 从 O(h^2) 降为 O(h^4)，直至 estimator、
Galerkin、corrector 与 realization error floor 占主导。该阶数只对局部 frozen-policy
tracking 成立，不外推为未知未来非自治最优控制的全局 regret rate。

T7 — Closed-loop practical stability

设 V* 满足：

  c1||X||^2 <= V* <= c2||X||^2,
  dot V*|_(pi*,theta fixed) <= -c3||X||^2，

且在主域内：

  ||e_u(X,t)|| <= kappa_u||X||+bar_e_u,
  ||d||<=bar_d,
  ||V_theta*||<=c_theta||X||^2，
  ||V_X*G||<=c_g||X||。

则存在 c_d>0 使：

  dot V* <= -mu||X||^2
             +(c_g bar_e_u+c_d bar_d)||X||,                (40)

  mu = c3-c_g kappa_u-c_theta v_theta。

若 mu>0，则闭环 UUB，ultimate radius 与 bar_e_u、bar_d 成正比；若二者为零，则恢复
渐近稳定。式 (40) 同时给出 trust-region gate：任何 NEOC/估计/critic/内环误差之和
都不得耗尽 mu。

注意：存在持续非零 bar_e_u 或 bar_d 时，不能再声称原始无限时域积分代价必然有限；
此时使用式 (39) 的有限时域性能界与 UUB 结论。这一区分必须保留。

8. 在线算法顺序
======================================================================

低频 adaptation cycle：

  1) 仅在持续接触有效域采集 state/force 数据；
  2) 更新 theta_hat、I_t、beta_t；
  3) 用上一个 anchor 的 C_theta 执行式 (31) predictor；
  4) 用式 (22) 做少量 HJB residual correction；
  5) 必要时更新 D、求解式 (17)，重建 anchor；
  6) 一次分解 A_W、多右端求解式 (19)，得到 C_theta；
  7) 由式 (21)、(25) 计算 P_hat_theta、M_t；
  8) 检查 DSI、worst-case decision loss、HJB residual、conditioning 与 stability margin；
  9) DSI 失败时才执行式 (29) 的 bounded targeted probe；
 10) 高频层发布 pi_W，并通过 safeguarded reference solver 实现；gate 失败时保持最近
     已验证 anchor/baseline，而不做无界外推。

计算结构：HC 参数通常为 3 维；每个 anchor 对 m x m 的 A_W 分解一次，随后解 3 个
右端。PDE 不在控制周期内网格求解，NEOC sensitivity 与 critic 共用 basis、data 和
factorization。新增计算位于低频适应层，不引入 finite-horizon OCP、第二 actor 或第二
critic。

======================================================================
9. Method fit / necessity 判定
======================================================================

Problem fit：通过。

  问题直接对应 NNBO 在未知、缓慢时变软环境中的真实失效链：数据只部分识别环境；
  参数估计一变，HJB optimum 移动；原 critic 继续表示旧问题。目标不是更快估计所有
  材料参数，而是在信息足够时持续维持近最优交互，在信息不足时明确触发最小必要激励。

Method fit：通过。

  NEOC 的求导对象与 NNBO 完全同构：continuous-time infinite-horizon closed-loop HJB。
  同一 P_theta 自然产生两件必需结果：它定义 decision-relevant parameter subspace，
  又给出 moving policy/value 的切向预测。不存在为了增加结构而并列拼接两个导数模块。

Necessity：通过，且可做消融式逻辑检验。

  - 删除 DSI gate：无法区分 harmless unidentifiability 与 policy-changing ambiguity；
  - 删除 NEOC predictor：theta_hat 更新后仍执行 stale critic；
  - 删除 corrector/re-anchor：二阶截断、basis 与估计误差长期累计；
  - 删除 confidence/trust gate：已知小扰动 NEOC 被错误用于未知大变化；
  - 删除 realization closure：理论 force policy 与实际 position-based impedance 脱节。

复杂度合理性：通过。

  只增加一个与 critic basis 同维的线性系统及低维多右端求解；homotopy 仅在大变化时
  触发。IDOC trajectory KKT、MPC 和额外 actor 均不是解决当前主要矛盾的必要结构。

可行性：条件通过。

  算法所需 F_theta、G_theta 对 HC 模型可解析获得；C_theta 由现有 critic basis/data 的
  HJB residual 线性化得到；theta 维数低。真正需要在实验前先验证的是 A_W conditioning、
  sensitivity residual 和 stability-margin gate，而不是先跑任务性能实验。

======================================================================
10. 不得越过的理论边界
======================================================================

  1) 只覆盖持续接触 compact domain，不覆盖接触切换/冲击；
  2) 主 HJB/NEOC 推导要求 optimal action 位于约束内部；force saturation 激活时需改为
     constrained HJB/variational inequality，不能沿用式 (10)；
  3) 只保证 local regular solution branch；A_W 奇异或 policy branch 切换时必须重锚；
  4) NEOC 使用 estimated Delta theta，参数误差必须经式 (28)、(34) 进入总界；
  5) Galerkin tangent 正确不等于 exact HJB tangent 正确，必须保留式 (35)–(36)；
  6) frozen-optimal tracking 不等于预知未来 theta(t) 的非自治全局最优；
  7) bounded probe 不等于 hard safety；没有 barrier/certificate 不作安全宣称；
  8) 持续扰动下使用 finite-horizon decomposition + UUB，不滥用 infinite-horizon regret。

12. 最终冻结表述
======================================================================

推荐方法名：

  Decision-Sufficient Adaptive Neighboring-Extremal Neural Optimal
  Impedance Control（DS-ANEOC-NNBO）

一句话研究问题：

  如何在未知缓慢时变软环境只能被部分辨识时，仅辨识会改变 HJB-optimal impedance 的
  环境方向，并沿闭环 HJB 解流形预测—校正地运输 NNBO critic，以持续跟踪瞬时最优
  交互律？

一句话技术路线：

  对 NNBO 的参数化 HJB/Galerkin 方程做 closed-loop NEOC 微分，以所得 policy tangent
  同时构造 decision-sufficiency 判据和 critic predictor，并用 confidence-aware
  corrector、homotopy 与 stability gate 限制未知参数误差和线性化余项。

最终因果链：

  partial contact information
  -> observation-null directions
  -> NEOC policy tangent identifies decision-null/relevant directions
  -> DSI decides whether existing data are sufficient
  -> targeted probe only when information is insufficient
  -> Galerkin-NEOC transports the moving HJB critic
  -> corrector/homotopy prevents accumulated tangent error
  -> realization error and drift enter one performance/stability bound。

这是当前最终 Method。后续理论工作只允许补完证明、常数和 NNBO-specific 展开；不得再
无依据增加 MPC、第二网络、额外安全滤波器或新的 paper-level objective。
