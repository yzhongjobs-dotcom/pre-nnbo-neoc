======================================================================
0. 最终结论
======================================================================

最终研究问题：

在 consequence-defined continuous soft-contact tasks 中，当环境力学使固定 raw force/tracking objective 无法保持同一显式交互偏好时，如何在 task-relevant context sufficient 的条件下，将该偏好 transport 为局部、可辨识的 impedance-control objective，并通过 closed-loop differentiable constrained optimization 产生满足 robust feasibility 与 passivity 的可执行 K、B？

最终核心 Idea：

NNBO 提供 nonlinear soft-contact optimal-interaction problem；implicit differentiation 提供 closed-loop task consequence 对每次 inner optimal-impedance solution 的局部 sensitivity。二者之间用一个新的科学对象连接：

  consequence-space utility
  -- transport/pullback through sufficient environment mechanics -->
  interaction-space objective metric。

Method 不让网络无约束地猜 Q、R，而是将 objective 分解为：

  explicit task preference p
  × integrable consequence map g_psi(y;chi_hat)
  → normalized PSD metric W(chi,x,p)
  → Q、R 及必要的 cross term N。

环境改变 mechanics-to-consequence realization；任务改变 preference。训练期利用高保真 closed-loop consequence objective：IDOC 计算每次 inner solve 的局部 VJP，outer adjoint 贯穿 repeated replanning；部署期仅估计 sufficient context、生成 metric、在线求解并发布通过约束复验的 K、B。

三项硬门槛：

Problem fit：PASS WITH NARROWED SEMANTICS。问题只针对真实效用定义在 deformation/energy/stress/contact-quality 等 consequence 上的 soft-contact tasks；若真实任务就是固定力/位置误差，则 fixed objective 正确，本文不激活。

Method fit / necessity：CLOSED ONLY IN G1-G6 REGIME。除 non-proportional pullback、analytic/online route 不充分和 nonzero decision sensitivity 外，还必须满足 online context sufficiency、aggregate closed-loop differentiable supervision 与 inner strong regularity。IDOC 是所选 backend，不是唯一可能的 differentiable solver。

Scientific strength：T-RO-STRONG AT THEORY-DESIGN LEVEL。核心强度来自 fixed-metric impossibility、context-aliasing impossibility、integrable objective transport、closed-loop constrained hypergradient、performance-regret 与 passivity/feasibility 的统一闭合，而不是 NN、MPC 或 IDOC 的模块数量。

1. Operating Envelope 与不声称的范围
======================================================================

1.1 目标范围

- 连续物理接触中的软环境；
- 环境刚度、阻尼、非线性指数或局部几何在一个 compact family 内变化；
- 机器人具有位置/速度与交互力测量；
- online context chi_hat=[theta_HC_hat,xi_task] 对所声明 consequence 的 optimal-action equivalence class sufficient；xi_task 仅在 HC port parameters 不充分时包含必要的局部几何、成像、材料类别或 history feature；
- 高层 task preference 可由任务协议或用户显式给出；
- 目标控制量是可执行 Cartesian stiffness K 与 damping B，以及必要的 reference/feedforward；
- 训练可离线使用多环境数据、高保真 closed-loop model/oracle；
- 部署需要实时 constrained impedance optimization，但不要求高频网络反向更新。

1.2 明确不声称

- 不声称从环境唯一恢复人的真实偏好；
- 不声称 learned R 本身提供安全保证；
- 不声称处理任意接触建立/脱离、冲击和 stick-slip 非光滑切换；
- 不声称全局最优或全局可微；
- 不声称完整 HC 参数在自然交互中总可辨识；
- 不声称对人体/临床安全作最终证明；
- 不把环境估计器、IDOC primitive、energy tank 或 solver 分别包装为独立创新。

理论主结果首先针对 continuous-contact interior：normal penetration delta >= delta_min > 0。接触建立/丢失由独立 hybrid guard/withdraw 处理，不进入主 hypergradient theorem。

1.3 Key Assumption Registry

A1（contact regularity）：在目标 continuous-contact mode 与 trust region 内，robot dynamics、HC/contact map 与 consequence map 至少 C^3，且接触坐标系连续可选。

A2（preference specification）：高层偏好 p 由任务协议或用户显式指定；环境只改变该偏好到实时变量的力学校准，不负责猜测偏好。

A3（local objective geometry）：在去除不可辨识/无决策作用方向后，复合 consequence objective 在保留的 raw-variable subspace 上具有统一正曲率 margin（因而覆盖 feasible tangent 的相关方向）；若存在显著负曲率，则本文的 convex local-metric realization 不适用，必须改用非凸 inner solver 并重新证明局部性质。

A4（training oracle）：训练期存在可微的 high-fidelity closed-loop consequence model/objective，或至少存在可生成近优闭环轨迹的 oracle；若只有 scalar black-box outcome，则不能使用本文的 IDOC hypergradient。

A5（context sufficiency and accuracy）：g_chi 在目标 task-relevant equivalence class 上是 chi_hat=[theta_HC_hat,xi_task] 的单值 Lipschitz function，未分辨环境只能具有相同 optimal-action ranking；真实 context 属于估计集合且 decision-sensitive directions 的误差有界。若两个不可区分 context 产生相反 optimal-action ranking，则任何 learner 都无解。

A6（inner regularity）：部署对应的 inner local optimum 满足第 9 节的 LICQ、SOSC、strict complementarity/strong regularity，并由 warm start 保持在同一局部分支。

A7（execution closure）：低层阻抗实现误差、离散化误差和时延具有可验证上界；否则 planned K、B 不能推出 executed behavior。

A8（safety closure）：存在可行初值、robust tightening、backup policy 与相应 terminal invariant set；若只满足其中一部分，安全结论相应降级为 verified one-step feasibility。

A9（scientific nontriviality）：第 3.7 节 necessity conditions 成立，且 analytic pullback 留有 decision-relevant residual；否则应使用 fixed metric 或纯 analytic pullback，而不启用学习模块。

2. 系统、接触与可执行阻抗模型
======================================================================

2.1 Robot dynamics

关节空间动力学：

  M(q) qddot + C(q,qdot) qdot + g(q)
  = tau + J(q)^T f_e + d_r，

其中 q in R^n，末端位置 x=h(q)，f_e 是环境施加的 wrench，d_r 是有界未建模项。

采用 operational-space impedance realization：

  tau = tau_comp
        + J^T [f_ff - K(x-x_r) - B(xdot-xdot_r)]，

其中 K=K^T>0、B=B^T>0。把 robot dynamics、controller 和 environment force 联立，得到用于 inner optimization 的 closed-loop map：

  s_{k+1}=F_cl(s_k,a_k;theta)+w_k，

  a_k=[x_r,k, f_ff,k, K_k, B_k]。

这里 F_cl 必须包含实际 controller interface；不能只求一个 desired force 后假定存在唯一 K、B。

2.2 Soft-contact dynamics

沿接触法向的 Hunt-Crossley 基础模型：

  f_n = K_e delta^n + B_e delta^n deltadot，

  theta=[K_e,B_e,n,theta_g]，

其中 theta_g 可包含局部几何或必要的低维 residual 参数。多维 wrench 可写为：

  f_e = n_c f_n + f_t，

但只有在 target task 确实需要 tangential/friction adaptation 时才加入 f_t model；否则主理论保持 normal-contact 最小形式。

2.3 Environment information

复用 NNBO 的 port-dynamics 辨识结果：

  theta_hat_k = Estimator(h_k)，

  h_k={x_0:k,xdot_0:k,f_0:k,a_0:k}。

若目标 consequence 不能由 theta_HC 唯一决定，加入最小 task context：

  chi_hat_k=[theta_hat_k,xi_task,k]，

xi_task,k 可由局部几何/成像、材料类别或有限 history 获得，其选择由第 3.6 节的 context-sufficiency condition 决定，而不是任意增加感知模块。若 HC 已充分，则 xi_task,k 为空。

环境 estimator/context encoder 不是当前 paper-level novelty。若估计误差不可忽略，维护 compact set Chi_k，使：

  chi_true in Chi_k

以给定置信或 deterministic assumption 成立。objective metric 使用 chi_hat_k；hard constraints 对 Chi_k 做 robust tightening。

3. Problem Necessity：fixed objective 何时原则上失败
======================================================================

3.1 Raw interaction objective

令实时可用的 interaction features 为：

  y=[e; f_e-f_ref; v_rel; ...]，

其中 e=x-x_d。NNBO 的基础 objective 是：

  l_NNBO(y)=e^T Q e + f_e^T R f_e，

对应固定 block metric diag(Q,R)。

3.2 Consequence-space utility

真实任务关心的不是 raw y 本身，而是 physical/task consequences：

  c=g_chi(y)，

例如 normalized tracking loss、indentation/strain、elastic energy、dissipated energy、contact quality 或其他任务后果。高层 preference p 定义 utility：

  U_p(c)。

于是正确但通常过慢/不可直接部署的 objective 是：

  L_chi,p(y)=U_p(g_chi(y))。

关键结构：p 定义“重视什么”，chi 决定 raw y 意味着什么；theta_HC 是 chi 的 mechanics 子集。把二者都塞进自由 Q、R 会产生 preference–environment confounding。

3.3 一维 constructive counterexample

取 quasi-static linear contact：

  f=k_e delta，

  e=delta-d。

若真实 preference 平衡 tracking 与环境 strain energy：

  L_true=q(delta-d)^2+lambda (1/2 k_e delta^2)，

则：

  delta_true*=2q d/(2q+lambda k_e)。

若 inner controller 使用固定 force penalty：

  L_raw=q(delta-d)^2+r f^2
       =q(delta-d)^2+r k_e^2 delta^2，

其 optimum 与 L_true 对所有 k_e 一致要求：

  r(k_e)=lambda/(2k_e)。

因此，不存在跨非平凡 stiffness family 的固定 r。这里需要变化的不是 preference lambda，而是 lambda 到 force-coordinate weight 的 mechanics-conditioned realization。若真实任务本身就是固定 force penalty，则不存在这一 failure。

3.4 General pullback metric

在 operating point y_bar(chi,p) 附近，令 Delta y=y-y_bar。若 g_chi 与 U_p 三阶连续可微，则：

  L_chi,p(y)
  = L_chi,p(y_bar)
    + a_chi,p^T Delta y
    + 0.5 Delta y^T W_chi,p Delta y
    + O(||Delta y||^3)，

其中：

  a_chi,p = J_g(chi)^T grad_c U_p，

  W_chi,p
  = J_g(chi)^T H_U(p) J_g(chi)
    + sum_j [partial U_p/partial c_j] H_{g_chi,j}。

这里第二项是 nonlinear mechanics 的曲率项，通常不能表示成单一的 J_g^T H_U J_g。后续 Method 因而同时建模 consequence Jacobian 与各 consequence component 的 Hessian；仅在 stationary consequence point 或局部仿射 mechanics 下才可退化为 Gauss–Newton pullback。

若 y_bar 是 consequence objective 的 stationary reference，或 g_chi 在局部近似仿射，则 a=0 或第二项消失；否则 Final Method 必须同时适配 affine term/reference，不能只学习 Q、R。

3.5 Proposition N1：No Universal Fixed Metric

定义 T_chi 为 y_bar 处的 feasible decision tangent space。对两个环境 chi_1、chi_2，若限制在共同非退化切空间 T 上的二次型满足：

  W_chi1,p |_T != alpha W_chi2,p |_T

对所有 alpha>0 均成立，则不存在一个固定 PSD metric W_0，使其在 y_bar 的完整邻域内同时保持两个环境的全部局部 consequence ranking 与 steepest feasible descent direction。

证明要点：两个正定二次型在维数至少为 2 的开放邻域内诱导相同的射线排序，当且仅当二者正比例；若不正比例，取其 generalized eigenvectors，可构造两条 feasible directions 发生 ranking reversal。

一维 feasible manifold 不使用该排序命题，而由第 3.3 节的最优解反例证明 necessity。精确 environment dynamics 只能改变 reachable map，不能修复两个可实现 behavior 之间错误的 utility ranking。

3.6 Proposition N2：Context-Aliasing Impossibility

令 controller 只观察 statistic h(o)。若存在 chi_1、chi_2 满足 h(o_chi1)=h(o_chi2)，但对两个可执行 impedance actions a_1、a_2 有：

  J_p(a_1;chi_1)<J_p(a_2;chi_1)，
  J_p(a_1;chi_2)>J_p(a_2;chi_2)，

则任何 deterministic policy pi(h(o),p) 在两个环境输出相同 action，不可能同时最优。故 HC parameters 只有在足以区分 optimal-action equivalence classes 时才可作为完整 context；否则必须加入最小 xi_task 或缩小 consequence claim。

3.7 Problem activation conditions

Objective transport learning 被激活，当且仅当以下条件联合成立：

N-A. task 是 consequence-defined，而不是 raw force/error-defined；

N-B. 不同 chi 诱导非正比例的 consequence pullback metrics，或产生第 3.3 节类型的 optimal operating-point drift；

N-C. online statistic chi_hat 满足 Proposition N2 的 context-sufficiency requirement；

N-D. consequence objective U_p o g_chi 无法直接以实时成本进入 inner controller，且解析 contact model 不充分；

N-E. residual geometry 对 applied K、B 具有非零 decision sensitivity；

N-F. 存在 differentiable aggregate closed-loop supervision，inner solution 位于 IDOC strong-regularity region。若只有 black-box return，改用 zeroth-order/RL。

任一条件不成立，相应模块必须删除或整个问题退化为更简单方案。

4. Final Research Question 与可检验假设
======================================================================

4.1 Primary RQ

在 consequence-defined nonlinear soft-contact family 中，能否在 sufficient context 下通过 mechanics-conditioned objective transport，将显式 task preference 转换为环境相关、可辨识的 NNBO inner metric，并利用 closed-loop constrained implicit differentiation 学习其未建模部分，使直接执行的 optimal K、B 跨环境保持 consequence-level preference consistency？

4.2 Subquestions

SQ1：哪些 task/environment 组合仅需 adaptive dynamics，哪些会使 fixed interaction objective 的语义失效？

SQ2：什么 online context 足以区分 task-relevant optimal-action equivalence classes，objective metric 又在何种 excitation 下局部可辨识？

SQ3：如何将 NNBO dynamics 与 impedance realization 写成满足 IDOC regularity 的 constrained finite-horizon layer？

SQ4：如何使 closed-loop learned objective 只改变可行域内的优选次序，而不破坏 passivity、force/contact 与 actuator conditions？

4.3 Main hypotheses

H1：当 N1 的非比例条件成立时，任何 fixed Q、R baseline 都存在至少一个环境产生 consequence-level preference drift；raw-defined task 不受此结论约束。

H2：physics pullback + bounded integrable residual 满足 preference-mechanics compositionality，并具有比 free Q,R 更小的 identifiable hypothesis class；不无条件声称其表达能力或最优性能更高。

H3：在 inner KKT strong regularity 区域，每次 solve 的 IDOC VJP 与 outer closed-loop adjoint 组成对应 receding-horizon deployment 的正确局部 hypergradient，而无需展开 inner solver iterations。

H4：把安全与 passivity 写成 independent constraints 后，objective transport 不改变已证明的 feasible/safe publication property。

5. Structured Mechanics-Conditioned Objective
======================================================================

5.1 Preference representation

令 p in P 表示显式高层偏好。P 为 compact simplex 或其他规范化集合。定义 consequence-space metric：

  b_c(p)=grad_c U_p(c_bar)，

  P_c(p)=P_c(p)^T，

  p_min I <= P_c(p) <= p_max I。

p 不由 environment network 预测。相同 p 跨环境代表同一个 consequence-space preference。

5.2 Mechanics calibration

令 g_HC(y;theta_HC,x) 为 nominal HC/contact consequence map。只对该物理映射学习 bounded smooth residual：

  g_psi(y;chi_hat,x)
  =g_HC(y;theta_HC_hat,x)+r_psi(y,phi(chi_hat,x))，

  ||r_psi||_C2 <= c_g。

采用 C^3 smooth activation，并由同一个 g_psi 自动微分得到：

  J_psi=D_y g_psi，

  H_psi,j=D_y^2 g_psi,j。

因此 learned Jacobian/Hessian 必然对应同一可积 consequence map，而不是两组可任意变化的导数。C2 norm bound 同时给出 Delta J、Delta H 的界。

phi 只包含 Proposition N2 要求的最小 sufficient context：K_e、B_e、n、penetration、relative velocity，以及在 HC 不充分时必要的 xi_task；不包含 p。p 只通过 b_c(p)、P_c(p) 进入目标，从结构上保持 preference–mechanics separation。

5.3 Pullback metric parameterization

定义 exact second-order pullback estimate：

  a_psi=J_psi^T b_c(p)，

  W_hat_psi
  =J_psi^T P_c(p) J_psi
   +sum_j b_c,j(p) H_psi,j。

在 A3 下，nominal W_hat 在 retained raw-variable subspace 上具有 curvature margin gamma_0>0，并约束 residual perturbation 的 operator norm 小于 gamma_0/2；因此：

  W_tilde_psi=W_hat_psi+epsilon I

在该切空间上保持正定。若此 curvature test 失败，不得通过任意 eigenvalue clipping 把非凸物理目标伪装成等价 convex objective；该 context 应退出本文适用域，或明确采用 SQP regularization 并把 regularization bias 计入 epsilon_eta。

消除正比例 scale ambiguity：

  W_psi
  = d_y W_tilde_psi / trace(W_tilde_psi)。

分块：

  W_psi = [ Q_psi      N_psi
            N_psi^T    R_psi ]。

若 consequence map 对 e 与 f 的 cross derivatives 在 operating envelope 内可忽略，则约束 N=0，得到 structured Q、R；若 cross coupling 显著，保留 N，否则 block-diagonal objective 在理论上不是 pullback 的充分表示。

5.4 Center/affine term

定义 residual：

  r_y = y-y_bar(chi_hat,p)。

inner stage cost：

  l_eta(y)=a_psi(chi_hat,x,p)^T r_y
           +0.5 r_y^T W_psi(chi_hat,x,p) r_y。

若 reference construction 保证 a=0，则删除 a_psi；若不保证，不允许仅学习 Q、R 并忽略一阶项。这样避免把 reference mismatch 错误地交给 weight adaptation 补偿。

5.5 Objective parameter vector

  eta_psi(chi_hat,x,p)
  = [vech(W_psi), a_psi, y_bar]，

只保留在当前 operating envelope 中通过第 8 节 identifiability test 的分量。其余固定为 analytic value，避免过参数化。


======================================================================
6. NNBO-derived Constrained Direct-Impedance Inner Layer
======================================================================

6.1 Inner solution object 的选择

Online critic 逼近 infinite-horizon HJB value；IDOC 对 finite-dimensional constrained trajectory optimum 的 KKT system 求导。二者并非同一 inner solution object。

同时保留 critic training 与 trajectory-KKT differentiation 会产生：

- 两套 optimality residual；
- critic approximation error 与 trajectory solution error 无法统一；
- outer gradient 不一定对应部署时实际 policy；
- PE、online critic update 与 bilevel weight update 的双时间尺度难以证明。

因此 Final Method 采用 NNBO 的 contact model、uncertainty term 和 optimal-interaction formulation，并将可微 inner object 定义为 finite-horizon direct transcription；部署 policy 与被求导的 KKT solution 是同一个对象，不再引入第二套 critic optimum。

6.2 Decision variables

对 horizon H，令：

  z={s_0:H, x_r,0:H-1, f_ff,0:H-1,
     k_0:H-1, b_0:H-1}。

主理论采用连续的 contact frame R_c，并优化 principal impedance：

  K_k=R_c diag(k_k) R_c^T，
  B_k=R_c diag(b_k) R_c^T。

这样正定性由 smooth scalar box constraints 保证，inner problem 保持标准 C^2 NLP 形式。任意 full-SPD K、B 是扩展项，需用光滑 Cholesky 参数化并单独处理上界约束，不属于主定理。

若 damping 可由 K 与 effective inertia 在目标阻尼比下唯一给出：

  B_k = D_map(K_k,M_eff,k,zeta_d)，

则从 z 中删除 B，减少 decision dimension。只有 anisotropic damping 或 independent dissipation control 确有作用时才独立优化 B。

6.3 Inner objective

  z*(eta)=argmin_z J_in(z;eta)

  J_in
  = sum_{k=0}^{H-1}
      [ l_eta,k(y_k)
        + lambda_K ||K_k-K_{k-1}||_F^2
        + lambda_B ||B_k-B_{k-1}||_F^2
        + lambda_u ||f_ff,k||^2 ]
    + V_f(s_H)。

lambda terms 是 actuator smoothness/execution regularization，固定标度并计入 metric normalization；不得让 global W scaling 与这些项产生新的不可辨识自由度。

6.4 Equality constraints

  s_{k+1}=F_cl(s_k,a_k;theta_hat_k)，

  y_k=Y(s_k,a_k;theta_hat_k)，

以及实际 controller/discretization 所需关系。

6.5 Inequality constraints

Executable impedance：

  k_min <= k_k <= k_max，
  b_min <= b_k <= b_max，
  ||k_k-k_{k-1}|| <= Delta k_max，
  ||b_k-b_{k-1}|| <= Delta b_max。

Robot/actuator：

  q_min <= q_k <= q_max，
  qdot_min <= qdot_k <= qdot_max，
  tau_min <= tau_k <= tau_max。

Interaction：

  f_min <= f_n,k <= f_max，
  delta_k <= delta_max，
  contact_margin(s_k)>=0。

令 Theta_k 为 Chi_k 在 dynamics parameters theta_HC 上的投影。若 dynamics uncertainty 影响约束，则对 theta_HC in Theta_k 和 bounded realization error 做 robust tightening，而不是增大 R 代替。

6.6 Energy/passivity constraint

对理想 Cartesian impedance，storage 包含：

  V_k=0.5 edot_k^T M_d edot_k
      +0.5 e_k^T K_k e_k。

时变 stiffness 产生额外功率项 0.5 e^T Kdot e。引入 energy budget E_k：

  E_{k+1}
  = E_k
    + Delta t edot_k^T B_k edot_k
    - 0.5 e_k^T(K_{k+1}-K_k)e_k
    - m_track,k，

  E_{k+1} >= E_min。

该离散约束施加于所有具有 K_{k+1} 的 stage（k=0,...,H-2）；horizon 末端使用 terminal energy condition 或保持最后一个 K。

m_track,k 是由 discretization、inner-loop tracking error 与模型残差给出的非负 margin。该约束保证 stiffness increase 所需的能量不超过已耗散/储存能量。若 x_r 或 f_ff 时变，其功率必须作为显式 external supply port 计入 passivity inequality，或从 tank 中扣除一个可证明的上界；忽略该功率时不能声称 robot–environment interaction port passivity。若采用 state-independent Kdot–B stability condition，可替代 tank，但两者不并列作为双重贡献。

6.7 Terminal feasibility and publication

存在 backup policy pi_b 和 terminal set X_f，使：

  s_H in X_f，

且 pi_b 在 tightened constraints 下保持 X_f 正不变。

在线只发布完整求解、通过 nonlinear rollout 与 energy check 的第一步 a_0*。timeout、KKT degeneracy、infeasible 或 environment set 失效时，发布 incumbent/backup，而不是最后一个 solver iterate。


======================================================================
7. Outer Objective 与 Bilevel Learning
======================================================================

7.1 Training-time closed-loop consequence oracle

假设训练环境 chi_j 可由 calibrated phantom、offline high-fidelity identification、FEM/contact model 或 task-relevant sensing 获得。对 outer horizon T_out，部署同构 rollout 定义为：

  eta_t=eta_psi(chi_hat_t,s_t,p)，

  z_t*=InnerOCP(s_t,eta_t)，

  a_t=First(z_t*)，

  s_{t+1}=F_HF(s_t,a_t;chi_j)。

只有 first action 被施加，下一步必须重新估计 context 并求解。令 tau_CL(psi;chi_j,p) 为该 repeated-replanning rollout，并定义：

  J_CL,p(tau_CL;chi_j)
  =sum_{t=0}^{T_out-1} U_p(c_t)+V_out(c_T)。

J_CL 不要求部署时实时可求。若只评价单次 inner planned trajectory，outer objective 与实际 receding-horizon policy 不一致。

7.2 Outer closed-loop regret

令 tau_CL,j^ref 为 high-fidelity oracle/reference policy 的最优闭环轨迹，或具有明确 suboptimality bound epsilon_oracle 的近优闭环轨迹。训练：

  min_psi L(psi)

  L(psi)=E_j[
    J_CL,pj(tau_CL(psi;chi_j,p_j);chi_j)
    -J_CL,pj(tau_CL,j^ref;chi_j)
  ]
  +lambda_res R_C2(r_psi)。

reference 为最优时差值是非负 closed-loop consequence regret。reference 仅近优时，它是 excess-to-reference，真实性能 regret 还需增加 epsilon_oracle。优化对象不是 Q、R recovery error。

R_C2 同时约束 residual 的函数值、一阶与二阶导数；lambda_res 只表达“在 analytic mechanics 足够时不引入 residual”的最小偏离原则，其必要性由 residual learning 的 ill-posedness 给出。

7.3 Why the surrogate and decision-focused gradient are needed

inner quadratic/affine metric 是 high-fidelity consequence utility 在当前 environment/operating point 的实时局部 realization。它存在的必要原因必须是以下至少一项：

- high-fidelity deformation/stress/quality calculation 太慢；
- consequence 仅训练期或 aggregate rollout level 可观测；
- direct objective 严重非凸，而 local metric + trust region 可实时；
- supervised consequence-model error 与 applied impedance decision error 不一致。

若 g_chi 可解析并实时计算，直接使用 analytic consequence objective；若 dense consequence labels 已使 decision error 足够小，supervised g_psi 即可；若 J_CL 只有 scalar black-box return，则使用 zeroth-order/RL。只有 aggregate differentiable closed-loop supervision + nonzero solution sensitivity 的 regime 才启用 IDOC fine-tuning。

Long-horizon information compression 与 mechanics-semantic transport 是两个不同误差源。只有前者被单独证明显著时，才加入 time-indexed terminal/value correction；它不是 Final Method 的默认第二机制。


======================================================================
8. Objective Identifiability 与最小参数化
======================================================================

8.1 Global scale ambiguity

当整个 inner task objective 同比缩放且 constraints 不变时，argmin 不变。通过 trace(W)=d_y 固定 scale；其他 regularization weights 使用固定物理归一化。不得声称恢复未规范化的唯一 Q、R。

8.2 Policy-equivalent metrics

即使固定 scale，不同 metrics 也可能在有限 trajectories 上给出同一 optimal z。定义：

  eta_1 ~_D eta_2

当且仅当它们在 training context set D 上诱导相同的 applied first-action sequence（容差内）。Method 学习的是 equivalence class [eta]_D，而非不可观察的“真实 cost”。

8.3 Local sensitivity identifiability

对训练 context j，IDOC 给出：

  S_j = D_eta z_j*(eta)。

构造 sensitivity information matrix：

  I_eta = sum_j S_j^T W_z,j S_j，

其中 W_z,j 是 outer consequence 对 decision directions 的正定权重。去除 global-scale null direction 后，若：

  rank(I_eta)=dim(eta_normalized)，

则 eta 在当前 context/excitation 集上局部 decision-identifiable；若秩亏，只学习 I_eta 的 identifiable eigenspace，其余参数固定为 analytic prior。

这给出网络输出维度的理论裁剪准则，防止任意 full Q、R 过参数化。

8.4 Preference–environment separation condition

训练集必须包含：

- 同一 p 下多个 theta；
- 同一 theta 下多个 p；

否则 p 与 C_theta 在数据上不可分。理论上要求 P_c(p) 的变化能够张成所声明的 preference subspace，environment feature variation 能够激活独立 calibration directions。


======================================================================
9. Implicit Differentiation of the Inner Layer
======================================================================

9.1 KKT system

将 inner NLP 写为：

  min_z J_in(z;eta)
  s.t. c(z;eta)=0，g(z;eta)<=0。

对 active set A，令 primal-dual variable：

  v=[z,lambda,mu_A]。

KKT residual：

  F(v,eta)=
  [ grad_z Lagrangian(z,lambda,mu_A;eta)
    c(z;eta)
    g_A(z;eta) ]=0。

9.2 Assumptions for local hypergradient

A-ID1：J_in、c、g 在当前 contact mode 邻域内二阶连续可微；

A-ID2：inner solution 是 isolated local minimizer；

A-ID3：active constraint gradients 满足 LICQ；

A-ID4：在 critical cone 上满足 second-order sufficient condition；

A-ID5：strict complementarity/strong regularity 使 D_v F 非奇异；

A-ID6：solver 返回与部署一致的 local solution branch。

9.3 Proposition D1：Local solution derivative

在 A-ID1–A-ID6 下，存在 eta 邻域，使 v*(eta) 单值且连续可微：

  D_eta v*(eta)
  =-[D_v F(v*,eta)]^{-1}D_eta F(v*,eta)。

IDOC 利用 trajectory block structure、变量消元和 VJP 计算该导数，避免显式构造完整 Jacobian，并保持 horizon-linear 的结构化 backward computation。

9.4 Outer hypergradient

定义实际 receding-horizon policy：

  pi_psi(s_t,chi_hat_t,p)=First(z_t*)。

IDOC 在每个 replanning step 提供 D_eta z_t* 以及同一 KKT system 对 initial state 的 sensitivity。outer state sensitivity 递推为：

  D_psi s_{t+1}
  =D_s F_HF D_psi s_t
   +D_a F_HF D_psi pi_psi，

其中 D_psi pi_psi 同时包含 direct eta_psi path 与 state/context-mediated path。最终：

  grad_psi L
  =sum_t [D_c U_p D_psi c_t]
   +D_c V_out D_psi c_T
   +lambda_res grad_psi R_C2(r_psi)。

因此 IDOC 只负责 per-solve implicit VJP；outer adjoint/BPTT 负责 repeated replanning 的 closed-loop chain。只使用 grad_z J_HF D_eta z* 的单次 open-loop 表达式不足以对应部署 policy。

若 outer oracle 不可微但可生成 tau_CL^ref，使用 closed-loop trajectory/action imitation loss；若只可获得 scalar black-box outcome，则 outer 层必须改用 zeroth-order/policy-gradient estimator，IDOC 不能凭空提供真实系统梯度。

9.5 Degeneracy handling

活动集切换本身不自动否定局部 IDOC，但在 strict complementarity、LICQ 或 KKT nonsingularity 失效点，经典导数无定义或非唯一。

每个 training sample 检查：

  sigma_min(D_v F) >= sigma_min_threshold，
  active multiplier margin >= mu_min，
  inactive slack margin >= s_min。

不满足时标记为 gradient-invalid，不用该样本声称精确 hypergradient。若此类点在目标 operating envelope 中非零测度且频繁出现，才升级为 generalized/nonsmooth differentiation；否则不增加该模块。


======================================================================
10. Local Approximation、Regret 与成立条件
======================================================================

10.1 Proposition P1：Pullback approximation accuracy

若 U_p o g_chi 的 third derivative 在 trust region ||Delta y||<=rho 内有界 M_3，则 Taylor remainder 满足：

  |R_3(Delta y)| <= M_3 ||Delta y||^3 / 6。

因此 inner surrogate 必须配置 trust region 或 receding-horizon locality；不能把 local metric 当作任意长时域的全局 objective。

10.2 Proposition P2：Metric error to decision error

设 inner oracle problem 在 feasible tangent 上满足强二阶增长，KKT inverse norm 有界：

  ||[D_v F]^{-1}|| <= kappa。

若 learned surrogate 与 ideal local pullback 的 stationarity residual 差异不超过 epsilon_eta，则：

  ||z_psi*-z_ideal*|| <= kappa epsilon_eta + O(epsilon_eta^2)。

该结论说明 metric 学习必须评价 KKT-relevant error，而非逐元素 Q、R error。

10.3 Proposition P3：Decision error to consequence regret

若 local consequence objective 在相关 feasible neighborhood 中 L_c-smooth，z_ideal* 为 stationary feasible solution，且 z_psi* 保持在同一光滑 active manifold 上，则：

  Regret_local(z_psi*)
  <= 0.5 L_c kappa^2 epsilon_eta^2
     + O(epsilon_eta^3)
     + epsilon_horizon
     + epsilon_model。

epsilon_horizon 是短 inner horizon 的可选压缩误差；epsilon_model 是 HC/real-system mismatch。论文必须分别界定它们，不能把全部性能差异归因于 objective transport。

10.4 Environment estimation sensitivity

若 eta_psi 对 sufficient context chi 是 L_eta-Lipschitz，且：

  ||chi_hat-chi|| <= epsilon_chi，

则 metric perturbation至多 L_eta epsilon_chi，并通过 P2 增加约：

  kappa L_eta epsilon_chi

的 local decision deviation。该项决定 context accuracy requirement；它不要求所有 HC 参数都高精度，只要求 decision-sensitive directions 受控。

10.5 Proposition P4：Per-step error to closed-loop regret

若 high-fidelity closed-loop transition 对 state/action 的 Lipschitz constants 为 L_s、L_a，且每步 applied-action deviation 不超过 epsilon_a，则：

  ||Delta s_t||
  <=L_a epsilon_a sum_{i=0}^{t-1}L_s^i。

若 outer utility 为 L_U-Lipschitz，对上式在 T_out 内求和得到 finite-horizon J_CL regret bound。L_s>=1 时误差可能随 horizon 放大，因此 terminal/stability design 是闭环结论的必要组成，而不是数值实现细节。


======================================================================
11. Feasibility、Passivity 与 Closed-loop Claims
======================================================================

11.1 Proposition S1：Objective-independent one-step feasibility

若：

- theta_HC,true in Theta_k（即 Chi_k 的 dynamics-parameter projection）；
- robustly tightened prediction 包含 bounded model/realization error；
- candidate z* 通过 nonlinear first-step verification；

则发布的 first action 满足定义的 state/input/contact constraints。该性质与 W_psi 的数值无关，因为 metric 只在同一 feasible set 内排序。

11.2 Proposition S2：Conditional recursive feasibility

若 terminal set X_f 对 backup policy pi_b robust positively invariant，且 shifted solution + pi_b 在下一时刻可行，则 receding-horizon problem recursively feasible。若无法建立这些条件，只能声称 verified one-step feasibility，不能写无限时域 safety。

11.3 Proposition S3：Passivity under energy budget

在 ideal impedance realization、离散能量核算正确、E_k>=E_min，且 reference/feedforward power 已作为 supply port 或保守 energy debit 显式核算的条件下，stiffness variation 的正能量注入由 tank/dissipation 覆盖，robot–environment port 满足所声明的 passivity inequality。存在低层 tracking/model error 时由 m_track,k 吸收；若无法可靠界定上述功率与 margin，则 passivity claim 不成立。

11.4 Stability boundary

passivity 不自动等同于 task convergence。若声称 tracking convergence，还需在固定/缓变 reference、环境被动性和 persistent contact 等条件下建立 Lyapunov/ISS result。Final Method 默认主张 passivity + constrained execution，不额外声称全局渐近跟踪。


======================================================================
12. 完整算法与时间尺度
======================================================================

12.1 Offline/meta-training

对每个 training context (chi_j,p_j) 与 initial state：

1) 初始化 high-fidelity closed-loop state；
2) 在每个 outer step 更新 chi_hat_t，计算 g_HC+r_psi 及其 J_psi、H_psi,j；
3) 构造 normalized W_psi、center 与必要 affine term；
4) 求解 constrained direct-impedance inner problem，只向 F_HF 施加 verified first action；
5) 保存 primal/dual solution、active set 与 closed-loop transition；
6) 检查每次 solve 的 IDOC regularity，对 valid steps 计算 VJP；
7) 由 outer adjoint 反向传播 repeated-replanning closed-loop consequence loss；
8) 更新 psi，并保持 residual norm、curvature margin 与 scale constraints；
9) 对 gradient-invalid solve/rollout 记录 failure，不伪造 gradient。

12.2 Online deployment

Fast low-level loop：执行 torque/position/impedance controller。

Estimator/context loop：由 force–pose history 与最小 task-relevant sensing 更新 chi_hat_k 或 Chi_k。

Planning loop：

  chi_hat_k,p,s_k
  → eta_psi
  → constrained inner solve
  → nonlinear/energy verification
  → publish K_k,B_k,reference/feedforward。

Fallback loop：deadline、infeasible、out-of-envelope、contact guard 或 energy shortage 时，使用 incumbent/backup/withdraw。

部署期不要求更新 psi；环境自适应来自 sufficient chi_hat_k 条件化的 objective metric。这样避免 online bilevel learning 与接触安全相互耦合。


======================================================================
13. Method Fit / Necessity：主要竞争机制的淘汰与保留
======================================================================

13.1 Fixed Q、R + environment-adaptive dynamics

当 N1 不成立时，该路线足够，Final Method 应被淘汰；当 N1 成立时，它无法保持 consequence preference，因此不能完整闭合 failure。

13.2 Pure analytic objective normalization

若 g_HC 及其一、二阶导数准确覆盖 consequence map，则这是更简单且应优先选择的方案。Final Method 只在存在经过证据支持、跨环境稳定且 decision-relevant 的 residual geometry 时保留 r_psi。

13.3 Directly optimize high-fidelity consequence objective online

若实时可行，这是最直接方案。只有 high-fidelity consequence calculation 过慢、仅训练期可见或直接优化不稳定时，学习 local surrogate metric 才必要。

13.4 Black-box BO / RL tuning of Q、R

可处理不可微 outer outcome，但需要更多 interaction、难以利用 inner KKT sensitivity，并且 online safe exploration 负担较高。当 differentiable training model/oracle 存在时，IDOC 是更直接的局部梯度机制；若不存在，必须承认 BO/RL/zeroth-order 更适合，不能强用 IDOC。

13.5 Direct context-to-K、B policy

它是强 simpler baseline。Final Method 的优势必须来自：

- 显式可干预 task preference；
- online changing constraints；
- model-based replanning；
- applied-action feasibility/passivity closure；
- 对 OOD theta 的结构化 response。

若 direct policy + identical safety layer 达到等价能力，inner optimizer 不必要。

13.6 Differentiate HJB critic fixed point

该路线要求 critic equilibrium unique、Bellman residual Jacobian nonsingular、approximation bias 可传递到 outer gradient，并需处理 PE 与双时间尺度。相较 direct-transcription IDOC 假设更强且 closure 更弱，因而不选为主路线。

13.7 Generic differentiable MPC prior boundary

Differentiable Robust MPC 已覆盖通过 IFT/DDP-style gradients 调整 robust MPC cost、model 与 barrier parameters；Performer-MPC 已覆盖 rich context -> quadratic/affine residual cost -> implicit differentiable MPC；DiffTune-MPC 已覆盖用 closed-loop performance horizon 学习 MPC cost；ZipMPC 已覆盖用 long context 生成 time-varying short-horizon cost并模仿 long-horizon MPC。

因此以下不是本文创新：context-dependent cost、bilevel MPC、closed-loop cost tuning、long/short-horizon imitation 或 implicit differentiation primitive。它们属于本 Method 的 mathematical superclass/strong alternatives，但不是 impedance-specific scientific problem。

本 Method 与它们的本质差异只能主张为：

- fixed raw objective failure 由 soft-contact consequence mechanics 推导，而非一般 manual tuning；
- learned object 受 integrable g_psi 与 explicit p 的 pullback structure 约束，而非 free context cost；
- context sufficiency/aliasing、preference compositionality 与 impedance-action identifiability 有明确条件；
- decision 是 executable K、B，feasible set 包含 impedance-specific energy/passivity closure。

Generic free cost learner 的 hypothesis class 包含更广，数据充分时可能获得更高 task performance；本文不声称普遍支配，只声称更强的结构属性和更小的可辨识搜索空间。

13.8 Impedance-specific prior boundary

Model-predictive VIC 已经覆盖 online K、B optimization、precision-compliance tradeoff 与 impedance constraints；近年的 unknown-soft-environment MPVIC 已覆盖 HC estimation、robust safety-performance switching 与 passivity；stable state-dependent VIC 已覆盖 learnable impedance 与 stability structure。

因此 HC estimator、MPC optimization of impedance、energy tank、passivity 或 safety-performance balance 均为必要 support/strong baselines，不是独立贡献。尚未被这些工作闭合的对象是 invariant consequence preference 到 raw interaction objective 的 mechanics-conditioned transport。

13.9 Selected route

在 N-A–N-F 联合成立、J_CL 不可实时直接优化且 differentiable offline high-fidelity model 可得时：

  physics-initialized structured objective metric
  + NNBO-derived constrained direct-impedance layer
  + per-solve IDOC VJP and closed-loop outer adjoint

形成与问题各 failure 一一对应的路线。若 dense consequence supervision 足够，先使用 supervised g_psi；只有其 decision error 仍显著或只有 aggregate closed-loop supervision 时，保留 IDOC fine-tuning。

14. Complexity Rationality
======================================================================

Core scientific mechanism：1 个。

  environment mechanics transports invariant consequence preference into impedance-control objective geometry。

Necessary support modules：

1) Existing environment estimator/task context：提供 sufficient chi_hat；不是贡献，且受 context-aliasing theorem 约束。
2) Structured objective generator：修复 fixed-objective semantic drift。
3) Direct constrained impedance optimizer：保证 Q、R 真正影响 executable K、B。
4) Per-solve IDOC + closed-loop adjoint：使 aggregate consequence 能训练实际 repeated-replanning policy。
5) Energy/terminal publication conditions：阻止 objective learning破坏交互闭环。

明确删除：

- additional online HJB critic；
- independent actor/critic RL；
- 第二个并列 performance optimizer；
- 无证据必要的 dual control/probing；
- 默认 generalized nonsmooth differentiation；
- 同时使用多套 passivity mechanism。

Complexity vector：

C_model：中。Robot + HC/contact + low-dimensional consequence map。
C_decision：中。K、B、reference/feedforward；B 可在条件满足时消元。
C_solver：中。一个 finite-horizon inner NLP + training-only IDOC backward。
C_guarantee：中高。Local sensitivity + robust first-step/terminal feasibility + passivity。
C_execution：中。Estimator/planner/low-level 三时间尺度。
C_evidence：未来较高，但与跨环境 objective-consistency claim 匹配。

不存在与 Scientific Delta 无关的第二条算法主线，复杂度合理。

15. Scientific Strength 与 Contribution Packaging
======================================================================

15.1 Paper-level scientific delta

不是：

- 首次学习 Q、R；
- 首次组合 NNBO 与 IDOC；
- 首次使用 differentiable MPC；
- 首次使用 HC + NN。

而是：

  将 soft-environment mechanics 从仅决定 dynamics 的角色，提升为同时决定 interaction-objective geometry；建立 environment-invariant task preference 到 environment-conditioned optimal impedance 的可微、受约束映射。

15.2 建议贡献表述

C1. 提出 soft-contact objective semantic invariance 问题，并给出 fixed metric 不可能性的条件与 constructive counterexample。

C2. 推导 consequence utility 经 nonlinear contact mechanics 到 raw interaction variables 的 pullback objective，并提出 preference–mechanics 可分、规范化、可辨识的结构化参数化。

C3. 将 NNBO 重构为直接输出 executable K、B 的 constrained finite-horizon layer，并利用 IDOC 给出 objective parameters 的局部 exact hypergradient 与 validity conditions。

C4. 建立 metric approximation → KKT/decision error → consequence regret 的理论链，并使 learned objective 与 robust feasibility/passivity publication 解耦。

这些贡献组成一条机制链，不应拆成四个独立卖点。

15.3 Technical depth

理论深度来自：

- differential geometry/composition Hessian 意义下的 pullback metric；
- quadratic-form equivalence 与 fixed-metric impossibility；
- parametric nonlinear programming strong regularity；
- sensitivity-rank local identifiability；
- local regret propagation；
- variable-impedance energy accounting。

每项均直接支撑主 claim，不是理论装饰。

16. 顶会顶刊对齐判断
======================================================================

16.1 Problem fit

PASS WITH NARROWED SEMANTICS。

机器人缺失的能力是：对 consequence-defined soft-contact tasks，在不同且可辨识的软环境中只给定一次高层交互偏好，仍能形成物理语义一致的 optimal impedance。若任务由 fixed force/position error 完整定义，本问题不成立。

16.2 Method fit / necessity

CLOSED ONLY IN G1-G6 REGIME。

Objective transport 修复 proxy representation failure，NNBO-derived inner layer 将其转换成 constrained K、B，per-solve IDOC + outer adjoint 连接 closed-loop consequence 与 repeated-replanning policy。N-A–N-F、context sufficiency 和第 13 节 simpler-rival gates 是必要成立条件；IDOC 仅是满足该信息结构的 backend choice。

16.3 Scientific strength

T-RO：ALIGNED AT METHOD-DESIGN LEVEL。若 fixed-metric/context-aliasing propositions、closed-loop hypergradient、solver/action interface 与 passivity conditions 均完成正式证明，并由未来证据支持 activation conditions，则问题规模、理论深度、方法复杂度和闭环形态进入 T-RO 参考分布。

ICRA/RSS：若先做 focused version，可缩减为 fixed-metric theorem + structured objective + differentiable constrained impedance，不必同时追求完整 robust/terminal generality。

IJRR：CONDITIONAL。需要把 N1 提升为 nonlinear contact families 上更一般的必要/充分条件，证明 preference–mechanics factorization 的统一性，或覆盖多个不同 continuous-contact tasks；仅一个 HC 应用不足以稳健进入 IJRR 分布。

17. 仍然必须接受的 Falsifiers
======================================================================

不展开实验，但 Method 必须保留以下证伪条件：

F0. 目标 task 的真实效用可由 measured force/position error 完整定义；不存在 consequence proxy mismatch。

F1. 目标 environment family 的 pullback metrics 实际近似正比例；固定 Q、R 已保持 consequence consistency。

F2. analytic HC pullback 足够准确；learned residual 无必要性。

F3. high-fidelity consequence objective 可以直接实时优化；surrogate objective 无必要性。

F4. normalized metric 对 optimal K、B 的 sensitivity rank 不足；claimed parameters 不可辨识。

F5. sufficient-context assumption 失败，或 context estimation error 产生的 decision deviation 超过 objective-transport 收益。

F6. direct context-to-K、B policy 在相同 constraints/preference/OOD 条件下等价。

F7. inner KKT degeneracy 在目标 operating envelope 中频繁出现，使 IDOC gradient 无法可靠使用。

F8. low-level controller、saturation 或 energy guard 系统性改写 planned K、B。

F9. outer performance improvement主要来自 metric 补偿错误 dynamics，而不是修复 consequence calibration。

F10. generic context-dependent cost learner 在相同 explicit-p、context、constraints 与 closed-loop supervision 下实现等价 compositionality 和 performance，结构化 transport 无独特收益。

F11. outer training 退化为单次 open-loop planned-trajectory loss，不能代表 repeated-replanning deployment。

任一 falsifier 成立，应返回对应上游环节简化或放弃 Method，不能靠增加模块防守。


======================================================================
18. 最终冻结版本
======================================================================

Method 名称（工作名）：

  Mechanics-Conditioned Objective Transport via Closed-Loop Differentiable NNBO
  （MCOT-DNNBO）

最终因果链：

  sufficient soft-environment context chi_hat=[theta_HC_hat,xi_task]
  → integrable consequence map g_psi=g_HC+r_psi and derivatives {J_psi,H_psi,j}
  + explicit task preference p
  → normalized pullback metric eta_psi={W,a,y_bar}
  → repeated NNBO-derived constrained direct-impedance solves
  → verified executable K,B/reference/feedforward first actions
  → closed-loop consequence-level outcome
  → per-solve IDOC VJPs + outer closed-loop adjoint to mechanics residuals。

最终一句话主张：

  对 consequence-defined soft-contact tasks，当环境力学使固定 raw interaction objective 无法保持同一高层偏好且 online context 足以区分 task-relevant environments 时，MCOT-DNNBO 将显式 preference 经 integrable mechanics model transport 为局部 objective geometry，并以 per-solve IDOC 和 closed-loop adjoint训练受约束的 optimal-impedance policy，使跨环境执行的 K、B 保持 consequence-level consistency，同时满足 objective-independent robust feasibility 与 passivity conditions。

该版本的 novelty 不再落在 context-dependent cost 或 implicit differentiation 本身，而落在 impedance-specific problem formulation：fixed-objective impossibility、context-aliasing boundary、preference-mechanics separable transport、closed-loop solution sensitivity 与 passive execution 的统一闭合。下一阶段只能做正式证明细化、数值求解实现和证据验证；不再增加新的 paper-level 模块。
