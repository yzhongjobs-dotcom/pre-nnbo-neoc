R15 NNBO × Implicit Differentiation 路线审计：Decision-Focused vs. PIB-NNBO
日期：2026-09-09
状态：研究问题与路线选择；不是 Final Method；不包含实验设计

======================================================================
0. 固定前提与结论
======================================================================

本审计只保留一个技术前提：

  Neural-Network-Based Optimal Impedance Control for Robots in Physical
  Interaction With Soft Environments（NNBO）

  ×

  Revisiting Implicit Differentiation for Learning Problems in Optimal
  Control（IDOC）所代表的“通过最优性条件隐式求导”机制。

不预设连续机器人超声、直接 K/B MPC、set-valued contact model、passivity tank
或此前任何 Final Method 架构。

结论：

1. 在 NNBO 原始研究域——机器人与未知非线性软环境的最优阻抗交互——中，
   decision-focused 路线比 PIB-NNBO 更符合 Problem fit、Method fit 和
   Method necessity。

2. 胜出的不是泛化表述“用下游 loss 学模型”，而是更精确的科学问题：

   NNBO 为获得最优交互而辨识完整 Hunt–Crossley 环境参数，并依赖 PE/probing；
   但有限且受交互代价约束的数据通常不能可靠恢复所有参数，而最优阻抗策略只
   对其中一部分参数组合敏感。如何只辨识会改变 HJB-optimal interaction policy
   的环境方向，并允许其余不确定性继续存在？

3. PIB-NNBO 并非数学错误。它适合“物理环境可估计，但任务偏好未知，需要从
   示范或结果识别 objective”的另一研究问题。然而，NNBO 原文没有证明 fixed
   Q/R 是其主要性能瓶颈；把 demonstrations、task preference 和 inverse optimal
   control 引入后，实际上新增了一个问题。它不能解决 NNBO 已明确暴露的完整辨识、
   probing 与模型失配问题。

4. NNBO 与 IDOC 不能按公式直接拼接。IDOC 原公式针对 finite-horizon、
   discrete-time constrained trajectory NLP 的 differential KKT system；NNBO 的
   内层对象是 continuous-time infinite-horizon HJB value/policy 及其在线 critic。
   保留 NNBO 时，正确迁移是对 critic/Bellman stationary system 使用 IFT；此时
   不能继承 IDOC 的 trajectory-KKT 公式或 O(T) complexity claim。

5. 当前路线因此应冻结为：

   Decision-Relevant Identification for NNBO（工作描述，不是最终命名）

   prediction/full-parameter identification
   -> implicit HJB-policy sensitivity
   -> decision-relevant parameter uncertainty / excitation
   -> optimal interaction without requiring full parameter convergence。

======================================================================
1. 按正确顺序确定研究问题
======================================================================

1.1 NNBO 已经解决什么

NNBO 已经提供：

- Hunt–Crossley 非线性黏弹软接触模型；
- EWRLS 环境参数估计；
- 包含模型不确定性补偿的 augmented dynamics 与 modified cost；
- continuous-time infinite-horizon HJB optimal interaction force；
- single critic 对 HJB value 的近似；
- 将最优 interaction force 转成 desired impedance relation/reference position 的实现。

因此，不能把研究问题重新表述成“现有阻抗控制不能处理非线性软环境”或“没有
在线最优阻抗”。NNBO 已经直接覆盖这些命题。

1.2 NNBO 的具体 residual failure

NNBO 的 environment estimator 以参数/预测残差为目标，并需要 PE；原文实验为满足
PE 加入 probing/exploration signal。该设计隐含以下充分条件链：

  完整参数可辨识
  -> 接触模型准确
  -> HJB policy 准确
  -> 交互性能良好。

但这个条件链不是必要条件：

- 不同参数误差对最优 interaction force 的影响并不相同；
- 某些参数方向可以造成明显预测误差，却几乎不改变当前任务中的最优 policy；
- 某些很小的参数误差在高 policy sensitivity 区域可能显著改变最优 force/reference；
- 为让所有参数方向都满足 PE 而加入 probing，可能付出不必要的接触扰动和数据代价；
- 当 HC 模型失配时，prediction-optimal 参数也未必是 interaction-optimal 参数。

所以最有价值的 failure 不是“参数估计还不够准”，而是：

  NNBO 不知道哪些尚未消除的环境不确定性会真正改变其最优交互决策，因而把
  完整物理辨识当成控制所需条件，并对 decision-irrelevant directions 也要求数据与激励。

1.3 Failure 根因

根因是 estimator geometry 与 controller geometry 分离：

- EWRLS 用 prediction/reconstruction metric 衡量模型；
- controller 只通过最优解映射 theta -> (V*, f*) 使用模型；
- 两者之间缺少 D_theta f* 或等价的 decision metric。

因此 Euclidean parameter error、one-step force prediction error 与 optimal-interaction
regret 一般不序等价。完整参数 convergence 是过强要求，而普通 prediction accuracy
又可能在关键决策方向上不足。

1.4 收敛后的 Research Question

在保留 NNBO 非线性软接触、robust HJB critic 和 force-to-impedance realization 的
条件下，能否通过对 Bellman/critic optimum 的隐式微分，识别并优先收缩只会改变
HJB-optimal interaction policy 的环境参数组合，从而在不要求完整 Hunt–Crossley
参数收敛或无差别 PE 的情况下，获得有界的最优交互性能损失？

这个问题的领域贡献不是“让模型更准”，而是把 optimal impedance 所需的辨识条件
从 full physical identifiability 改写为 decision-relevant identifiability。

1.5 Scope 边界

In scope：

- 持续接触区间内的非线性黏弹软环境；
- NNBO 原有 interaction-force policy 与 impedance/reference realization；
- task objective Q/R 已由设计者给定且含义固定；
- 有限数据下的参数 covariance、partial identifiability 与 policy sensitivity；
- critic fixed point 的近似隐式导数及其误差。

Out of scope：

- 同时学习未知 dynamics 和未知 preference；
- 接触建立/分离、冲击及一般混杂接触模式；
- 从 human demonstrations 恢复个体偏好；
- 声称学习权重可提供 hard-safety guarantee；
- 将 IDOC 的 finite-horizon O(T) 结论直接转移到 HJB critic。

同时学习 dynamics 与 preference 暂不进入主问题，因为相同的行为差异可以由环境
参数或 cost 参数解释；没有额外干预或标签时会形成结构性 confounding。

======================================================================
2. NNBO 与 IDOC 如何形成数学上正确的组合
======================================================================

2.1 两篇论文的原始数学对象

NNBO：

  X_dot = F(X;theta) + G(X;theta) f，

  J = integral_0^infinity l(X,f;theta,Q,R) dt，

  l = X^T Q_tilde X + f^T R f + zeta_epsilon(X;theta)^2。

HJB optimum 满足：

  min_f H(X,f,nabla V*;theta)=0，

  f*(X;theta)=-1/2 R^{-1}G(X;theta)^T nabla V*(X;theta)。

NNBO 用 V_W(X)=W^T phi(X) 和 Hamiltonian/Bellman residual 在线学习 W。

IDOC：

  xi*(lambda)=argmin_xi sum_t c_t(x_t,u_t;lambda)

  subject to discrete dynamics/equality/inequality constraints，

并通过最优轨迹的 KKT stationary system F_KKT(xi,mu;lambda)=0 使用 IFT：

  D_lambda(xi*,mu*)
  =-[D_(xi,mu)F_KKT]^{-1}D_lambda F_KKT。

2.2 不能采用的拼接

不能写成：

  “NNBO critic 得到 W*，然后直接套用 IDOC Equation (5)/(6) 得到 D_theta W*”。

原因是：

- W* 不是一条 finite-horizon optimal trajectory；
- critic update 不是 trajectory NLP 的 KKT system；
- NNBO 没有 IDOC 中按时间形成的相同 block-sparse KKT matrix；
- IDOC 的线性 horizon complexity 不适用于 critic Hessian/Jacobian。

2.3 正确的 source-mechanism migration

固定一组 critic samples/distribution D，定义 regularized Bellman objective：

  E_B(W,theta;D)
  =1/2 E_D[H_hat(X,f_hat(W,theta),W;theta)^2]
   +lambda_W/2 ||W||^2。

critic stationary point 由：

  g(W,theta;D)=nabla_W E_B(W,theta;D)=0

隐式定义。若在考察的局部分支上：

- g 连续可微；
- g_W 非奇异；
- sampling distribution D 在求导时的处理被明确固定，或其 dependence 被完整计入；

则：

  D_theta W*(theta)=-g_W^{-1}g_theta。

NNBO policy 的总灵敏度是：

  S_theta(X)=D_theta f_hat*(X;theta)

              =partial_theta f_hat
               +partial_W f_hat D_theta W*。

对 scalar outer quantity L 不显式构造完整 Jacobian，而解 adjoint system：

  g_W^T v=(partial_W L)^T，

  dL/dtheta=partial_theta L-v^T g_theta。

这保留了 IDOC 的真正 source mechanism：

  不展开 solver/learning iterations，
  而通过 optimum/stationary conditions 对最优解映射求导。

但必须准确命名为 Bellman/critic implicit differentiation；IDOC 是机制来源与理论
参照，不能宣称使用了其 trajectory-KKT solver 或继承其 complexity theorem。

2.4 Decision-focused 外层对象

EWRLS 产生环境估计 theta_hat 和 covariance P_theta。由 S_theta 得到局部 policy
uncertainty：

  Sigma_f(X)=S_theta(X) P_theta S_theta(X)^T。

若 H_f(X) 是 true/local action-value 在 f* 附近的 reduced curvature，则一阶 policy
误差对应的二阶局部 decision-regret metric 为：

  M_dec(X)=S_theta(X)^T H_f(X) S_theta(X)，

  E[Reg_dec] approximately
  1/2 trace(M_dec P_theta)。

因此：

- delta-theta in ker(S_theta) 是局部 first-order decision-irrelevant direction；
- full P_theta -> 0 不是 policy convergence 的必要条件；
- 应优先获得能缩小 row(S_theta) 所对应不确定性的交互数据；
- estimator/excitation criterion 应降低 projected decision uncertainty，而不是无差别
  降低 trace(P_theta) 或 prediction MSE。

这给出最小、自然且可实现的组合：

  EWRLS/HC physical estimate and covariance
  -> critic implicit sensitivity S_theta
  -> decision-relevant uncertainty/regret
  -> decision-focused weighting or bounded probing
  -> original NNBO optimal force/reference realization。

它不要求把物理模型替换成任意 reward-seeking neural model，也不要求重构成 finite-
horizon MPC。

======================================================================
3. 为什么 Decision-Focused 比 PIB-NNBO 更符合 Method fit / necessity
======================================================================

3.1 两条路线应在同一隐式接口上比较

共同 inner system：

  g(W,lambda)=0 -> W*(lambda) -> f*(X;lambda)。

Decision-focused：lambda=theta，学习/收缩 environment dynamics 中影响最优 policy
的方向。

PIB-NNBO：lambda=eta，eta 参数化 Q/R 或 normalized preference，从 demonstrations /
outcomes 学 objective。

数学上二者都可以使用相同的 critic-level IFT。优劣不能由“是否可微”决定，而应由
哪个 lambda 对应已经证实的 primary failure 决定。

3.2 Problem fit

Decision-focused：

- 直接承接 NNBO 的 environment identification、PE 与 model uncertainty 链；
- 即使 task objective 完全正确，有限数据/模型失配仍会造成该 failure；
- 解决后新增能力清晰：不必完整恢复材料参数，也能获得可靠 optimal interaction。

PIB-NNBO：

- 只有在 Q/R 无法由任务设计者指定，且不同示范确实表达不同 preference 时才必要；
- 若 objective 已知，PIB 无事可做；
- 它没有降低环境辨识要求，也没有处理 prediction-optimal model 与 policy 的错位；
- 把 demonstration 作为新信息源后，研究对象已变成 inverse optimal control / LfD。

判定：Decision-focused 通过；PIB 对当前源问题不通过 primary-problem gate。

3.3 Method fit

Decision-focused 为什么自然需要隐式微分：

- 环境参数不只直接进入 force law，还会改变 HJB value/critic optimum；
- 只计算 partial_theta f 会漏掉 theta -> W* -> f* 的 re-optimization effect；
- 展开全部 critic learning history 代价高、依赖训练路径且内存不可控；
- optimum-level IFT 正好给出 policy 对 environment uncertainty 的总灵敏度；
- 该灵敏度又正是定义 decision-relevant identifiability 与 projected PE 所缺的量。

PIB 为什么不具有同等 necessity：

- demonstrations 存在时，direct inverse HJB/IOC、maximum-entropy IRL、behavior
  cloning、GMM/GMR impedance learning 都是直接替代；
- 若只学习一个低维 eta，gradient-free BO 也可能足够；
- cost 存在 scale、shaping 与 feature confounding，不会因为使用 IFT 自动可辨识；
- 若 demonstration trajectory 已直接给出目标行为，必须证明“恢复 preference 后再
  求 NNBO optimum”比直接学 policy 更能跨环境泛化。

判定：Decision-focused 中 implicit sensitivity 是根因所需量；PIB 中 implicit
sensitivity 只是若干 inverse-learning solver 之一。

3.4 Method necessity 相对更简单替代

与 ordinary EWRLS 相比：

ordinary EWRLS 只知道 prediction information，不知道 parameter uncertainty 是否会
改变 optimal force。删除 implicit policy sensitivity 后，无法定义 decision-relevant PE。

与 robust NNBO 相比：

robust compensation 可以容忍有界 uncertainty，但不区分哪些 uncertainty 值得继续
学习。若长期使用统一 worst-case bound，可能保持不必要保守；decision-focused
learning 的作用是用数据缩小会改变 policy 的 uncertainty，而不是替代 robustness。

与 model-free RL 相比：

model-free 路线可以绕过参数辨识，但需要更多真实交互，且丢失 HC 物理结构与 NNBO
已有稳定性论证。当前痛点是“无需 full identification”，不是“无需任何 model”。

与 generic control-oriented model learning 相比：

通用 value-aware/control-oriented model learning 已证明 prediction-optimal model 在
model misspecification 下不一定带来最好 return，并可对 Bellman optimum 隐式求导。
因此，“用 downstream return 学模型”不是本研究的创新。

R15 必须增加而且只增加与软接触 optimal impedance 根因一致的内容：

- HC/soft-contact parameter directions 的 local decision-null space；
- decision-relevant identifiability / projected PE 条件；
- 未收缩参数不确定性到 optimal-force/impedance regret 的界；
- 由 critic approximation 引起的 sensitivity/hypergradient error；
- bounded probing 与 critic/estimator two-timescale 的闭环边界。

这些内容使方法区别于“generic end-to-end model learning”，同时没有改变 primary
problem。

4. PIB-NNBO 的独立价值与当前淘汰理由
======================================================================

PIB-NNBO 最强的科学版本应当是：

  在不同软环境 dynamics 下，从有限 demonstrations 中识别可跨环境复用的
  interaction preference，而不是直接复制 environment-dependent behavior。

该问题是成立的，因为同一 preference 在不同环境中会产生不同 optimal behavior，
而 behavior cloning 容易把 mechanics 与 preference 混为一体。NNBO 提供 forward
optimal-control model，critic-level IFT 可用于 inverse objective learning。

但它目前不能成为主路线，原因有三：

1. 需要先证明 fixed/manual objective 确实造成目标领域中的可重复 failure；当前只有
   “Q/R 需要手调”这一通用症状。
2. sparse optimal demonstrations 下，PIB 本质上属于 model-based IOC；若没有超越
   direct IOC 的新 information structure 或 generalization theorem，不能把
   “preference bottleneck + implicit gradient”视为顶刊创新。
3. 当前 scalar tracking-force ratio 无法普遍表达非线性软组织/材料后果；扩大成自由
   cost network 又会失去 identifiability 和物理解释。

因此 PIB 不是永久否决，而是一个不同的候选论文：只有当证据显示“模型已经足够，
但 objective mismatch 才是主导失败”，它才应重新进入路线竞争。

======================================================================
5. 理论正确性与可行性硬门
======================================================================

5.1 Exact HJB 与 empirical critic 必须分开

不能从 exact HJB sensitivity 直接推出 learned critic sensitivity。主方法实际使用：

  finite-data regularized Bellman stationary point W_D*(theta)，

因此定理和实验必须报告：

- Bellman residual；
- g_W condition number / regularization；
- sample-distribution dependence；
- approximate hypergradient 与 finite difference/autodiff reference 的误差；
- critic approximation error 如何传播到 S_theta 和 decision metric。

5.2 HC smoothness 边界

Hunt–Crossley contact 在持续压入区间内可进行局部光滑分析；接触建立/分离点和某些
非整数指数在 delta=0 附近不能默认满足普通 C1/C2 假设。主理论应限定 delta>=
delta_min>0，或显式采用平滑 contact regularization，并报告其偏差。

5.3 IFT 非奇异性不是事实

g_W 非奇异必须由 regularization、局部 isolated stationary point 和经验 condition
diagnostics 支持。若存在多 critic minima 或近奇异 Hessian，D_theta W* 可能不稳定，
此时需使用 damped linear solve，并把得到的导数称为 regularized sensitivity。

5.4 Decision-null 只是一阶局部结论

delta-theta in ker(S_theta) 只表示 first-order policy invariance。跨大范围状态、参数或
policy branch 时，null space 可能变化；必须在 state/task distribution 上定义 aggregate
metric，并用二阶 remainder 或局部 trust region 限定 claim。

5.5 不能把 probing 的安全性当作自动成立

本路线可以减少无差别 probing，但“decision-focused”不等于“safe”。若只使用
NNBO 原有 admissible policy 与有界激励，claim 应限于 bounded interaction burden；
若要声称硬安全，必须另有明确约束/屏障机制，不能由 cost 或 covariance 间接推出。

5.6 两时间尺度

theta_hat/P_theta、critic W 和 probing policy 同时变化时，stationary IFT 只在更新相对
critic convergence 足够慢时近似有效。需要给出 frozen-parameter analysis 加 tracking
error bound，不能把每一步在线网络权重都当作已收敛 optimum。

======================================================================
6. 顶会顶刊标准下的创新与技术深度判定
======================================================================

单纯版本：

  “把 EWRLS loss 换成 task loss，并通过 Bellman implicit differentiation 更新 model”

判定：不够。generic control-oriented model learning 已覆盖这一机制骨架。

达到 T-RO/IJRR 潜力所需的单一科学增量：

  把未知非线性软环境的 full physical identifiability，重构为由 NNBO optimal-policy
  sensitivity 定义的 decision-relevant identifiability，并证明只收缩该子空间即可
  控制 optimal-interaction regret，从而减少为完整 PE 所需的无关 probing。

相应技术深度最低要求：

T1. Parameter error 与 policy/decision regret 不等价：给出局部二阶展开或上下界。

T2. Local decision-relevant dimension：由 rank(S_theta) 给出局部必要辨识维数，并
    说明跨状态分布的 aggregate rank。

T3. Projected PE / observability：数据 regressor 必须在 row(S_theta) 对应方向上提供
    信息；无需要求完整参数空间 PE。

T4. Critic implicit sensitivity：给出 W_theta、policy sensitivity 与 VJP，并明确
    regularized empirical branch。

T5. Approximation robustness：Bellman/critic误差、parameter covariance误差到
    decision metric 与最终 policy regret 的传播界。

T6. Closed-loop/two-timescale boundary：说明 estimator、critic、policy update 的
    稳定性或最终有界性条件。

这些理论必须服务于“无需完整参数收敛仍可获得 optimal interaction”这一能力，不能
变成与问题无关的 theorem 堆叠。

当前判定：

- Problem significance：有条件通过，前提是完整 PE/probing 的真实代价和 partial
  identifiability 在目标软接触中被证实。
- Novelty：generic 版本不通过；decision-relevant identifiability + projected PE
  版本具有顶刊潜力。
- Technical depth：可达到，但需要 T1–T6 闭环，当前尚未完成。
- Feasibility：比直接以 real-world return 端到端更新任意 dynamics model 更高，因为
  保留 HC/EWRLS，只用 implicit sensitivity 改变 uncertainty/excitation geometry。
- Method necessity：通过；若删除 implicit policy sensitivity，就无法知道哪些参数
  uncertainty 是 controller-relevant。

======================================================================
7. 最终路线决定
======================================================================

选择：Decision-Focused NNBO × Bellman Implicit Differentiation。

不选择：当前 PIB-NNBO 作为主路线。

选择理由的因果链：

  NNBO 需要完整 environment identification 与 PE
  -> 有限交互下参数只部分可辨识，且不同误差方向对 optimal policy 影响不同
  -> prediction metric 与 optimal-interaction metric 不一致
  -> 需要求 theta -> critic optimum -> optimal force 的总灵敏度
  -> IDOC 的 optimum-level implicit differentiation 是自然 source mechanism
  -> 由该灵敏度定义 decision-relevant identifiability 与 projected PE
  -> 只收缩影响 optimal impedance 的 uncertainty，保留 NNBO 的物理与控制主干。

PIB 的链条则是：

  假设 task preference 未知
  -> 收集 demonstrations/outcomes
  -> inverse-learn objective
  -> 再求 NNBO optimal policy。

其中第一步不是 NNBO 已证明的 residual failure，而且 inverse optimal control 有大量
直接竞争者。因此它的 Method necessity 弱于 decision-focused 路线。

======================================================================
8. 下一步，不提前设计 Final Method
======================================================================

下一步应只做三个审计，不进入实验方案：

1. 证据审计：确认真实 soft-contact tasks 中 full PE/probing、HC partial
   identifiability 和 prediction-control mismatch 是否具有足够普遍性与性能量级。
2. strongest-prior 审计：以 control-oriented model learning、value equivalence、
   task-oriented system identification、dual control 和 active experiment design 为主线，
   判断 decision-relevant identifiability/projected PE 的残余科学增量。
3. 数学闭合审计：在 NNBO 原方程上正式推导 g_W、g_theta、S_theta、projected
   information matrix、regret expansion 与 two-timescale assumptions，检查是否存在
   不可修复的奇异性或不可观测性。

只有这三项通过，才能冻结 Final Research Problem 和 Final Method。

10. 一句话结论
======================================================================

在 NNBO × implicit differentiation 这一固定技术族内，最自然且最有顶刊潜力的路线
不是学习“机器人应该偏好什么”，而是重新定义“为了获得最优阻抗，机器人究竟必须
从软环境中辨识什么”：用 critic-optimum 的隐式 policy sensitivity 把完整参数辨识
改写为 decision-relevant identifiability，并只为会改变 optimal interaction 的方向
付出数据与 probing 代价。
