NNBO + Implicit Differentiation：基于实际算法结构的最小充分重构审计
版本：2026-09-09
目标：IEEE Transactions on Robotics；不以实验结果预设 Method 成立

======================================================================
0. 审计结论
======================================================================

结论 1：此前 DECOR-IC 级别的整体重构不是由“NNBO 的 Q、R 需要人工设定”这一 failure 推出的最小必要修改。它把主要矛盾从 objective specification 转移到了 contact representation / partial identifiability，改变了研究问题。除非另有证据证明完整 HC 辨识正是性能瓶颈，否则该大改属于 ABOVE-BUT-UNJUSTIFIED complexity。

结论 2：原始“environment -> NN -> Q,R -> differentiable OC”也不能直接保留。环境动力学决定同一目标下如何控制，却不能单独决定机器人应该重视 tracking 还是 contact consequence；同一环境可对应不同任务偏好。因此 environment-only objective prediction 是欠定的。手工调参是真实症状，但其根因不是“缺少一个输出 Q、R 的网络”。

结论 3：NNBO 原文的 inner problem 是连续时间、无限时域 HJB，control variable 是 interaction force f；critic 近似 value，最后由 f-policy 生成 nonlinear force-position relation 和 reference position x_r。它不是有限时域 constrained trajectory NLP，也不直接输出一般 K、B。Revisiting IDOC 的 differential-KKT 公式不能直接接在该 critic 后面。若为使用 IDOC 而把 NNBO 换成 finite-horizon direct-impedance MPC，便改变了 solver、decision variable、feedback semantics 与 execution interface；这只在研究问题要求 hard constraints、direct K,B 和 receding-horizon prediction 时才必要，对当前 objective-learning failure 过重。

结论 4：最小且科学上成立的路线是保留 NNBO 的 HC/EWRLS、robust auxiliary system、HJB force policy、single critic 与 Newton reference realization，只修改两处：

  A. 把任意 Q、R 改成 preference-identifiable、量纲归一、任务与环境角色分离的 objective parameterization；
  B. 将 IDOC 的“对最优性条件做 IFT”迁移为对 HJB/Bellman fixed point 做 implicit differentiation，而不是套用 finite-horizon KKT 公式。

最终 Method 工作名：PIB-NNBO
Preference-Identifiable Bellman-Differentiable NNBO。

唯一 paper-level mechanism：

  externally specified interaction preference
  -> identifiable normalized objective coordinate
  -> implicit sensitivity of the robust HJB/Bellman optimum
  -> NNBO optimal force/target-impedance policy。

这是一项局部、公式级但非浅层的修改。其科学深度来自 continuous-time infinite-horizon feedback optimum 的 implicit differentiation、objective identifiability 与 approximation-to-policy sensitivity，而不是增加 MPC、direct K,B、passivity tank、decision-equivalent representation 等并列模块。


======================================================================
1. NNBO 实际算法结构：不可越过的事实边界
======================================================================

1.1 Environment model and estimator

定义 penetration delta=x-x_e。NNBO 使用 Hunt-Crossley model：

  f = B_e delta^n xdot + K_e delta^n。

经 logarithmic linearization 后以 EWRLS 估计 K_e、B_e、n。该估计器直接进入 augmented interaction dynamics。

1.2 Actual optimal-control variable

由 HC 模型得到：

  xdot = -K_e/B_e + f/[B_e delta^n] + epsilon。

与 desired-position generator 合并为：

  Xdot = F_chi(X)+G_chi(X)f+K epsilon，

其中 chi=[K_e,B_e,n,x_e]，而 f 是 HJB control input。原始 performance objective 为：

  J = integral_0^infinity [e^T Qe + f^T Rf + zeta_epsilon(X)^2] dt。

因此环境变化已经通过 F_chi、G_chi 改变 optimal policy。固定 Q、R 不等于固定控制行为；它表示固定的 raw tracking-force preference。

1.3 HJB and critic

对 admissible policy，value V 满足：

  0 = min_f H(X,f,grad V)
    = min_f {grad V^T(F_chi+G_chi f)+e^TQe+f^TRf+zeta_epsilon^2}。

无 control constraint 时：

  f*(X) = -0.5 R^{-1}G_chi(X)^T grad V*(X)。

NNBO 用 V_hat=W^T phi(X) 近似 V*，用 Hamiltonian/Bellman residual 更新 W。

1.4 Execution interface

原文将 critic policy 写为：

  f_hat = -[grad(phi)_1^T W_hat]/[2 R B_e delta^n]，

并在所选 basis 下改写为 nonlinear force-position relation：

  f_hat = delta^{-n}(K_1 x-K_2 x_d)。

随后解 S(x_r)=0 得到 reference position x_r，由 inner position controller 执行。因此准确表述是“optimal interaction force / nonlinear target-impedance relation with admittance-style reference realization”。不能把它未经推导写成 optimizer 直接输出独立 stiffness K 与 damping B。


======================================================================
2. Failure 审计与根因定位
======================================================================

2.1 已被原文直接支持的 failure

F1. Q、R 受量纲影响，作者依赖 partial knowledge 和 trial-and-error。

F2. 不同 Q 会显著改变 penetration、tracking error 与 force；所以 weight selection 不是无效参数。

F3. 原文分别为不同材料/设置选择不同 Q 和 critic initialization，但没有给出可复用的 specification-to-weight rule。

这些事实证明“objective calibration 有成本”，但尚不证明“environment 应自由生成 objective”。

2.2 原始 Idea法中的根本欠定性

命题 P1（environment-only objective impossibility）：

固定同一 environment chi。取两个合法任务 p_1、p_2，前者更重 tracking，后者更重 contact protection；其 optimal policies 一般不同。若 objective generator 仅为 eta=h(chi)，则对相同 chi 必须输出同一 eta，不能同时表示两个任务。故 environment state 不足以确定 Q、R；至少还需要 explicit task preference p、demonstration、task-level consequence label 或显式 performance specification。

这不是 prior 防守，而是信息 identifiability failure。网络容量无法消除信息缺失。

2.3 主要矛盾

NNBO 已能针对 chi 改变 dynamics 和 optimal behavior；缺失的是：

  如何把一次给定或从示范/结果中识别的 interaction preference，转成可辨识、量纲一致的 objective coordinate，并对 NNBO 的 infinite-horizon optimal feedback 计算正确梯度。

因此 Required Mechanism Change 为：

  hand-tuned, dimensionful objective weights
  -> preference-identifiable normalized objective
  + implicit derivative of the Bellman optimum。

不是：

  full HC model
  -> decision-equivalent contact representation；

也不是：

  HJB critic
  -> generic finite-horizon MPC。

2.4 与安全问题的边界

若真正需求是 guaranteed peak force/deformation limit，应把它写成 hard constraint 或 control barrier/passivity condition；学习 Q、R 不能给出 hard-safety guarantee。那将是另一个 research problem，并可能要求 constrained HJB 或 MPC。当前 Method 只解决 preference/objective calibration，不借“安全”扩大 claim。


======================================================================
3. 为什么 IDOC 不能直接套用，以及应如何迁移
======================================================================

3.1 IDOC 的原问题

IDOC 考虑 finite-horizon discrete-time constrained OCP：

  min_{x_0:T,u_0:T-1} sum_t c_t(x_t,u_t;theta)+c_T(x_T;theta)
  s.t. dynamics and equality/inequality constraints。

它假设 solver 返回一个 local minimizer trajectory xi*(theta)，然后对 active-set KKT system 做 IFT。其关键 regularity 包括 twice differentiability、constraint Jacobian full row rank、相关 Hessian/KKT matrix nonsingular。其 O(T) 结果来自 time-block sparse KKT structure。

3.2 与 NNBO 的不匹配

NNBO 的 unknown object 是 feedback value V*(X) 和由其梯度定义的 policy，不是一条固定初态下的 finite trajectory xi*。其 critic W_hat 又是在线 Bellman-residual learner，而非 IDOC 假定的 trajectory NLP solver。因此：

  D xi*/D theta 的 IDOC 公式 != D V*/D eta；
  differential KKT matrix != Bellman/HJB linearization；
  IDOC 的 O(T) claim 不能转移为 NNBO critic 的 complexity claim。

3.3 同构 intervention

可迁移的是 IFT intervention：

  differentiate the optimum through its defining optimality equation，

而不是照搬 differential-KKT algebra。NNBO 的 defining equation 是 HJB/Bellman operator：

  B(V,eta;chi)=0。

正确迁移是：

  D_V B[V_eta] + D_eta B = 0，

其中 V_eta=partial V*/partial eta。这是 Bellman implicit differentiation（BID）。


======================================================================
4. 最终研究问题
======================================================================

在保留 nonlinear soft-contact NNBO feedback architecture 的条件下，如何从少量 expert force-position interaction demonstrations 中识别量纲一致且可辨识的 task preference，并通过对 robust HJB/Bellman optimum 的隐式微分，学习跨软环境可复用的 optimal force/target-impedance policy，而无需为每个新环境手工重调 Q、R 或把 controller 重构成 MPC？

In scope：

- single-point, one-direction continuous soft contact；
- HC/EWRLS 提供 chi 或其有界估计；
- task descriptor p 与少量 expert force-position trajectories 可用；
- NNBO 的 robust auxiliary-system + HJB critic + reference realization 保留；
- piecewise-stationary / sufficiently slow environment variation。

Out of scope：

- environment-only 猜测人类偏好；
- direct independent K,B optimization；
- arbitrary contact-rich mode switching；
- 仅靠 cost weight 保证 hard safety；
- 一般 differentiable MPC 新算法。


======================================================================
5. PIB-NNBO Method
======================================================================

5.1 Preference-identifiable objective

定义 dimensionless features：

  q_e(X;p) = ||e/e_scale(p)||^2，
  q_f(X,f;chi,p) = ||f/f_scale(chi,p)||^2。

e_scale、f_scale 是任务给定 tolerance；只有当同一 raw force 在不同材料上对应不同 physical consequence 时，f_scale 才依赖 chi。环境 dependence 必须进入 physically interpretable feature/normalization，而不是自由改变 preference。

用一个有界 log-ratio eta 表示 tracking-force preference：

  alpha(eta)=alpha_min+(1-2alpha_min)sigmoid(eta)，
  l_eta=alpha q_e+(1-alpha)q_f+zeta_epsilon^2。

这把原 1-D interaction 中无结构的 Q、R 搜索变为一个明确的 Pareto coordinate。alpha_min>0 保证 force penalty positive definite。若任务确有多个独立 consequence，再扩展为 simplex eta；不默认输出 full matrices。

eta 的信息来源为：

  eta=h_psi(p,chi)，

但 h_psi 必须有 p 或 outer supervision。若只给 chi，不允许宣称 learned objective 有 task meaning。

5.2 Parametric robust HJB

令 Q_eta、R_eta 是上述 normalized cost 的矩阵表示。定义：

  B(V,eta;chi)(X)
  =grad V^T F_chi + X^T Qtilde_eta X + zeta_epsilon^2
   -0.25 grad V^T G_chi R_eta^{-1}G_chi^T grad V
  =0。

最优 policy 仍为：

  f*_eta(X;chi)=-0.5 R_eta^{-1}G_chi^T grad V*_eta。

HC estimator、auxiliary dynamics、uncertainty term与 Newton x_r implementation 不改变。

5.3 Exact Bellman sensitivity

令 S_j(X)=partial V*_eta(X)/partial eta_j。对 HJB 使用 envelope theorem，得到线性 sensitivity equation：

  grad S_j^T [F_chi+G_chi f*_eta]
  + partial_eta_j(X^T Qtilde_eta X)
  + f*_eta^T(partial_eta_j R_eta)f*_eta
  =0，

  S_j(0)=0。

若 optimal closed loop 渐近稳定，则：

  S_j(X_0)=integral_0^infinity
    [partial_eta_j q_eta(X_t)+f*_t^T(partial_eta_j R_eta)f*_t]dt。

policy sensitivity 为：

  partial f*/partial eta_j
  =0.5 R_eta^{-1}(partial_eta_j R_eta)R_eta^{-1}G_chi^T grad V*
   -0.5 R_eta^{-1}G_chi^T grad S_j。

该式精确说明 objective change 既有 direct R effect，也通过 entire value gradient 产生 indirect future effect。只对 f* 的显式 R 项求导是错误的短视梯度。

5.4 Implementable critic-level IFT

在 replay/concurrent-learning sample set D={(X_i,chi_i,eta_i)} 上定义 Bellman residual delta_i(W,eta,chi)，并令：

  E_c(W;eta,chi)=0.5 sum_i omega_i delta_i^2 + 0.5 lambda_W||W||^2。

critic fixed point 由：

  g(W,eta,chi)=grad_W E_c=0

定义。若 H_WW=partial g/partial W nonsingular，则：

  dW*/deta=-H_WW^{-1}H_Weta。

对 outer loss L，不显式构造 full Jacobian；解 adjoint：

  H_WW^T v=(partial L/partial W)^T，

得到：

  dL/deta=partial L/partial eta-v^T H_Weta。

这与 IDOC 的思想同构，但 linear system 是 critic/Bellman normal-equation Jacobian，不是 trajectory KKT matrix。可用 Hessian-vector product 与 conjugate gradient；不需要展开 critic training history。

5.5 Outer learning signal

主设置冻结为 sparse demonstration supervision：

  L_out=sum_t ||x_t-x_t_demo||_{W_x}^2+||f_t-f_t_demo||_{W_f}^2。

demonstration 规定 task preference evidence；chi 规定 environment dynamics。二者不混为一个 environment-only input。将 delayed task consequence C_task(tau) 作为 outer loss 属于后续扩展，不放入主 Method；若 C_task 本身可直接、实时进入 HJB，则 objective learning 无必要，应直接优化 C_task。

outer derivative 还须通过 closed-loop dynamics，而不能只对单点 f 求导。对 rollout state sensitivity或 adjoint求：

  dL_out/deta = L_eta + integral lambda_x^T G_chi(partial f*/partial eta)dt。

5.6 Training and deployment

Offline/meta-training：

1. 从多个 soft-environment chi 与 task preference p 收集 safe trajectories / simulations；
2. 对当前 eta=h_psi(p,chi) 收敛 critic fixed point g=0；
3. 计算 closed-loop outer loss；
4. 以 critic-level implicit VJP + rollout adjoint 得到 dL/dpsi；
5. 更新 psi，并检查 objective positivity、critic Hessian conditioning 与 Bellman residual。

Online：

1. EWRLS 按 NNBO 原流程估计 chi；
2. h_psi(p,chi) 输出 eta；
3. 原 critic 以邻近 context 权重 warm start 并按 NNBO 更新；
4. 按原 f_hat -> S(x_r)=0 -> x_r 流程执行。

若环境变化快于 critic 收敛，则本架构不具备所声称能力。此时才需要 conditional critic V(X,chi,eta) 或 MPC；conditional critic 属于第二阶段工程扩展，不能预先加入主 Method。

6. 理论结论与证明义务
======================================================================

T1. Environment-preference non-identifiability

已由第 2.2 节反例成立。它否定 environment-only Q,R predictor，并规定输入信息边界。

T2. HJB sensitivity correctness

若 V*_eta 在邻域内唯一且 C^2，R_eta 正定，closed-loop optimum 唯一，HJB operator 关于 V 的线性化可逆，则第 5.3 节 sensitivity equation 由 IFT 与 envelope theorem 得到。该结论是 exact optimum 层面的理论结果。

T3. Critic-level hypergradient correctness

若 E_c 二阶连续、g(W*,eta,chi)=0 且 H_WW 非奇异，则第 5.4 节 implicit VJP 等于所收敛 critic branch 的 exact derivative。它不等于自动宣称 true HJB gradient；两者差异由 approximation error 控制。

T4. Value-gradient error to policy error

若 ||grad V_hat-grad V*||<=epsilon_grad，R_eta>=r_min I，||G_chi||<=g_max，则：

  ||f_hat-f*||
  <= g_max epsilon_grad/(2 r_min)。

若 Newton reference map S(x_r)=0 在解处满足 |partial S/partial x_r|>=m_S>0，则由 IFT：

  |x_r_hat-x_r*|<=C_S epsilon_grad+O(epsilon_grad^2)。

这给出 critic approximation -> force policy -> executable reference 的完整误差链。

T5. Hypergradient error

若 ||H_WW^{-1}||<=kappa_H，H_Weta 和 outer derivatives 有界，则 residual/Jacobian perturbation epsilon_B 引起的 hypergradient error 为 O(kappa_H epsilon_B)。condition number 必须报告；不能只验证 outer loss 下降。

T6. Robustness inheritance boundary

只要 learned eta 保证 Q_eta>=0、R_eta>0，且 original robust auxiliary-control conditions 对每个 eta 的 admissible policy成立，objective learning不改变 uncertainty decomposition。它可以继承 NNBO 的 robust-control reduction，但不能无条件继承原 critic convergence proof。

T7. 必须修正 NNBO 原文的 PE 推理

原文从 instantaneous lambda_min(xi xi^T)>0 推 Ldot<0，再用 interval PE 支撑该条件。对于 m>1，xi xi^T 是 rank-one，instantaneous minimum eigenvalue恒为 0；integral PE 不等价于 pointwise positive definiteness。因此最终论文必须改用 linear time-varying PE/UUB theorem 或 concurrent-learning Gramian：

  sum_i omega_i nu_i nu_i^T >= beta I，beta>0，

并在该 integral/batch condition 下证明 critic error exponential convergence/UUB。不能复制原式 (45)-(48) 的 pointwise eigenvalue 论证。

T8. Two-timescale condition

若 eta 在线变化，critic tracking error 满足：

  ||W_hat(t)-W*(eta(t),chi(t))||
  <= transient + c_eta sup||eta_dot|| + c_chi sup||chi_dot|| + c_sigma epsilon_approx。

因此部署 claim 必须限定 eta、chi 的变化率相对 critic convergence rate 足够小；否则 outer objective 再正确也不能实时实现对应 optimal policy。


======================================================================
7. 路线对比：为什么这是最小充分修改
======================================================================

Route A：仅把 Q、R 做归一化。

优点：最小；修复量纲问题。缺点：仍需人工 preference mapping，不能从 demonstration/outcome 学习。只能作为 simpler baseline。

Route B：environment/task -> free Q,R + 直接套 IDOC。

淘汰原因：environment-only 欠定；free matrices 过参数化；IDOC 与 infinite-horizon critic 不匹配。

Route C：PIB-NNBO（选定）。

改动：一个 identifiable objective coordinate + 一个 critic fixed-point implicit VJP。保留 NNBO 主干和 deployment semantics，逐一修复 information failure 与 derivative failure。

Route D：finite-horizon constrained MPC + IDOC + direct K,B。

它在 hard constraints、preview、rate limits、direct variable impedance 是 problem requirement 时更优；但对当前 objective-calibration问题增加 solver、decision、stability 与 evidence burden，属于不必要重构。Differentiable Robust MPC、ZipMPC、Performer-MPC 属于该 superclass 的强 method priors，不是当前 impedance-HJB problem 的直接否决证据。

Route E：DECOR-IC。

它解决 representation sufficiency / partial identifiability，不解决 objective information source。除非先证明 HC/EWRLS 的 decision-irrelevant identification 是主要性能瓶颈，否则不能由当前 failure 推出。

Route F：black-box BO/RL 调 Q、R。

不要求 differentiability，但 interaction/sample burden较高。若只学习一两个 scalar 且 real-system trials 便宜，BO 可能比 PIB-NNBO 更合适；所以 PIB-NNBO 的目标场景必须包含 costly interaction、多 context reuse 和可用 differentiable/identified dynamics。


======================================================================
8. 与当前领域方法的本质关系
======================================================================

1. Impedance/admittance optimization 文献已经解决“给定 cost 后优化 interaction”，包括 NNBO 和近期 constrained/gradient-based adaptive admittance。它们没有自动赋予 Q、R task meaning。

2. Multiobjective Bayesian optimization 已说明 impedance tuning 的 transient/steady-state tradeoff 可由少量 trials 搜索。它是同问题的 simpler black-box rival；PIB-NNBO 必须在 model reuse、gradient efficiency 或跨 environment transfer 上形成 capability gain。

3. Differentiable Robust MPC、Performer-MPC、ZipMPC 已覆盖 automatic/context-dependent MPC cost 的通用机制。因此“NN 输出 cost + optimizer + backprop”不是创新。它们不直接解决 continuous-time robust HJB critic 的 implicit sensitivity，也不规定 soft-contact preference identifiability。

4. IDOC 提供 finite-horizon constrained trajectory derivative 的高效 differential-KKT 求解。PIB-NNBO 的新技术对象是 Bellman fixed-point derivative；IDOC 是 source mechanism，而不是可直接复用的 backend。

5. 若最终改为 finite-horizon direct K,B MPC，则必须承认研究主线已经变为 model-predictive variable impedance，而不是 NNBO critic extension；不能同时声称“仅对 NNBO 做小改”。


======================================================================
9. Venue 标验收
======================================================================

D1 Problem Level：PASS。

问题不再是“省去调参”，而是使 nonlinear soft-contact optimal feedback 能从可观测 preference evidence 中获得 task-identifiable objective，并跨环境复用。该能力缺口真实且与 physical interaction 直接相关。

D2 Scientific Delta：T-RO POTENTIAL，尚不能用“组合 NNBO+IDOC”表述。

主 delta 必须表述为：首次建立 preference identifiability -> robust HJB fixed-point sensitivity -> executable NNBO policy 的理论与算法闭环。若最终只实现 free Q,R regression 或 finite-difference tuning，则降为 incremental。

D3 Packaging：PASS。

一个主机制；HC/EWRLS、critic、Newton realization 是继承主干；IFT、adjoint、PE 是 support，不拆成多个创新点。

D4 Complexity：ALIGNED。

相比 NNBO 仅增加 low-dimensional eta generator 与 training-time implicit linear solve。没有第二个 online optimizer、direct-impedance stack 或 representation learner。

D5 Method Necessity：PASS WITH A SHARP RIVAL GATE。

当 outer supervision 存在、interaction昂贵且需要跨 context reuse 时，analytic hypergradient 比 per-environment trial-and-error自然。若只有单个 scalar、少量环境且 trials 便宜，BO/bisection 是更合适路线，顶刊 Method claim 不成立。

D6 Theory：当前为可闭合设计，尚需完成正式 proof。

必须完成 T2-T5、T7-T8；尤其修正原 PE 证明并区分 true-HJB sensitivity 与 approximate-critic sensitivity。

D7 Engineering：可行但限定 slow context variation。

online 路径保留原 NNBO；implicit solve 主要在 training。若每次环境骤变都要从零重新收敛 critic，则不满足实时 adaptation claim。

D8 Evidence：本文件暂不展开实验。未来证据必须针对 objective transfer，而不是只比较同一 learned cost 下的低 cost value；否则 evaluation 是自证循环。

最终判断：

  - DECOR-IC：对当前 failure，REJECT（过度重构）。
  - 原始 environment->NN(Q,R)->IDOC：REJECT（问题欠定 + solver mismatch）。
  - PIB-NNBO：理论 Method 结构达到 T-RO-aligned candidate；正式顶刊 PASS 依赖上述 theorem completion 与后续 evidence。
  - IJRR：当前不主张。除非 Bellman implicit differentiation 被推广为更一般的 continuous-time constrained feedback theory，并在多个 interaction classes 上统一，否则问题一般性不足。

10. 冻结后的最简技术路线
======================================================================

  sparse expert force-position demonstrations + task descriptor p
  + EWRLS soft-environment estimate chi
  -> identifiable normalized tradeoff eta=h_psi(p,chi)
  -> original robust NNBO HJB B(V,eta;chi)=0
  -> original critic and force policy f*_eta
  -> original nonlinear target-impedance/reference realization x_r
  -> closed-loop outer loss
  -> Bellman fixed-point implicit VJP + rollout adjoint
  -> update psi。

禁止在主 Method 中预先加入：

- decision-equivalent contact representation；
- direct K,B optimizer；
- finite-horizon MPC；
- energy tank/passivity module；
