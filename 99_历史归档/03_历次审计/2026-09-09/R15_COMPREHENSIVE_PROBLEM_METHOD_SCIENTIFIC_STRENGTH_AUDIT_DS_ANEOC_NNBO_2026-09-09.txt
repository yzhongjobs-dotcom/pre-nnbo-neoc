======================================================================

严格结论：当前研究问题与核心技术路线具有真实、清楚且有顶刊潜力的匹配关系；核心
Scientific Delta 在已核 strongest-prior 边界内成立，跨领域机制迁移也成立。但完整路线
目前还不能无条件判为“同时完全达到 Problem fit、Method necessity 和 top-venue-ready

  Problem fit                         ALIGNED，经验中心性仍待直接证据
  Core mechanism fit                  ALIGNED

  Target-domain scientific delta      ALIGNED-PROVISIONAL
  Theory depth                        ABOVE-BUT-JUSTIFIED
  Exact-HJB claim closure             CONDITIONAL；实例化前仍有 Closure Veto 风险
  Engineering closure                ALIGNED-CONDITIONAL

这里最重要的区分是：

  1) 研究问题不是伪问题，核心机制也不是拼接；
  2) paper-level 新关系在当前检索边界内没有被 strongest prior 覆盖；

所以答案不是“需要推翻”，也不是“已经完全通过”。最准确的决定是：保留核心路线，冻结
主 Scientific Delta；在进入大规模实验前，先关闭第 9 节的四个决定性 discriminator。

1. 固定审计参照系
======================================================================

1.1 Target failure

未知、缓慢时变的非线性软接触环境中，低扰动持续接触数据可能只识别 HC 参数的部分组合。
参数误差的欧氏大小并不等于控制后果：某些 observation-null directions 不改变最优动作，
另一些方向会改变 HJB-optimal actual-force policy。与此同时，theta_hat 更新后，原 NNBO
critic 仍表示旧 frozen environment，形成 stale-optimum error。

1.2 Root cause

根因不是单纯“辨识精度不足”或“critic 学得慢”，而是两个相关的 relation mismatch：

  RCA-1：observation equivalence != optimal-policy equivalence；
  RCA-2：static HJB root update != moving HJB solution-branch tracking。

1.3 Required mechanism change

需要一个共同的局部对象，把 parameter variation 映射到 actual optimal policy variation；
该对象必须同时回答：

  哪些参数歧义需要消除？
  当前 critic 应沿哪个方向移动？

1.4 Target constraints

  单点、单方向、持续接触；
  无量纲 HC 模型与 p=3 的低维参数；
  环境缓慢变化且仅局部 regular；
  低扰动数据，主动 excitation 受 contact/actuator bounds 限制；
  保留 NNBO single critic 与 position-based realization；
  不使用第二 actor/critic、在线 MPC 或无界 probe optimization；
  只有 actual applied force/reference 通过 gate 后才允许发布。

1.5 当前理论的新增 scope condition

为消除“delta_s>0 但绝对 force cost 的无折扣无限积分发散”这一矛盾，Final Method 把主理论
限定为围绕可行持续接触平衡 (X_s,f_s(theta)) 的增量调节。这一修正数学上必要，但它使
论文的问题对象比原先的一般“NNBO optimal interaction”更窄。Introduction、baseline 和
实验必须全部使用同一个 equilibrium-centered objective；否则会形成 problem drift。

======================================================================
2. Problem fit 审计
======================================================================

2.1 为什么问题是真实的

原 NNBO 的 HC/EWRLS 依赖接触轨迹提供足够激励；其 critic 又对应当前估计环境的 HJB。
低扰动交互天然限制速度和压入变化，因此 K_e、B_e、n 可能只通过少数局部组合进入观测。
当两个观测等价环境需要不同 actual optimal forces 时，任何只看同一历史的控制器都无法
同时接近两者的 optimum。Final Method 的式 (41) 已把这个事实写成 two-point lower bound。

参数漂移则产生第二个真实 failure：即使新 theta_hat 是正确的，旧 critic 仍求解旧 HJB。
遗忘因子只更新 estimator，普通 Bellman learning 只会渐近追逐新 root，二者都没有给出
moving root 的一阶运输。

这两个 failure 都作用在实际 interaction policy 上，而不是只作用于 parameter MSE 或训练
loss，因此属于机器人软接触控制中的能力缺口。

2.2 为什么问题不是人为制造的

Final Method 没有要求“所有环境参数必须不可辨”，只要求存在 task/data 条件使 observation-
null 与 decision-null 不一致；若二者一致，DSI 直接通过且不探测。它也没有假设所有参数
变化都值得追踪；若 P_theta 很小，更新被自动降权。因此 problem statement 不依赖把普通
估计误差夸大成普遍危机。

2.3 Problem fit 的证据缺口

当前材料建立了机制可行性，但尚未证明该 failure 是目标应用中的主要性能瓶颈。还缺：

  同一低扰动预算下 I_data 的谱与 null-space 稳定性；
  null directions 上 actual P_theta 的投影；
  stale critic error 相对 estimator error、inner-loop error 的占比；
  环境变化时间尺度与 re-solve/critic convergence 时间尺度的比值；
  equilibrium-centered task 是否覆盖目标应用的主要操作阶段。

若这些量显示 full identification 容易、P_theta 在 null space 上近零，或变化远慢于从头重求，
则 paper-level problem 会缩小。故 Problem fit 判为 ALIGNED，而“领域核心痛点的经验中心性”
仍需验证，不能提前写成普遍事实。

2.4 Problem scope 风险

当前一句话问题仍容易被读成一般软接触 optimal impedance，而主定理只覆盖 equilibrium-
centered、interior-action、single-contact、slow-drift local branch。若标题/摘要不写清这四项，
会触发 narrative inflation。正确包装应是“continuous soft-contact regulation around a
feasible contact equilibrium”，而不是一般 contact-rich optimal impedance framework。

Problem fit 最终判定：ALIGNED，scope 必须收紧到真实定理域。

3. Source mechanism 迁移与创新合法性
======================================================================

3.1 Source Problem-Intervention Pair

Source：parameter-dependent closed-loop neighboring-extremal optimal control（NEOC）。

  Source problem：参数变化后，已求得的 closed-loop infinite-horizon optimum 如何局部调整；
  Source intervention：对定义 optimum 的 HJB/Galerkin root 直接求参数导数；
  changed relation：theta -> HJB solution/policy 的静态重求变为局部 solution-branch tangent；
  effect：用一阶 predictor 和 homotopy 近似邻近参数下的最优闭环律；
  boundary：已知参数变化、regular branch、局部光滑性、admissible closed loop。

3.2 Target Required Mechanism Change

Target 需要的是 theta uncertainty/drift -> actual optimal-force change 的映射。它不仅用于
移动 critic，还必须判断 observation ambiguity 是否改变控制决策。

3.3 Intervention-level isomorphism

  variable role：两者都是环境参数 theta；PASS。
  changed relation：两者都改变 theta -> closed-loop optimum；PASS。
  intervention position：都在 HJB solution map，而非 estimator 或 inner loop；PASS。
  activation：local regular parameter change；PASS。
  target mismatch：theta 是估计量、信息可能奇异、critic 近似、action 要转成 reference；
                   这些 mismatch 被 robust DSI、Galerkin/re-anchor、reference gate 修复。

因此迁移是机制同构，不是因“NEOC 也是控制方法”而表面套用。

3.4 迁移后真正新增了什么

NEOC 已经给出 HJB/policy sensitivity、Galerkin sensitivity 与 homotopy；这些均不能单独
作为创新。application-oriented identification 已经说明并非所有参数误差同等重要；
decision-weighted probing 和 online identification + neighboring extremal 也已有一般先例。

当前仍成立的 target-domain Scientific Delta 是：

  用同一个 actual-force HJB policy tangent，构造从 observation quotient 到 optimal-policy
  quotient 的 decision-sufficiency map，并把该 tangent 同时作为 moving NNBO critic 的
  transport generator；由此形成 information gate -> conditional probe -> root transport
  -> actual reference -> performance/stability 的单一发布闭环。

这属于经验标尺允许的“已有 source primitive 获得新的 control relation / role / capability”。
改造并非仅换场景：source NEOC 不处理 estimated partial information，也不决定何时应采集
信息；target adaptation 改变了 sensitivity 在闭环中的角色。

3.5 Novelty 边界

截至当前已核全文，没有 prior 覆盖上述完整 problem-mechanism-role-capability，因此未触发
Novelty Veto。但这是 bounded-search conclusion，不是绝对首次证明。正式投稿前必须更新
检索，尤其攻击以下交叉区域：

  dual/control-oriented identification + HJB policy sensitivity；
  adaptive dynamic programming with parameterized critic continuation；
  task-oriented experiment design for nonlinear feedback policies；
  set-membership optimal control under partial identifiability。

Scientific Delta 判定：ALIGNED-PROVISIONAL。跨领域迁移提高了创新强度，但创新必须包装
为新的 relation/capability，不能写成 NNBO+NEOC、implicit differentiation、homotopy 或
Fisher information 的组合首创。

4. Method fit / necessity：主要机制路线淘汰
======================================================================

4.1 Route A：full identification + 从头重训/重求 NNBO

Intervention：先让 I_data 满秩并恢复完整 theta，再求新 HJB。

优点：对象直接、无需 DSI。失败：在低扰动数据下可能没有完整信息权；它对 decision-null
方向也支付辨识和激励成本；每次漂移后仍有 root-convergence delay。

判定：在 partial, decision-relevant ambiguity 成立时 FAIL；若 I_data 在相同预算下稳定
满秩且重求足够快，它是更简单正确路线，并否决完整 DS-ANEOC。

4.2 Route B：full identification + NEOC

Intervention：完整估计 theta 后，用 source NEOC 运输 critic。

它闭合 moving-optimum tracking，但不闭合“现有部分信息是否已经足够”，仍要求无差别 PE。
当 full ID 容易时，它比当前路线更简单；当 full ID 困难且部分信息已足以决策时，它过度
辨识；当 ambiguity 改变 policy 时，它又没有决定如何最小补信息。

判定：是最危险的简化竞争者之一；胜负由 I_data rank、probe burden 和任务误差决定。

4.3 Route C：forgetting/concurrent-learning NNBO

Intervention：提高 estimator/critic 对漂移的常规追踪速度，不显式求 solution tangent。

它可以改善 stale critic，但不能区分 harmless 与 harmful parameter ambiguity，也没有局部
二阶运输保证。若其实测 moving-optimum error 与 ANEOC 相同，则 ANEOC predictor 没有净
必要性。

判定：不能在机制上完整闭合两个 RCA，但可能在目标时间尺度上经验等价；必须直接比较。

4.4 Route D：robust fixed/set-based NNBO

Intervention：对整个参数集合求一个共同的 robust/minimax policy，不恢复真实 optimum。

它无需主动辨识，稳定性语义可能更直接。但若集合中两个环境的 optimal policies 按式 (41)
分离，则任何共同 policy 都有不可消除的 action gap；它闭合 robustness，不闭合“持续跟踪
每个真实 frozen optimum”。若 robust policy 在允许误差内已足够，则 DSI/probe 是过度设计。

判定：对 near-optimal tracking 目标一般不等价；对较松性能预算可能支配当前路线。

4.5 Route E：finite-difference P_theta + warm-start/Newton re-solve

Intervention：在 theta_hat+/-h e_j 重求 Galerkin roots，用中心差分构造 policy sensitivity；
参数变化后直接 warm-start Newton，而不维护解析 ANEOC tangent theorem。

它能近似构造 DSI，也能避免旧 critic 长期训练。对于当前 p=3、原始 m=3 的小系统，六次
邻近 root solve 可能足够便宜，而且实现/证明显著更简单。这是当前 Method necessity 最大的
未闭合挑战。解析 tangent 的优势只有在以下至少一项成立时才成立：

  root solve 明显贵于一次 factorization + 三个 RHS；
  analytic tangent 的误差/稳定性证书显著优于 finite difference；
  高频连续更新使多次 re-solve 超过 deadline；
  basis 扩展后 m 足够大，使复杂度差异实质化。

判定：UNRESOLVED DISCRIMINATOR。未做 wall-clock/error comparison 前，完整 Method
necessity 不能无条件 PASS。

4.6 Route F：parameter-conditioned critic/policy retrieval

Intervention：离线学习 V(X,theta) 或压缩参数条件策略，在线直接检索。

它可处理更大参数变化且在线开销小，但需要覆盖 Theta 的离线数据/求解，仍不能独自解决
partial-information ambiguity；若与 set inference 结合，训练与验证负担更高。当前约束强调
保留单 critic、少量在线数据和局部漂移，因此 ANEOC 更自然。若可获得密集离线 environment
coverage，则 conditional critic 可能更合适。

判定：当前约束下不支配；是 operating-regime 改变时的替代路线。

4.7 为什么当前核心路线仍是最自然候选

在以下联合条件下：

  I_data 确有 rank deficiency；
  至少一个 null direction 对 actual optimal policy 有显著影响；
  自然数据不能在允许时间内消除该 ambiguity；
  存在满足 contact bounds 的有限 probe；
  环境漂移小于 branch trust radius，但快于普通 critic/re-solve convergence；
  analytic tangent 相对 finite difference/re-solve 有可测计算或误差优势；

DS-ANEOC-NNBO 是最小的完整 causal repair。DSI 修复 RCA-1；同一个 tangent transport 修复
RCA-2；probe 只在 DSI 失败时激活；corrector、admissibility 和 reference 只是使主机制可
正确执行的 support。不存在两个互不相关的 paper-level objectives。

如果上述联合条件中任一决定性条件长期不成立，应按第 9 节删减路线，而不是用更宽 claim
保护完整架构。

Method fit / necessity 最终判定：ALIGNED-CONDITIONAL，而不是无条件 PASS。

5. Scientific strength
======================================================================

5.1 创新性

创新单位是一个 relation：observation equivalence 通过 actual-force HJB tangent 映射成
policy equivalence，同时该 tangent 生成 moving optimum 的局部运输。这比“更精确辨识”或
“更快 critic”提供了新的控制原则：信息充分性由任务最优动作决定，而非由参数空间本身决定。

该 relation 具有可证伪性：如果 ker(I_data) 已为空、ker(I_data) subset ker(P_theta) 总成立，
或 finite-difference/re-solve 等价支配，则 Scientific Delta 的实际价值会下降。可证伪边界
增强科学性，不削弱它。

判定：相对 NNBO/NEOC 原子 prior 是 nontrivial target-domain delta，处于 T-RO 候选分布。

5.2 科学深度

理论不是公式数量堆积，而是围绕同一对象形成：

  exact closed-loop HJB sensitivity；
  Galerkin root inf-sup/Kantorovich regularity；
  approximate-tangent + second-order robust DSI；
  two-point impossibility boundary；
  blockwise predictor-corrector/re-anchor tracking；
  actual reference root 与 force realization；
  exact action-gap performance identity；
  drift/disturbance/policy-error UUB。

这条链的深度高于一般会议级“模块 + 实验”，并与近最优、稳定、在线发布等 claim 相匹配。
因而 Theory Depth 为 ABOVE-BUT-JUSTIFIED。

5.3 理论闭合仍有的关键风险

风险 T1：exact-HJB a posteriori gate 尚未真正实例化。

Final Method 以 candidate closed-loop 衰减构造 transport operator 的 C1 right-inverse bound
kappa_H。仅有状态指数衰减并不足以自动给出 C1 inverse bound；还需要 state-transition
Jacobian、residual-gradient、正不变域和 characteristic boundary 的明确界。覆盖网格加一个
标量 Lipschitz remainder 也只在所声明范数下有效。若这些量无法计算，则 exact-HJB policy
error epsilon_G/epsilon_P 仍是 assumption，不是 certificate。

处置：完成加权 C1/C2 空间中的 transport inverse lemma 与可计算常数；若做不到，把主理论
comparator 降为 verified Galerkin optimum。不得一边降级算法、一边保留 exact-HJB 标题 claim。

风险 T2：incremental equilibrium objective 改变了与 NNBO 的比较对象。

修正 M12 是正确的，但 baseline 也必须使用同一 X_s、f_s 和增量 cost。若用原 NNBO 的绝对
force objective 作 baseline，而用增量 objective 评价当前方法，性能比较不公平；若继续声称
“完全保留 NNBO objective”，则定义不实。

风险 T3：reference equation 仍需与实际 inner-loop wiring 一一对应。

式 (54)-(58) 给出正确的抽象根条件，但 NNBO 原实现可能以 measured-force matching 而非
固定 f_target 形成 S(x_r)。最终代码、论文方程和实验记录必须选择一个版本；不能用“只需
替换”同时覆盖两套闭环。

风险 T4：统计 coverage 与 worst-case certificate 的语义必须统一。

若 C_t 来自经验校准，主结论是声明覆盖率下的 probabilistic guarantee；若来自 deterministic
set membership，才是集合内确定性保证。实验不能混用两种语言。

5.4 完整性

Method specification 已覆盖 estimator -> information -> candidate policy -> actual reference
-> applied force -> performance/stability，并给出 no-authority/fallback。这比旧稿完整。

然而“完整 Method”与“实例已闭合”仍不同。D2/D3 Galerkin tangent test、kappa_H、epsilon_P、
epsilon_G、m_ref、mu、probe coverage 尚无具体数值。对 exact-HJB 与 actual-robot claim，当前
仍是条件定理。

Scientific strength 判定：概念创新与理论结构达到 T-RO 候选水平；完整 top-venue readiness
尚未达到。

======================================================================
6. Complexity 与是否过度设计
======================================================================

Complexity vector：

  C_model      中等：HC + contact-equilibrium shift；
  C_learning   中等：nonlinear EWRLS/Gauss-Newton + one critic；
  C_solver     中等：one Galerkin factorization、多 RHS、small QCQP、finite probe library；
  C_guarantee  高：robust DSI、finite/function-space Kantorovich、admissibility、reference、UUB；
  C_execution  中等：low-rate candidate loop + high-rate position realization + atomic fallback；
  C_evidence   高：每个 gate、probe、transport、reference 都需要直接验证。

与 Pollayil T-RO 相比，本方法明显更重；额外复杂度对应 partial information 与 moving optimum
两个额外 failure，原则上有理由。与 Li T-RO 相比，模块数和系统闭环相近，但本方法把更多
负担放在 certificate 而非 learned feedback。与 NNBO 相比，新增复杂度只有在 DSI 避免无谓
探测、ANEOC 减少 root-update delay 时才产生净价值。

当前 online probe OCP 已被有限 library 删除，这是正确收敛。主要 overdesign 风险转移到
exact-HJB function-space certification：如果它需要在线高维 interval verification，复杂度会
ABOVE-BUT-UNJUSTIFIED。最自然做法是把与固定 domain/basis 有关的 derivative/inverse bounds
离线预计算，在线只更新低维 margin；若仍无法满足 deadline，则降低 exact claim，而不是
增加求解器。

复杂度判定：核心算法 ALIGNED；guarantee layer 暂为 ABOVE-BUT-JUSTIFIED/UNRESOLVED。

9. 四个决定性 discriminator 与最小收敛方向
======================================================================

D1 Problem discriminator

测量低扰动任务中 I_data 谱、ker(I_data) 上 P_theta energy，以及它们造成的真实 action gap。

  若 partial + decision-relevant：保留 DSI/probe；
  若 full ID 容易：简化为 full-ID + transport；
  若 null 始终 decision-null：删除 probe，只保留 no-probe sufficiency certificate。

D2 Transport discriminator

在完全相同 basis、stack、tolerance 和硬件上比较：

  analytic ANEOC predictor-corrector；
  finite-difference P_theta + warm Newton；
  direct warm Newton/re-anchor；
  forgetting/concurrent-learning NNBO。

报告 policy error、root residual、失败率、P50/P95/P99/max time 和 drift bandwidth。若 m=3
时 analytic transport没有实质优势，删除或降为理论分析，不得因“更漂亮”保留为主模块。

D3 Robust-policy discriminator

比较 robust fixed/set-based NNBO 与 DSI-triggered adaptation，在同一 uncertainty set、实际
force error 和 probe burden 下报告 worst-case/average action gap。若 robust baseline 已在
epsilon_D 内，主动信息与完整适应没有 necessity。

D4 Exact-comparator discriminator

在冻结 Omega_X、basis 和 stack 后给出 kappa_H、epsilon_full、epsilon_G、epsilon_P 的复算
过程，并完成 D2/D3 derivative tests。

  若通过：保留 exact-HJB local claim；
  若失败：统一把标题、定理、DSI 和评价对象降为 verified Galerkin-optimal policy；
  禁止新增第二网络、MPC 或更重 certificate 来保护原 claim。

同时必须执行两个接口闭合：

  固定 measured-force matching 或 fixed-target reference equation 中唯一一个实际版本；
  所有 baseline 使用同一 equilibrium-centered state/cost，避免 objective advantage。

这些动作都是裁剪、验证或 claim 对齐，不需要增加新方法模块。

======================================================================
10. 三项标准的最终回答
======================================================================

10.1 Problem fit

是，机制上准确命中了软接触在线最优控制中的真实问题：partial observation information 不能
直接推出 optimal-decision sufficiency，参数漂移又使 HJB critic 过时。它比“提高 HC 参数
精度”更接近真实控制后果。

限定：该结论只对 equilibrium-centered、持续接触、slow-drift local branch 成立；其作为
目标领域主要瓶颈的普遍程度仍需 D1 证据。因此判为 ALIGNED，不判 universal core pain point。

10.2 Method fit / necessity

核心机制是自然的：Required Mechanism Change 正是 theta -> closed-loop optimal policy，
NEOC/HJB tangent 在 intervention level 与其同构；同一 tangent 同时服务 DSI 和 transport，
所以不是方法拼接。

但完整路线的必要性尚为条件成立。尤其在 p=m=3 时，finite-difference + warm re-solve 可能
更简单；robust fixed NNBO 也可能在允许误差内足够。未关闭 D2/D3 前，不能宣称“最合适且
必要”已经由证据确定。判为 ALIGNED-CONDITIONAL。

10.3 Scientific strength

创新性与科学深度足够形成 T-RO 级候选：跨领域迁移改变了 policy tangent 在软接触控制中
的角色，产生了 observation quotient -> policy quotient -> information/transport 的统一关系；
理论和实际执行链也明显超过普通 warm-start 技巧。

完整性仍分两层：相对 Galerkin branch 的 Method 已闭合；相对 exact HJB 和真实机器人能力
仍需 T1/T3/T4 与实验验证。当前 Scientific strength 是“强且可信的 method hypothesis”，
不是已经完成证据闭环的顶刊成果。

11. Venue fit

ICRA/RSS：若用聚焦的 Galerkin-DSI + real-time robot evidence 表达，一个清晰机制与直接控制

多自由度/多 contact family，或以非常强的跨任务实证证明一般控制意义，否则不应把局部
HC 持续接触结果包装成 IJRR framework。

======================================================================
12. 冻结后的主张方式
======================================================================

推荐主 claim：

  For slowly varying continuous soft contact around a feasible equilibrium,
  DS-ANEOC-NNBO uses the same closed-loop HJB policy tangent to certify whether
  partially identified environment uncertainty is decision-sufficient and to
  transport the single-critic optimum when it is; when it is not, a finite,
  constraint-verified probe library acquires only the missing decision-relevant
  information before an admissible position reference is atomically released.

禁止主张：

  first NEOC impedance control；
  first decision-weighted identification/probing；
  general optimal impedance under arbitrary contact；
  hard safety without the declared model/uncertainty envelope；
  exact-HJB guarantee before the a posteriori constants are instantiated；
  real-time superiority before P95/P99/max comparison；
  top-journal readiness before evidence closure。
