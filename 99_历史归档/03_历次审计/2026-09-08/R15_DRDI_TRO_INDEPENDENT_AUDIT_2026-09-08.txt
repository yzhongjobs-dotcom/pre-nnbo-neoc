0. 审计结论
======================================================================

总体结论：NOT ACCEPTED AS T-RO METHOD/THEORY-CONVERGED。

该稿相比 00—06 中的候选蓝图有明显进展：它建立了状态、动作、belief/set、
约束、fallback、passivity 和在线近似的完整接口意识，也主动承认 explicit force、
robust fixed impedance 与 passive adaptation 可以在适用区间获胜。然而，它目前仍
不能通过 T-RO 实验前 Method/理论门槛，原因不是“实验尚未完成”，而是存在四项
实验之前就必须解决的结构性问题：

1. Scientific Delta 被压缩成 decision gate / regret parameterization；新能力仍未
   相对 task-/controller-relevant dual control 明确建立。
2. 专门信息动作 rho 与 nominal torque/reference action 在物理输入通道上不独立，
   导致“被动策略—主动策略”的划分依赖变量命名而非真实 control authority。
3. Theorem 3 没有给出整个 passive/separated policy class 的统一 regret 下界；
   观测分布本身依赖被比较策略，当前固定 P_i^0 的写法不能证明复杂 Method 必要。
4. decision-sufficient latent、actual impedance 和曲面接触坐标下的能量/无源链均未
   完成物理级推导，现有 A1—A6 不能替代这些缺失。

因此，原稿中以下结论撤销：

- “研究问题冻结”；
- “Method necessity THEORY PASS”；
- “Complexity rationality PASS”；
- “Technical depth PASS AT METHOD LEVEL”；
- “Theoretical correctness PASS UNDER A1—A6”；
- “已达到 T-RO Method/理论设计门槛”。

保留的是：目标领域、取消 patient-specific 离线逐点触诊的部署痛点、连续扫描中的
未知空间接触、法向—切向任务耦合、必须对抗强简单替代，以及不追求完整材料参数
辨识的原则。

1. 研究问题层级审计
======================================================================

1.1 真实痛点：PASS

患者/位置相关接触差异、组织与表面运动、连续滑动中的 force–path–slip–contact
耦合，以及 Beber 路线的离线逐点表征负担，均是真实且重要的问题。该研究方向不应
因存在相关 prior 而被放弃。

1.2 当前研究问题表述：BELOW T-RO DISTRIBUTION / METHOD-EMBEDDED

当前问题直接写入：

- “仅当不确定性改变阻抗决策时”；
- “生成信息动作”；
- “更新 decision-relevant belief”；
- “输出法向—切向阻抗”；
- “增量无源”。

这已经不是独立于 Method 的领域问题，而是把预选 Solution Principle、决策变量和
support guarantee 写进问题本身。它使后续 necessity 审计出现循环：先规定问题必须
输出 impedance 并使用 information action，再证明 dual impedance 正好解决它。

真正需要重新确认的领域能力缺口应位于更高一层，例如：

    在没有 patient-specific 预表征的连续超声中，机器人如何在接触属性、表面运动
    和声学可见性共同变化时，自主获得并维持可诊断成像所需的稳定、可恢复、低扰动
    物理交互？

这只是重新调研的 problem hypothesis，不是本审计替用户冻结的新研究问题。它允许
explicit force、scan-speed/force co-planning、image/contact feedback、impedance 或
其他机制在相同目标下公平竞争。

======================================================================
2. Scientific Delta 与当前领域边界
======================================================================

2.1 当前稿正确承认已经覆盖的原子能力

- deformable-contact-aware real-time MPC 已覆盖；
- online estimation + MPVIC + passivity 已覆盖；
- task-oriented exploration、contact-aware FIM、safe SysID 已覆盖；
- explicit dual MPC + set-membership + recursive feasibility 已覆盖；
- target-domain variable impedance、explicit force、disturbance-observer force control
  均有强先验。

2.2 一个遗漏的危险 prior 改变了 novelty 判断

Vantilborgh et al., “Dual Control Reference Generation for Optimal Pick-and-Place
Execution under Payload Uncertainty,” arXiv:2510.20483（2025）明确提出：

- 任务执行中同时进行在线适应与激励；
- reference design 显式包含 closed-loop controller 与 adaptation law；
- 用 expected task cost 或 optimality loss 衡量参数信息的 downstream 价值；
- 只强调 task-/controller-relevant parameters，而不是一般 FIM 精度。

该工作不是本项目的 venue calibration 样本，但作为 strongest-prior/boundary prior
不受 venue 限制。它直接压缩“信息价值由后续任务/控制 regret 定义”这一宽主张。

因此 DRDI 当前可剩余的差异主要是：

- 把 downstream decision 特化为 executable impedance policy；
- 以公共 epsilon-近最优安全策略交集定义 decision cell；
- 加入软接触、硬安全与增量无源接口。

这些差异目前更像 target-specific formalization + safety/execution integration，尚未
证明产生了此前不能获得的机器人能力。不能仅凭“完整关系未在单篇 prior 中同构”
判 T-RO Scientific Delta 成立。

2.3 当前领域的强简单替代压力进一步增大

- Piedra et al., IJRR 2026 已表明 explicit force/moment architecture 可在异质、动态
  超声接触中显著改善 phase lag、force error 和成像结果。
- Li et al., Control Engineering Practice 2026 的 DOSMAC 不在线辨识 stiffness，
  而把 stiffness/position variation 作为 lumped disturbance 实时补偿。
- “Autonomous robotic ultrasound scanning on complex surfaces ... DO-MPAC”，online
  2026 / issue 2027，进一步用 trajectory generation + disturbance observation +
  predictive admittance 在未知曲面和空间刚度变化下获得强 force-tracking 改善。
- Beber et al. 2026 的连续 ergodic palpation 已实现 online viscoelastic estimation、
  spatial GP update 与连续主动探索；它不是 ultrasound scan control，但削弱“连续
  任务交互中在线获得组织信息”作为独立新能力的表述。

这意味着研究必须说明：为什么目标能力不是“更稳定的力跟踪”，也不是“连续组织
建图”，而确实需要一种新的 scan/contact/imaging control relation。

Scientific Delta verdict：INDETERMINATE / CURRENTLY BELOW T-RO。

3. Method necessity 的决定性理论问题
======================================================================

3.1 action decomposition 并不非冗余

稿件写为：

    tau = bar_tau + J_c^T[-K_app e - D_app edot + rho].

其中 bar_tau 决定 nominal force–motion，rho 被命名为信息微交互。但 bar_tau 与
J_c^T rho 作用于同一 generalized torque/contact-wrench channel。除非对 bar_tau 的
可行子空间、频带、时间尺度或投影结构施加互斥约束，否则任一 rho 可被吸收到
bar_tau，任一 nominal action 也可以产生信息。

后果：

- “rho=0 的被动策略”不是由物理 authority 定义，而是由变量标签定义；
- passive/dual policy class 的比较可能人为排除能利用任务动作辨识的简单策略；
- DRDI 的核心 intervention 可能只是对同一控制量重新分块。

必须二选一：

A. 取消专门 rho，让全部 admissible task action 的 dual effect 内生进入统一 OCP；或
B. 给出可验证的正交/频带/时间尺度 authority，使 rho 成为真正独立且临床允许的
   intervention，并证明 nominal controller 不能等价实现。

3.2 Theorem 3 不是 policy-class necessity bound

对固定策略 pi，二假设 Bayes regret 与 total variation overlap 的下界思路可以成立。
但稿件允许 Pi_0 根据自然扫描观测反馈行动，因此每个 pi 会诱导不同观测分布
P_i^pi。当前写成固定 P_1^0,P_2^0，并声称“任意该类 controller”满足同一下界，
缺少统一性。

合法的 class-level 形式至少需要处理：

    inf_{pi in Pi_0} R(pi)
      >= inf_{pi in Pi_0}
         Delta(pi)/2 * [1-TV(P_1^pi,P_2^pi)],

或另证 uniform overlap 与 uniform decision separation。右侧可能为 0：某个正常扫描
策略本身就能使 TV 接近 1，无需专门 probing。当前严格收益条件因此不能证明 DRDI
优于整个 passive/adaptive/simple-control class。

这不是“待实验验证”，而是当前定理量词和比较对象不正确。

3.3 切向 witness 只证明 toy ambiguity，不证明 Method necessity

串联弹簧公式和给出的两个阻抗区间在其准静态假设下代数上成立。但该 witness：

- 用“尚未切向运动时 F_t=0”制造观测相同，而连续扫描天然包含切向运动；
- 固定了 r_t、F_n 与任务约束，只允许 k_t 解决冲突；
- 没有允许更简单的 scan-speed/reference adaptation、normal-force adjustment、
  explicit tangential force/slip control 或 robust hybrid mode；
- 没有证明安全微交互比自然扫描更早、更可靠地获得信息；
- 没有证明所用 g_t、mu 数值处于真实凝胶—探头—组织工作包络。

因此它仅证明一个受限模型中“存在不相交 k_t 区间”，不能支撑
“fixed/explicit/passive controllers 必然失败而 dual impedance 必要”。

Method necessity verdict：FAIL。

4. 技术深度与理论正确性
======================================================================

4.1 decision cell 的数学形式目前主要是定义性重写

Gamma_R <= epsilon 当且仅当 epsilon-near-optimal policy sets 交集非空，是由定义
直接得到的等价关系。Theorem 1 是 truth containment 在 set update 下的直接归纳；
Theorem 6 是策略集包含关系。它们有助于澄清语义，但不是足以承载 T-RO 核心深度的
新理论结果。

真正可能具有深度的结果应回答至少一个非定义性问题：

- 哪些接触动力学与观测条件使 decision cells 可由有限安全交互分离？
- 何时 task scan 本身已提供充分激励，何时必须增加额外 action authority？
- decision-sufficient quotient 相比完整参数 belief 可降低多少维数/样本/计算量？
- 该 quotient 如何改变可实现的 closed-loop performance/safety boundary？

当前稿没有给出这些结构性条件。

4.2 minimal latent 未完成 identifiability / sufficiency 推导

eta=[g_n,c_n,g_t,mu_eff] 是合理候选，但目前是直接指定，而非从 available
force/pose/image observations 与 impedance decision 推导得到：

- stick 区间内 mu_eff 通常不激活，无法由小扰动辨识；
- g_t 与 mu_eff 在不同 contact modes 下的可观测条件不同；
- g_n、c_n 是 operating-point-dependent differential quantities，随 preload、速度、
  呼吸与位置变化；
- 对 normal–tangential coupled dynamics，四个标量未证明对安全/最优 K 充分；
- 从一个位置向下一位置传播 eta 的 bounded random-walk 需要真实空间正则性，肋骨
  边界等突变可能直接破坏该假设。

在结构可辨识性、practical observability 与 decision sufficiency 未证明前，A1 的
truth containment 只是把最难的问题放入假设。

4.3 actual impedance 模型不足以代表 rendered mechanics

软件定义笛卡尔阻抗在真实机器人上通常是 configuration-、frequency-、delay-、
saturation-dependent 的闭环传递特性，不是简单的一阶 K_app/D_app 参数状态。
需要说明如何在线测得/验证 rendered impedance，及其与 torque controller、robot
inertia、inner-loop bandwidth 的关系。

4.4 曲面接触坐标变化使 passivity 证明不闭合

稿件用 S=0.5 e^T K_app e + E，并只核算 Delta K 与 rho 的能量。但连续曲面扫描中
normal–tangential contact frame 随位置/姿态旋转。将 local diagonal K 变换到机器人
坐标会产生 basis-change / geometric stiffness power terms。Lachner et al., IJRR
2025/2026 已明确证明忽略曲空间基向量变化会造成非对称 stiffness、非保守力场和
passivity violation。

当前 W_K 没有覆盖 frame rotation/Jacobian variation；axis-wise damping-ratio 公式也
不能自动保证耦合多自由度、时延与 stick–slip switching 下的稳定/耗散。因此
Theorem 5 在目标任务的运动坐标系中不成立，除非补入几何一致 stiffness mapping、
moving-frame power 与完整 port definition。

此外稿件明确排除 nominal trajectory source 的供能，所以结论只能是一个人工拆分
子端口的增量性质，不能支撑 whole interaction safety/passivity。

4.5 robust safety 依赖尚未构造的强 oracle

A2 要求每周期得到覆盖完整非线性 trust region 的联合 Jacobian/remainder enclosure；
A4 要求 population envelope 下的 backup predecessor 非空；A5 要求 rendered
impedance、速度与离散余项有可信界。这些不是普通 calibration detail，而是决定
安全集合是否非空、实时问题是否可解的核心技术对象。

在没有给出可构造算法、复杂度和至少一个真实量级实例前，不能判“theoretical
correctness PASS under assumptions”；否则假设已经包含了所需安全结论的关键部分。

Theoretical correctness verdict：FAIL。
Technical depth verdict：BROAD BUT NOT CORE-DEEP；CURRENTLY BELOW T-RO。

5. Complexity 与 feasibility
======================================================================

当前实际 complexity vector 不是“一个母线、一个 core、两个 support”，而是：

- nonlinear contact-aware force–motion MPC；
- spatial latent dynamics；
- Bayesian belief；
- deterministic set-membership envelope；
- uncertain Jacobian/remainder tube；
- oracle lower/upper-bound programs；
- decision-cell compression；
- observation-branch MPC；
- actual K/D dynamics；
- energy tank；
- robust predecessor backup；
- asynchronous revalidation/fallback。

这是 Type-S/高复杂度结构，但 paper-level claim 当前仍是 Type-F/M 规模的
decision-gated active identification。与 Pollayil、Piedra 等真实样本相比，额外复杂度
尚未换来更强的一般结果或不可替代 capability，属于 ABOVE-BUT-UNJUSTIFIED。

“latent 只有 3—4 维、scenario 只有 3—5 个”不能证明实时。每周期还需集合更新、
区间/Jacobian 外包、多个 oracle primal/dual bounds、公共 robust solve、条件 branch
solve、nonlinear revalidation 与 communication。当前 5—10 Hz 只是愿望值，没有
问题规模、凸性条件、worst-case iterations 或 deadline proof。

Complexity verdict：ABOVE-BUT-UNJUSTIFIED。
Engineering feasibility verdict：INDETERMINATE。

7. 下一阶段必须如何推进
======================================================================

不应在 DRDI-MPC 上继续补 theorem、certificate 或 safety layer。正确回退点是：

Step 1：解冻 research problem 与 DRDI Method。

Step 2：从当前机器人超声领域恢复 capability-level failure，而不是从 impedance
decision boundary 出发。至少比较：

- explicit force/moment + orientation；
- disturbance-observer/predictive admittance；
- robust fixed/variable impedance；
- scan-speed / force / pose co-planning；
- image-quality/contact multimodal feedback；
- task-embedded mechanical characterization。

Step 3：找到这些路线共同不能解决、且会造成诊断任务失败的根因。候选根因必须由
真实 operating-envelope evidence 支撑，不能预设答案是 dual control 或 impedance。

Step 4：把研究问题表述为机器人此前缺失的能力，再恢复 RMC。只有 RMC 明确要求
“动作必须改变未来信息结构”时，才重新考虑 dual mechanism。

Step 5：若 dual mechanism 仍胜出，必须先修三项 core theorem，再设计完整系统：

1. 用物理输入集合而非 rho 标签定义 passive/active policy classes；
2. 给出 policy-dependent observation kernels 下的统一 necessity bound；
3. 推导 scan-action/force/impedance 联合权限中，额外信息行为不可被简单任务动作
   等价替代的条件。

Step 6：只有 core delta 与 necessity 成立后，才选择最小 safety/execution support。
不得保留当前全部 robust tube、energy tank、belief+set 和 branching 结构作为默认包袱。

8. 可保留资产与禁止继承状态
======================================================================

可保留：

- strongest-prior comparator 表及大部分事实边界；
- Beber offline characterization 的修正；
- explicit force / robust fixed K 的 veto 条件；
- Bayesian performance 与 deterministic safety 不混用的原则；
- applied action 而非 command action 的工程要求；
- 切向串联弹簧 witness 作为 hypothesis generator；
- backup 只保证安全撤离、不保证扫描继续的语义边界。

禁止继承：

- Final / Frozen / Converged 状态；
- T-RO Method-level PASS；
- Theorem 3 已证明 Method necessity；
- eta 四维表示已最小且可辨识；
- K_app 一阶模型已代表真实 rendered impedance；
- Theorem 5 已覆盖曲面扫描中的 passivity；
- 低维 scenarios 自动意味着 real-time。
