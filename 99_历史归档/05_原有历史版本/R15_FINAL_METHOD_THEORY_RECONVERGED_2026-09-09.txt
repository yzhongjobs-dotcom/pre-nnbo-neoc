Decision-Equivalent Contact Representation for Constrained Optimal Impedance Control
实验前最终理论 Method
版本：2026-09-09
目标 venue：IEEE Transactions on Robotics；一般化充分时具有 IJRR potential

======================================================================
0. 最终研究问题与方法结论
======================================================================

最终研究问题：

对于只有端口力—运动历史可观测、物理参数部分不可辨识的未知软环境，如何学习一个最小接触表示，使它不必重建全部环境参数，却能保持固定任务效用下的安全可行阻抗集合与最优 K、B 决策，并能在变化的状态、任务偏好和约束下实时重新优化？

最终方法：Decision-Equivalent Contact Representation for Optimal Impedance，简称 DECOR-IC。

唯一核心关系：

  interaction history
  -> passive set-valued contact representation
  -> constrained impedance KKT/value equivalence
  -> directly executable K,B
  -> closed-loop task consequence。

任务效用 U_p(c) 保持显式且固定。环境适应发生在 contact representation/dynamics，而不是由网络改变 Q、R。训练目标也不再是完整物理参数误差，而是由该表示诱导的闭环阻抗决策 regret 与安全可行集误差。

NNBO 提供 nonlinear soft-environment optimal-control 母线；implicit differentiation 提供 constrained inner optimum 对表示参数的精确局部梯度。二者之间的新科学对象不是 learned cost，而是 constrained impedance-decision equivalence。

实验前 Method verdict：PASS。该判断指 Problem、RCA、RMC、Method selection、公式、理论义务和执行接口已经闭合；机器人能力、实时数值和模型包络常数仍由实验验证，不被公式预先宣称。

======================================================================
1. 领域现状 -> failure -> 根因
======================================================================

1.1 已有主线

现有软环境 optimal/variable impedance 方法主要沿四条路线发展：

A. 物理辨识后优化：估计 Hunt–Crossley、Hertz、阻尼或摩擦参数，再由 HJB、MPC、QP 或解析式选择阻抗。
B. 鲁棒/随机阻抗优化：在给定参数集合或分布上优化 K、B。
C. 直接策略学习：由状态或 context 直接回归阻抗。
D. cost learning / differentiable MPC：由 demonstration、outer task loss 或 context 学习 MPC cost，再通过可微优化得到动作。

NNBO 属于 A：EWRLS 估计软环境参数，critic 近似 HJB value，最优 interaction force 再被实现为 target impedance。其真实贡献是让 nonlinear soft-contact mechanics 进入 optimal interaction design；它没有解决部分可辨识条件下“究竟应辨识什么”，也没有给出 force 到唯一 executable K、B 的一般映射。

1.2 可观测 failure

- 两组物理参数可能具有很大参数距离，却对所有可执行 K、B 给出几乎相同的安全/最优决策；继续区分它们浪费数据和模型容量。
- 两组参数可能只有很小欧氏误差，却位于阻抗决策边界两侧，导致明显不同的最优 K、B 或可行集；普通 parameter MSE 会低估该误差。
- 参数拟合最好的模型不一定产生最好的 receding-horizon impedance policy。
- 用环境相关 Q、R 吸收 model error 会把“环境如何响应”与“任务重视什么”混在一起，任务偏好或约束变化后失效。
- 最优 force 不能唯一决定 stiffness、damping、reference 与 feedforward，故 force-optimal 不推出 impedance-optimal。

1.3 机制级根因

estimate-then-optimize 使用 reconstruction equivalence：模型是否准确由参数或一步预测误差判断。真正需要的是 decision equivalence：模型只保留会改变 constrained optimal impedance 的动力学方向，同时保持 hard-constraint classification。

设当前 active set 不变，并用局部坐标 u 参数化真实可行流形上的 first impedance action a=[K,B,x_r,f_ff]。令 u*(theta) 为 inner optimum，真实 reduced action-value Hessian H_u>0。对不改变该局部可行分支的估计误差 dtheta：

  u*(theta+dtheta)-u*(theta)=S_theta dtheta+O(||dtheta||^2)，
  S_theta=D_theta u*(theta)。

由此产生的局部 decision regret 为：

  Reg(theta+dtheta;theta)
  =0.5 dtheta^T G_theta dtheta+O(||dtheta||^3)，
  G_theta=S_theta^T H_u S_theta>=0。

普通参数 MSE 使用 I；控制真正关心的是低秩、状态/任务/约束相关的 G_theta。Null(G_theta) 中的误差一阶不改变局部最优决策，而高特征值方向上的小误差会显著改变决策。若误差改变 constraint sign 或 active set，则由独立的 feasible-set equivalence 处理，不能套用该二阶式。这一 representation-objective mismatch 是主要矛盾。

1.4 Hunt–Crossley constructive witness

在固定 indentation velocity v_0 的有限观测段，Hunt–Crossley law

  f=K_e delta^n+B_e delta^n deltadot

退化为：

  f=delta^n alpha_0，alpha_0=K_e+B_e v_0。

因此任意满足 K_e+B_e v_0=alpha_0 的 (K_e,B_e) 在该观测段不可区分；完整二参数辨识没有唯一解。若未来任务仍只使用 v_0，则 alpha_0 已是充分的一维 contact coordinate，分别恢复 K_e、B_e 是多余的。若未来候选阻抗产生 v_1!=v_0，则两个观测等价模型的预测差为：

  Delta f=Delta B_e (v_1-v_0)delta^n，

它可能跨越 force constraint 或改变最优 damping。此时正确响应不是让 cost weight 吸收差异，而是保留与未来 candidate K、B 相关的 (K_e,B_e) ambiguity，直到可行集/决策对该差异不敏感或获得足够观测。这个 witness 同时证明 full-ID、固定低维压缩和 point-context cost adaptation 都不是一般正确答案；表示必须由 query-dependent impedance decision equivalence 定义。

1.5 Required Mechanism Change

  full-parameter/prediction-equivalent environment model
  -> constraint-and-impedance-decision-equivalent contact representation。

表示必须保留 candidate K、B 对闭环接触响应的作用、fixed utility 下的 action ordering、hard-constraint margins，并对无法区分的环境保留集合；输出必须直接进入真实 impedance controller。

======================================================================
2. Source mechanism 与自然迁移
======================================================================

Value-equivalent/value-aware model learning 的源问题是：预测最准确的模型未必最适合规划；有限模型容量应优先保持影响 Bellman/value update 的方向。其干预是用 downstream value/policy effect 定义模型等价，而不是用完整 transition reconstruction 定义等价。

目标 RMC 是 contact-parameter accuracy -> feasible optimal-impedance equivalence。二者干预位置相同：都在 environment representation 进入 optimizer 之前改变训练标准，且都不改变真实 task preference。

普通 value equivalence 仍不足以直接迁移，因为：

- impedance 是反馈力学，不是普通 open-loop action；
- force/contact/actuator constraints 必须逐场景保持；
- active constraints 会改变 KKT sensitivity；
- 接触模型应满足能量/耗散结构；
- 部署是 repeated-replanning closed loop。

因此必要改造为：passive contact representation + constrained KKT/action-value equivalence + set-valued ambiguity + direct impedance execution。IDOC 从 closed-loop decision regret 反传到 contact representation；它不是独立创新点。

======================================================================
3. 决定性路线比较与选择
======================================================================

固定比较条件：固定 U_p，未知软接触，部分可辨识端口数据，变化的 state/preference/constraints，输出 executable K、B。

Route A：完整物理参数辨识 + optimal impedance。其训练 geometry 与 G_theta 不一致，不可辨识方向被迫估计，不能闭合 RMC。

Route B：固定/集合鲁棒 impedance。能保持安全，但把所有差异都当 adversarial，不能利用历史缩小 decision-relevant ambiguity，在宽集合中保守。

Route C：context -> Q,R -> differentiable optimal control。它改变错误变量：environment uncertainty 属于 dynamics/representation，task preference 属于 utility。自由 cost 可补偿错误模型，却不能保持 preference composition、constraint semantics 或环境反事实。淘汰。

Route D：context -> K,B direct policy + safety projection。它在固定任务上简单，但 task/constraint/actuator envelope 改变后必须重训；projection 若明显改写 action，learned policy不再是训练的policy，不能等价满足可重新优化目标。

Route E：高保真 deformable model 直接在线 OCP。科学上直接，但不满足实时条件；只作为训练 oracle 和性能上界。

Route F：decision-equivalent passive contact representation + constrained direct-impedance OCP。它直接改变 RMC 指定的 representation criterion；固定真实 utility；保留 constraints；处理 partial identifiability；支持重新优化；并把高保真计算限制在训练期。删除 representation learning 会退化为 A/B；删除 OCP 会退化为 D；删除 set-valued feasibility 会在不可辨识场景伪造安全性。

因此选择 Route F。它是一条单一因果修复：学习 optimizer 所需的最小、安全决策等价接触模型。

======================================================================
4. 系统、信息与固定任务语义
======================================================================

关节动力学：

  M(q)qdd+C(q,qdot)qdot+g(q)=tau+J(q)^T f_c+d_r，

其中 f_c 是环境施加于机器人的 wrench。下文以 f_re=-f_c 表示机器人施加于环境的共轭 contact wrench，并以 v_c 为机器人相对环境的 contact velocity，使 f_re^T v_c 是进入环境的功率。

低层 Cartesian impedance：

  tau=tau_comp+J^T[f_ff-K(x-x_r)-B(xdot-xdot_r)]。

在 contact frame T_c=[n,t_1,t_2] 中：

  K=T_c diag(k_n,k_t1,k_t2)T_c^T，
  B=T_c diag(b_n,b_t1,b_t2)T_c^T。

优化变量直接包含 a=[k,b,x_r,f_ff]，并满足正上下界和 rate limits。实际 gain 动态为：

  a_app,k+1=F_act(a_app,k,a_cmd,k)，

且 a_app 进入预测模型、约束和能量账户。所有闭环结论针对 a_app。

观测历史：

  h_k={q_0:k,qdot_0:k,x_0:k,xdot_0:k,f_0:k,a_app,0:k}。

在线保持 latent consistent set Z_k，不假设 history 唯一确定完整 theta。

任务 preference p 显式给出：

  J_p=sum_i l_p(c_i,a_i)+V_p(c_H)。

c 可包括 tracking、force regulation、deformation/energy proxy、contact quality 与 control effort。环境变化不改变 p；安全由 hard constraints 表达。

======================================================================
5. Passive decision-equivalent contact representation
======================================================================

5.1 Structured reduced contact model

令 delta 为局部 deformation、v_c 为 relative contact velocity、zeta 为低维 latent：

  f_hat_re(delta,v_c;zeta)
  =grad_delta Psi_phi(delta;zeta)+D_phi(delta,v_c;zeta)v_c，

其中 Psi_phi(0;zeta)=0，Psi_phi 对 delta 凸，D_phi=D_phi^T>=d_min I。可用 HC/Hertz potential 作解析主干，仅以结构化 neural residual 补足主干外的 decision-relevant behavior：

  Psi_phi=Psi_HC+Psi_res,phi，
  D_phi=D_HC+D_res,phi。

force、Jacobian 和 Hessian 均由同一个势能—耗散模型产生，不能自由回归互不一致的量。

5.2 Set-valued online inference

给定离线标定的 error envelope epsilon_f：

  Z_k={zeta in Z_0:
       ||f_re,i-f_hat_re(delta_i,v_i;zeta)||_W<=epsilon_f,
       i=k-L,...,k}。

在线使用外包 Z_k 的小型 particle/polytope/ellipsoid Zhat_k。不可区分的 latent 保留在集合；若剩余 latent 对阻抗决策等价，无需继续缩小。

5.3 Exact decision-equivalence

对 query Q=(s,p,C)，C 为 constraints/actuator envelope，定义真实 first-action Q-function：

  Q_theta^H(s,a;p,C)
  =min_{a_1:H-1} J_p
   subject to true dynamics and C, a_0=a。

theta_1、theta_2 在 query family 上 epsilon-decision-equivalent，当二者相对最优值的 action-value gaps 一致到 epsilon_Q，robust feasible first-action sets 的 Hausdorff distance不超过 epsilon_A，并保持 margin band epsilon_g 外的 constraint-sign classification。该定义同时保存 action ordering 与 feasibility，不要求恢复 theta。

5.4 Local KKT-equivalent coordinate

固定 active set 和 regular solution 附近：

  F_KKT(w;theta,Q)=0，w=[trajectory,multipliers]。

若 D_wF_KKT 非奇异：

  D_theta w*=-(D_wF_KKT)^(-1)D_theta F_KKT。

用可行流形局部坐标得到 first-action sensitivity S_a=D_theta u*。再令 m_C(theta) 收集会决定 robust feasibility/active-set classification 的约束 margins，定义联合敏感度：

  S_Q=[S_a;D_theta m_C]，r=rank(S_Q)。

任一同时一阶保持 optimal action 与这些 constraint margins 的 differentiable coordinate，其维数至少为 r；取 S_Q row-space 的基 U_r，zeta=U_r^T(theta-theta_0) 可构造局部充分坐标。DECOR-IC 学习这一 quotient structure 的非线性、跨状态版本，不声称 latent 是唯一材料参数。

======================================================================
6. Inner constrained optimal-impedance problem
======================================================================

给定 (s_k,Zhat_k,p,C_k)，对用于性能积分的 representative latent scenarios zeta_j、权重 omega_j 求：

  min_{a_0:H-1,s_1:H}
      sum_j omega_j[sum_i l_p(c_i^j,a_i)+V_p(c_H^j)]
      +sum_i ||a_i-a_i_prev||_R^2

  subject to performance scenarios j 的动力学：

      s_i+1^j=F_cl,phi(s_i^j,a_i;zeta_j)，
      a_i in A_exec，
      f_min<=f_n,i^j<=f_max，delta_i^j<=delta_max，
      friction_margin_i^j>=0，
      q,qdot,tau within robot limits，
      energy inequality，terminal state in X_f；

  并对完整外包集合 Zhat_k 强制：

      sup_{zeta in Zhat_k} g_r(s_i,a_i,zeta)<=0

  for every hard constraint g_r。

性能使用 calibrated distribution/weights；hard constraints 必须通过解析 support bound、interval/zonotope propagation 或 verified maximization 覆盖完整 Zhat_k，有限 representative scenarios 本身不能构成安全证书。集合较宽时返回公共可行的 minimum-risk impedance，而非虚假的 environment-specific gain。每次仅发布通过 nonlinear first-step verification 的 first action。

======================================================================
7. Decision-focused learning 与 IDOC
======================================================================

训练环境 theta 与 task query p,C 从覆盖集采样。部署同构 rollout 为：history -> latent set -> inner OCP -> apply first action -> high-fidelity transition -> update and replan。

  L_dec(phi)
  =E[J_HF^CL(pi_phi;theta,p,C)-J_HF^CL(pi_oracle;theta,p,C)]。

oracle 具有同一 action authority/constraints，只获得高保真环境信息；其值对 phi 为常数。总训练目标：

  L=L_dec+lambda_port L_observed-port+lambda_cov L_set-coverage。

port loss 只约束可观测 force/power response；不要求不可辨识物理标签。coverage 用独立 calibration data 确定 enclosure，不以 soft penalty 代替 hard constraints。

对第 t 次 inner solve：

  F_t(w_t,phi,h_t,p,C)=0，
  dw_t*/dphi=-(D_wF_t)^(-1)D_phiF_t。

总梯度由 per-solve KKT VJP、history/set-update derivative 和 high-fidelity closed-loop adjoint组成。只对一次 planned trajectory 求导不对应 deployment policy。active-set 切换点使用 one-sided/generalized sensitivity或标记为nonsmooth sample；不把退化 KKT 系统的 singular inverse 当普通梯度。

IDOC 在这里是自然 backend：监督对象是 inner decision 产生的 aggregate closed-loop consequence，不是 latent parameter label。

======================================================================
8. 核心理论结果
======================================================================

Theorem 1 — Parameter accuracy is not decision sufficiency

若 active set 固定、真实可行流形存在光滑局部坐标 u，且 reduced Q-function 在 u*(theta) 处有 H_u>0，则：

  Reg(theta+dtheta;theta)
  =0.5 dtheta^T S_theta^T H_u S_theta dtheta+O(||dtheta||^3)。

因此 Euclidean parameter loss 与 decision regret 一般不序等价。该结论只评价同一可行分支上的 performance；constraint-sign 变化由 Theorem 4 处理。

Theorem 2 — Local representation dimension

若 differentiable representation rho(theta) in R^d 能在邻域内一阶保持 u*(theta) 与选定 constraint margins m_C(theta)，则 d>=rank(S_Q)。反之 S_Q 的 row-space coordinate 以 d=rank(S_Q) 同时保持二者的一阶变化。证明由链式法则的 rank bound 与 SVD 构造得到。

Theorem 3 — Value-equivalence implies bounded impedance regret

若共同 robust feasible set A 上 sup_a|Q_hat-Q_true|<=epsilon_Q，a_hat minimizes Q_hat、a* minimizes Q_true，则：

  Q_true(a_hat)-Q_true(a*)<=2epsilon_Q。

若 Q_true 在 A 上 mu-strongly convex，则 ||a_hat-a*||<=2sqrt(epsilon_Q/mu)。

Theorem 4 — Robust constraint preservation

若真实 latent 包含于 Zhat_k，且 g_true<=g_hat+epsilon_g，inner problem 对所有 zeta in Zhat_k 强制 g_hat<=-epsilon_g，则发布 action 满足 g_true<=0。该保证与性能模型是否完全准确分离。

Theorem 5 — Context-aliasing lower bound and complete response

若 theta_1、theta_2 在当前 history 下 observationally indistinguishable，但 epsilon-safe-optimal first-action sets 不相交，则任何 deterministic point-context policy 至少在一个环境产生正 regret 或 constraint violation。DECOR-IC 将两者保留在 Zhat_k 并选择公共 robust action；公共可行集为空时发布 backup/withdraw 并报告 task infeasibility。不可辨识性由保守性或任务中止承担，不伪装成错误个体化。

Theorem 6 — Passive learned contact model

令 environment storage S_e=Psi_phi(delta;zeta)。若 Psi nonnegative/convex、D_phi>=0，则：

  f_re^T v_c=dS_e/dt+v_c^T D_phi v_c>=dS_e/dt。

因此机器人到环境的 contact port 是 passive，耗散为 v_c^TD_phiv_c>=0；learned residual 不会仅因网络参数化产生主动环境。机器人动力学中使用反作用 wrench f_c=-f_re。

Theorem 7 — Correct implicit gradient

若当前 optimum 满足 LICQ、SOSC 与 strict complementarity，使 D_wF_KKT nonsingular，则 implicit derivative 等于该局部分支的 solution-map derivative；active-set change 上不声称经典导数存在。

Theorem 8 — Closed-loop performance propagation

若每步 surrogate first-action regret<=epsilon_t，closed-loop transition与value函数满足相应Lipschitz/curvature bounds，则有限时域 rollout regret 满足 Reg_T<=sum_t alpha_t epsilon_t；alpha_t由state amplification递推。terminal/stability design使其有界，否则不能从单步等价推出长时域等价。

9. Execution、passivity 与发布逻辑
======================================================================

机器人阻抗 storage：

  S_r=0.5 edot^T M_d edot+0.5 e^TKe。

离散 energy budget：

  E_k+1=E_k+Delta t edot^TB edot
        -Delta E_K-Delta E_ref-m_track,k，
  E_k+1>=E_min。

Delta E_K、Delta E_ref 使用实际 a_app；feedforward/reference power计入supply或保守debit。每周期按以下顺序执行：读取state/force/a_app；更新Zhat；warm-start OCP；以原nonlinear model、latent set、actuator和energy account复验first action；通过且未超时则发布；否则发布已验证incumbent；incumbent不可行时进入预构造backup/withdraw controller。

可证明范围是给定model-error和execution envelope内的robust first-step feasibility、terminal条件下recursive feasibility及端口层增量无源性；不外推为临床安全认证。

======================================================================
10. 实时复杂度与工程接口
======================================================================

在线维数由Theorem 2的sensitivity rank决定。初始实现采用2–4维latent、3–7个代表场景、task-frame diagonal K/B、短horizon multiple shooting或RTI-SQP、共享factorization与first-action nonlinear verification。

训练期IDOC不进入控制频率。部署只有set update + small scenario OCP + verification。若时延不足，先减scenario/horizon或预计算terminal value，不引入第二solver、critic或额外safety filter。

======================================================================
11. 理论已解决与实验待证边界
======================================================================

实验前已经解决：parameter MSE与impedance regret不等价；局部最小representation dimension；value误差到action/regret界；set enclosure到真实constraint；aliasing不可能性与算法响应；passive contact parameterization；constrained IDOC gradient；closed-loop error propagation；optimizer到actual K/B与energy guard的执行链。

需要实验/数值标定：真实soft contact中G_theta的rank；同数据预算下decision-focused representation的regret优势；model envelope与OOD coverage；相对full-ID、direct policy、robust fixed impedance、generic cost learner的能力；unseen mechanics/task/constraints的ordering；P95/P99/worst-case runtime与fallback；actual K/B和energy一致性。

这些是经验量，而不是未定义的理论条件。若数据显示G_theta满秩且完整参数易辨识，则该场景无需压缩；若direct policy等价支配，则paper-level necessity被经验否决。这是可证伪性，不是Method逻辑未收敛。

======================================================================
12. Strongest-prior boundary 与贡献
======================================================================

Generic priors 已覆盖：Value Equivalence的planning-relevant model；Differentiable Robust MPC的model/cost/barrier implicit learning；Performer-MPC的context-dependent quadratic/affine cost；DiffTune的closed-loop cost tuning；ZipMPC的long-to-short-horizon cost compression；DiffStack的decision-focused prediction。因此这些不能作为原子创新。

Impedance priors 已覆盖：NNBO的nonlinear environment identification + optimal interaction + impedance realization；MPVIC的unknown environment、online estimation、constraints/passivity；IRL/BO/RL的gain/cost tuning；contact-aware MPC的soft-contact real-time planning。

14. 最终冻结表述
======================================================================

推荐标题：Decision-Equivalent Contact Representation for Constrained Optimal Impedance Control in Unknown Soft Environments

摘要主句：

Existing optimal impedance controllers identify contact models by parameter or prediction accuracy, although only a low-dimensional subset of contact uncertainty changes the constrained optimal impedance. We learn a passive set-valued contact representation whose equivalence is defined by feasible impedance actions and downstream closed-loop regret, and differentiate through a direct-impedance optimal-control layer to preserve task performance without recovering non-identifiable physical parameters.

最终因果链：

  partial observability makes full contact reconstruction non-minimal
  -> KKT/value sensitivity identifies decision-relevant directions
  -> passive set-valued representation preserves ordering and constraints
  -> constrained OCP produces executable K,B
  -> closed-loop IDOC trains representation on task consequence
  -> robust verification and energy accounting govern publication。

实验前不再增加paper-level模块。后续只完成正式证明、实现、标定与判别实验；证据否决低秩/决策优势时，简化claim或终止路线，而不是修改task utility或增加结构挽救。
