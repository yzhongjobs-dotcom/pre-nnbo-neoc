# R15：连续软接触中的模型认识与阻抗控制

本项目从空间接触观测、环境建模和实际阻抗执行出发，研究持续变化条件下的控制能力。用户目标是把**研究问题、现有方法的不足和方法设计共同打磨到顶刊水平**。

打磨起点是[已有B0完整研究问题](研究/研究问题.md)、方法和八项条件性证明。用户已明确纠正向抽象采集框架漂移，当前围绕[环境变化后快速更新有控制收益的近最优阻抗](研究/最优阻抗更新_问题与方法.md)推进模型优化与学习生成两条路线。已实施[优化、学习与瞬态验证](实验/最优阻抗更新/README.md)，再做[非线性接触/能量执行与任务代价学习](实验/接触约束阻抗更新/README.md)：网络未胜普通RBF，当前局部增量不足，后续回到原持续扫描的环境认识—实际执行链寻找重要未解困难。尚未达到顶刊；NEOC/PPO不是预设必须保留的算法，先前候选A及公开记录作为证据保留，不能默默替代原问题。

最新[同次扫描快速验证](实验/同次扫描阻抗反馈/README.md)已实现模型预测与直接任务损失离线训练：首批48例联合策略对解析规则有小幅改善；随后24例纯K/D未胜连续调优固定；再修正接触运动耦合，在另24例冻结参数测试中仍未获得对充分解析控制的可靠优势。当前具体原型仍不足以支撑顶刊贡献，继续围绕原问题共同深化重要任务与方法机制。

2026-10-19继续完成[闭环策略滚动与输运机制探查](实验/闭环策略滚动阻抗/README.md)：组合候选新24例尚未可靠胜调优固定/原学习；由材料输运结构形成区分软硬变化与整体运动的具体候选，识别探查有条件正结果，下一步接入控制验证，不把它当已成立的论文贡献。
