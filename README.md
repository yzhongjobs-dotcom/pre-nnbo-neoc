# R15：连续软接触中的模型认识与阻抗控制

本项目从空间接触观测、环境建模和实际阻抗执行出发，研究持续变化条件下的控制能力。用户目标是把**研究问题、现有方法的不足和方法设计共同打磨到顶刊水平**。

打磨起点是[已有B0完整研究问题](研究/研究问题.md)、方法和八项条件性证明。完成[强prior对照](研究/研究现状.md)及[候选2快速评估](实验/候选2_学习阻抗/候选2评估.md)后，用户授权继续推进；当前沿[候选A的问题与方法设计](研究/候选A_问题与方法设计.md)研究有限准备/扫描资源下的整段有效采集与接触适应。已完成[信息—控制判别](实验/扫描接触信息判别/README.md)、[机械与路径能力核查](实验/采集覆盖与接触载荷/README.md)及[公开实际记录分析](实验/公开采集记录/README.md)。尚未建立顶刊缺口或新方法贡献；成熟反馈、图像搜索与安全执行是强参照，NEOC/PPO不是预设主线。公开观察记录和机械模型结果不等于我们的采集收益或完整机器人验证。
