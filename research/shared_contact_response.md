# 共享运动的局部接触响应与控制功能量：候选及三轮验证

2026-11-03。承接[主动激励§9](active_excitation.md)和[第一模块§9–10](first_module_information.md)。用户要求理解已有机制、主动形成候选、实现验证并持续迭代，不要求每次尝试成功。**本轮已实现具体模型、估计与控制接口，完成10个定向闭环；尚未得到可采纳的闭环改进。** 原正式方法、较强精简候选、对象及冻结快照保持不变。

## 1. 为什么设计这个候选

Rossi主动产生可区分的接触响应，再用估计结果服务柔度补偿；高频隔离依赖准静态变化和近似弹性关系。当前任务中组织运动、材料变化和记忆共同进入测力。已有项目证据是：动态接触模型曾改善硬组织的条件力预测，但只把20.8 Hz响应实部作为一个刚度数值接入，闭环反而退化。这不足以否定动态模型，也不能由预测改善直接宣称任务增量。

因此本轮不另改波形，先继承有效20.8 Hz探测和上层反馈/IMM，设计一个完整候选：**同一运动状态驱动弹性与记忆响应，估计控制作用时域内的动态柔顺，再以该算子构造等效运动观测。** Moreira等CMPB2014已将黏弹建模、在线刚度与未知运动补偿结合，不能把这些一般概念声称为本文首创；见[原文](../literature/papers/field_supplements/F10.pdf)及[能力核查](../literature/aris_concurrent_survey_2026-10-31.md)。本轮共享状态剖面、变参数逆和功能量计算为针对当前测量/位置接口的推导，不称复现其转矩控制/AOB。

## 2. 模型、估计与接口

### 2.1 共享运动，不再给力漂移完全独立的自由系数

使用已有局部SLS族，但显式关联未知运动对两支路的作用：

\[
F=k_e(t)(y-s)+k_m r,\qquad \dot r=\dot y-\dot s-r/\tau_m,
\quad k_e(t)=k_0+k_1(t-t_e)/T.
\]

在窗口内令s为未知常加速度轨迹，初始记忆自由。给定接触参数，运动初值及记忆初值是线性未知量，统一作用于弹性项和记忆卷积。与原B4+指数的六个独立力漂移系数相比，本候选有四个共享状态系数。运动可进入两个支路，不能让两个支路各自拟合不同运动。

正端点ke与非负km的约束参数化保证冻结模型的被动弹性/松弛系数，但不保证时变闭环无源。局部CA、km不变及单一松弛时间均是假设，不代表所有突发运动/非线性/材料过渡。尤其局部非线性接触的工作点力偏置，可能使同一几何运动下的等效截距另有变化；这里的共享轨迹不能自动解释成真实几何表面或绝对压入。该假设的适用性仍需辨别，不能仅因其减少方差便认定物理更真。

本轮τm=.04 s是前期开发中使用的公开模型假设，**未从对象读取，也未在线识别真实松弛时间**。与既有单频、短窗条件一致，不能凭增加状态就宣称全部动力学可辨识。

估计用变量投影：外层只优化三个正接触参数，内层解共享状态。运动基随接触参数变化，Jacobian同时包含这一项；协方差用完整局部Jacobian剖面，不能只拿编码器列当信息。预计算双线性基和解析剖面导数，避免在每次优化评价重复卷积。使用无约束局部信息矩阵作正约束解的参考，**不是约束后已校准后验**；单一起点也没有全局最优保证。

### 2.2 输出动态柔顺，而非把各个时间尺度叫作同一刚度

对同一接触算子下的两条轨迹，定义力差E及位移差c。直接微分可得

\[
\dot c+\frac{\dot k_e+k_e/\tau_m}{k_e+k_m}c
=\frac{\dot E}{k_e+k_m}+\frac{E}{(k_e+k_m)\tau_m}.
\]

冻结参数时，它退化为已有稳定SLS逆；km=0且参数恒定时退化为静态柔顺。实际计算采用力误差的分段线性输入及系数中点冻结，不数值微分测力。中点冻结对时变参数是近似；冻结参数/线性输入的更新是精确的。状态c用米表示，参数更新时不重除历史状态。

对单位力阶跃的逆响应J(h)，在0、8 ms、当前命令延迟加伺服滞后的时刻计算参考不确定性。仅在相关响应有条件信息支持、物理系数可用且事后预测检验通过时使用。沿用ln(1.2)量级作原型精度评分，**它不构成动态前馈闭环的稳定性或真实概率保证**。

观测量用Δc−Δy进入原IMM；它是恒力任务的等效接触漂移，未声称无混淆还原生理运动。原保守力反馈、探测幅值/频率/换算和接触恢复保持不变。力与编码器沿用已有滤波对齐；变系数逆作用于区间平均量仍有近似，不能把固定LTI算子的滤波交换性无条件推广到时变模型。

### 2.3 因果发布、历史状态和实际观测可信度

每32 ms拟合一次，仅用当时及以前的七通道测量，32 ms后发布。发布前以随后已观测编码器作条件预测，检查最近四个创新。支持旧模型时允许短时延续，按ke斜率传播参数协方差，最多超出原窗口长度T；条件预测不等于提前知道未来组织运动。

首版动态逆在开始使用时由当前力误差初始化，其未知逆初态只作为衰减瞬态。第二版用完整已观测窗口重放同一逆模型，比较该模型下相邻输出，避免把模型坐标更新直接当成组织位移；报告剩余初态敏感性，不把它当成初态误差界。

第三版把**当前实际力历史的逆输出**对参数的敏感性传到运动观测方差，并独立计算力传感噪声的影响行，保留创新变换造成的相邻样本相关。参数与力来自共用数据，不假设独立，以两项边际标准差之和平方作局部保守参考，原R不作为调参搜索变量。未知初态偏差、模型失配及跨模型累计坐标误差仍不在该参考的保证内。

## 3. 理论实现与机制检验

`verify_response.py`的独立检验包括：冻结逆对闭式解，单步分段线性输入对solve_ivp；独立时变SLS前向ODE驱动力差，匹配初态下逆恢复误差约0.077 μm，静态近似约19.0 μm；未知二次运动和非平衡记忆的1 ms物理力生成/测力滤波后恢复[12000,1000,6000]；解析剖面Jacobian对数值差分相对误差约5e−9；固定参数下传感器噪声影响行与独立噪声样本标准差一致。**这些检验数学/实现，不是实际组织或原对象的任务收益证据；逆恢复检验的匹配初态没有提供给控制器。**

同一冻结输入、相同窗口末端比较条件预测。给定后续编码器、隐藏后续力；重叠窗口不是独立样本。表为32 ms条件力预测RMSE N：

| 表示 | 运动非均匀T3m | 硬组织推拉 |
|---|---:|---:|
| 保留精简候选 | .18619 | .82600 |
| 原自由B4+初始指数SLS | .17683 | .86848 |
| 同四个干扰参数的B2+指数SLS | **.11095** | **.53016** |
| 共享运动SLS | .15340 | .58191 |

共享表示改善了相对原候选的预测，但**同自由度对照在此时域更好**，所以不能把收益全归因于共享物理结构或宣称其全面胜过简单替代。8 ms时硬组织共享表示更好，完整正负结果均保留。共享表示的逆响应评分中位数T3m/硬组织为.354/.349，仍普遍高于ln(1.2)；其条件信息较原自由表示改善，不代表真实覆盖率已校准。此对照检查表示/自由度，不用估计指标代替闭环收益。

## 4. 实际闭环、迭代与当前决定

只使用既有T3m和T2m-stiff各一开发实例，原对象不变、屏蔽隐状态，不扩大随机种子/场景矩阵。10次新闭环分三轮；原有效基线直接复用已验证冻结回合。力RMSE N如下：

| 实际接口 | T3m | 硬组织推拉 |
|---|---:|---:|
| 原有效精简候选 | .114827 | .266780 |
| 原自由SLS＋动态逆 | .114827（未启用） | .267604 |
| 共享模型＋动态逆 | .121127 | .276490 |
| 共享模型＋同门限标量消融 | .116717 | .277437 |
| 同候选，增加完整历史初始化 | .114194 | **1.005408** |
| 同候选，进一步传递实际逆观测不确定性 | .116111 | .286426 |

历史初始化版在硬组织有明显失接触/恢复和力峰值11.858 N，不隐藏失败。加入观测不确定性后该峰值降到5.160 N、RMSE降到.286426，但仍未超过原方案。**R修正缓解的是该被测实例的严重退化，不证明初态或方差是唯一原因，也不支持宣称完整动态接触估计已经成立。** 每版使用同一对应控制器贯穿回合，不挑选各版最好时段。

记录的最慢接触拟合约29.9 ms，小于本次模拟的32 ms发布延迟，但同步Python回调不等于部署了异步识别器，也不保证8 ms主环期限；没有真机实时认证。原方法不承担新模型的虚构计算成本。当前代码重放原v1与最终v3的代表回合，仅给可测前缀，指令逐点误差为0；v1/v2文件中的源码哈希对应当时版本，当前代码兼容这些分支，新增字段与不启用的分支不改变其任务行为。

**决定：保留共享模型、完整动态接口和全部迭代为研究候选，不替换原有效方法。** 接触记忆、动态估计和联合分离路线未被这10个实例否定；同复杂度负对照也约束了“共享结构本身就是贡献”的主张。下一项仍在同一候选内，重点是：实际逆状态/工作点偏置/模型外变化怎样进入观测可信度，哪些控制功能量确能从现有信息获得；必要时联合改变激励/状态到达信息与估计对象。不能只继续放宽门限或调R，也不另开MPC/MHE专项。

源码、原始测量与核验在[contact_information](../experiments/contact_information/README.md)。`shared_response_same_input_matched_v2.json`为加入同自由度对照后的主回放，v1回放仍保留；`shared_response_checkpoint.json`检查10行完整性、哈希、延迟、共同启动、物理/导数及因果重放。
