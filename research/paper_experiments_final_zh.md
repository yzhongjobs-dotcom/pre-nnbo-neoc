# 5 仿真实验

> 说明（2026-10-22）：本节为当前基线组合下的结果。按已确认方案，将新增DOSMAC式总扰动补偿、Cao式视觉运动补偿和Wang TIE2026三个基线，并在C1、C2改进后重跑更新。

本节通过三个仿真实验验证所提方法：刚度变化下的力跟踪、组织推拉下的接触保持，以及二者同时存在的组合扫描。最后给出机理消融和计算时间。

## 5.1 仿真设置

**机器人与控制。** 仿真对象为 UR5、xArm 一类位置控制协作臂：
- 外环控制周期 8 ms，指令延迟 1 个周期；
- 位置伺服等效为时间常数 19 ms 的一阶滞后，依据 UR servoj 实测滞后和 Wang 等（TASE 2024）；
- 力传感器 1 kHz 采样，噪声标准差 0.08 N，经 30 Hz 低通滤波；
- 法向采用导纳控制 M ÿ + D ẏ + K(y − y_r) = e_f + k_i∫e_f，叠加力误差直通项 K_PF·e_f 与参考补偿 u_ff；
- 目标接触力 4 N。

**组织模型。**
- 圆柱探头与组织有限面积接触，组织为粘弹性，含接触阻尼和摩擦。
- 软组织模量 10–40 kPa，骨样区域模量为软组织的 10–30 倍。
- 组织运动包括 1 mm 呼吸和 3–8 mm 推拉，推拉过渡时间 0.5 s，与咳嗽收缩时长相当。

**所提方法。**
- **C1（模型优化）：** 用滑动窗口对最近的力和位置数据联合估计局部刚度与组织表面运动，在 128 ms 预测时域内优化阻尼 D、力增益 K_PF 和参考补偿 u_ff，每 8 ms 更新一次；接触丢失时切换为保守固定增益。
- **C2（离线学习）：** 64-64 神经网络，输入 0.4 s 的力与位置历史，输出 D、K_PF 和 u_ff。训练时由已知真实刚度的教师策略蒸馏，再以任务代价微调；部署时只使用可测信号。

**对比方法。**
- **固定阻抗：** 参照 Jin 等（TMECH 2023）的做法，取所提方法自身增益规则（D = max(20, k/80)，K_PF = 2/k）在两端的取值：
  - 柔顺固定：按最软组织（k = 1.75 kN/m）设定，D = 22 N·s/m，K_PF = 1.0×10⁻³ m/N；
  - 刚性固定：按最硬组织（k = 25 kN/m）设定，D = 313 N·s/m，K_PF = 8×10⁻⁵ m/N。
- **在线估计 + 规则：** 抖动锁相辨识刚度后按上述规则调增益。
- **Haninger 等（RAS 2023）：** 基于估计刚度的阻尼匹配规则。
- **Jin 等（TMECH 2023）：** 多步 MPC 变阻抗。
- **Xue 等（RAS 2025）：** MPVIC，在线 Hunt–Crossley 估计加 MPC。
- **Li 等（T-RO 2025）：** 学习变阻抗，以进化策略训练。
- 各变阻抗方法使用同一批训练场景整定参数。

**评价。**
- 每个实验 40 个随机测试场景，组织参数、骨样区域位置和运动事件随机，所有方法使用相同场景和噪声。
- 指标：接触力误差 RMSE、最大误差、峰值接触力（去掉前 1 s）。实验二另报告恢复时间，即运动结束后力回到 4 ± 0.5 N 并保持 0.2 s 所需的时间。
- 表中为 40 个场景的均值；“显著”指场景配对 bootstrap 的 95% 置信区间不含 0。

## 5.2 实验一：刚度变化下的力跟踪

**目的。** 检验方法能否在组织刚度突变时及时调整阻抗。场景参照 Song 等（RA-L 2025）、Li 等（T-RO 2025）的刚度突变实验。

**设置。** 探头以恒速扫描 8 s，依次经过软组织和骨样区域，刚度比 30，组织不动。

**表 1 刚度变化任务结果**

| 方法 | RMSE (N) | 最大误差 (N) | 峰值力 (N) |
|---|---|---|---|
| 柔顺固定 | 7.524 | 77.68 | 81.68 |
| 刚性固定 | 0.170 | 0.81 | 4.79 |
| 在线估计 + 规则 | 0.107 | 0.55 | 4.52 |
| Haninger | 0.122 | 0.71 | 4.66 |
| Jin MPC-VIC | 0.117 | 0.58 | 4.57 |
| Xue MPVIC | 0.276 | 1.14 | 5.11 |
| Li 学习 VIC | 0.113 | 0.56 | 4.55 |
| **C1** | **0.060** | **0.30** | **4.27** |
| C2 | 0.083 | 0.44 | 4.40 |

**结果。**
- 柔顺固定在软组织上合适，但进入骨样区域后振荡，峰值力超过 80 N。刚性固定始终稳定，但在软组织上响应偏慢。
- 变阻抗方法都好于两种固定阻抗。
- C1 的 RMSE 最低，比最好的现有方法（在线估计 + 规则）低 44%。C2 次之。C1、C2 相对所有对比方法的改善均显著。

**结论。** 固定阻抗无法同时适应软、硬组织。及时识别刚度并调整阻抗可以解决这一矛盾，C1 的跟踪误差约为现有方法的一半。

## 5.3 实验二：组织推拉下的接触保持

**目的。** 检验组织突然推近或拉开时，方法能否保持接触、限制冲击并快速恢复。场景参照 Xue 等（RAS 2025）的组织撤离／推压实验。

**设置。**
- 均匀软组织（10–40 kPa）和均匀硬组织（0.5–1.5 MPa）各 20 个场景，无呼吸。
- 第 2 s 组织推近或拉开 5 mm，过渡 0.5 s，保持 2 s 后返回。
- 各方法沿用实验三的参数，不针对本实验重新整定。

**表 2 组织推拉任务结果**

| 方法 | RMSE 软 / 硬组织 (N) | 峰值力 (N) | 2 s 内恢复率 | 平均恢复时间 (s) |
|---|---|---|---|---|
| 柔顺固定 | 0.049 / 22.72 | 99.06 | 50.0% | 1.00 |
| 刚性固定 | 0.775 / 1.261 | 6.90 | 52.5% | 1.29 |
| 在线估计 + 规则 | 0.147 / 0.551 | 5.82 | 100% | **0.055** |
| Haninger | 0.178 / **0.433** | **5.58** | 100% | 0.072 |
| Jin MPC-VIC | 0.265 / 1.268 | 6.22 | 75.0% | 0.589 |
| Xue MPVIC | 0.383 / 3.414 | 9.44 | 68.8% | 0.794 |
| Li 学习 VIC | 0.188 / 6.132 | 25.29 | 70.8% | 0.609 |
| **C1** | 0.057 / 1.372 | 6.97 | 90.0% | 0.250 |
| C2 | 0.143 / 0.493 | 5.63 | 99.6% | 0.065 |

注：恢复率与恢复时间合并推近和返回两次事件；未在 2 s 内恢复的事件按 2 s 计入平均恢复时间。

**图 2**（`experiments/cobot_scan_benchmark/completed_tasks/figures/final_fig_T2.png`）：第一个软组织和第一个硬组织推压场景的接触力（上）与探头法向位置（下），按场景编号选取。

**结果。**
- 刚性固定在软组织推拉后持续振荡，柔顺固定在硬组织上失稳。
- 软组织上 C1 误差很低（0.057 N），与按软组织设定的柔顺固定相当。
- 硬组织上 C1 明显变差（1.372 N），恢复率 90%，不如在线估计 + 规则、Haninger 和 C2。
- C2 在软、硬组织上都稳定，整体与表现最好的 Haninger 规则相当。

**结论。** 变阻抗方法普遍比固定阻抗更能保持接触。C2 在组织推拉下稳健。C1 在持续推拉硬组织时优势消失，是其主要局限：硬组织上的大幅表面运动可能被部分误判为刚度变化，导致过度回退（推断）。

## 5.4 实验三：组合扫描

**目的。** 检验刚度变化与组织运动同时存在时的综合表现，对应实际脊柱超声扫描。

**设置。** 扫描 10 s，探头经过多个骨样区域，同时叠加 1 mm 呼吸和随机 3–8 mm 推拉。

**表 3 组合扫描任务结果**

| 方法 | RMSE (N) | 最大误差 (N) | 峰值力 (N) |
|---|---|---|---|
| 柔顺固定 | 7.099 | 43.28 | 47.28 |
| 刚性固定 | 0.502 | 2.12 | 6.02 |
| 在线估计 + 规则 | 0.230 | 1.32 | 5.22 |
| Haninger | 0.273 | 1.44 | 5.34 |
| Jin MPC-VIC | 0.285 | 1.39 | 5.35 |
| Xue MPVIC | 0.511 | 1.99 | 5.94 |
| Li 学习 VIC | 0.269 | 1.32 | 5.28 |
| **C1** | **0.147** | **1.15** | **5.04** |
| C2 | 0.210 | 1.32 | 5.23 |

**图 1**（`experiments/cobot_scan_benchmark/completed_tasks/figures/final_fig_T3.png`）：第 0 号测试场景，上为真实局部刚度，中为接触力，下为各方法实际施加的阻尼；橙色区域为组织推拉。

**结果。**
- C1 的 RMSE 为 0.147 N，比刚性固定低 71%，比最好的现有方法（在线估计 + 规则）低 36%，相对所有对比方法均显著。
- 图 1 中，刚性固定在每次进出骨样区域时出现约 2 N 的力波动。C1 的阻尼随真实刚度同步升降，该场景中力保持在 4 ± 0.5 N 内的时间比例最高（C1 94%，C2 93%，在线估计 + 规则 90%，刚性固定 76%）。
- C2 的 RMSE 为 0.210 N，优于固定阻抗和大多数现有方法，但与在线估计 + 规则的差异不显著。

**结论。** 在刚度变化与组织运动叠加的扫描中，C1 的力跟踪误差明显低于固定阻抗和现有变阻抗方法。C2 有改善，但不足以显著超过最强的现有方法。

## 5.5 消融实验

**目的。** 检验所提方法各组成部分的作用。在实验一和实验三的同一批场景上逐项去掉组成部分，不重新整定。

**表 4 消融结果（RMSE，N）**

| 配置 | 刚度变化 | 组合扫描 |
|---|---|---|
| C1 完整 | 0.060 | 0.147 |
| C1 去掉表面运动估计 | 0.897 | 1.502 |
| C1 只调阻抗增益（去掉参考补偿） | 0.102 | 0.489 |
| C1 更新周期 40 ms | 0.097 | 0.288 |
| C2 完整 | 0.083 | 0.210 |
| C2 只调阻抗增益 | 0.086 | 0.217 |
| C2 去掉力历史输入 | 3.520 | 3.610 |
| C2 决策周期 96 ms | 0.130 | 0.287 |

**结果与结论。**
- **表面运动估计是 C1 的关键。** 去掉后误差增大一个数量级。组织运动与刚度变化都会改变接触力，只估计刚度时前者会被误判为后者，导致刚度估计失真。
- **参考补偿应对组织运动。** C1 只调增益时，刚度变化任务上仍优于现有方法（0.102 N），但组合扫描误差升至 0.489 N。C2 的收益主要来自增益调整，因此在组织运动明显时不如 C1。
- **更新须及时。** 更新周期放慢到 40 ms 或 96 ms，两种方法的误差都明显上升。

## 5.7 小结

1. 固定阻抗无法同时兼顾软、硬组织：柔顺设定在硬组织上失稳，刚性设定在软组织上跟踪差。
2. 在刚度变化和组合扫描中，C1 的力误差为最好现有方法的 56%–64%，改善显著。其关键是把组织运动与刚度变化分开估计，并同时调节阻抗增益与参考位置。
3. C2 在组织推拉下稳健，但整体精度不如 C1，在组合扫描中未显著超过最强的现有方法。
4. C1 在持续推拉硬组织时表现较差，是需要改进的主要局限。
