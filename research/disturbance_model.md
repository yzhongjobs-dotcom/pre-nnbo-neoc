  - **扫描里的 d：** 主要是很慢的（呼吸、蠕变、体表起伏）或很突然的（咳嗽活化、肋骨边缘、运动起止），正好落在 D⁴ 没有优势的两端。只有身体 7–10 Hz 的共振和 100–200 ms 的事件在它的有效频带内，这与跨肋骨、惊跳时 D⁴ 略好一致。

  - **周期内插值：** Method 回归仍按一阶伺服插值位移，而对象执行器是两极点，带来约 +.04。
  - **两项扣除后：** 剩余约 +.02。
  - **散布主要来自噪声：** 无噪声时四分位距从 .37 降到 .11。
- **真正的瓶颈：**
  1. **d 的处理不是瓶颈。** 慢的 d 已被完全去除；突变的 d 任何线性先验都分不开，由门控处理；中频 d 在这个场景里很少。完美估计器（Method 其余照常）在闭环上没有收益（+.078，区间跨 0）。
  2. **刚度估计的散布受噪声限制，偏差受物理路径和模型近似影响。** Method 本来要求刚度不被低估，这些误差都在安全一侧。
  3. **任务误差来自咳嗽时的肌肉活化。** 组织在零点几秒内变硬，受回路延迟限制。
- **2026-11-06：时变刚度的鲁棒窗口 MHE（TVK，`tvk_mhe.py`、`tvk_compare.py`，未采纳；[运行记录](../project_records/agent_runs/2026-11-06_codex_tvk_mhe/)）。**
  - **动机：** Huber-D⁴ 假设窗口内 k 不变，跨越软硬组织时这一假设不成立。TVK 在窗口内联合估计 k 的轨迹和 d：
    - 目标：min ‖z − k̄Y − (k − k̄)Ỹ − d‖² + Huber-Dᵖd + λ_k·Huber-Dᵠk；
    - Ỹ 为探测频带分量，用来保证参考不变；
    - q = 1 时，λ_k → ∞ 即 Huber-D⁴。
  - **k 的真实变化（日志真值统计，0.192 s 窗口内的 |Δlog k|，p99.5）：**
    - 跨肋骨 0.21，接近线性斜坡：探头足印 12–17 mm 平均了组织刚度；
    - 咳嗽 0.66，起始快；
    - 综合 0.68；
    - 呼吸、快推拉、惊跳 ≤ 0.1。

    据此预测二阶差分（分段线性）先验最合适。
  - **单元检查：**
    - q = 1 的常数极限与 Huber-D⁴ 一致（k、σ 相对差约 1e-7），参考不变。
    - 无噪声斜坡上，q = 2 的端点偏差 −0.8%，q = 1 为 −6.6%，常数 k 为 −16.7%。预测成立。
    - 但有噪声时，端点标准差从 105 N/m 增至约 280 N/m，约 2.7 倍。
    - 注意：q = 2 的零空间含斜率，λ_k → ∞ 不回到常数 k。原设计要求它回到 Huber-D⁴，这一点是错的。
  - **闭环结果：**
    - 开发集 24 组。选中 q = 1、λ_k = 1（上边界），即最接近常数 k 的设置。
    - 168 场景诊断（该格子已看过）：
      - q = 1，ΔL = +0.023 [−0.013, +0.062]，各工况都与 Huber-D⁴ 持平；
      - q = 2，ΔL = +0.735 [+0.512, +0.986]，最大力 80 N。
  - **模块级结果：**
    - q = 2 的方差使门控几乎全部拒绝，静止段可用率只有 0.014；k 上升段低估超过 10% 的比例从 0.152 升到 0.246。

  - **结论：** 在现有探测信号和控制结构下，Huber-D⁴ 仍是最合适的估计器，辨识主线已接近信息极限。
    - **还没测的原则性变体**：q = 2 配更长窗口（如 48 拍）。时变 k 去掉了滞后，窗口才能放长。按上面的方差估算，它在静止段仍差于常数 24 拍，预期收益很小。
    - **剩余收益的来源**：一是增加信息，即激励设计；二是控制如何使用 k 和 σ，即对低估和刚度变化的容错。
- **2026-11-06：针对快速变化场景的改进尝试——带一个结构突变的 D⁴（`d_break.py`、`d_break_check.py`，未采纳）。**
  - **问题和约束：** 窗口内 z = kY + d + ε。d 是平滑分量加少数几处在未知时刻 τ 的水平或斜率突变，k 也可能在同一时刻跳变。要求因果、取窗口末端的刚度、每次计算约 1 ms。D⁴ 的平滑先验分不开突变，只能整窗丢弃。
  - **方法：** 结构突变回归（Hinkley 1970；Bai–Perron 1998）放进 D⁴ 的部分线性模型：窗口内至多一个 τ，d 加阶跃和斜坡项，k 可以跳变。每个 τ 闭式求解，用 BIC 判断是否有突变、刚度跳变是否有足够证据。没有突变时就是原来的 D⁴。
  - **先测上限（`d_ceiling2.py` 的 available 模式）：** 窗口估计等于真值，并且在突变中也始终可用。
    - 综合工况平均 L −.35（RMSE .67 → .34），咳嗽 −.15；
    - 但惊跳 +.66（一次峰值 27 N），整体 +.03（区间跨 0）。
  - **模块级（与 D⁴ 比）：** 达到设计目的。窗口可用率：事件时 .86 → .92，刚度变化时 .82 → .86；误差中位 .163 → .157、.220 → .202。静止时不变。
  - **闭环（72 个配对）：** 没有达到目标。整体 +.098 [−.045, +.295]；呼吸、快推拉为 0；综合 −.10、咳嗽 −.01（区间跨 0）；惊跳 +.24，跨肋骨 +.46（一次峰值 27–32 N）。调用时间 p50 从 1.2 ms 增加到 3–4.6 ms。
  - **失控的机理（逐拍追踪）：** 跨肋骨时检测到突变，突变后只剩 7 个样本，估出的刚度比真值低 34%，却通过了门控。前馈回路对低估刚度不稳定，于是失控。让 BIC 在“只有 d 突变”和“d 加刚度跳变”之间选择后，仍有失控。根本原因是：D⁴ 的 χ 检验本来会丢掉刚度在变化的窗口，起着安全保护作用；突变模型把残差解释掉，接受了有偏的窗口。
  - **结论：** 在现在的控制结构下，提高突变中的估计可用率会同时引入低估风险，而控制对低估不容错。上限也显示，即使估计完美，惊跳仍会变差。所以快速场景的闭环瓶颈在控制如何使用刚度（前馈对刚度误差和变化的容错），不在 d 的处理。突变模型保留为候选：等控制能容忍刚度变化后，它的模块级收益才可能转化为闭环收益。
- **2026-11-06：改用重尾先验的 D⁴（Huber-D⁴，`d_robust.py`，建议采用）。**
  - **为什么换正则项，而不是加判断：** 任何二次先验都按频率给 d 加权。50 ms 的短脉冲和 20.8 Hz 的探测响应在同一频段，二次先验无论怎么设计都分不开。但两者的结构不同：短脉冲的四阶差分只在少数几个点非零（稀疏、局部），探测响应的四阶差分在每个点都大（稠密、周期）。所以把 D⁴ 的二次惩罚换成重尾惩罚，就能在同一频段按结构把两者分开。
  - **目标：** min_{k,d} ‖z − kY − d‖² + 2ρs²·Σ h_c((D⁴d)_i/s)，其中 s = noise/√ρ，h_c 是标准 Huber 函数。
    - 四阶差分小时，惩罚就是 ρ‖D⁴d‖²，即原来的 D⁴，所以平滑窗口的估计不变；
    - 四阶差分大时，按一次增长，允许少数突变。
    - 唯一的新常数是统计学标准值 c = 1.345，没有调参。
  - **求解：** 迭代重加权最小二乘，每步是一次加权 D⁴ 平滑。用带宽为 4 的带状求解，同时解两个右端项（Codex 实现，Claude 验收）。与稠密实现逐窗口相比，k、σ、χ 的最大相对差约 1e−7。单独计时，估计器 0.35 ms，整个策略每次调用约 0.83 ms；15 进程并行时 1.8 ms，D⁴ 为 1.2 ms。

    - **尾部：** D⁴ 最严重的一次失控（169 N）降到 60 N；但有一个跨肋骨场景从 30.9 N 升到 49 N，D⁴ 在这个场景里本来就接近失控，属于已知的跨肋增益滞后问题。

  - **局限：** 闭环在接近失稳的场景里对极小差别敏感，单个场景的结果不稳，结论以多场景统计为准。跨肋骨的尾部需要在增益滞后问题解决后再看。

  - 下一处瓶颈：控制对快速变硬的响应（回路延迟和反馈增益）。另外，咳嗽活化的幅度和速度本身是假设，需要真实依据。

问题：局部接触 `F = k·y + d + ε` 中，d 到底是什么，才能据此设计 k 的估计方法。带通和多项式投影都是对 d 的假设，这里先检验 d，不比较估计器。

## 仿真检验（`experiments/rossi_failure_study/d_structure.py`）

投影估计器闭环，23 个工况×组织格，每格 5 场景，共 115 个。用真值刚度从力中提取未解释运动：`s = Σ(ΔF/k − Δy)`，`d = k·s`。

实测：

## d 的估计方法（回放与闭环）

把多项式投影放松为 d 的二次先验：

    min_{k,d} ‖z − kY − d‖² + ρ‖D⁴d‖²
    k = Y'Mz / Y'MY,  M = I − (I + ρD⁴'D⁴)⁻¹
    σ_k² = σ²/(Y'MY),  χ² = r'Mr/σ²/(m−5),  r = z − kY

M/σ² 是该先验下 d + ε 的逆协方差，k 是广义最小二乘解。ρ → ∞ 时 M 收敛到同窗三次投影（Codex 数值核对），所以现有方法是特例。ρ 由转折频率 fc 设定，窗口可从 8 拍增长。
