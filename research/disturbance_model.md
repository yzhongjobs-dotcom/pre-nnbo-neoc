# 未知干扰 d 的结构：检验与文献依据

## 2026-11-05 阶段三：新对象上 D⁴ 与投影的比较（最新，以下各节是旧对象上的记录）

**两个宿主的实际形式。** 同一回归 z = kY + d + ε（z 是力滤波的一步逆，Y 是同样滤波后的探头位移）：
- **D⁴：** k = Y'Mz / Y'MY，M = I − (I + ρD⁴'D⁴)⁻¹。它对应的先验是 d 的四阶差分为白噪声（四重积分随机游走），频率响应是截止 fc 的四阶高通。ρ → ∞ 时退化为同窗三次投影。
- **投影：** 实际部署的是 16 拍五次多项式（P5_16），不是三次。两者不嵌套，所以比较时各自调自己的结构。

**公平比较（`d_compare.py`）。** 两个宿主都用阶段二选定的 H，调参预算相同：自身结构 3 档 × 门控 2 档 × 跟踪器 4 档。在 8 个开发场景上选参：
- D⁴ 选中 32 拍、fc 14 Hz；
- 投影选中原来的 16 拍五次。

新种子测试覆盖慢运动、突发事件和滑动中的刚度突变：6 种工况 × 2 种动态形状 × 14°/28° × 3 次，共 72 个配对。

**还剩多少改进空间（`d_ceiling.py`）。** 在同样的 72 个场景上，把刚度换成真实的探测频率增益（只作诊断）：

- 反馈也换：.264；
- 自己估计的 D⁴：.273。

- **呼吸、快推拉、惊跳、跨肋骨：** 真值不带来改善。
- **咳嗽：** 有一些改善（RMSE .43→.31，平均 L −.14 到 −.23）。
- **综合工况：** 用真值反而变差（+.09 到 +.30，有一次峰值 72 N）。

**判断：**
- D⁴ 比投影好，而且它的刚度估计已接近这个 Method 闭环能用到的上限。按阶段三的要求（D⁴ 不好才优化），现在没有依据去改 D⁴ 本身。
- 咳嗽和综合工况的大误差主要不来自刚度估计。即使刚度完全准确，RMSE 也还在 .3–.4 N，瓶颈在事件期间的控制和前馈。这是下一个模块的问题，不是 d 的估计问题。
- 咳嗽时刚度跟踪有一点价值（真值能把 RMSE 降约 .1 N），可能来自咳嗽伴随的肌肉活化。这是 D⁴ 唯一看得到的改进空间，但同一个上限在综合工况下为负，证据不足以支持专门为它改方法。

问题：局部接触 `F = k·y + d + ε` 中，d 到底是什么，才能据此设计 k 的估计方法。带通和多项式投影都是对 d 的假设，这里先检验 d，不比较估计器。

## 仿真检验（`experiments/rossi_failure_study/d_structure.py`）

投影估计器闭环，23 个工况×组织格，每格 5 场景，共 115 个。用真值刚度从力中提取未解释运动：`s = Σ(ΔF/k − Δy)`，`d = k·s`。

实测：

| 工况 | D² 离群能量 | D³ 离群能量 | 判断 |
|---|---:|---:|---|
| 惊跳 + 咳嗽 | .873 | .761 | 稀疏（约 4.5% 样本） |
| 综合工况 | .917 | .775 | 稀疏 |
| 快速推拉 | .719 | .164 | 大而平滑，D³ 接近高斯 |
| 慢移 / 跨肋骨 / 静止和呼吸 / 震颤 | .045 / .042 / .136 / 0 | .035 / .086 / .265 / 0 | 接近高斯 |

- **L 的阶数：** D¹ 的核心滞后相关约 +.9，D² 约 −.01 至 −.31，D³ 约 −.4 至 −.6，所以 D² 最接近白噪声。这与牛顿第二定律一致，但仿真的运动本来就由二阶身体动力学生成，不能算独立证据。
- **离群段长度：** 惊跳和咳嗽的 D²d 离群段中位 1 拍，P90 为 6 拍。此前“上升段 4–12 拍、ℓ1 分不开”的判断说重了。
- **核心幅值：** 正常时 D²d 的核心约为噪声底的 .14–.31，单拍不可观测。
- **推论 `污染 ∝ k` 不成立：** ln(相对污染) 对 ln(k) 的斜率，安静 .23，事件 .17，预测为 1。高 k 时污染确实更大，但此式解释不了。
- **通带内 d 与探测锁相：** 16–26 Hz 内约 49–67% 的 d 能量可由 y 及其正交分量解释。这部分由探头自身引起，不是独立干扰。

- **切向 + 法向：** 对象里切向力不反作用于法向，当前无法检验，这不是否定。

## d 的估计方法（回放与闭环）

把多项式投影放松为 d 的二次先验：

    min_{k,d} ‖z − kY − d‖² + ρ‖D⁴d‖²
    k = Y'Mz / Y'MY,  M = I − (I + ρD⁴'D⁴)⁻¹
    σ_k² = σ²/(Y'MY),  χ² = r'Mr/σ²/(m−5),  r = z − kY

M/σ² 是该先验下 d + ε 的逆协方差，k 是广义最小二乘解。ρ → ∞ 时 M 收敛到同窗三次投影（Codex 数值核对），所以现有方法是特例。ρ 由转折频率 fc 设定，窗口可从 8 拍增长。

| D² 先验，24 拍 | .462 | .765 |
| D⁴ 先验，24 拍 | .295 | .248 |

| D⁴ + 记忆，48 拍 | .211 | .139 |

- **阶数：** 选到 D⁴，不是由 d 的白化判断出的 D²。D² 的滤波过渡太缓，y 的非探测内容留在回归中，而这些频带的增益不等于探测增益。d 本身的结构不足以决定 L，还要看 y。
- **稀疏部分：** Huber 没有带来可见收益，虽然 d 的驱动确实稀疏。这一条否定了此前“高斯 + 稀疏”的方法预期。

## 接触模型对比与部件消融（`contact_compare.py`、`contact_compare_extra.py`、`final_config.py`）

**对上一节的更正：** 启动锁死的机制成立，但主要诱因是 y 记忆滤波的离散错误（快支路系数过大，χ 虚高），不是融合规则本身。修正离散（对 tick 内线性运动精确，两通道统一）后，种子 403000 的同批硬组织场景不用启动规则也不再锁死（未获取 0，L 1.127，P5 为 1.072）。所以根因是实现错误经启动循环放大。上一节的 401000、405000 数字是离散修正前的。

**理论：** 单个探测频率只给一个复增益。这些局部形式的差别在频率趋势和力依赖上，只靠一个频点分不开。

| 形式 | 局部增益 | 相位 | 力依赖 | 只用力和编码器的可辨识性 |
|---|---|---|---|---|
| 弹性，AuSoScan 静态自洽（d = d0，v = 0） | k，随频率不变 | 0 | 无 | k 可辨识；几何和 E* 与 k 合并 |
| AuSoScan 滑动项 | 占静态力 .03–.09%（v = .01–.03 m/s，3–12 N，表 I，L = 15 mm） | | | 系数在 .2–1 m/s 下辨识，扫描速度不可辨识，且影响可忽略 |
| Hertz 球（T-RO 2023） | k ∝ F^(1/3) | 0 | γ = 1/3 | γ 与 E(x) 混淆；线阵探头几何不符 |
| HC，n = 1.26（Moreira） | k_t √(1+(ωτ)²)，τ = λF/k_t | atan(ωτ) | γ = .206 | 相位只给 τ，分不开 λ 和记忆；文献无可迁移的 λ |
