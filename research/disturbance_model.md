# 未知干扰 d 的结构：检验与文献依据

问题：局部接触 `F = k·y + d + ε` 中，d 到底是什么，才能据此设计 k 的估计方法。带通和多项式投影都是对 d 的假设，这里先检验 d，不比较估计器。

## 仿真检验（`experiments/rossi_failure_study/d_structure.py`）

投影估计器闭环，23 个工况×组织格，每格 5 场景，共 115 个。用真值刚度从力中提取未解释运动：`s = Σ(ΔF/k − Δy)`，`d = k·s`。

实测：

| 工况 | D² 离群能量 | D³ 离群能量 | 判断 |
|---|---:|---:|---|
| 惊跳 + 咳嗽 | .873 | .761 | 稀疏（约 4.5% 样本） |
| 综合工况 | .917 | .775 | 稀疏 |
| 快速推拉 | .719 | .164 | 大而平滑，D³ 接近高斯 |
| 慢移 / 跨肋骨 / 静止和呼吸 / 震颤 | .045 / .042 / .136 / 0 | .035 / .086 / .265 / 0 | 接近高斯 |

- **L 的阶数：** D¹ 的核心滞后相关约 +.9，D² 约 −.01 至 −.31，D³ 约 −.4 至 −.6，所以 D² 最接近白噪声。这与牛顿第二定律一致，但仿真的运动本来就由二阶身体动力学生成，不能算独立证据。
- **离群段长度：** 惊跳和咳嗽的 D²d 离群段中位 1 拍，P90 为 6 拍。此前“上升段 4–12 拍、ℓ1 分不开”的判断说重了。
- **核心幅值：** 正常时 D²d 的核心约为噪声底的 .14–.31，单拍不可观测。
- **推论 `污染 ∝ k` 不成立：** ln(相对污染) 对 ln(k) 的斜率，安静 .23，事件 .17，预测为 1。高 k 时污染确实更大，但此式解释不了。
- **通带内 d 与探测锁相：** 16–26 Hz 内约 49–67% 的 d 能量可由 y 及其正交分量解释。这部分由探头自身引起，不是独立干扰。

## 文献（Codex 定向核查，见[运行记录](../project_records/agent_runs/2026-11-04_codex_d_model_literature/)）

这次是 30 分钟的定向检索，不是正式 ARIS 流程。Claude 用 Crossref 核对了 8 个 DOI 的题名、作者和年份，全部相符；各文献结论未逐篇读原文核实。

| 机制 | 来源 | 对应关系 |
|---|---|---|
| 部分线性模型 | Speckman 1988；Robinson 1988 | `F = k·y + d` 的标准形式，先消除 d 再估 k |
| 新息模型与 representer 定理 | Unser, Tafti 2014；Unser, Fageot, Ward 2017 | `Ld = w`，ℓ1 下解为有限结的样条 |
| 广义 Kalman 平滑 | Aravkin 等 2017；Ohlsson 等 2012 | 状态空间下的 Huber 和稀疏跳变，全序列平滑成本对时长线性 |
| 物理 ODE + 随机驱动 | Alvarez 等 2009；Hartikainen, Särkkä 2011 | 潜力模型及其序贯推断，默认高斯驱动 |
| 已知导频 + 稀疏干扰 | Lin, Nassar, Evans 2013 | 通信中结构最接近 |
| 闭环辨识偏差 | Forssell, Ljung 1999 | y 受反馈影响，d 不能当外生 |

- 未查到已有工作把这些结构用于接触刚度在线估计。这只是定向检索的结果，主张新颖性前要做正式覆盖。
- 未查到咳嗽、惊跳、突然移动时探头接触力的公开原始时序，也未查到腹壁 1–50 Hz 的直接接触阻抗。仿真里事件的力幅和时序仍是假设。

## 接触模型的确定（2026-11-04，用户要求后续研究）

要回答的是：哪些接触项能把探头运动引起的力解释正确，并且只用力和编码器可在线使用。

对象频率响应（`contact_response.py`，无噪声回放，冻结状态）：

| 组织 | 1 Hz 增益 / 20.8 Hz 增益 | 刚性支撑时 | 由 20.8 Hz 相位按幂律预测 |
|---|---:|---:|---:|
| 软 | .70 | .72 | .72 |
| 中 | .70 | .75 | .80 |
| 硬 | .61 | .78 | .81 |

- k 只对探测频带准确，y 的其他频带响应都进入 d。
- 单频相位只能预测组织记忆，预测不了身体屈服，因此不能作为硬组织的单频外推依据。
- k 随力的指数：软 .79，中 .25，硬 .15（对象内）。

闭环价值，同一控制器（`dynamic_gain_value.py`，115 场景）：

| 力到运动换算 | L | RMSE 中位 | 事件 RMSE | 失控 |
|---|---:|---:|---:|---:|
| 真值增益 | .577 | .200 | .452 | 2 |
| 真值动态逆（记忆 + 串联刚度） | .538 | .186 | .396 | 1 |
| 1 Hz 真值的标量增益 | 4.457 | 6.394 | 7.072 | 35 |

真值动态逆相对真值增益 L −.039 [−.061, −.021]。这是上限，幅度不大。不能简单换成低频标量，必须按频率处理。

可部署项（`deployable_contact.py`，自身 k_good，总体常数，115 场景）：

| 对象 | 记忆换算的 L 差 | RMSE 中位 | 事件 RMSE |
|---|---:|---:|---:|
| 名义 | +.009 [−.043, +.072] | .227→.201 | .554→.455 |
| 低记忆 | −.027 [−.074, +.016] | .187→.175 | .445→.369 |
| 高记忆 | −.044 [−.118, +.011] | .242→.218 | .608→.522 |
| 单分支 | −.017 [−.062, +.036] | .190→.183 | .473→.404 |

记忆模型与对象不匹配时也未出现损害。k 随力修正（γ=.25）名义下 L +.032 [−.046, +.141]，没有收益。

**决定：** 接触关系用局部增益加弱幂律记忆，`F = k·H_β[y−s] + d`，k 由探测在线估计，β 为总体常数。
- **Hertz、柱面足迹：** 其工作点效果已包含在在线 k 中，不再单独建模。
- **Hunt-Crossley：** 对象内没有单独做消融；文献未见其优于线性黏弹的证据，未采用。
- **切向 + 法向：** 对象里切向力不反作用于法向，当前无法检验，这不是否定。
- **真实数据：** 在体腹部静态刚度放松约 .24–.72 N/mm，主动约 1.08–5.22 N/mm（Remus 2024）。对象的硬组织（约 17 N/mm）超出腹部软组织范围，只对应肋骨或骨面。在体 β 依方法差异大（.25 与 .85，定义不同），无与探头一致的 1–50 Hz 阻抗数据。

## d 的估计方法（回放与闭环）

把多项式投影放松为 d 的二次先验：

    min_{k,d} ‖z − kY − d‖² + ρ‖D⁴d‖²
    k = Y'Mz / Y'MY,  M = I − (I + ρD⁴'D⁴)⁻¹
    σ_k² = σ²/(Y'MY),  χ² = r'Mr/σ²/(m−5),  r = z − kY

M/σ² 是该先验下 d + ε 的逆协方差，k 是广义最小二乘解。ρ → ∞ 时 M 收敛到同窗三次投影（Codex 数值核对），所以现有方法是特例。ρ 由转折频率 fc 设定，窗口可从 8 拍增长。

**回放（`d_estimator_replay.py`，选择种子 390000，评估种子 386000，115 场景，ln(k̂/k) 平均单元 P90）：**

| 估计器 | 全部 | 硬 |
|---|---:|---:|
| P3_16 | .384 | .414 |
| P5_16 | .380 | .278 |
| P5_24 | .324 | .324 |
| D² 先验，24 拍 | .462 | .765 |
| D⁴ 先验，24 拍 | .295 | .248 |
| D⁴ + Huber | .295 | .247 |
| D⁴ + 记忆，24 拍 | .273 | .225 |
| D⁴ + 记忆，48 拍 | .211 | .139 |

- **阶数：** 选到 D⁴，不是由 d 的白化判断出的 D²。D² 的滤波过渡太缓，y 的非探测内容留在回归中，而这些频带的增益不等于探测增益。d 本身的结构不足以决定 L，还要看 y。
- **稀疏部分：** Huber 没有带来可见收益，虽然 d 的驱动确实稀疏。这一条否定了此前“高斯 + 稀疏”的方法预期。

## 硬组织差距的根因（`root_cause.py`、`root_cause_confirm.py`、`root_cause_acquire.py`）

上表的硬组织尾部差距，主因是候选与现有方法的启动规则不匹配，不是方法本身。

| 假设 | 检验 | 结果 | 判断 |
|---|---|---|---|
| 实现错误 | 同一组数组上，大 ρ 候选与同窗三次投影比较 | ρ = 10⁶ 时 k 相对差 P99 为 5e−5，残差比 .99997 | 排除。此前 ρ ≈ 2e10 的差异来自矩阵病态（条件数约 2e12），只影响极限对照 |
| 调参 | 候选用 30 次门控预算（与投影相同） | L .622，差 −.020 [−.066, +.030]；硬组织打平，但惊跳和咳嗽的改善消失 | 次要。放宽 χ 能缓解启动，代价是事件时门控变松，一个尺度顾不了两头 |
| 方法本身 | 只把第一个增益换成真值，之后全部自主 | L .548，差 −.094 [−.141, −.050]；硬组织 −.03 [−.09, +.02] | 排除为主因：启动解决后不再比投影差 |
| 融合方式 | 见下 | 去掉后差距消失 | **主因** |
| 设置 | 投影 P5_16 的 k_good 中位偏高 +.12，低侧 P10 为 −.01 | 同为投影，P3_24 的 P10 为 −.48，失控 56/105，P5_16 为 0/105 | 投影的硬组织稳定部分来自偏差，比较基线本身带安全裕度 |

**启动锁死的机制（实测）：** 未获取 k_good 的场景里，窗口已很精确（k 误差 2–7%，rel 约 .002–.003），但 χ 中位 20–38，超过门限 2.68。现有规则在 k_good 获取前每拍把探测放大（k_seek × .85）。于是形成正反馈：χ 不过 → k_good 为空 → 探测继续放大 → χ 更大。短窗投影约 .1–.5 s 内即可通过，不会落入这个循环。χ 同时承担了两个职责：启动时的准入和运行中的事件拒绝。

**可部署修正（不读真值）：** 获取首个增益时只要求精度（rel ≤ rel_max），不要求 χ；窗口一旦精确就停止放大探测。该规则对投影几乎没有影响（L 差 −.001 [−.003, +.002]）。

## 证据边界

- 修正后的启动规则没有在记忆失配对象上重跑，也未做部件消融。启动规则放宽 χ 后，接触瞬态可能被接受，当前结果未见损害（未获取为 0），但没有专门的压力测试。
- 所有闭环结果来自同一仿真对象，对象的 Prony、单一身体模态、足迹都是构造假设。记忆模型只在 4 种记忆设置下核对过，没有真实人体数据验证。
- 候选的门控预算（6 次）少于投影（30 次），控制参数未为候选重调。
- Codex 独立审查（[记录](../project_records/agent_runs/2026-11-04_codex_ridge_review/)）查出的 χ、自由度、回放错拍、动态换算归一化、接触复位问题已修正。串联刚度仍未进入部署版换算，属于已声明的假设。
