# 辨识模块三个问题的独立核查（2026-11-12）

对象：[Huber 误差机制](huber_error_mechanism_20261110.md)、[V2 信息量](v2_information_design_20261110.md)、[V2 斜率限制](v2_slope_limits_20261110.md)第八、九节的归因。数据：已存的 42 例 Huber-D⁴ 闭环窗口（`results/huber_windows`），另跑 7 个同配置回合看力矩通道。没有新候选的闭环结果。脚本在 `experiments/rossi_failure_study/`：`review_info_chain.py`、`review_lf_rate.py`、`review_lf_level.py`、`review_moment_look.py`。每类只看少数回合，属于机制核查，不作统计。

## 结论

- **噪声与信息不足：归因成立，而且是探测通道本身的限制，不是估计器浪费了信息。** 现有估计器已取到探测频带信息的约九成，换估计方式最多再多 1.3–1.5 倍。
- **时变跟踪偏差：归因成立。** 探测通道的信息率决定了快变化段的误差下限，任何只用这一通道的估计器都绕不过去。
- **持续低估的塌陷：机制的前半（信息离开探测频带）可靠，后半（62.5 Hz 增益为负）落在仿真自己标为不可靠的频段。** 把估计限制在探测频带的修正不依赖后半。
- **“频带估计放大咳嗽起始瞬变”的归因没有证据。** 原文同窗口回放中两者的最大高估相同，差别只在闭环里出现。
- **低频力—位移通道此前的负面结论需要修正：** 关系是真实且干净的，但只在大而快的跨肋上占主导，而且与身体运动不可区分；按现有检验它不足以成为估计器的主要输入。
- **闭环上限：** 理想标定下，完美刚度相对 Huber-D⁴ 的 L 均值只差 .035（.504 对 .539），差距集中在咳嗽和大变化跨肋。

## 一、探测信息的去向

`review_info_chain.py`，10 例，24 拍窗口，每拍信息 = k²·(回归量能量)/σ²/24，中位数。

| 量 | 结果 |
|---|---|
| 回归域噪声 σ | .023–.025 N，相邻拍相关 .03–.17，可当作白噪声 |
| 回归域探测力 rms | .024–.043 N，多数约 .03 N |
| 每拍信息：只取探测载波 | 1.2–1.9（多数），大变化和综合 .9–2.9 |
| 每拍信息：D⁴ 14 Hz（现用） | 1.2–1.6（多数），硬组织 2.1–4.1 |
| 每拍信息：只去三次多项式 | 1.5–2.2（多数） |
| 单窗相对 sd：预测 / 实测 | .10–.18 / .09–.18 |

- 现用 D⁴ 与只取载波相差约一成；与最窄的干扰假设（三次多项式）相差 1.3–1.5 倍，与 [11-08 的结果](stiffness_module_problem_20261108.md)（1.28–1.45）一致。
- 所以“利用已知激励结构降噪”的上限是 sd 下降约 13–18%，补不了变化段所需的 4–31 倍。
- 此前文档的“每拍信息 .86”与这里的 1.2–1.6 口径不同（前者可能用了设计噪声 .04 N），单窗 sd 的结论一致。

**纹波代价的一处边界。** 按节拍采样的真实轴向力在 20.8 Hz 的纹波为 .071–.093 N rms，而 k_eff × 编码器纹波只有 .046–.050 N（案例 0、12、36）。多出的 1.5–2 倍与[第 10 节](identification_module_scheme_20261108.md)的节拍采样增益（1.47–2.04）相符，即指令保持的 104 Hz 镜像混叠进来的力。这部分依赖 35 Hz 以上的对象行为，仿真已标为不可靠。因此“纹波约占力误差方差 35%”含有这部分，真实占比不确定。这一点只作记录，不作为研究方向。

## 二、塌陷机制与频带修正

- **可靠的部分：** 估计 = Σ s_b G_b，只有回归量能量集中在 G_b = k_eff 的频点时才无偏。闭环振荡使能量离开探测频带，估计随之失去依据。
- **依赖仿真的部分：** 62.5 Hz 是节拍采样的奈奎斯特频率，那里的负增益来自保持镜像和准静态机械臂方程，属于不可靠频段。真实机器人上塌陷的方向和深度可能不同。
- **旁证：** [表 3](../experiments/rossi_failure_study/comparison_tables.md) 中 Rossi-ID 下降段最大低估最差值为 .55，D⁴ 族为 4.5。Rossi 的带通本来就有这层保护，D⁴ 联合估计把它丢了。
- **咳嗽变差的归因：** [频带分离](probe_band_separation_20261110.md)的同窗口回放里，咳嗽 26 的最大持续高估为 +.68 对 +.69，综合 35 为 +1.29 对 +1.46。回放中并没有被放大，闭环差异（3.28 倍对 1.43 倍）来自轨迹分叉，原因未查。这是采用频带修正前必须查清的一项。

## 三、低频力—位移通道

**推导。** 设接触力 F = q(x,a)·g(δ)，压入 δ = y + u（符号按跟踪时 ẏ ≈ −u̇ 取），恒力附近

\[
\dot F = k_{LF}(\dot y+\dot u) + nF\,\frac{d\ln k}{dt},\qquad n=\frac{g'^2}{g'^2-g\,g''}\ (\text{幂律时为指数}).
\]

刚度场变化在力上产生 nF·d ln k/dt，控制器为保持力而被迫移动 Δδ = −(nF/k_LF)·Δ ln k。这一项的信噪比很高，困难只在于它与 k_LF·u̇ 相加。

**速率域（`review_lf_rate.py`，用 k_eff 代替 k_LF，约 0.1 s 平滑）：**

| 回合 | 已知真实运动：相关，增益 | 只用编码器：相关 | 身体运动占扰动方差 |
|---|---|---:|---:|
| A_large 36、37（28°，23 mm/s） | +.94，7.7；+.84，4.7 | +.91，+.79 | .05，.07 |
| A_large 39、40（14°，23 mm/s） | +.93，.92；+.79，1.04 | +.85，+.73 | .17，.11 |
| A_large 38、41（8.5 mm/s） | −.16；+.76，.57 | +.55，−.14 | 1.7，2.5 |
| A 0、3 | +.74，5.0；+.81，.90 | +.38，+.34 | .66，.82 |
| A 1、2、4、5 | −.23 到 0 | −.08 到 +.33 | .80–.89 |
| A慢薄 6–11 | −.24 到 +.55 | −.47 到 +.03 | .85–1.75 |

- 增益约为 n·k_eff/k_LF：14° 粘性型约 1，28° 实测谱约 5–8，与幂律色散（20.8 Hz 对低频约 3 倍）相符。回合内稳定，随组织而变。
- 此前“相关 .57、增益约 4、不是有标定的斜率”来自把增益不同的回合合在一起。回合内的关系比那时判断的干净得多。
- 但它只在大而快的跨肋上占主导。慢扫描和薄覆盖层的 A 中，呼吸项相当或更大，A 的一半回合即使已知真实运动也不成立，原因未查。
- 推拉和咳嗽产生同样大小的低频扰动（事件段 2.5–21，对平稳段 .4–1.9）。这正是[两点界](stiffness_separation_20261107.md)所说的不可区分。

**水平域回放（`review_lf_level.py`，42 例）。** 2 s 高通后 ln k 对压入变化的 R²（已知真实运动 / 只用编码器）：B .96/.08，咳嗽 .91/.11，A慢薄 .87/.04，A+B .73/.19，A_large .57/.33，A .16/.43，综合 .04/.08。一个粗糙的因果估计（探测窗口输出定水平和系数，压入变化定形状）在各段都不如原始窗口：A_large 上升段 rms .51（已知真实运动）对 .22。估计器本身很粗（递推最小二乘定系数、指数平均定水平），这一负结果只说明“直接当回归量”在这个实现下不成立，不否定该通道。

**量级判断。** 最好的回合里速率关系留下约 12–35% 的未解释方差。与探测通道按互补方式融合，粗算过渡段误差约可从 .3 降到 .2；其他场景没有收益，事件段有害。它是一条有物理依据的辅助信息，不足以单独成为主线。

## 四、力矩通道（只作观察）

对象已经物理地建模了力矩通道（足印压力一阶矩加摩擦力臂加噪声），并且一直提供给 Method，现方法没有使用。`review_moment_look.py`，7 个回合：

- 身体运动事件几乎不移动压力中心（咳嗽 .31 对 .32 mm，推拉 1.30 对 1.74 mm），与预期一致。
- A_large 中压力中心与刚度变化率零时差相关约 0，四分之一周期处为 ±.6 到 ±.77，即与刚度水平相关。对象的足印只沿探头长轴积分，A_large 的扫描方向是短轴，扫描方向的压力梯度没有建模。看到的是姿态倾角项 tanθ·L²/(12δ)，它与压入深度成反比。
- 所以这个对象不能检验“力矩区分空间非均匀与身体运动”。是否使用力矩通道涉及观测范围，由用户决定。

## 五、闭环上限

[表 1](../experiments/rossi_failure_study/comparison_tables.md)，理想标定：Oracle L 均值 .504、中位 .127；Huber-D⁴ 为 .539、.137。分场景只有咳嗽（.441 对 .594）和 A_large（.174 对 .353）差别明显；综合在 Oracle 下也是 2.48。辨识精度在现有控制器下能换到的闭环收益集中在这两类场景和少数塌陷回合。

## 局限

- 每项核查只用少数回合，未做扰动敏感性检验。
- 速率域用了真实 k_eff 和约 0.1 s 的非因果平滑；水平域回放的估计器未经设计和调参。
- 纹波与镜像的对应只是量级相符，没有做控制变量。
- 未经独立复核。
