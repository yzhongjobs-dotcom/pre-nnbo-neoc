# Huber-D⁴ 的理论预期与实验不符：根因分析（2026-11-09）

已经 Codex 独立复核（[记录](../project_records/agent_runs/2026-11-09_codex_huber_review/)）。复核指出的错误已改正，改正内容见第三节和第五节。

## 结论

问题同时出在理论和实验两边，没有发现代码实现错误。

- **比较设置（实验问题）：** 三张表里 D⁴ 用 32 拍窗口、σ 尺度 1.5，Huber-D⁴ 用 24 拍、σ 尺度 .796。表 2 平稳段的差别（.142 对 .129）全部来自窗口长度：窗口相同时，11158 个平稳窗口的估计完全相等。
- **快推拉没有优势（理论表述问题）：** 原表述把“人感觉快”当成“D⁴ 意义下的突变”。场景里的推拉上升 180–400 ms，在 8 ms 采样下很平滑，12 次推拉只有 1 次轻微激活 Huber 权重，其余时候 Huber 在数学上就等于 D⁴。可控实验中 D⁴ 对这种推拉的泄漏约 .01–.03，低于噪声下限。B 场景的误差主要表现为标定和噪声。
- **咳嗽有优势但幅度小（理论方向对，缺少量级条件）：** 尖脉冲确实激活 Huber。咳嗽 26 上 D⁴ 塌到 200 N/m 下限，Huber 保持 1756（真值 2564），峰值力从 30.4 N 降到 19.7 N。但大台阶下 Huber 残留的相对误差中位约 .98、网格最大 4.56，多数窗口只改善很少。门控也已替 D⁴ 挡掉了这些坏窗口，所以门控版看不出差别。
- **整体不稳定（理论假设在高刚度窗口不成立）：** 窗口内非探测的高频运动远大于探测响应时，先验在大部分行上放松，信息比降低。明显变差的 154 个窗口有 149 个在综合场景，其中 65% 收敛后落到 k 下限（含负值）。独立求解器确认这些窗口的目标函数最优确实可以落在 k<0，不是迭代未收敛。其余窗口最优仍为正，只是更差。
- **闭环 L 不宜用来判断先验：** 差别最大的 8 例中，只有咳嗽 26 的差距在 ±0.5% 扰动下保持稳定。其余差距不稳健，不能据此判断先验好坏，但也不能说明先验没有作用。

## 一、理论的准确表述

观测模型 z = kY + d + ε，联合求解：

min_{k,d} ‖z − kY − d‖² + 2ρs²·Σ h_c((D⁴d)_i / s)，s = σ_n/√ρ，c = 1.345

驻点条件是 Y'r = 0，r = z − kY − d = ρs·D'ψ(D⁴d/s)，其中 ρs = σ_n√ρ。

IRLS 的每一步都是 k = Y'M_w z / Y'M_w Y，M_w = I − (I + ρD'WD)⁻¹，w_i = min(1, c/u_i)，u_i = |D⁴d̂|_i / s。

由此得到四条可检验的预期。

1. **等价条件：** 所有 u_i ≤ c 时 W = I，Huber-D⁴ 与 D⁴ 完全相同。Huber 只比 D⁴ 多处理“四阶差分超过阈值”的 d，阈值在 z 单位下是 cs = .0121 N（ρ = 19.62，σ_n = .04）。
2. **激活判据：** 准确条件是二次解处 ‖D S (z − k̂Y)‖_∞ > cs。对平滑推拉，u_max ≈ .28·(d/10 N)·(270 ms/上升时间)³（由 `huber_synthetic_map.py` 定标）。10 N 时上升时间要短于约 160 ms 才触发。
3. **台阶下的残留误差：** A 为解处 ψ = ±c 的饱和行，N 为其余行，则

   δk = ρs c · sgn'D_A S_N Y / (Y'M_N Y) + Y'M_N(d₀ + ε)/(Y'M_N Y)，S_N = (I + ρD_N'D_N)⁻¹，M_N = I − S_N

   无噪声且 D_N d₀ = 0 时第二项为零。只要饱和集合和符号不变，δk 就不含台阶高度。这是这一族台阶的饱和值，**不是对任意干扰的统一上界**。此时 δk/k = (c σ_n √ρ / kA)·Γ，kA 是 z 中探测力幅值，Γ 只取决于窗口几何。
4. **代价：** k 失配 δ 留下 δ·Y_band，经 D S 进入判据。正常探测 k·MY 的等效力幅约 .13 N，很难触发；窗口内高频运动很大时就会大面积触发，先验放松，部分探测信号进入 d。

原表述“允许 d 局部突变”方向正确，但缺两个条件：什么算突变（预期 2），以及放松后残留多少误差（预期 3）。“刚度信号可能被 d 吸收”也成立，发生条件是预期 4。

## 三、根因

### 理论问题

1. **“快推拉”不属于 Huber 的作用范围。** 判据是四阶差分和阈值之比，不是人感觉的速度。场景推拉 u ≤ .68（只有 1 次 1.59），而 c = 1.345。这也解释了历史结果“呼吸、快推拉 ΔL = 0”：这部分数学上相同。
2. **饱和后残留的误差太大，实际保护有限。** 名义 σ_n = .04 时 cσ_n√ρ/kA = 1.83，台阶网格上的残留误差中位 .98、最大 4.56 倍 k。σ_n 换成实测 .0231 后是 .57 和 2.63。再把阈值压到 c ≈ .72（噪声 3 倍标准差，仍用 σ = .0231）时约 .30 和 1.4。它的量级由每拍信噪比决定：kA/σ ≈ 5.6，而 c√ρ ≈ 6，所以只改 s 或 c 不够。s 降到 .25 倍时，综合刚度变化段 P90 反而从 .458 升到 .719。
3. **“探测响应稠密，不会被吸收”的假设在高刚度窗口不成立。** 该假设默认窗口内稠密的高频成分只有增益为 k 的探测响应。综合 31、32 在 k 约 20 kN/m 时，k·MY 的 rms 为 .4–1.6 N，是探测响应（.09 N rms）的约 5–15 倍，含 62.5 Hz 成分。明显变差的 154 个窗口 k 中位 21 kN/m、信息比 .41，有 65% 收敛到 k 下限。独立求解（对偶箱约束加一维搜索，未用 IRLS）确认案例 31 第 163 行的全局最优 k = −19781 N/m。也有反例：同例第 46 行变差明显，最优仍为 +7423，属于放松后信息减少但没有变号。去掉 d 后（z = k_eff Y 加噪声）Huber 与 D⁴ 一样准，说明探测响应本身不是问题。D⁴ 在这些窗口也偏低约 15%，只是没有崩溃。
4. **Huber 不处理窗内刚度变化。** 咳嗽事件的误差预算里，窗内 k 项（rms .181）与其余项（.162）同量级。Huber 的模型只有一个常数 k，这部分超出它的模型。

### 实验问题

5. **表中对比混入了窗口和门控尺度。** “B 上 Huber .086、D⁴ .047”也来自这里，同配置时都是 .086。
6. **B 场景的误差主要表现为标定和噪声，这掩盖了先验差别。** B 事件 rms 中噪声 .339、标定 .274；中位绝对值中标定 .206、噪声 .105；其余项 .054。软组织上，质量和伺服标定误差直接变成刚度误差（δk ≈ δm·ω²）。考虑质量、伺服和时延误差后，预测与测量的相关系数 .93（斜率 .73，未经独立复核），只算质量时 .60。这些标定误差范围（±5%）是假设，不是这台机器人的实测。Oracle 在 B 上 L = .650、理想标定后 .050，也反映同一点。
7. **闭环 L 被少数不稳健案例主导。** 差别最大的 8 例里，综合 31、32 用 1e-6 扰动就能改变 L 约 1；A_large 36、综合 35 用 ±0.5% 扰动就打乱。每组 6 例时，这些案例足以决定均值。

**检查后排除的因素：**
- **阈值中的噪声值：** σ_n 用 .04，实测 .0231，尺度偏大 1.73 倍。改成实测值后没有改善（突发段 P90 .451 → .456）。这是设置不准，不是根因。
- **IRLS 只迭代 6 次：** 大幅值合成台阶上没收敛（误差可达 37，收敛解 4.6）。真实窗口上影响很小（综合刚度变化段 P90 .458 → .493，收敛后还更差）。
- **代码实现：** 回放差 2.3e-7，驻点残差 1e-9，窗口与日志行的对应经独立核对。

**D⁴ 的误差预算（24 拍，rms，逐窗相减）：**

## 四、对已有结论的影响

- **`disturbance_model.md` 2026-11-06 采用 Huber-D⁴ 的依据需要复查。** 当时依据是 168 场景的闭环 ΔL（全部 −.083，综合 −.319，惊跳 −.144）。今天的结果表明，综合这类场景的单例差距可能不稳健。那批结果未重跑，这里只标为“待复查”，不等于已被推翻。
- **“平滑窗口不变”** 对平稳段成立；高刚度综合窗口不成立。
- **表 2、表 3 的 D⁴ 行不能直接当作“先验的效果”。** 要比较先验，应读本文同窗口结果，或在表中增加 24 拍的 D⁴。

## 五、局限

- 42 例、每组 6 例，只作描述。咳嗽 26 是唯一证实的闭环收益，属于单例机制证据，不代表统计优势。
- 同窗口回放全部取自 Huber 闭环轨迹，两种先验在各自闭环中遇到的窗口分布并不对称。
- 敏感性实验只扰动 k，不动 σ 和 χ。Huber 的 σ、χ 是冻结权重下的代理统计量，门控切换这条通道没有单独分开，A_large 36 门控版的差距可能来自这里。“L 对扰动敏感”也不足以证明动力学意义上的混沌。
- 台阶残留误差的数值是有限位置和相位网格上的中位数和最大值。
- “其余”项没有进一步分开 d 泄漏与模型误差。
- 仿真结论只到约 35 Hz，高刚度窗口里的 62.5 Hz 成分受对象准静态臂近似影响，真实系统中是否同样出现未验证。
