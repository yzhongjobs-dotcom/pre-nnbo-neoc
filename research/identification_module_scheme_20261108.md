## 2. 记忆：理论分析

**基准。** \(\ell_t=\ell_{t-1}+w_t\)，\(\hat\ell_w=\ell_t+\varepsilon_t\)，噪声强度 \(N=s^2T_0\)。连续或小步长近似下，固定 \(q\) 时记忆 \(\tau=\sqrt{N/q}\)，测量噪声贡献 \(N/(2\tau)\)，确定性斜坡滞后 \(\rho\tau\)。

**这一滤波器族的折中。** \(\tau^*=(N/4\rho^2)^{1/3}\)。\(s=0.2\) 时，\(\rho=0.05,0.29,0.73\ \mathrm{s^{-1}}\) 对应 RMSE 0.079、0.142、0.194。这是指数记忆族的近似结果，不是所有估计器的下界。

**Monte Carlo（`memory_theory_check.py`，合成数据）：**

| 方法 | 相对 Kalman 的改动 | 平稳 sd | 斜坡 0.73/s RMSE | 结论 |
|---|---|---:|---:|---|
| 窗口 | 无记忆 | 0.200 | 0.20 | |
| Kalman q=0.002 | — | 0.044 | 1.42 | 与公式吻合 |
| Kalman＋Huber 新息 | 大新息时增大 R | 0.044 | 9.39 | 持续变化时跟丢 |
| Lepski c=2 | 选最长相容窗口 | 0.050 | 0.43 | |
| 创新遗忘 | \(P/\lambda\) | 0.025 | 0.49 | 软响应 |
| Huang ARD，固定精度 | \(\alpha^*=(\nu^2-S)_+\) | 0.103 | 0.22 | |
| 门限 ARD κ=3（改造） | \((\nu^2-\kappa^2S)_+\) | 0.061 | 0.32 | |

**Huang 方法的标量分析。** 固定精度、观测系数为 1、关闭参考层时，eq.(14) 的定点是 \(\alpha^*=(\nu^2-S)_+\)，触发分支的增益为 \(1-r/\nu^2\)（未触发时为 \(P_0/(P_0+r)\)）。校准高斯新息下触发概率 31.7%；取 \(P_0\approx0\)、\(S\approx r\) 时，更新量方差每步 0.333r，触发条件下 1.05r。因此在低信噪比标量问题里它并不稀疏。
- 原文是多传感器结构问题，条件不同。
- 第二层"相对参考值的稀疏"不适用：刚度沿扫描双向变化，没有稀疏偏离的参考值。原文第 15 页关闭这一层只是对照试验，报告了漂移。
- 逐拍 dual 版本在单传感器下不适定：ARD 要么冻结，要么方差按 \(1/Y^2\) 发散，合成阶跃已复现，未进闭环。
- 我的精度学习实现（eq.15、17）尺度有误，所以"学习精度几乎无记忆"不能归因于原文算法，已从结论中删除。

**被否定的改造。** 不对称阈值（上调阈值低于下调）在闭环中更差；恢复 \(\bar k\) 裕度在闭环中无改善。

## 4. 判断

**成立：**
- 现有 Huber-D⁴ 和门控相对各辨识基线总体领先或持平，相对完整控制器基线（完整 Rossi、Xing、DO-MPAC）总体优势明确。场景 A 单看，Xing 均值更低，区间跨零。
- 平稳噪声不是现阶段限制恒力的主要问题：门控后的 k 散布已接近平台半宽。这也解释了为什么记忆没有收益：我的理论假设原始窗口噪声直接到达控制，这个前提不成立。
- 固定记忆在强对比下变差，创新遗忘比固定 q、Lepski 和 ARD 更稳健，这些理论预测与实验方向一致，但相对真实基线都没有转化成收益。

**不成立或未解决：**
- 记忆融合、距离先验、固定减小探测幅值（有 ×0.7、×0.5 两档，强对比下变差）、增益范围修正，都没有证明带来闭环收益。距离先验恒速时与固定 q 不可区分，现有场景无法单独验证它。
- 尾部没有解决：文献速度下基线 45.6 N，六类工况 44.8 N。无噪声 f=1.2 显示尾部可以大幅下降，机制未查明。
- A、B 典型误差中 D⁴、Rossi-ID 的 <2 Hz 慢带约 0.02 N，Huber 约 0.05 N，原因未查明；绝对值很小。

**下一步要查的。** 尾部究竟由哪条通道决定（送给前馈的 \(k_{\rm good}\)，还是送给反馈的 \(\bar k\)），这决定问题属于辨识模块还是控制接口。
