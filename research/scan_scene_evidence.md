# 超声恒力扫描：仿真环境与证据

2026-11-05。实现在 `experiments/rossi_failure_study/physics_plant3.py`、`scenes3.py`。验证：`check_curve3.py`、`check_plant3.py`、`check_dynamics3.py`、`smoke3.py`；对真实数据的核查：`real_data_audit.py` 和 `project_records/agent_runs/2026-11-05_codex_real_data_audit/final.md`。

研究范围由任务决定，不由数据来源决定。代表性难点是软硬突变（肋骨、硬夹杂）、组织运动、曲面和突然推拉。现有肋骨和骨脊工况能覆盖的，不另建场景。

## 系统参数和探头惯性

对象用真实系统参数，Method 只拿真机能标定到的值。这些量的范围都是假设，没有本机实测。

| 量 | 对象（真值） | Method 拿到的 | 依据 |
|---|---|---|---|
| 探头质量（传感器之后） | .15–.45 kg | 真值 ±5% | 假设，按实际探头和夹具改 |
| 执行器滞后 | 15–25 ms | 真值 ±5% | 假设 |
| 力信号相对编码器的时间偏移 | 0–2 ms | 真值 ±.25 ms | 假设。自由空间正弦运动时读数就是 m·a，它的幅值和相位同时给出质量和偏移 |
| 软件力滤波器、控制周期、指令延迟 | 已知 | 已知 | 系统自己设定 |

**测力模型。** 传感器装在法兰和探头之间（Piedra 第 3 节、Beber 式 3–4），读数 = 接触力 + m·a。对象只加了两项：测量里的 m·a，以及机械臂挠度里的同一项。后者对接触压深的影响只有约 1–2 µm，几乎可以忽略，惯性的影响基本都在测量上。加速度按一个控制周期取，因为一阶伺服模型的速度阶跃不符合真实探头运动。

**补偿在传感环节，不改 Method 算法。** `method3.ForceSensing` 用标定的质量、滞后和时间偏移，加上编码器和指令，算出 m·a，经同一滤波器后从读数中减去，并把力和编码器对齐到同一时刻。真机上这也是传感器数据进入控制器之前的一步。

**验证（`check_system3.py`，24 个场景，L，8 N，实测谱 14°，与理想系统比平均 L）：** 开环下读数幅值与 mω²y 相符（比值 .968），补偿后残余 .3%。

| 情形 | 平均 L 变化 |
|---|---|
| 探头质量，精确标定 | +.01 |
| 质量误差 +5% / −5% | +.36 / +.46 |
| 滞后误差 +5% / −5% | +.07 / +.09 |
| 偏移 1 ms，标定误差 +.25 / −.25 ms | +.01 / +.10 |
| 偏移 2 ms，精确标定 | +.45 |
| 全部因素同时存在 | +.24 |
| 不补偿惯性 | +3.74 |
| 偏移 1 ms 完全不标定 | +2.46 |
| 滞后误差 10%（应力） | +1.41 |

**已修的 bug（Codex 定位，Claude 验收；[运行记录](../project_records/agent_runs/2026-11-05_codex_sensing_fix/)）。**
- **原因：** `ForceSensing` 为了让力和位置对齐，平移了编码器；但 Method 的在线伺服辨识仍把平移后的编码器与未平移的指令配对。真实滞后 17.7 ms，被辨识成 25–34 ms。
- **修复：** 让伺服辨识读平移前的观测，`method3.py` 共加 6 行。
- **效果：**
  - 全部因素同时存在：+.47 → +.24；
  - 偏移 2 ms 精确标定：+.79 → +.45；
  - 有效性运行 RMSE 中位 .25 → .19 N。

**未修、已知的对象近似：惯性项相位滞后。** 对象里探头加速度按一个控制周期取平均，相对理想 m·ẍ 滞后约 41°（开环正弦实测）。真实探头的惯性力与位移同相，质量标定误差只会表现为一个刚度偏差。在对象里，它却带有正交分量，会被 χ 检验拒绝。所以对象高估了 Method 对质量标定误差的敏感度（上表 ±5% 的 +.36/+.46）。这是偏保守的近似，对所有接触模型和宿主的影响相同。

**根因（已定位，独立最小模型复现了同样的数字）。** 不是时间索引或离散实现的错误，问题出在执行器模型：零阶保持加一阶伺服，会让速度在每个 8 ms 指令边界跳变。
- **逐毫秒取加速度：** 跳变产生的 104、146 Hz 加速度镜像按 ω² 放大，经 30 Hz 滤波和 125 Hz 采样后折叠到 20.8 Hz，与真实分量相互抵消，所以幅值只剩约 1/3。
- **按周期取平均：** 幅值对了，却带来半个周期的滞后。

**两种速度连续的执行器都试过，没有采纳（改动保存在临时目录，未入库）：**
- **指令线性插值 + 两极点：** 惯性项正确（幅值比 1.04，相位 −11°），但插值多出半个周期的延迟。Method 内部按零阶保持建模，结果连理想系统都变差：RMSE 中位 .09 → .23 N，324 场景中位 .19 → 3.5 N。
- **保持设定点 + 两极点（快极点 2 ms，假设）：**
  - 理想系统基本不变（.10 N）；
  - 对质量误差的敏感度下降（+.20/+.06）；
  - 对滞后误差的敏感度大幅下降（10% 时 +1.41 → +.08）；
  - 但力时间偏移的对齐变差：偏移 2 ms、无质量时 +.06 → +.53，324 场景中位 .19 → .45 N。原因还没查清。

所以，要正确修好惯性项，需要同时重新核对传感环节的时间对齐，改动面已超出小修。在那之前保留现状：滞后约 41°，偏保守，对所有候选的影响相同。

**这说明：** 惯性补偿和力—位置对时都是真机上必须做的，否则方法失效；做好标定后损失不大。Method 对这些标定的精度要求是一条实际约束。

## 动态响应：由真实数据辨识

**做法。** 不预设机制。各机制族用同一个前向模型 F = S·(w_e u + Σ w_i q_i + 粘性项 + HC 项)，u = d^n。四组协议共享形状参数，每个文件只拟合一个尺度，再用留一协议预测检验（`neumann_dynamics.py`、`neumann_tests.py`）。

**数据。** Zenodo 14536174 的 Fig. 7/8、12、13、14 原始记录：Chiaro 纳米压痕，球半径约 100 µm，1 kHz。原文全文没拿到，只核对了摘要：
- 松弛常数约 1.4 s 和 36–46 s；
- 速率提高两个数量级，模量约翻倍；
- 20→37 °C 模量最多降 30%；
- 五个循环后刚度最多降 20%。

**数据可信度。**
- 接触点按 F^(2/3) 线性重拟合，误差多在 1% 以下。
- 仪器标为 NOK 的文件，只是它自己的 Hertz 拟合失败，按曲线判断都可用。DMA 有一个文件接触点错误，不用于深度分析。
- 相位与幅值斜率满足因果（Bode）关系，偏差在 ±2° 以内。由此推出两通道时间偏差不超过约 .23 ms，在 20.8 Hz 不到 2°。

**模型无关的读数（白质 / 灰质）：**

| 读数 | 结果 | 对机制的含义 |
|---|---|---|
| DMA .5→20 Hz 相位 | 12.0→26.6° / 15.8→29.6°，随频率上升 | 不是常相位的单一幂律，20 Hz 附近斜率变陡 |
| tan φ 随深度的指数（8–40 µm） | −.21 到 −.08 / +.02 到 +.05 | HC 预测 +1，被否定；与线性粘弹接触一致，这一深度范围内未见孔弹性的尺度效应 |
| 刚度随深度的指数 | .62–.67 / .55–.57 | 弹性指数约 1.6；斜坡上的表观指数 1.5 = 1.6 减去记忆斜率，两个协议互相印证 |
| 力随速度（1–150 µm/s） | 斜率 .137 / .154；直线拟合误差 8.9%，幂律 1.5–1.6% | 速率依赖来自对数型记忆，不是线性速率项 |
| 松弛（斜坡结束后 1、10、100 s） | 中位 .85、.71、.60；100 s 时各试样 .43–.69 | 跨三个数量级，100 s 后趋平 |
| 五次循环 | 峰值降到 .92–.95；耗能 41–46%；卸载段 10–13% 的时间无力 | 有滞回、预调节和脱离 |

**留一协议：**
- 2 参数弱幂律对没参与拟合的协议，时域误差 3.4–6.4%，20 Hz 相位误差 −3° 到 −4°。
- 参数多的谱只用时域数据外推 20 Hz，相位误差 20–30°；只用 DMA 外推慢松弛也失败。所以 20 Hz 必须由振荡数据定，慢松弛必须由时域数据定，两者要合在一起用。
- HC、KV、单分支 KB 在所有留出协议上误差 10–17%，DMA 相位误差 17–61°。

**结论：** 这种软组织的记忆是线性、可分离、宽谱的，速率依赖、松弛、滞回和频响由同一个谱解释。它不是 HC 那种随深度和速度线性增长的速率项，也不是单一时间常数。

| 耗能 | 41% / 43% | 40% / 46% |

**对象怎么用（`derive_dynamic_truth.py` → `dynamic_truth.json`，`scenes3._measured_response`）：**
- **形状：** 白质、灰质两种实测谱，加一种粘性型（四分之一相位来自弱的慢记忆，其余来自 1.5 ms 快支），三者均衡抽样。
- **强度：** 用 K(f)^p 把实测形状移到目标相位：形状不变，相位和斜率按 p 缩放。20 Hz 以上没有数据，沿 20 Hz 处的斜率延伸。相位档 8、14、21、28°。
- **慢松弛的量：** 取拟合值的 .4–1.2 倍，对应 Neumann 试样间的差异。拟合谱的 1→10 s 降幅在试样范围的上端，所以中心取低一些。
- **Remus 曲线的位置：** 曲线不改，视为它自己加载速率（约 .3 Hz）下的响应，因此平衡力低于曲线。场景开始时探头已到位 2–60 s：剩余记忆留在状态里，已发生的蠕变体现在压深上。这不是对曲线做动态放大校正，曲线在它自己的速率下不变。代价是压深比按曲线反算的深一些。闭环测试中，去掉慢记忆、取上端、刚到位、已到位 60 s，平均 L 变化在 −.08 到 +.06 之间，影响小。
- **分支网格：** 1.5 ms 到 25 s，每 4 倍一支，与候选的网格不同。

**对象实现核对（`check_dynamics3.py`）：**
- 网格上的表格对四组协议：速率误差 1.8–1.9%、松弛 5.3–6.9%、循环 2.0–4.4%；DMA 相位误差 1.9–2.6°，增益误差 2.6–2.9%。
- 对象代码开环正弦与解析解比，.5–20.8 Hz 相位差不超过 .13°。

**和候选是否同构。** 旧的三种真值正好各对应一个候选：HC 对 H，弱幂律对 W（构造公式相同），KB 对 S。Neumann 数据否定了 HC 和单分支 KB 作为真实形式，所以它们不再作默认，只保留给显式的敏感性运行。

新真值与任何候选都不同构。在探测频率按在线相位对齐后，.3–20 Hz 内的增益偏差：
- W：7–43%。W 的相位在频带内恒定，实测相位随频率上升。
- S：4–41%。
- H：3–65%。

每种形状偏向的候选不同：
- 粘性型：H 最接近（3–12%）。
- 低相位的实测谱：S 最接近（4–8%）。
- 高相位谱：三者偏差都在 20% 以上。

选型时要按形状分开报告，并留出一种形状只用于测试。

**相位和不确定性对闭环的影响**（`check_dynamic_sensitivity.py`，24 个场景，只用 L，平均 L 变化，以白质 14° 为基准）：
- 8–14°：各形状之间 −.05 到 +.03，与旧 HC、power 11° 相当。
- 28°：白质 +1.17，粘性型 +.40。
- 38° 应力档（假设探头尺度辐射再加约 10°，无数据）：白质 +3.17，粘性型 +1.59。

所以真实相位是最重要的未知量，选型结论必须按相位档给出。

## 已知的简化和未解决项

- Remus 曲线视为它自己加载速率（约 .3 Hz）下的响应，记忆从这一点起算。这个对应关系按 Remus 的加载时间（约 1–5 s）设定，未被腹部数据验证。
- Remus 含腹壁和身体的整体响应，再串联身体支撑和局部背衬，可能部分重复计入（支撑刚度远大于接触刚度，静态影响小）。
- 5 mm 下限是正则化假设：多项式在 5 mm 以下斜率不随接触面积归零。约 61% 的工作点落在这一段。
- 未建模：探头重力随姿态变化的残差（缓慢，近似偏置）、机械臂结构共振、关节纹波（粗测影响小）。结构共振要在真机上查。
- 体表起伏改变压入，不改变无跟踪时的局部法向，姿态角只含宏观曲率和误差。
- 平底对齐初触时切线有阶跃，力连续，这是该理想几何的结果。
- 4 mm 覆盖只作端点，回放较慢（约 1.2 s/仿真秒）。
- 半空间闭式力在凸阵加覆盖层时与 ∫k 差约 13%，真值切线取力的实际斜率。

## 接触公式

局部压入：δ(ξ) = d − g(ξ) − ξ tanθ − ξ²/(2R_s)，线阵 g = 0，凸阵 g = ξ²/(2R)。θ > 0 表示表面前方下降：压力后移，摩擦使轴向力增大。

参考力：局部支撑 p = qδ/(1−δ/h)，覆盖层硬化到局部刚度达到肋骨和胸廓上限后线性延伸；半空间 k = 1.1E\*√A，F 为闭式。空间场只含相对变化，均值为 1。参考力经单调映射（PCHIP，切线严格一致）变成该受试者曲线给出的力。`q_scale` 作用在映射之后，是真正的整体倍乘。

动态：F = f_e + Σq_i，q_i' = α_i ḟ_e − q_i/τ_i，八个分支（1.5 ms–25 s），因果更新；f_e = 平衡份额 × 曲线映射力。场景开始时 q_i 按到位后剩余的记忆设定。(1 + λḋ) 只保留给旧形式的敏感性运行，默认 λ = 0。

观测：策略默认只拿到测量通道，真值只在 `episode(..., diagnostic=True)` 时提供，只用于诊断。Method 控制轴向力；评价分别报告轴向和法向。
