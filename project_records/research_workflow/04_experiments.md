# 四、实验验证（顶刊水平的仿真与真机）

**何时读：** 设计正式实验、选择对比方法、整理实验结论时。

**2026-11-03 用户修正优先：** 顶刊实验的深度来自明确科学问题、排除替代解释和完整证据链。取消统一重复次数及每族 50＋剂量扫描的采纳门槛；不默认全面参数扫描、分布外验证或全组合矩阵。规模由主张和尚存不确定性决定，科研迭代记录不等于论文章节。工作 solid 与问题—贡献—证据的包装同时重视。

例子只用于说明，不是必须照做的规定；合适就用，不合适就回到判断标准。例子出处见[逆向分析](../../research/independent_reverse_analysis_of_top_journal_methods.md)：R 编号见 §2–3，Buchli、Kang、Xue、Dyck、Jin、Fu 和 R22 见 §7。本项目的具体失败经过见[失败复盘](../research_failures_and_corrections.md)。

**核心目的。** 为最终主张提供与之相称的任务证据，查清方法解决了什么问题、有哪些收益与代价、在哪些条件下有效。主张优于已有方法时，选择最相关且适合对比的强方法进行公平比较。主张收益来自特定机制时，设计能区分关键替代解释的对照。

**判断标准：**
- 每项主张都有对应证据。按需要排除会影响归因的替代解释，如调参、信息不对等或场景偏向。
- 对比公平。
- 结论的强度与证据一致。
- 实验配置达到目标期刊同类论文的水平。

**怎么做：**
1. **从主张出发设计实验。** 每项主张的能力都有对应实验。不要先选基线或照搬某篇论文的任务，再让方法去迎合。
2. **仿真平台保留任务的真实结构。** 关键的动力学、噪声、延迟和执行限制都要有，参数有依据。不靠堆复杂度或人为制造条件让方法赢。
3. **少量有科学目的的场景。** 既有 2–4 个作组织参考，不作数量配额。每个回答一个明确问题，按“目的—设置—比较排除什么解释—结果—结论与边界”组织；已有数据足够就不新增任务或重跑。
4. **对比方法以最接近的强方法为主。**
   - 忠实复现或合理适配：核对原文方程，保留原方法本有的自由度。
   - 在相同的可用信息、调参预算和场景下比较。
   - 需要判断相对其他技术路线的优势与代价时，补充少量有代表性的对照。
   - 固定参数的方法按领域惯例取上下界两端，不拿调到最优的版本当主基线。
   - 没有合适的对象，就不强行设置。
5. **必要的因果比较。** 围绕核心机制设置有辨别力的消融/替代机制对照，排除调参、信息不对等或特定场景等关键解释；不默认遍历所有模块组合。
6. **指标用任务的物理指标。** 例如误差、峰值、接触丢失、成功率。按主张和实际变异选择必要重复、离散程度与统计分析，不统一设样本数，也不默认所有比较必须显著性检验或全面最坏条件扫描。不用方法自身优化代价当任务成绩；少量成功不能证明尾部安全。
7. **报告计算时间，** 并说明计时包含哪些环节。
8. **按证据报告结论。** 说明各项主张获得了哪些支持，以及相应的代价和适用范围。
9. **后续做真机实验，** 证明方法在真实的噪声、延迟和执行条件下仍然有效。

**可借鉴的做法：**
- **两难问题：** 主要对比站在另一边的方法，并同时测两边。R12 就同时测了误差和人的施力。
- **正面对比最像自己的方法，讲清机理区别：** Kang 专门用一节讲与 DOB 的区别，Xue 给出与 EMA 的理论对比。
- **按机制拆开设计条件，让每个机制单独起作用：**
  - R11 用三种扰动，分别检验前馈、K、D；
  - R01 设“只变运动、只变刚度、两者都变”三种条件；
  - R19 设对齐和失配两种条件。
- **一次观察到的配置档次（只是观察，不是规定）：**
  - 普通顶刊（TMECH、RA-L、TIM）常见做法：经典或固定参数对照 + 真机或模体 + 清楚的能力提升；
  - 高引论文和 T-RO、IJRR 论文：还会逐一对比直接竞争的方法族，加上理论、敏感性分析和消融，仿真和真机都有。
- **真机样本量可以不大：** 例如 6 名受试者，或 7 次、20 次试验。

**AI 犯过的错：**
- **实验目标失真：** 给方法理想的刚度标签，用信息代理指标代替任务收益，甚至考虑不断加难度让算法赢。
- **把控制器自身的偏好代价当成物理成绩。**
- **无意中削弱对照：** 例如给 Jin 方法的两个轴强加同一个正则值，NNBO 适配的值域写错，消融替换错了参数。
- **主比较对象选错：** 把调到最优的固定阻抗放在主比较位置。
- **调参信息不对等：** 例如我方用过 T2 开发数据，对照方法却沿用旧配置。
- **数值结果说过头：** 把局部数值解说成近最优，把软件计时当成实时认证。
