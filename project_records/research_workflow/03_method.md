# 三、方法设计（含快速验证与迭代）

**何时读：** 问题选定后设计或改造方法时，或者快速验证结果不理想、需要判断下一步时。

例子只用于说明，不是必须照做的规定；合适就用，不合适就回到判断标准。例子出处见[逆向分析](../../research/independent_reverse_analysis_of_top_journal_methods.md)：R 编号见 §2–3，Buchli、Kang、Xue、Dyck、Jin、Fu 和 R22 见 §7。本项目的具体失败经过见[失败复盘](../research_failures_and_corrections.md)。

**核心目的：** 设计或改造出一套方法，要做到三点：
- 准确解决选定的问题；
- 在关键指标上胜过最强 baseline（如果有的话）；
- 达到顶刊的专业完整度。

贡献检查和初步验证都在这一步内进行。

**判断标准：**
- **改动对准瓶颈：** 每处改动都对应一个已定位的瓶颈，并能说清它为什么能消除这个瓶颈。
- **准确解决问题：** 每项主张的能力都有对应的机制和证据。
- **增量清楚：** 相对最接近的工作，讲得清继承了什么、改了什么、新增了什么能力。改动小也可以。
- **胜过最强 baseline：** 在关键指标上胜过它，并有消融。
- **专业完整：** 模型、假设、执行接口齐全；问题最看重的性质有推导、定理或机理分析支撑。

**怎么做：**
1. **写清目标能力和成功判据。** 方法要估计什么、决策什么、受哪些约束；在哪些指标上要胜过最强 baseline。
2. **定位最强已有方法的瓶颈。** 看它卡在哪个环节：表示、模型、可用信息、优化/训练，还是执行。
   - 改一个还是几个环节，按实际情况分析。
   - 没有问题的部分尽量继承。
3. **把瓶颈表述为数学问题，再找机制。** 先用简化模型、极限或反例弄清障碍来自哪一条关系。能改变表示时，检查新表示是否保留原任务的关键约束并显露可利用的结构。
   - 本领域若已有同任务、同条件的成熟解法，核对它实际覆盖的能力，再追问还有哪个重要差距值得解决。
   - 按共同的数学结构找外域机制。说清原问题与本任务的变量、观测和约束如何对应，哪些假设要替换，改造后重新推导关键性质，并检查在线可用性。贡献由适配后取得的新能力及证据决定。
   - 需要自行构造时，从要满足的性质倒推需要哪条关系或哪类信息，结合任务中成立的结构，推导新的表示、约束或更新机制。需要组合时，明确各机制的分工与接口。
4. **先用推导或机理说明改动为什么有效，** 再投入大规模实验，避免靠调参碰运气。
5. **组合成完整方案。** 写清输入输出、模型和假设、求解或训练方式、执行接口，每部分对应第 1 步中的一项能力。不能用模块清单代替设计。
6. **主动提出并检验候选。** 用最接近的已有工作、反例、边界情形或独立推导检验决定成败的假设。某个论证有误时，判断其中的结构能否保留。关键障碍持续出现或确有取舍时，比较在表示、信息来源或作用机制上实质不同的路线。
7. **快速验证，与最强 baseline 公平对比，然后迭代。**
   - 用保留任务关键困难的最小可信实验。
   - 调优过的简单方法用于诊断，不作为主基线。
   - 不如 baseline 时，查是哪一环没起作用（估计、决策还是执行），就改那一环。
   - baseline 本身已经足够好时，回到第二部分重新审视问题。

**可借鉴的做法：**
- **改动位置因问题而异：**
  - R13 重新设计能量函数的表示；
  - R01 让刚度和运动共享相位；
  - R03 用滤波历史构造含误差信息的残差；
  - Jin 同时改了模型表述、约束、求解和执行。
- **外域来源可以很远：**
  - 化工过程控制（Kang 的 IMC）；
  - 计算机图形学（Dyck 的离散微分几何）；
  - 数值数学（Xue 的张量列）；
  - 随机最优控制（Buchli 的 PI2）。
- **迁移时做一次重新表述，** 把本领域的问题改写成成熟工具能直接处理的形式：
  - Jin 把变阻抗律设计转成控制律设计，MPC/QP 才能用；
  - Buchli 把增益调度放进 DMP 参数，PI2 才能同时优化轨迹和增益；
  - Dyck 定义了曲面任务坐标，经典阻抗控制才能用于任意曲面。
- **迁移原理后，在本领域重新推导并给出保证：** R11 从代价函数出发，用 Lyapunov 方法推出更新律。
- **组合时先找出会冲突的地方，再设计分工去化解。** 这是组合方法和简单拼接的区别，可以对比 R12 和 R22。
- **理论集中保证问题最看重的性质：** 交互类论文常是稳定性或无源性；R19 没有理论，靠明确的物理成功率支撑。

## 从 AI 数学研究借鉴的思考方式

- OpenAI 研究者 Ven Chandrasekaran 先让模型寻找物理机制，用尺度、量纲和简化极限形成预期，再补齐计算。Ernest Ryu 从 GPT-5 提出的有误推导中识别出有价值的方程结构，并发展成证明。这两例分别说明怎样找到切入点和怎样保留经得起检验的局部洞见。[物理研究访谈](https://forum.openai.com/public/videos/event-reeplay-using-ai-at-scale-to-solve-math-and-science-challenges-discussion-with-an-openai-researcher-2026-10-14) · [Ryu 案例](https://openai.com/index/gpt-5-mathematical-discovery/)
- OpenAI 的单位距离反例从经典格点构造出发，把产生大量单位距离的要求转成寻找许多模长为 1 的差向量。代数数论提供了构造这些向量的机制，再经嵌入得到满足原题约束的平面点集。[论文](https://cdn.openai.com/pdf/74c24085-19b0-4534-9c90-465b8e29ad73/unit-distance-proof.pdf)
- Anthropic 的可逆量子电路案例中，Claude 发现迭代后的数对可能包含恢复分支的信息。试探规则在全尺寸输入上失败后，它从迭代关系推导代数恒等式，得到可验证的解码规则。遇到这种障碍，可以回到生成观测的关系，检查所需信息是否已经由现有量隐式携带。[量子电路案例](https://www.anthropic.com/research/designing-efficient-quantum-circuits)

**本项目的例子。** 构造两条物理允许的刚度与扰动轨迹，使它们在现有激励下产生相同观测，或使其预测差异可被有依据的噪声范围掩盖。两种解释的目标刚度之差给出当前观测下的误差下界。将该下界与控制所需精度对照，判断是否应利用更多可信的物理结构、改变激励或观测，或改估更直接服务于控制的量。[刚度分离的两点界](../../research/stiffness_separation_20261107.md)

**AI 犯过的错：**
- **用简单拼接代替设计：** 堆上策略库、后验规划等模块，却说不清它们怎样共同解决问题。
- **要求部件独有、全新：** 例如坚持 NEOC 必须独有。
- **实际实现与方案名称不符：** 例如把候选 2 实现成短历史直接 PPO，却仍按“候选 2”下结论。
- **结论超出证据，或者反过来无限保护 idea。**
- **把更准的估计当成贡献：** 从信息到动作再到性能，这条链没有验证。
- **混淆理论对象和数值对象：** 把节点根当成优质策略，把条件性的界当成实际保证。
