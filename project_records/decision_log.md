**2026-11-06 · 估计主线：评估时变刚度鲁棒 MHE（TVK）后保留 Huber-D⁴，主要空间转向控制如何使用信息**
- 触发：用户提出，从物理问题出发重新选择估计主线，候选为时变刚度的鲁棒 MHE（k 用一阶差分 Huber/TV，d 用鲁棒 Dᵖ），要求独立评估，并与 Kalman、MHE、Huber-D⁴ 比较。
- 决定：
  - 实现 TVK，k 的先验 q = 2 和 q = 1 都测；
  - 结果是 q = 2 闭环明显退化，q = 1 被开发集推回常数极限，与 Huber-D⁴ 持平；
  - 不采纳 TVK，保留 Huber-D⁴。
- 依据：
  - 日志显示跨肋骨时 k 是斜坡，窗口内变化 ≤ 0.21，所以理论上偏向 q = 2。但窗口内 4 个探测周期的信息只够可靠估计一个 k：多估斜率使端点方差约增 7 倍，换来的滞后偏差减少 ≤ 0.1。
  - 完美估计器上限总体只有 +0.03，估计器的闭环空间本来就小。
  - 我原先"q = 2 更符合物理"的预测，在无噪声时成立，在有噪声的闭环中不成立。
- 被否：
  - q = 2 加斜率收缩：极限仍是常数 k；
  - 继续扩 λ_k：已在常数侧边界。
  - 唯一未测的原则性变体是 q = 2 加 48 拍长窗口，预期收益很小，未做。
- 推翻条件：提高激励信息量（幅值、频率、多频）后，窗口内能可靠估计斜率；或控制改为能利用 σ、对低估容错后，TVK 的模块优势能转化成闭环收益。
- 链接：[disturbance_model.md TVK 条](../research/disturbance_model.md)、[运行记录](agent_runs/2026-11-06_codex_tvk_mhe/)。
