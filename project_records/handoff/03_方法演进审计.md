**阅读提示：**

- **闭环结果**是中位/均值力 RMSE（N），r=失控，L=长失联。

**对量测增益融合的审查（2026-11-02）：**

1. **与历史的关系：** §16 已否定“量测增益 Kalman 平滑”和“不一致窗口上调”，这里实际是带软权重的同类做法，新增部分只有力矩门控。当时未对照历史，属于重复踩坑后才加门控。
2. **名称与实现不符：** 这不是接触模型升级（量测模型仍是 \(f=k(y-s)\)，只多一个力矩阈值），也不是 E2（E2 是窗口内联合 Schur 消元与漂移连续性，这里是对窗口结果后验融合）。
3. **可能只在仿真成立：** 阈值约 1.7×10⁻⁴ N·m（RM65 级噪声下约 7×10⁻⁴），只按随机噪声设定；RM65-6F 精度 ±0.035 N·m，约大 50 倍。对象的 \(M_y\) 不含摩擦力臂，而 B0 明确写了切向力力臂。偏置足够大时门控恒为真，等于无门控上调。
4. **IMM 没有在切换：** 模式概率恒约 0.49（[输出](../../experiments/contact_model/results/p3_evidence_checks.txt)），实际是两个滤波器的固定混合。
5. **报告口径须修正：** “快速推拉失控 3→0”只对 \(a_f=0.10\) 的对照成立；相对 \(a_f=0.17\)，失控都是 0，快速推拉中位和均值更差。硬推拉失控 r2→0 不能归因于融合（见上）。“恢复 78%”混用了不同样本和激励幅值，撤回。
6. **诊断集已被用于调试和再确认**（软组织尾部的启动缺陷就是在这个集上发现并修的），不是独立证据。

## 5. 反复出现的偏差模式

| 模式 | 例子 | 对新工作的要求 |
|---|---|---|
| 诊断出原因后不修原候选，转向下一模块 | E3、E2-A、E4-A、模量图 | 先按诊断结果修这一环，再判断路线 |
| 把原型结论扩大到路线 | “接触模型收益上限小”“C1 导纳不相容”“GLS 不采纳” | 结论写明对象是哪个实现 |
| 用错误的上限 | 用 Wij 代理代替本方法结构下的真值替换 | 上限用同结构真值替换 |
| 先做试验、后贴机制名 | 监督切换、语音增强、E2 递推 | 实验前写出：升级哪个模块、需要什么条件、为什么这个机制满足 |
| 为省事改掉已批准的方案 | §21.5 → 阈值 + 融合 | 偏离方案先说明依据，等用户确认 |
| 不查历史，重复已否定做法 | Kalman 平滑、上调规则 | 动手前查本文件第 0 节和 §19.3 |
| 只测随机噪声就声称传感器稳健 | RM65“结论不变” | 偏置、标定误差、未建模耦合都要进测试 |
| 报告挑统计量或对照 | 中位数对 p90、\(a_f\) 对照选择 | 同时报告中位、均值、失控、长失联和全部对照 |
