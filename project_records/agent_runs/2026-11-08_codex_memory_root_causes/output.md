**单位修正与延迟：**q 是每秒强度，须加 \(Q=q\Delta t\)；距离系数应为 \(q_s=Q/(\Delta t v_{\rm ref})=q/v_{\rm ref}=9.6\times10^{-5}/\mathrm{mm}\)。题给式仅在分子代表 Q 时成立。hop24 本身增加至多约 **.192 s** 延迟；四窗分块更新周期为 **.768 s**。缺窗导致的实际更新间隔另计，实测最大8.096 s。

- **固定 Kalman〔理论〕：**长/短记忆的噪声—滞后折中复现；单个固定q无法同时兑现两种记忆要求。这一固定形式受限，不能据此排除 Kalman 族。
- **IMM〔固定参数限制的修正〕：**高q权重从平稳约11%升至两种斜坡的80%/94%，切换有效；平稳sd仍高于.045，闭环尾峰仍在，不支持排除。
- **Lepski〔实现/协方差〕：**差分方差实测/理论比 .996–1.000；修正成立，但新检验更严格，且仍硬切换，未解决闭环尾峰；不支持排除。
- **EWA〔硬切换的修正〕：**短τ权重从平稳2%升至斜坡90%/99.7%，软适应有效；闭环收益未随合成降噪兑现，不支持排除。
- **创新遗忘〔假设/实现〕：**底限有效；同采样消融的阶跃延迟从2.688/1.728 s降至.960/.768 s。仍有斜坡滞后；同一qs跨速度测试未显示一致控制收益，不支持排除。
- **Huang ARD〔实现/参数〕：**a的联合公式残差〈\(8\times10^{-16}\)，但 \(a_0=1,b_0=10^{-10}\) 时精度仍约\(10^{10}\)，近单窗结论未改变；b使等效平稳记忆增至 **3.97倍**，改变“记忆不能增长”的结论，却增加滞后且三场景L均升高；不支持排除ARD整类。
