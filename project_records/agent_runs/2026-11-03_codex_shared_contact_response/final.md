这轮实际改了**干扰分离与接触响应估计**，正弦激励先保留。

具体候选是：让同一条组织运动轨迹同时作用于弹性和接触记忆，估计“力误差随时间对应多少位移”，再用于补偿，避免把动态响应压成一个刚度数值。

实现后，继续修正了历史状态初始化和换算不确定性的传递。最终力控制RMSE如下，越低越好：

| 场景 | 已有有效候选 | 本轮最后一版 |
|---|---:|---:|
| 运动、软硬不均 | 0.1148 N | 0.1161 N |
| 硬组织推拉 | 0.2668 N | 0.2864 N |

**目前不采纳。** 历史初始化版曾明显退化，纳入换算不确定性后得到缓解，但仍未超过原方案。预测虽然改善，同复杂度简单对照也能达到类似甚至更好的结果，因此创新增量也尚未成立。
