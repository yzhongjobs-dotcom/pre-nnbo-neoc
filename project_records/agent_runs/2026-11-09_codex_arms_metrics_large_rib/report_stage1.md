# 三臂、变化跟踪与 A_large 结果

**结论：** A_large 确实增大了日志中的跨肋骨对比，纯无门控臂在该组的闭环均值更好，但收益不统一：Huber 无门控臂在全部 42 例的平均 L 更高，Huber＋IMM 在 A_large 案例 36 超过 36.5 N。D4 无门控臂总体平均 L 降低，却仍出现 216.2 N 的最坏峰值。不能据均值宣称统一优势或解决了尾部失败。

**改动文件：** 修改 `identification_completion.py`、`corrected_comparison.py`、`memory_closed_loop.py`、`rib_transition_eval.py`；新增 `rib_contrast_evidence.py`、`arms_reproduction_check.py`。更新闭环、回放、历史行注记及 84 份逐拍文件；新增两份证据/复现 JSON，重生成 [comparison_tables.md](comparison_tables.md)。参数未重调，研究文档、项目记录和冻结快照未改；未提交、未推送。

**复现：** 旧 36 例全部场景 SHA-256 一致，每组代表哈希见 [复现记录](results/arms_reproduction_checks.json)；A_large 与 A 的场、运动、肋骨中心/宽度及 k_rib 一致。O.chosen() 哈希不变。16 种既有方法各复现一行，L、RMSE、峰值、失联时间差均为 0；576 行旧闭环结果和 612 行历史比较结果均保留。双源各 42 例，来源轨迹指标差和命令回放误差均为 0（原上界 <1e-10）。独立重算 3,821 个变化段误差及 3,822 个最大低估值，差均为 0，恢复计数分区通过。
