# Raw task prompt

**任务：在修复 H 后的现有多方法对比中，增加两个简单刚度辨识基线，进行最小规模验证。**

仓库：`yzhongjobs-dotcom/pre-nnbo-neoc`

先阅读 `experiments/rossi_failure_study/corrected_comparison.py`、`d_robust.py`、`contact_candidates.py` 和 `common._build()`，理解现有辨识接口和实验结果结构，然后直接复用，不要重新搭建实验。

## 一、目的

验证简单的 (F=ky) 或 (F=ky+b) 辨识是否可能优于当前 Huber-D⁴，以及已有的 Rossi-ID、Kalman、MHE 等方法。不预设结论。

## 二、新增两个辨识器

- Simple-1：(z=kY)，普通最小二乘。
- Simple-2：(z=kY+b)，普通最小二乘。

这里的 ((Y,z)) 必须是现有 Method 使用的、经过相同传感补偿及 H 接触预处理后的回归量。常数偏置应按 `common._build()` 的测量域构造，不能直接混用原始力和编码器位置。

只替换刚度估计计算，保持当前修正后的 H 预处理、24 拍窗口、相位估计、门控规则、控制器和其他参数不变。正确返回现有接口需要的 ((k,\sigma,\chi))，不要为了让简单方法通过门控而人为修改统计量或阈值。

## 三、实验规模：只新增 6 次仿真

直接复用 `corrected_comparison.py` 中已有的 `cases()`、场景生成、随机种子及评价函数。

固定选三个已有案例：A（呼吸＋跨肋骨）、B（呼吸＋推拉）、combo（综合）。每类选一个相同设置的案例，例如 `neural_white`、28°、`i=0`，选择在查看比较结果之前固定。

- 原有 17 种方法：直接读取 `results/corrected_comparison.json` 中这三个案例的结果，不重新运行。
- 新增两种方法：各运行这三个案例，共 **2×3=6 次**。

不要运行完整的 612 次比较，不增加种子、不调参、不扩展场景。

## 四、结果

将原有方法和新增方法放在**同一张三场景对比表**中，沿用原实验的闭环综合指标 (L)，并报告力 RMSE、峰值力。对新增方法顺便核查刚度估计误差和低估情况，辨识真值使用当前 (k_{\mathrm{eff}})。

注意：这是三个固定案例的小规模配对验证，不能把单案例结果直接追加到原表每场景六案例的均值／中位数中。

## 五、完成标准

新增一个简短实验脚本及结果文件，不覆盖原有结果。验证两个简单求解器实现正确，且三者的预处理和控制设置一致。最后给出统一结果表，并用几句话说明简单方法在哪些案例更好或更差，以及差异的可能原因。

本轮只做验证，不研究新算法、不重构框架、不扩大实验。以科研质量为优先，充分复用现有代码，尽量减少运行和额度开销。
