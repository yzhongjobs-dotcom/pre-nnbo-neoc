# 最终输出

本轮完成原物理轨迹上的辨识回放与理论推进。6类×3条原 Huber-current 轨迹上，独立窗口求解复现基线最大相对误差2.21e-10；三个场景的记录器与未加记录器的物理轨迹逐元素相同。自由斜率、直接 TV-gain 和两极点测量对照均未满足统一验收，默认方法不变。

直接 TV 的探索性回放中，咳嗽相对 RMSE 均值18.46%→17.48%，综合35.74%→36.29%，不采纳。独立锥规划与高精度ADMM核对排除了迭代上限导致的主要错误。另有同预测、端点相差20%的分解反例，说明一般变化约束加原扰动代价尚不足。

理论已改为针对当前 k 的功能量分离界，并从身体动力学算出冻结局部模型下的同频被动响应约束。在当前仿真假设下，支撑阻抗模下界206384.6 N/m，实际增益分布对应的被动增益偏差界p90/p99约1.66%/2.03%。这只限制被动支撑，不限制全部外生运动，也不是人体实测界。

下一候选的具体设计对象是接触响应、身体支撑状态、外生组织运动和有界标定误差的联合物理关系。尚未实现为通过验收的完整在线方法，也没有新候选闭环或人体证据。详见 `research/stiffness_separation_20261107.md` 与其中的源码、参数及原始回放数据。
