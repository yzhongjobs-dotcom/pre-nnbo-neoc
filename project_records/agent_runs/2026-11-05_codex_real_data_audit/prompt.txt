## 纪律（最重要）

- 不要把其他组织的参数当成人体腹部参数。脑、脊髓、胰腺、明胶、仿体的数值不能直接进仿真；它们只能说明机制的形式（例如松弛是单时间常数还是跨数量级、滞回是否存在、速率依赖强弱、是否有预调节效应），并且要写明适用边界。
- 没有直接实测的量，用物理推导或合理假设处理，并明确标为假设。不要强求。
- 不要为了复杂而加模型或场景。不要为了某个候选方法的表现提建议，不要参考任何方法的比较结果。
- 原始数字和推断分开写。每个结论写明数据来源和计算方法。查不清单位或含义就写查不清，不要猜。

## 要回答的问题

### 静态
1. 用 Remus S1 的逐人逐部位拟合：
   - 人与人、部位之间的离散程度（在 4、8、12 N 或相应压深下的切线刚度和力—深度指数）。
   - scenes3.py 现在用的是均值曲线（R1–R5，A1–A5），按分位数选区。这低估了多少个体差异？应如何抽样？

   - 哪些部位与超声扫描相关，R6（后侧）是否应作为单独情况。
2. Dahmani：
   - 解释 0 mm 处约 6 N 的偏置（预载？接触零点？传感器零漂？）。去掉偏置后，力—压入曲线的形状、指数、切线、6 次采集的离散和噪声是多少。
   - 这是真实探头几何上唯一的力—压入数据。没有明胶模量和探头规格时，它能检验 probe_curve 的哪些假设（曲线形状？），不能检验哪些（绝对刚度）？如实写。
3. 综合判断：现在用 γ = .5 到 1 表示几何迁移，这个范围与现有证据是否相符，是否有依据收窄。

### 动态
4. 对每个动态数据集，先搞清组织、加载方式、时间基、应变幅值、单位。然后提取能说明机制形式的量：
   - 松弛：归一化松弛曲线的形状，是单指数还是跨多个时间量级（在对数时间上的斜率），松弛比。
   - 循环：滞回能量比随幅值和速率的变化，预调节（前几圈是否变化）。
   - 速率依赖：如果有多速率数据，力或模量随速率的斜率（幂律指数）。
   - 能否由松弛曲线估计 1–20 Hz 的相位？数据带宽够不够？不够就写不够。
5. 用同一协议跑当前仿真的三种动态机制（hc、power、kb，见 scenes3._dynamic_response，可直接调用 physics_plant3 的 replay，或者写解析计算），比较无量纲形状（归一化松弛、回线能量比、相位随频率的趋势），不比绝对值。判断：
   - 当前三种机制的形状范围是否覆盖实测的形状。
   - 有没有明显不符的（例如真实组织松弛跨数量级，而某机制只有单一时间常数；或相位随频率的趋势不符）。
   - 总相位 7–23° 的范围是否与证据相符。Boyer 只有摘要，只能作边界。
6. 判断 HC 速率项 F = (fe + Σq)(1 + λḋ) 在这些数据里有没有依据，还是形式上可有可无。不要预设答案。
