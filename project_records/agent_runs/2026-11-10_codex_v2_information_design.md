# V2斜率信息与同力预算激励

## 用户原始任务

目前 V2 的理论优势已得到无噪声实验支持，但实际实验中存在两个限制：

1. **噪声放大：** 新增刚度变化率 (v) 需要更多信息，当前24拍窗口内的斜率信号弱于噪声，导致理论收益被抵消。
2. **干扰与模型失配：** 人体运动、机器人振荡等非刚度成分也会影响估计。已有频率分离方法虽然改善了原 Huber-D⁴ 的持续低估问题，但仍未提高 V2 的斜率辨识能力。

机器人闭环振荡的控制问题暂不展开。针对 V2，我认为有三个可能的改进方向：

1. **优化主动激励：** 现有激励主要用于辨识刚度 (k)，未必适合同时辨识变化率 (v)。能否在不明显增加接触力波动的前提下，设计更有信息量的激励？
2. **改进信息分离：** 利用已知激励的频率和时间结构，更有效地分离刚度信息与噪声、人体运动等干扰，同时保留斜率信息。
3. **利用历史信息：** 如果单个24拍窗口的信息不足，能否通过跨窗口积累信息降低噪声，同时避免刚度变化时产生明显滞后？

**请先从数学上分析：V2 的斜率估计究竟缺少多少信息，噪声为什么被放大，以及优化主动激励能否补足这些信息。**

如果理论上可行，再进一步设计合理的激励和估计方法，并给出能够通过实验检验的理论预期；如果仍然信息不足，再研究利用历史信息或其他方案。

整个研究不预设必须保留 V2，以理论分析和实验依据决定最终方法。

## 最终输出

结论：斜率并非在所有阶段都不可辨，但同力预算的小幅激励优化不足以普遍补齐缺口。

水平与斜率主要来自同一载波，去掉水平和干扰后才剩下有效斜率信息。趋势校正的有效时间杠杆约0.095 s；相对斜率噪声3/s，会给当前增益带来约29%的额外噪声。

36号大变化跨肋实例中，上升/下降/反转的同窗SNR中位分别为1.53/.34/.60；达到SNR=1所需信息倍数为.43/8.53/2.76。这是噪声层面的低门槛，不代表已排除模型偏差。

固定20.8 Hz、192 ms、同力RMS的共享H名义包络优化，在峰值最多增加25%并限制频带外能量时，信息增加约14%–16%，斜率噪声仅下降6%–7%；不能补下降段8.5倍缺口。波形结果为名义矩阵设计，尚非实际机器人闭环效果。

信息分离要保留水平和时间调制模板；只保留载频sin/cos会损失斜率信息。下一候选应研究保留时间模板的端点估计与自适应有效历史，避免重复计算重叠观测。近线性条件下，历史加倍使斜率噪声约除以2.83；反转处必须考虑曲率偏差。
