偏离及实现约定：

- 严格平底、平面和指定线性接触律在首次整面接触时必有切线跃变；未擅自添加平滑接触层以制造通过结果。
- 肋边缘采用余弦窗平滑逆覆盖深度；halfspace的压力分布由局部增量载荷积分定义。两者均是明确的迁移假设，非实测压力分布。
- AuSoScan压力不对称保留为默认开启的有界权重重分配，接触域仍由统一δ方程限定；不是截断后仍照搬论文扩展足迹原式。需要实验标定其幅值。
- 开环指令仍为8 ms阶梯位置；额外以0.5 ms记录并分离阶梯频谱镜像，否则125 Hz日志会混叠，无法与连续20.8 Hz解析值公平比较。默认回放/episode日志周期不变。
- 半球halfspace使用有限半球圆形接触刚度2E*a及满半球后的线性延伸；另记录Hertz外推数值，不将d≥r的Hertz外推当精确几何。

需要用户判断：是否允许理想平底初触的切线例外，或另设有物理厚度的接触过渡；是否接受目前两个跨肋工况的耗时，或继续做保持精度的加速。压力重分配及肋边缘深度约定、Remus迁移误差也需要后续实物依据；本轮不据此选择接触模型。
