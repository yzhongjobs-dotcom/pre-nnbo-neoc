本轮从原激励的实际任务作用入手，完成了信息审计、两项幅值干预和已有自适应机制的针对性修正。**保留原有效候选，尚未采纳新的通用策略。**

在同一估计器、控制器和仿真对象下，结果为真实力 RMSE（N）：

| 激励方式 | 静止非均匀 S2 | 运动且非均匀 T3m |
|---|---:|---:|
| 原持续激励 | 0.11498 | 0.11483 |
| 启动后减半 | **0.09924** | 0.11527 |
| 启动后关闭 | 0.10493 | **0.11023** |

这说明持续探测的代价值得优化，但不能直接选择半幅或关闭：效果随条件变化，且关闭激励仍保留了启动辨识；S2关闭后的峰值还从4.52升到4.69 N。

随后检验了原代码已有的自适应幅值机制，并分别修正精度来源、同时考虑反馈与运动补偿需求。三版都在S2改善、在T3m退化，因此暂不采用。**仅凭估计精度评分调节激励，还不能保证闭环更好。**

下一步继续查清激励变化如何影响增益接受／回退和运动观测，再决定改激励还是联合改进分离、估计环节。这处耦合已有实验依据，具体退化原因仍需验证。
