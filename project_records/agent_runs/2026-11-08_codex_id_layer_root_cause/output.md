逐方法的证据解释如下：

- **raw**：稳定段散布和过渡低尾均明显；最深低估窗口同时包含噪声与窗口内变化贡献。
- **gated**：稳定段散布下降、极端低尾缩小，但保留正偏差；门控选择和中心修正均有贡献。
- **Kalman τ=2**：稳定段散布降低，变化段出现较长滞后和负误差；较长历史保留了旧估计。
- **Kalman τ=.2**：散布下降而正偏差保留；较快更新仍不能消除小过渡中的滞后。
- **IMM**：散布降低，下降过渡仍滞后；模式混合未消除共同系统项。
- **Lepski**：稳定段散布较小，小上升滞后增加；精度加权的历史聚合改变了跟踪。
- **EWA**：稳定段散布降低，小过渡滞后仍明显；多时间尺度聚合保留系统偏差。
- **遗忘＋下限**：稳定段偏差较小，但上升时出现负误差；低过程噪声下的历史保留参与了偏差抵消。
- **ARD 固定精度**：稳定段散布降低，下降滞后仍明显；创新驱动更新没有消除共同剩余误差。

采样增益通过原命令附近的 ±1 μm、20.8 Hz 正弦无噪声中心差分测量。上表差距属于**目标定义／采样系统项，不算估计器误差**；结果同时保存了相对该增益的误差。它测的是采样真轴向力／编码器增益，不等同于经过 sensing、H 后的目标，也不能代表宽频控制增益。gated 的实际中心因子为 **1.05409**，单独增加 **.05268** 对数偏移；其绝对贡献占比约为稳定段 **12.5%**、变化段 **11.9%**。

冻结后的 \(|K|\) 与目标值最大对数差小于 \(2.6\times10^{-12}\)。但该干预冻结了末端局部本构和几何，“冻结差”包含线性化及交互，不能视为纯标量刚度变化的独立贡献。交换去噪与运动移除的顺序后，同一变化段子样本的噪声／运动占比由 **27.32%／6.40%** 变为 **27.30%／6.45%**；稳定段子样本由 **30.53%／8.80%** 变为 **30.84%／9.45%**，分解确实依赖顺序。

变化段绝对误差与探测幅值的 Spearman 相关为 **−.24 至 −.92**，与相对 sigma 为 **−.34 至 .04**：前者有关联，后者没有统一的正向关系；这些相关不能证明激励不足的独立因果效应。本批数据能确认散布缩小、历史滞后和去噪后残差并存，不能确定长期平均极限、呼吸锁定偏差、闭环收益或真实机器人上的系统差距。
