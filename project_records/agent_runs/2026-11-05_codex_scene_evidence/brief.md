# 场景证据调研：共同要求

背景：机器人超声恒力扫描（位置接口协作臂，探头以 20.8 Hz 小幅探测在线估计接触刚度）的接触模型选型。候选含线性、弱幂律、Kelvin-Boltzmann、Hunt-Crossley（HC）、AuSoScan、T-RO 2023。上一轮仿真部分参数缺少依据，要重建工况。

目的：建立可信的场景与物理依据，不是给每个仿真参数找一篇论文。查不到的量之后会用物理推算加敏感性分析处理，所以查不到是正常结果，直接写“未查到”。

## 要核实的问题

| 编号 | 问题 | 影响的决定 |
|---|---|---|
| A1 | 软组织在约 1–50 Hz 的接触动态响应：相位、增益随频率的形状（相位近似恒定，还是随频率增大）；人体腹部在体 HC 参数 | 速率与记忆工况的强度和形式 |
| A2 | 真实探头压在人体上的力—压入关系：临床力下的压入深度和切线刚度 | 接触几何、放松组织标定 |
| A3 | 临床接触力的分布，按部位和体型 | 力设定值（现固定 4 N） |
| A4 | 常用凸阵、线阵探头接触面的长度、宽度、曲率半径 | 接触几何 |
| B1 | 肋骨和浅层骨上的局部接触：局部刚度、骨上软组织厚度、肋间距与探头尺寸的关系 | 硬组织和跨肋工况 |
| B2 | 扫查运动：滑动速度、加速度、启停、换向、法向位移速度、探头倾角变化 | 速度、加速度、曲面工况 |
| B3 | 患者运动：呼吸体表幅值和速度，惊跳、咳嗽等突发运动的幅值和速度 | 干扰工况 |
| B4 | 探头—耦合剂—皮肤的摩擦系数 | 摩擦工况 |
| C1 | 协作臂末端法向和切向刚度；力传感器噪声和带宽 | 对象柔顺、测量噪声 |

注意：HC 的 λ 描述法向压入速度的效应，不能由滑动速度确定。

## 已有线索，只作核对起点，不要当结论

- Remus 2024（10.3389/fbioe.2024.1384062）：r = 10 mm 半球压头，腹部放松 .24–.72 N/mm，主动 1.08–5.22 N/mm，进给 5 mm/s，没有粘弹数据。
- Moreira 2014（10.1016/j.cmpb.2013.11.005）：离体松弛试验；n = 1.26；KB 参数 α = 34.3、β = 200、γ = .024。
- Courrèges 2015（10.1007/978-3-319-22368-1_21）：人体腹部在体 HC，数值未读到。
- Boyer 2007：在体皮肤动态压痕 10–60 Hz，k 47.3–128.3 N/m，c .08–.121 N·s/m。
- von Gierke 等 1952（10.1152/jappl.1952.4.12.886）：活体软组织，数值未核实。
- Ottensmeyer：TeMPeST 1-D 活体猪肝频率响应。
- AuSoScan（10.1109/TMECH.2025.3583041）：探头 80 × 15 mm，R = 30 mm，E\* = 6.3 kPa。
- 腹部接触力：Work 2017 均值 8.2 N（SD 4.3，范围 1.2–36.5 N）；Gilbertson 2013 轴向约 7.0 N。
- 胸廓整体压缩约 9.4 N/mm；羊肋三点弯约 44.7 N/mm（均只见检索摘要，链接未逐一核对）。

## 纪律

- 不钻牛角尖：同一问题两轮检索没有直接数据就写“未查到”，转下一个。
- 每个数字要有可打开的 URL 或 DOI 和原文位置。只看到摘要或搜索片段的要写明。不凭记忆写数字，不编造。付费或打不开的写明，不绕过。
- 每条证据标来源等级：人体在体实测 / 离体或动物实测 / 仿体实测 / 规范指南 / 厂商规格 / 行业经验 / 开源设定 / 模型推算。不同测量方法的差异要指出，不取平均。
- 原始数字和推断分开写。
- 不改仿真代码，不提交，不推送；只写本任务指定的输出文件。
- 输出中文，简洁。
