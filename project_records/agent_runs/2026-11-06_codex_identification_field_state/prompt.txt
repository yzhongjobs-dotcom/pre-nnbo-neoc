## 研究背景（以此为锚划定范围）
- 任务：位置接口协作臂（只能下发位置，伺服有延迟）做恒力超声扫描。观测只有轴向接触力和编码器（探头位置）。组织在动（呼吸、推拉、惊跳、咳嗽），局部刚度在变（跨肋骨软硬相差数倍，肌肉活化）。
- 辨识问题：窗口内 z = k·Y + d + ε。z 是力滤波的一步逆，Y 是同样滤波后的探头位移，k 是探测频率的局部接触增益（刚度），d 是等效接触扰动（组织运动、黏弹记忆、肌肉活化、摩擦等全部未被 kY 解释的力，不等于真实组织运动）。Method 在机器人运动上叠加 20.8 Hz 小幅探测，每窗口输出 k、不确定度 σ 和模型检验 χ，σ 与 χ 用于门控（只把可信窗口交给控制）。
- 本项目的估计器演进：Rossi 式带通+EWRLS → 同窗多项式投影（d 为低阶多项式） → D⁴ 二次先验（d 的四阶差分为白噪声，k = Y'Mz/Y'MY，M = I − (I+ρD'D)⁻¹） → 当前默认 Huber-D⁴（min ‖z−kY−d‖² + 2ρs²Σh_c((D⁴d)_i/s)，IRLS 求解）。理由与证据见 research/disturbance_model.md 第一节（只读该节，约前 110 行）。
- 不预设 Huber-D⁴ 优于已有方法。
