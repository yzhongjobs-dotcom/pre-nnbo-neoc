## 严重问题

### 1. reversal 速度规划同时违反加速度约束并越出模量场

`experiments/rossi_failure_study/scenes2.py:38-45, 89`

问题：

- `span = vmax / accel`，但速度从 `+vmax` 变到 `-vmax`，实际加速度为 `2*accel`。
- 第二次换向时，代码可能从 `-vmax` 在一个采样点直接跳到 `+vmax`。
- 速度轨迹从 `X0 + .02` 开始，但模量场由 `scenes.py:55-58` 从 `X0` 向正方向分配。

实算样例 `reversal, rest/soft, i=0`：

- 模量场范围：`[0.42000, 0.74000] m`
- 轨迹范围：`[0.35478, 0.48451] m`
- 左侧越界：约 `65.22 mm`
- 最大离散加速度：`43.87 m/s²`
- 该工况规定上限为 `1 m/s²`

后果：越界部分被 `_lookup()` 静默夹到场边界，reversal 工况实际反复读取同一边界模量；同时换向尖跳制造了规格外的高频激励，矩阵结果不能代表声明的 reversal 工况。

修改：按实际速度方向连续规划换向，使速度变化量为 `2vmax` 时使用 `2vmax/accel` 的过渡时间；第二次换向也必须从当前速度连续过渡；模量场范围应覆盖轨迹的最小、最大坐标。

### 2. LF 的切向力扣除公式与规格不一致

`experiments/rossi_failure_study/contact_candidates.py:190-191`

规格要求：

```text
f = F_x - mu_hat * F_slow * s(v_hat)
```

代码实际为：

```python
fv = fx - self.mu_hat * s * (F - self.fslow)
```

在稳定力 `F == F_slow` 时，代码完全不扣除模型摩擦；而规格应扣除 `mu_hat * F_slow * s`。

后果：LF 的“实测切向力”被错误地当成耦合变化；WF 通过同一分支继承该错误。LF/WF 的 `c_hat`、修正力和闭环表现都会偏离声明模型。

修改：按规格使用 `self.fslow`，保持当前符号和 `s(v)` 定义不变。

### 3. 耦合辨识的遗忘时间和门限不符合规格，且对候选不公平

`experiments/rossi_failure_study/contact_candidates.py:197-201`

问题：

- `0.95` 是每 8 ms 的遗忘因子，对应时间常数：

\[
-\frac{0.008}{\ln(0.95)}=0.15597\text{ s}
\]

规格要求 3 s，对应遗忘因子应约为：

\[
e^{-0.008/3}=0.99734
\]

- LF/WF 使用 `0.05` 门限，AS/TR/WA/WT 使用 `0.02`。
- 规格要求按噪声三倍门限，代码使用固定数值，并额外要求速度变化超过 `0.5 mm/s`。

后果：`c_hat` 主要追踪短时变化和噪声，不是 3 s 记忆；不同候选的更新敏感度不同，比较不再一视同仁。

修改：按规格使用 3 s 遗忘因子和统一的噪声三倍门限；保留当前候选物理量定义。

### 4. S 候选的时间常数错误，且改变了可辨识相位范围

`experiments/rossi_failure_study/contact_candidates.py:36, 64-70`

规格要求：

```text
SLS tau = .05 s
```

代码为：

```python
SLS_TAU = .024
```

实算：

- 代码使用 `.024 s` 时，目标相位 `phi=.2 rad` 可得到 `alpha≈2.639`。
- 若按规格使用 `.05 s`，同一离散响应下 `alpha` 反解为负值，代码因 `den <= 0` 直接返回零权重。
- `.05 s` 且 `alpha<=3` 时最大可达相位仅约 `5.90°`，而 `.2 rad` 为 `11.46°`。

后果：S 不是规格中的 SLS 候选；其相位到记忆权重的映射、与 W 的比较以及 rate/memory 结果都会改变。

修改：恢复规格中的 `.05 s`，并按规格重新核对该反解的边界行为。

### 5. 相位辨识没有实现规格指定的 \(Y/Y_q\) 二元最小二乘，也没有按完整窗口接受条件更新

`experiments/rossi_failure_study/contact_candidates.py:140-157, 213-215`

问题：

- 规格要求用 \(Y\) 和其正交量 \(Y_q\) 解 2×2 最小二乘。
- 代码使用 `common._build()` 得到 `Y,z`，再用复载波计算 `angle(zc/yc)`；没有构造 \(Y_q\)，也没有显式求解 \(k_c,q\)。
- 更新条件只检查 `self.rel <= rel_max`，没有检查窗口的 `chi2` 一致性。

后果：含漂移、非正弦扰动或未建模接触变化时，`phi` 可能被错误更新；而且各记忆候选的 `rel` 会因各自预处理不同而不同，精度门控会偏向某些候选。

修改：按原规格使用同一窗口的 \(Y,Y_q\) 二元拟合，并只在完整窗口通过精度和一致性条件时更新。

## 中等问题

### 6. physics_plant2 的初始压入量总在 `X0` 求解，未使用实际初始扫描位置

`experiments/rossi_failure_study/physics_plant2.py:282-297`

代码在 `OLD.X0` 处求 `d0`：

```python
_fe(OLD.X0, mid, ...)
```

但实际初始接触点使用：

```python
x0 = sc['xcmd'][0]
```

`scenes2.py:44` 的 stop_go/reversal 初始位置是 `X0 + .02`。

后果：初始压入量使用错误位置的模量，导致初始 `F_n`、记忆状态和前若干辨识窗口产生非物理瞬态，尤其影响组织空间变化场景。

修改：初始法向平衡应在实际 `x0` 处求解，并使用同一接触位置的模量。

### 7. `ideal_tangent` 快路径漏掉了 \(k_d\)

`experiments/rossi_failure_study/physics_plant2.py:154-169`

`ideal_tangent` 条件没有检查 `c[17]`（`k_d`）。因此当摩擦、压力不对称、倾角和交叉柔顺均为零，但 `k_d>0`、`K_t` 很大时，代码直接令：

```python
vc_new = vs
xc_new = s[1]
```

跳过了速度阻尼项。

后果：某些合法的纯速度阻尼场景不遵循规格的切向动力学。当前零物理回归因同时将 `k_d=0`，不能发现该问题。

修改：只有 `k_d==0` 时才允许进入该快路径；否则走半隐式动力学。

## 这个矩阵能与不能证明什么

能证明：

- 在固定控制器、固定场景、配对随机种子和当前人工参数下，各实现版本的相对闭环表现。
- 当前候选在这些合成工况中的失控、长失联、法向力误差和轴向力误差差异。

不能证明：

- 原文模型在真实人体/真实探头上的优劣。
- 候选物理公式本身的纯粹优劣，因为部分候选额外使用了 `F_x`。
- 当前 reversal 结果的物理意义，因为轨迹越出模量场且含规格外速度跳变。
- 当前 `c_hat`、`phi` 机制辨识已正确，因为时间常数、相位算法和门控存在上述偏差。
- “实时认证”：单次 Python 调用时间只能说明当前实现的短算例耗时，不能证明部署级实时性。
