**第三部分：错误、矛盾与复核缺口，按严重程度排序**

1. **指标错标，容易直接读错研究结果。**  
   《审计》行7统称数字为“中位/均值 RMSE（N）”，但 E1–E3、E4开环及模量图数字是无量纲绝对对数误差，有些斜杠表示中位/P90或P95。原始定义见 `step2_estimators.py` 行397–410、`row3_gls.md` 行53。

2. **A1 抽样被扩大为整个集合结论。**  
   《审计》行50、《状态》行51及 methods §20.8、§21.3存在此问题。代码只抽六个带宽分位点加最终设计，不能证明535个设计全部无更优，更不能据此排除在线选择。

3. **硬推拉失控减少被过度归因于融合。**  
   《审计》行80用幅值0.17的r2与融合幅值0.10的r0比较。但同幅值0.10的原方法已经r0，无法把这项变化单独归于融合。原始消融行16–20。

4. **“偏置超过阈值＝无门控”缺少条件，也不是直接偏置实验。**  
   《审计》行76、83、91如此表述。代码实际检验 `abs(mean(My)+偏置)>阈值`；偏置仅超过阈值，并不保证所有时刻通过。`+raise` 是取消门控的消融，支持偏置风险判断，但不能冒充实际偏置扫描。

5. **当前状态对 V1 是否已采纳存在字面矛盾。**  
   《状态》行7一面称可靠主体含 V1，一面说“11-01之后没有候选被采纳”；《审计》行45又明确 V1 在11-01采纳。应将 V1 与其他未采纳候选明确区分。
