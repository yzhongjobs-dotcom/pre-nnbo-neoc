对，研究顺序应当是：**共有的真实痛点 → 所需能力 → 模型与方法设计 → 必要的仿真调整 → 公平验证。** 最终判断落在 Proposed Method 的实际能力、物理合理性和专业完整度上。

我已将这点写入长期要求，并补做了此前不足的“论文痛点—本项目—仿真机制”对应检查，得到两个具体结论：

- **当前仿真不能检验滑动摩擦负载补偿的那部分收益。** 五族各一个诊断场景中，将摩擦系数改为 0.5/1.5 倍，切向力明显改变，但法向力、位置和指令逐位相同。这说明当前仿真的作用通道有限，不能据此判断真实任务中该机制是否重要。
- **上一轮逆压入原型仍有接触量混用问题。** 准静态弹性关系与快速激励所见的动态增益需要区分；直接用总力和动态增益反推弹性压入，可能把接触状态误差吸收到材料和边界参数里。应先修正这一点，再判断压力分布模型的价值。

因此，**现阶段保留原仿真，继续修正接触模型的物理关系与观测接口**。若后续物理证据表明仿真漏掉了影响本任务的重要机制，再对各方法统一调整并保留原环境结果。

新模型仍是候选。初步结果用于定位和修正问题，不作为采纳或否定整条路线的依据。分析与验证已记入[研究记录 §6](E:/github_project/scan-impedance-update/research/contact_model_study.md)，并同步 GitHub。
