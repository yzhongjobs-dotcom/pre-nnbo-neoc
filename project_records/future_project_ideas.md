# 后续新项目的点子

用户 2026-11-03 确定：优化主动激励不是当前项目的必须项。这里记录相关点子，留到本项目完成后，作为新项目的启发。它们都未经验证，也不是本项目的待办事项。

## 主动激励与信息获取

以下点子都面向当前假设之外的未知变化，比如突发运动和窗口内的快速刚度变化。

| 点子 | 核心想法 | 需要先回答的问题 |
|---|---|---|
| 信息最优激励 | 建立激励、接触响应、运动干扰的联合模型，在带宽和力预算下优化激励的有效刚度信息，再配匹配的估计器 | 优化目标能否反映模型外干扰造成的偏差，而不只是方差 |
| 通信导频与时变信道估计 | 把激励视为导频，接触视为时变信道，借鉴编码、相关检测和信道跟踪 | 编码在白噪声下没有天然增益，它在本任务中究竟解决什么 |
| 空载波干扰感知 | 激励频率旁留空频点，或利用正交分量，直接估计当前干扰强度和估计可信度 | 空频点能否预测真实偏差，刚度变化是否也会污染它 |
| 按需探测 | 平静时降低幅值并靠历史积累，事件时集中探测 | 能否及时发现事件，幅值切换是否带来新的瞬态 |
| 编码式微压入 | 用微小压入—保持—释放获取瞬态和松弛响应，并与相关估计联合设计 | 低频能量易与运动混淆，单频信息不足是否真的影响闭环 |
| 法向—切向正交导频 | 同时沿法向和扫描方向施加正交微振动，测 \(\partial F/\partial y\) 和 \(\partial F/\partial x\)，用激励方向而非频率区分运动和空间变化 | 切向粘滞、表面坡度、机器人微小运动精度；需核查滚动压入、滑动触诊、AFM 调制等已有工作 |
